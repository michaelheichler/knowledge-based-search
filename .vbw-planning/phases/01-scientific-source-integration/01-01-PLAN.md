## Objective

Add arXiv, PubMed, Semantic Scholar, and CrossRef as keyless adapters in `server/engines.py` (REQ-12), reachable only through a new `providers` filter on `search()` (groundwork for REQ-14, wired to the CLI in plan 04), with pacing and 429 cooldown handling per REQ-17 and REQ-09-by-construction.

## Context

- Adapter pattern, wiring points, and shape constraint: `01-RESEARCH-providers.md`. Every hit goes through `engines.result(title, url, snippet, engine, rank)` (engines.py:132). Extra keys added after `result()` (like `citation_count`) survive `merge()` because `_merge_hit` copies the dict.
- Decision (supersedes the facet's `_DIRECT_DEFAULTS=True` wiring note): the four adapters register in a new `_scientific_callables(query, config, k)` dict, NOT in `_direct_callables`/`_DIRECT_DEFAULTS`. REQ-14 makes `--scientific` an explicit trigger, so default-on registration would hit arXiv on every plain web query. REQ-12's "default" means ungated within the scientific group (no key, no config gate), unlike OpenAlex which stays out entirely (REQ-13).
- Repo conventions (conventions.json): return-type annotations on every function (CONV-003), why-docstrings (CONV-004), no per-adapter try/except for malformed payloads (CONV-006 is handled by `_task_outcome`), `# ponytail:` markers for deliberate corner cuts (CONV-009).
- Live-verified endpoints and payload shapes: evidence table in `01-RESEARCH-providers.md`. Semantic Scholar returned reproducible 429s on all four attempts. Treat it as the fragile one.

### Task 1: Four scientific adapter functions

**Files:** `server/engines.py`

**Action:**

Add a module constant for an identifying User-Agent (NCBI and Semantic Scholar ask for identification, not a browser spoof):

```python
_SCIENCE_UA = "kbs/0.2 (keyless research CLI)"
```

Add a rate-limit guard used by all four adapters. `_get()` raises `urllib.error.HTTPError` on non-2xx, so intercept 429 only:

```python
_RATE_LIMIT_COOLDOWN = 120.0

def _api_get(url, provider, timeout, headers=None) -> str:
    """429 maps to a short cooldown because API throttles clear in minutes, not the scraper-block half hour."""
    try:
        return _get(url, timeout, headers=headers)
    except urllib.error.HTTPError as exc:
        if exc.code == 429:
            raise ProviderBlocked(provider, cooldown=_RATE_LIMIT_COOLDOWN) from exc
        raise
```

Extend `ProviderBlocked.__init__(self, provider, cooldown=None)` storing `self.cooldown`. `_task_outcome` uses `getattr(exc, "cooldown", None) or _COOLDOWN_SECONDS` when calling `engine_state.block_provider`. Existing `ProviderBlocked("name")` call sites keep working.

Write four adapters, all shaped `name(query, k=10, timeout=_TIMEOUT) -> list` (crossref additionally takes `config=None`), all parsing naively per repo convention:

1. `arxiv`: GET `https://export.arxiv.org/api/query?search_query=all:<quoted>&start=0&max_results=<k>`. Parse Atom XML with `xml.etree.ElementTree` (stdlib, do not regex-parse XML). Per `<entry>`: `id` text is the abs URL (becomes `url`), `title` and `summary` need whitespace collapsing (`" ".join(text.split())`), then `hit = result(...)` and override `hit["date"] = published[:10]` since arXiv's ISO timestamp is already structured. Namespace prefix: `{http://www.w3.org/2005/Atom}`.
2. `pubmed`: two calls via `_api_get` with `headers={"User-Agent": _SCIENCE_UA}`. First `esearch.fcgi?db=pubmed&term=<q>&retmode=json&retmax=<k>`, collect `esearchresult.idlist`. If empty, return `[]` without a second call. Then `esummary.fcgi?db=pubmed&id=<comma-joined>&retmode=json`. For each PMID in idlist order: `title`, url `https://pubmed.ncbi.nlm.nih.gov/{pmid}/`, snippet built from `source` (journal) plus `pubdate`. Parse `pubdate` (free text like "2024 Jan 15" or "2024 Jan") with a small year-month-day split using `_MONTHS` and `_safe_iso_date`, assign to `hit["date"]` (empty string when unparseable).
3. `semanticscholar`: GET `https://api.semanticscholar.org/graph/v1/paper/search?query=<q>&limit=<k>&fields=title,abstract,year,citationCount,url` via `_api_get` with `_SCIENCE_UA`. Per item: `title`, `url` direct, snippet from `abstract` falling back to author/year text. Set `hit["date"] = _safe_iso_date(year, 1, 1)` when `year` is present, and `hit["citation_count"] = row.get("citationCount")`.
4. `crossref`: GET `https://api.crossref.org/works?query=<q>&rows=<k>`, appending `&mailto=<value>` only when `config` has `crossref_mailto` (polite pool is a courtesy signal, never hardcode a personal email). Per item in `message.items`: `title[0]` guarded for an empty list (skip titleless records), `URL` as url, snippet from `container-title` plus author family names. Date comes from the first available of `published-print`/`published-online`/`issued`/`created` `date-parts` via `_safe_iso_date` (tolerates `[[2019]]`). Set `hit["citation_count"] = row.get("is-referenced-by-count")`.

**Done when:** all four functions exist, return the six `result()` keys (plus `citation_count` on semanticscholar/crossref), and no adapter contains defensive try/except beyond the shared `_api_get` 429 guard.

### Task 2: providers filter and pacing floor

**Files:** `server/engines.py`

**Action:**

1. Add:

```python
SCIENTIFIC_PLATFORMS = frozenset({"arxiv", "pubmed", "semanticscholar", "crossref"})

def _scientific_callables(query, config, k) -> dict:
    return {
        "arxiv": lambda: arxiv(query, k),
        "pubmed": lambda: pubmed(query, k),
        "semanticscholar": lambda: semanticscholar(query, k),
        "crossref": lambda: crossref(query, k, config=config),
```

`SCIENTIFIC_PLATFORMS` is public (CONV-002) because plan 04's CLI validation reads it.

2. Change signatures to `search(query, config, k=10, cap=20, providers=None)` and `_build_tasks(query, config, k, outcomes=None, providers=None)`. When `providers is not None`, extend it with `_scientific_callables(...)` and filter: `enabled = {name: thunk for name, thunk in available.items() if name in providers}`. The filter runs over the config-gated union, so a config-disabled web provider (bing, google) can never be resurrected by naming it, and nothing outside the union is callable. That is REQ-09 by construction. `providers=None` must leave every existing call path unchanged.

## Remediation amendment, DEV-01

The scientific adapters are implemented in `server/science_engines.py`, a cohesive module that owns only the four scientific HTTP adapters and their payload mapping. `server/engines.py` imports and re-exports those adapters, the shared rate-limit helper, and the public platform set so existing `import engines` callers and tests retain their original paths. This extraction keeps provider-specific parsing separate from web scraper wiring without changing result shapes, error handling, or provider filtering. DEV-01 is resolved by this source-plan amendment, not by frontmatter classification alone.
