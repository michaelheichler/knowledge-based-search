This unit covers advanced use of search engines including Google, Bing, Yandex, and international alternatives, historical recovery of web content through caches and archives, and translation tools for non-English sources. The material runs from page 149 through page 156 of the book.

## Google Custom Search Engines and File Type Refinements

A Google Custom Search Engine (CSE) can be configured with refinements that filter results by document type. Each refinement is given a label and an "Optional word(s)" field containing one or more `ext:` operators joined by OR. The operator strings for common types are:

- PDF: `ext:pdf`
- DOC: `ext:doc OR ext:docx`
- XLS: `ext:xls OR ext:xlsx OR ext:csv`
- PPT: `ext:ppt OR ext:pptx`
- TXT: `ext:txt OR ext:rtf`
- WPD: `ext:wpd`
- ODT: `ext:odt OR ext:ods OR ext:odp`
- ZIP: `ext:zip OR ext:rar OR ext:7z`

Once saved, each refinement appears as a clickable tab on the results page. A search for "osint" across all types returned 717,000 results. Narrowing to the PPT tab alone returned 45 files. The same CSE structure can be scoped to a single domain, for example to monitor for sensitive file types appearing on a company's domains. One limitation: custom Google search engines return at most 100 results, presented as ten pages of ten results each. For specific search terms this is rarely a problem, but it can be constraining for general searches.

## Google Alerts

Google Alerts (google.com/alerts) monitors the web for new content matching a saved search term and sends email notifications on a schedule the user selects (such as daily). A logged-in Google account is required. The tool is useful when a target search has been exhausted and an investigator needs to detect new postings without repeating manual searches. A real-world example from the text: a detective set a Google Alert for a 15-year-old runaway's name and city of residence, and within three days received an alert for a blog that identified the runaway's current location. She was located within 30 minutes.

## Bing

Bing (bing.com) is Microsoft's search engine. Since 2009 Yahoo has used the Bing engine, making a separate Yahoo search redundant after a Bing search. Standard operators including `site:` and quoted phrases work the same on Bing as on Google. Bing also supports time-filtered searching (last 24 hours, week, or month).

**LinkFromDomain.** Searching `LinkFromDomain:inteltechniques.com` on Bing (with no spaces in the entire string) returns every external website that the target domain links to, pulled from the site's underlying code rather than from visible page text. This exposes links that would not be apparent by browsing pages manually.

**Contains.** The `filetype:` operator returns files stored on a given domain. The `contains:` operator is broader: `contains:ppt site:cisco.com` returned 36,200 results versus 13,200 for `filetype:ppt site:cisco.com`, because `contains:` also captures links on cisco.com pages pointing to PowerPoint files hosted on other domains. Both operators should be attempted.

## Google Images and Bing Images

Google Images (images.google.com) indexes images based on filename, surrounding link text, and text adjacent to the image. For common names, enclosing the name in quotes and appending a city, employer, or personal interest filters results toward the correct subject. The "Tools" button offers filters for size, color, time range, image type, and license. The reverse image search feature is explained elsewhere in the book.

Bing Images (bing.com/images) autoloads additional images as the user scrolls, avoiding page reloads. It adds layout filters (square or wide) and a People tab with options for "Just faces" and "Head and shoulders." Suggested filter links that appear alongside any image search may lead to additional photographs and reveal previously unknown affiliations of the target.

## International Search Engines

U.S.-based search engines do not index the full web equally across all countries. Yandex (yandex.com) is the dominant engine in Russia and offers an English-language version. Its results are often prioritized differently from Google's and have surfaced unique intelligence when Google returned nothing. Baidu (baidu.com) is China's dominant engine and has no English version, but a search can still be executed by typing a query and pressing Enter. New results not found on Google or Bing are rare but occasionally appear.

Additional international engines, listed in order of usefulness for international investigations, with direct search URL patterns:

**I Search From (isearchfrom.com)** allows the user to run a search on a country-specific version of Google (for example google.co.jp) while specifying a language and device type, without results being biased toward a U.S. user. The News tab on foreign Google versions is calibrated to the target geographic audience and can surface articles that are buried in a U.S. results page.

## Yandex Advanced Operators

Yandex's advanced search operators are not accessible through a menu. They must be typed directly into the search box. The key operators are:

- **Exact phrase:** quotation marks, same as Google.
- **Wildcard within a phrase:** an asterisk inside quotes, for example `"Open Source * Techniques"`, matches any word in the asterisk position. This produced results for "Open Source Development Techniques" and "Open Source Responsive Techniques" alongside the target title. It is also useful for finding a person's middle name, for example `"Michael * Bazzell"`.
- **Words in the same sentence:** the ampersand (`&`) without quotation marks requires both words in one sentence. `Hedgehog & Flamingo` is an example. Adding `/N` restricts to within N words of each other: `Hedgehog /2 Flamingo`.
- **Words on the same page:** double ampersand (`&&`) requires both words anywhere on the page. Adding `&& /N` restricts to within N sentences: `Hedgehog && /3 Flamingo`.
- **Require a word:** a plus sign before a word (`+Bazzell`) mandates that word appears on the page. Other terms in the query are optional.
- **Any of several words (OR):** the pipe symbol (`|`, found above the backslash on a keyboard). For example, `+Bazzell Michael | Mike | M` returns results for Michael, Mike, or M Bazzell.
- **Exclude a word:** the official operator is the tilde (`~`), but the hyphen (`-`) also works and is preferred until it stops functioning. Example: `Michael Bazzell ~Mike`.
- **Repeated identical words:** the exclamation point (`!`) before each word, for example `!Carina !Abad !Abad`, matches those words regardless of spacing, punctuation, or hyphenation between them. This captures variants that an exact-phrase search in quotation marks would miss.
- **Date range:** specified inline with the `date:` prefix:
  - `date:20111201..20111231 OSINT` finds pages mentioning OSINT between December 1 and 31, 2011.
  - `date:2011* OSINT` covers the full year 2011.
  - `date:201112* OSINT` covers December 2011.
  - `date:>20111201 OSINT` covers anything after December 1, 2011.

Standard operators including `site:`, `domain:`, `inurl:`, and `intitle:` work the same as in Google. Multiple Yandex operators can be combined in one query. The full operator reference is at `https://yandex.com/support/search/how-to-search/search-operators.html`.

## Web Archives and Caches

Web archives are historical copies of web pages. They are described as one of the most vital resources in any type of online research. Their value extends beyond pages that have been taken down entirely. Even a site that appears normal and unaltered should be checked in caches, because minor content changes can reveal information the subject intended to permanently delete.

**Google Cache.** In search results, a small green down arrow next to the result URL opens a menu containing a "Cached" link. The cached page displays its capture date. Clicking "Similar" in the same menu surfaces pages with similar content. To navigate directly to a cached version of a specific URL, type `cache:www.example.com/page` into Google.

**Bing Cache.** A small green down arrow next to the domain name in results opens a menu with a "Cached page" option.

**Yandex Cache.** A green drop-down under each result title offers a "Cached page" option. The banner on the cached page shows the capture date, original URL, and a keyword highlighter. Yandex updates its cache less frequently than Google or Bing, making its cached version more likely to contain content that has since been modified. In a demonstration using phonelosers.org on September 7, 2019: Google's cache was from September 6, Bing's was from September 7, and Yandex's was from September 1. The older Yandex snapshot is an advantage for detecting changes. Baidu's cache is often older still.

**Baidu Cache.** Search results are mostly in Chinese. Each result has a green link near the bottom. The cache link is a Chinese character directly to the right of that link, which Baidu calls a "snapshot." Not every result with this link has a cached version available.

**The Wayback Machine (archive.org/web/web.php).** The most extensive historical archive. A search for phonelosers.org returned 1,280 captures dating from December 21, 1997 through June 10, 2019. Archived pages are interactive: links can be clicked as on a live server, and graphics are included. Since 2016, the Wayback Machine supports keyword search across its entire collection. The URL pattern for a keyword search is:

```
https://web.archive.org/web/*/Michael Bazzell
```

This returns every archived page containing those terms across all domains, including sites that have since shut down and including domains whose owners explicitly blocked archiving via server configuration files. Those blocked domains do not appear in a direct Wayback Machine domain search but they do appear in keyword search results.

Automated tools that claim to extract full site histories from caches are unreliable. Bing and Yandex generate unique session codes when serving cached pages, which blocks automated scraping. Manual navigation to each resource is the only dependable approach. A recommended workflow is to bookmark Google Cache, Bing Cache, Yandex Cache, Baidu Cache, and the Wayback Machine in a single folder and open all tabs whenever a domain is the target.

## Non-English Search and Translation

**2Lingual (2lingual.com)** runs a single query on two country-specific Google versions simultaneously and displays results in side-by-side columns. Foreign results are automatically translated to English. The first sponsored results are similar across countries, but organic results differ. The tool is also useful for demonstrating to others why searching across multiple countries matters.

**Google Translator (translate.google.com)** translates pasted text or entire websites. Pasting a URL and clicking "Translate" renders the foreign site in English in a native layout view. The translation is not perfect but indicates the content. It works on social network pages including Twitter and Instagram.

**Bing Translator (bing.com/translator)** functions identically to Google Translate for both text and full URL translation. Its results are usually slightly different from Google's.

**DeepL (deepl.com/translator)** is described as the most accurate translation service the author has found, despite being smaller than Google or Bing. Its interface and function are identical to the others but the results may differ substantially.

**PROMT Online Translator (online-translator.com)** supports full website URL translation like Google and Bing, providing a third independent translation source among the many online options.

The recommended practice is to use all four services (Google Translate, Bing Translator, DeepL, and PROMT) on any critical foreign content. Minor variations between translations can matter, especially for grammatically irregular short text such as tweets. Using multiple services also documents investigative due diligence.
