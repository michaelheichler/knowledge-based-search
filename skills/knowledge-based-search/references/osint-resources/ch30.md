This material spans two related topics: locating accounts and data by username, and searching for individuals by real name through aggregator services.

## Username Investigation

### Services That Accept a Direct Username Query

**Gravatar** (gravatar.com) stores profile images tied to email accounts and allows lookup by username. The pattern is `https://en.gravatar.com/<username>`.

**LinkTree** (linktr.ee) lets members list all their social networks in one place. A direct URL such as `https://linktr.ee/<username>` will reveal every platform the person has linked.

**Search My Bio** (searchmy.bio) is an Instagram biography search tool covering current and historic profile text. It is worth querying even if you have never seen an Instagram account for the target, because the username may appear on someone else's account (common in romantic relationships). Query format: `https://www.searchmy.bio/search?q=<username>`.

**People Data Labs** (peopledatalabs.com) requires a free API key. Using the person-enrich endpoint with a social profile URL as the `profile` parameter, you can retrieve aggregated identity data. The endpoint is:

```
https://api.peopledatalabs.com/v5/person/enrich?pretty=true&api_key=<KEY>&profile=www.twitter.com/<username>
https://api.peopledatalabs.com/v5/person/enrich?pretty=true&api_key=<KEY>&profile=www.facebook.com/<username>
https://api.peopledatalabs.com/v5/person/enrich?pretty=true&api_key=<KEY>&profile=www.linkedin.com/<username>
```

A Twitter query can return location history going back to 2009. A Facebook query for a well-known account returned full name, birth year, LinkedIn URL, mobile phone, email, and university. The IntelTechniques Username Tool includes all three options and requires the API key to be substituted in the source code where "XXXX" appears.

### Skype Username Recovery

Skype usernames are not visible during a name or email search, but can be extracted indirectly. While logged in to Skype (web or app), search by the target's real name or email address. Click the result to open the profile. Right-click the profile photo (or the silhouette that appears when no photo is set) and choose "Open image in new tab" (Chrome) or "View image" (Firefox). The URL of the image contains the target's Skype username.

### Email Assumption Technique

When only a username is known, construct assumed email addresses by appending the most common domains and then check those addresses against breach databases such as HaveIBeenPwned (HIBP) and Dehashed. A positive result confirms the address existed in at least one breach. The standard domain list to try is: gmail.com, yahoo.com, hotmail.com, protonmail.com, live.com, icloud.com, yandex.com, gmx.com, mail.com, mac.com, me.com. For investigations outside the US, substitute regional providers such as qq.com.

The IntelTechniques Username Tool automates this by opening a new browser tab for each assumed address. The code uses a `setTimeout` function with 3000 milliseconds between each tab to avoid rate-limiting the servers. An example of how to add qq.com as an additional option looks like this in the source:

```
setTimeout(function(){window.open('https://dehashed.com/search?query=%22' + all3 + '@qq.com%22', 'leak3window');},35000);
```

The same set of assumed addresses can be pasted into a Google search using quotation marks and the OR operator. Bing and Yandex can also receive the query but tend to return less reliable results. The "Email Search" option at the bottom of the Username Tool performs this Google search automatically.

Additional breach and leak sites worth querying directly include leakpeek.com, leakedsource.ru, breachdirectory.org, and weleakinfo.to.

### University Personal Pages

Universities issue students email addresses that follow a predictable naming convention, such as `lastname.firstname@university.edu`. The first part of the address is usually the username assigned for a personal homepage on the university domain.

Procedure:

1. Identify the university the target attended using prior searches.
2. Find the university's domain (for example, siue.edu for Southern Illinois University at Edwardsville).
3. Run a Google site search to discover personal pages: `site:siue.edu <firstname>`.
4. Examine a result to determine the naming convention. For SIUE, a result at `www.siue.edu/~lswanso/` reveals the pattern: tilde, first initial, first six letters of surname.
5. Construct the target's probable URL from the pattern. For a target named Scott Golike: `www.siue.edu/~sgolike/`.
6. Construct the probable university email: `sgolike@siue.edu`.
7. Search that email in breach databases and use the email-to-Facebook-profile technique.
8. If the page is currently empty (universities typically remove content after graduation), check archived versions at wayback.archive.org as well as Google Cache, Bing Cache, and Yandex Cache.

A real-world example: a deleted student page located through this method contained a list of friends, roommates, family members, and interests that were not known from any other source. That information led to locating the individual within hours.

When two students share a similar name, universities often handle the collision by appending a number (for example, "2") after the username.

### ISP Personal Pages

Internet service providers also host personal pages under a subscriber's username. Comcast, for example, provides 25 MB of storage at `home.comcast.net/<username>`. A sample list of personal-page patterns using "crazycheetah70" as the username:

```
360.yahoo.com/crazycheetah70
crazycheetah70.webs.com
crazycheetah70.weebly.com
webpages.charter.net/crazycheetah70
sites.google.com/crazycheetah70
about.me/crazycheetah70
angelfire.com/crazycheetah70
geocities.com/crazycheetah70
reocities.com/crazycheetah70
crazycheetah70.tripod.com
home.earthlink.net/~crazycheetah70
home.comcast.net/~crazycheetah70
```

For deleted pages at any of these addresses, check the Wayback Machine and cache services described in Chapter Nine.

## People Search Engines

People search engines aggregate publicly available data and present it in a summary interface. Most are free for basic queries. The author orders them from most to least useful in his investigations and recommends exhausting all free options before considering any paid report. Many services now block IP addresses associated with VPNs because competing sites use VPNs to scrape data. An "access denied" error often means the VPN is blocked.

**True People Search** (truepeoplesearch.com) is the author's first stop for US subjects. Free results typically include current and previous addresses, telephone numbers (including cell), email addresses, relatives, and associates. Direct URL: `https://www.truepeoplesearch.com/results?name=michael%20bazzell`.

**Fast People Search** (fastpeoplesearch.com) appears to use the same underlying database as True People Search, but received far less media coverage as a "stalking" tool. As a result, far fewer people have used its opt-out process. If a target has removed their profile from True People Search, it is often still present here. Direct URL: `https://www.fastpeoplesearch.com/name/michael-bazzell`.

**Nuwber** (nuwber.com) presents results by location and often includes full name, age range, home address, telephone number, and neighbors. Direct URL: `https://nuwber.com/search?name=michael%20bazzell`.

**XLEK** (xlek.com) can surface email addresses not found on other sites. A typical entry includes full name, current and previous addresses, phone numbers, possible relatives, and age. Direct URL: `https://xlek.com/search_results.php?fname=michael&lname=bazzell&locations=all`.

**Family Tree Now** (familytreenow.com) specializes in connecting a person to relatives. It does not display home addresses, only age and a list of family members. The site sources data from public databases. Direct URL: `https://www.familytreenow.com/search/genealogy/results?first=Michael&last=Bazzell`.

**Cyber Background Check** (cyberbackgroundchecks.com) appears related to True People Search and Fast People Search but occasionally yields unique data. Direct URL: `https://www.cyberbackgroundchecks.com/people/michael-bazzell`.

**Intelius** (intelius.com) is a premium service, but its free preview page (before the payment prompt) displays exact age, aliases, cities lived in, previous employers, universities attended, relatives, and spouse (including maiden name for female subjects). The author does not recommend purchasing the full report. Direct URL: `https://www.intelius.com/people-search/Michael-Bazzell`.

**Radaris** (radaris.com) uses a similar business model to Intelius. Free preview content accessed by choosing "Full Profile" can include middle name, age, current and previous address, landline phone, and links to social networks. Background Check links on the site lead to paid services and should be avoided. Direct URL: `https://radaris.com/p/Michael/Bazzell/`.

**Spytox** (spytox.com) limits free results to city, state, and phone. Direct URL: `https://www.spytox.com/michael-bazzell`.

**Search People Free** (searchpeoplefree.com) uses a database similar to True People Search and Fast People Search. A notable feature is that email addresses in results are hyperlinks that can connect to additional associated names. Direct URL: `https://www.searchpeoplefree.com/find/michael-bazzell`.

**That's Them** (thatsthem.com) stands out for surfacing data not available elsewhere for free, including age range, cell phone, landline, full address, home IP address, associated email addresses, and the exact VIN number of previous vehicles. The religion and financial information fields are noted as unreliable. Purchase links on the site are third-party advertisements and should be avoided. Direct URL: `https://thatsthem.com/name/Michael-Bazzell`.

**Spokeo** (spokeo.com) is well-known but provides less detail in its free tier than the services above. Results include full name, gender, age, and previous cities and states. The site no longer shows the actual current address for free. The URL parameter `?loaded=1` bypasses the animated loading screen that simulates a real-time search. Direct URL: `https://www.spokeo.com/Michael-Bazzell?loaded=1`.

**Advanced Background Checks** (advancedbackgroundchecks.com) presents results that appear redacted, but clicking the masked fields opens a new page revealing the complete record for free rather than prompting for payment. Free data typically includes home address, landline phone, age, and relatives. The "See full info" button adds previous addresses, additional phone numbers, and aliases. Direct URL: `https://www.advancedbackgroundchecks.com/names/michael-bazzell`.

**Yasni** (yasni.com) is a German site and is strongest for non-US targets. It returns news articles, websites, and social networks. The results page includes a "lives/works in" filter to narrow results to the most plausible location for the target. The United States is not listed as a country filter. Direct URL: `http://www.yasni.com/michael+bazzell/check+people?sh`.

**Zaba Search** (zabasearch.com) offers one genuinely free option among its links: a real name combined with a state of residence returns full name, date of birth, address, and phone number, often including unlisted numbers. All other links on the results page forward to paid Intelius services. Direct URL: `https://www.zabasearch.com/people/michael+bazzell/`.

**People Search Now** (peoplesearchnow.com) appears to share a parent company and database with True People Search. It should be checked when a target has opted out of the related sites, due to the increased prevalence of opt-out behavior.
