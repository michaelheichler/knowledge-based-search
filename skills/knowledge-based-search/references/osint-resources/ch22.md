title: Twitter Third-Party Analytics Tools for OSINT Investigation
source: Open Source Intelligence Techniques, Resources (Bazzell, 9th ed.)

This section of Chapter 11 covers third-party web tools that extend Twitter investigation beyond what the native Twitter interface provides. The tools fall into several categories: bulk account analysis, follower and friend comparison, biography change history, posting pattern analytics, geolocation, fake follower detection, and miscellaneous analytics. Bazzell illustrates each tool with real investigative scenarios.

## TweetBeaver (tweetbeaver.com)

TweetBeaver is Bazzell's top-recommended third-party Twitter tool. Its core operations are:

- Lookup user account data for a single account or in bulk (up to 15,000 usernames at once).
- Download a target's friends list (accounts the target follows).
- Download a target's followers list (accounts that follow the target).
- Find common followers of two accounts (people who follow both targets simultaneously).
- Find common friends of two accounts (people whom both targets follow).
- Find conversations between two users, presented as a spreadsheet.

The bulk lookup feature is the most powerful. Pasting up to 15,000 usernames produces a CSV file with columns for screen name, Twitter ID, name, bio description, account creation date, location, URL, time zone, geo-enabled status, language, verified status, tweet count, follower count, and following count. The investigator can sort this CSV by location to cluster suspects geographically, by creation date to flag newly made accounts, or by geo-enabled status to identify accounts that may expose precise locations.

Bazzell provides a real-world example. While investigating a threat made against a celebrity, the suspect's account had been sanitized to remove location data. TweetBeaver extracted the suspect's friends and followers, which were fed into the bulk lookup. Sorting by location revealed a concentration in a specific Midwest city. Several of those accounts were geo-enabled and yielded home addresses. Person-search tools then produced full names and phone numbers. Cross-referencing group photos on Facebook tied an unaccounted individual in the photos to a named Facebook profile, ultimately identifying the suspect.

A limitation noted is that Twitter API changes can disable this service without warning.

## Followerwonk (followerwonk.com)

Followerwonk adds three distinct capabilities.

The Compare Users tab accepts up to three Twitter handles. It can compare either who each target follows ("Compare their friends") or who follows each target ("Compare their followers"). The "Compare followers" mode is more investigatively valuable because shared followers are more likely to represent real associates than shared followings, which often include celebrities and businesses. In Bazzell's example, two subjects shared zero followers with a third, while the first and third shared 200 followers, indicating a probable real-world connection.

The Search Twitter Bios tab performs full-text keyword search across all Twitter bios, with optional filters for location, name, and follower count. A search for "John Smith" returns 21,156 profiles. Adding a location of "New York City" reduces that to 125. Adding a minimum of 100 tweets reduces it further to 44 manageable profiles.

The Analyze tab takes a single handle and maps the approximate locations of that account's followers or followings. Bazzell recommends analyzing followers rather than followings for more relevant results. The map is approximate and should be used to identify the general city or region of connected accounts, not precise addresses. In homicide investigations, he has used this map to eliminate out-of-state contacts and focus on local individuals who could be interviewed quickly.

A limitation: since 2019, Twitter blocks Followerwonk analysis of private accounts. The tool displays a warning that the report contains protected accounts and that viewing requires being an authorized follower.

## Social Bearing (socialbearing.com)

Social Bearing analyzes the most recent 3,200 tweets of an account (the Twitter API limit). It surfaces total audience reach, total impressions, retweet count, favorites count, tweet sentiment, tweet types (original versus retweet), tweet sources (mobile, desktop, or API, revealing device types), domains shared, and a word cloud of common terms. It also provides geo-search options for location-tagged tweets. The web interface offers graphical output, and a CSV export is available. Accounts can be queried directly via static URL in the pattern `https://socialbearing.com/search/user/<username>`, which allows the tool to be incorporated into automated workflows.

## Spoonbill, Twitter Bio Change History (spoonbill.io)

Users frequently modify their Twitter biography, sometimes removing usernames, email addresses, or handles from other platforms. Spoonbill records these changes over time. It displays previous content as strikethrough text and highlights new content in green with timestamps. A direct URL bypasses the login requirement: `https://spoonbill.io/data/<username>/`. Bazzell warns against creating a Spoonbill account because the service demands access to the investigator's own follower list, which could expose investigative connections. The alternative SearchMyBio (searchmy.bio) is mentioned as a substitute.

A real-world case illustrates the value. In a 2017 missing juvenile investigation, the subject's active Twitter posts contained nothing useful. Checking Spoonbill revealed that two months before her disappearance she had briefly listed a Snapchat username in her bio. That username led to a profile photo not previously encountered. The username was connected to an email address, which was linked to a previously unknown Facebook profile. The Facebook user ID, obtained through Facebook tools described elsewhere in the book, led to hidden images and a single suspect. The juvenile was located safely within an hour.

## Twitonomy (twitonomy.com)

Twitonomy is described as the most complete analytics service for a single Twitter handle. A typical search produces: total tweet count, following count, follower count, account join date, average tweets per day, total users mentioned, reply rate, and retweet count and percentage. Additional data includes posting frequency by day of the week and by hour of the day, platforms used to post (identifying devices such as Android phone, iPhone, and Mac computer, as well as browser, check-in service, photo sharing service, and video sharing service), most favorited and most retweeted posts, and the users most frequently mentioned or replied to.

## Twitter Location and Geolocation Tools

Before 2014, GPS coordinates were embedded in many tweets. Twitter changed the default to disabled, so most users stopped sharing location without realizing it. As a result, historical geolocation data is often more productive than current data for investigations. Three specialized map tools are described.

Omnisci (omnisci.com/demos/tweetmap) is a large database platform developed through MIT and Harvard collaboration. It allows search by topic, username, or location, and shows matching tweets as blue dots on a dark map. The original MIT and Harvard interfaces have been retired into this single platform.

One Million Tweet Map (onemilliontweetmap.com) shows only the most recent one million tweets on a global map and updates with new tweets every second. It does not access the full Twitter data stream, so it is not a comprehensive record, but it is useful for monitoring a live event in real time. Zooming in reveals individual tweet dots that can be clicked to view content.

Tweet Mapper (keitharm.me/projects/tweet) is a fallback option. The project appears to be abandoned but occasionally returns results for targets with older geotagged tweets. Social Bearing (described above) also provides a geo-search feature.

## Fake Follower Detection

Both tools described require the investigator to be logged into a Twitter account.

SparkToro (sparktoro.com/tools/fake-followers-audit) is the more detailed option. It defines fake followers as accounts that are unreachable and will not see the target's tweets, including spam accounts, bots, propaganda accounts, and inactive accounts. It provides a percentage of fake followers along with a methodology explanation. Static URL format: `https://sparktoro.com/fake-followers/<username>`. In Bazzell's own account test, 28.6 percent (5,915) of his 20,682 followers were identified as fake.

Twitter Audit (twitteraudit.com) is a simpler option. It produces a fake percentage with few supporting details. It requires an audit request to be submitted on the page. Static URL format: `https://www.twitteraudit.com/<username>`.

A high fake-follower percentage indicates an artificially inflated account and means the target's real social graph and engagement level are smaller than they appear.

## Miscellaneous Twitter Tools

Sleeping Time (sleepingtime.org) analyzes the timestamps of a user's public tweets to infer the hours when the user is usually sleeping due to inactivity. Bazzell used this on Kevin Mitnick's account and found a likely sleep window of 12am to 7am.

Twiangulate (twiangulate.com) identifies mutual friends between two accounts. It lists full name, photo, bio, and location of each common friend. Bazzell recommends it as a backup to TweetBeaver if that service is unavailable, but considers Followerwonk superior for multi-suspect work.

Tinfoleak (tinfoleak.com) generates an analytics report that includes Twitter ID, account creation date, follower and following counts, location, time zone, tweet count, Twitter clients used, hashtags, user mentions, image metadata, and geolocation data. It requires Twitter login. Reports are available at `https://tinfoleak.com/reports2/<username>.html`.

FollerMe (foller.me) provides standard analytics plus a per-hour posting pattern. Results are reported in UTC and must be converted to the suspect's local time zone. The output makes sleep patterns and peak activity hours visible.

TweetTopic (tweettopicexplorer.neoformix.com) collects the most recent 3,200 tweets and builds a word cloud of the most common terms. Clicking any word in the cloud filters the view to show only tweets containing that term. This lets an investigator rapidly identify the topics a high-volume account focuses on and drill into specific areas of interest without reading thousands of posts manually.

## IntelTechniques Custom Twitter Tool

Bazzell created a locally hosted custom tool, downloadable from IntelTechniques, that consolidates the manual Twitter searches described in the chapter. Entering a target username and clicking "Populate All" pre-fills that username into every search field. Clicking "Go" next to any option opens the corresponding query in a new browser tab. Functions covered include: Twitter profile, outgoing tweets, incoming tweets, media tweets, liked tweets, outgoing and incoming tweets filtered by year, TweetBeaver user ID lookup, username lookup, user data, followers, friends, tweets, and likes, Social Bearing report, FollerMe report, Google archive search, Google tweets search, Bing archives, Yandex archives, and Google Cache. No data is transmitted to IntelTechniques servers. All queries run within the investigator's own browser.

Bazzell closes by noting that Twitter is under-used by most investigators because they tend to browse a live profile briefly and move on. The most valuable information is rarely visible in that initial view, and requires the historical, comparative, and analytical tools described throughout the chapter.
