The image does not correspond to any real person and should not appear in reverse image searches. Refreshing the page produces a new image each time. The author recommends saving a collection of images locally in case the site disappears.

## Chapter 9: Search Engines

The chapter focuses on Google and Bing, with an emphasis on Google. Most techniques apply to any search engine. The author notes this chapter is largely unchanged from the 7th edition and that no written guide replaces practicing these techniques in a live browser.

### Quotation Marks

Placing a search term in quotation marks forces the search engine to return only pages where the words appear adjacent to each other. Without quotes, a search for "Michael Bazzell" returns about 147,000 results, because pages only need to contain both words somewhere on the page, not necessarily next to each other. With quotes, the same search returns about 31,800 results, each containing the exact phrase. Google's related-name technology (which would surface "Mike Bazzell" as a variant of "Michael Bazzell") does not apply when quotes are used, so investigators searching a target named "Michael" should run a separate search for "Mike." If a quoted search returns no results, remove the quotes and try again.

When a quoted search returns too many results, add additional terms after the phrase. Adding "FBI" to "Michael Bazzell" reduces results from 31,800 to 12,000. Adding the target's occupation, city, college, or a known interest helps eliminate unrelated matches. Quoting an email address works the same way: an unquoted search for an address returns about 14,200 results, while a quoted search returns only the 7 pages that actually contain that address.

### Search Operators

Operators are commands within the search field, separated from their arguments by a colon. The chapter covers the following operators.

**site:** Limits results to a specific domain. The query `site:forbes.com "Michael Bazzell"` returns all eight pages on forbes.com that contain that name. The query `site:inteltechniques.com` (without a search term) returns all 628 publicly indexed pages on that domain. This is useful for reviewing a target's entire website without manual navigation, and it can reveal pages the owner considers private if those pages were ever publicly linked. A practical example: a background check query of `site:amazon.com "target name"` revealed book reviews written by an applicant that contradicted a signed affidavit about drug dependency.

**filetype:** (or **ext:** in Google only) Filters results to a specific file extension. Google and Bing both support `filetype:`. The example searches are `"Cisco" filetype:ppt` (returns 15,200 PowerPoint files) and `"Cisco" filetype:pptx` (returns an additional 12,700 files). Narrowing further with `"Cisco Confidential" filetype:pptx` reduces results to 1,080. Searching `filetype:doc "resume" "target name"` often surfaces resumes the target created and uploaded, which typically contain phone numbers, personal addresses, work history, education, and references. The operator can be combined with `site:` to enumerate all files of a given type on one domain (example: `site:irongeek.com filetype:pdf`). File types that are currently indexed and return useful results include: 7Z, BMP, DOC, DOCX, DWF, GIF, HTM, HTML, JPG, JPEG, KML, KMZ, ODP, ODS, ODT, PDF, PNG, PPT, PPTX, RAR, RTF, TXT, XLS, XLSX, ZIP. Media files such as MP3 and MP4 are no longer reliably indexed due to anti-piracy measures.

**Hyphen (-):** Excludes a term from results. No space between the hyphen and the excluded term. The chapter demonstrates progressively narrowing a search by adding exclusions one at a time. Starting from 31,800 results for "Michael Bazzell," successive additions of -police, -FBI, -osint, -books, -open, -source, and -"mr. robot" reduce results to 92 pages, which refer to other people with the same name.

**inurl:** Applies the filter to the URL of the page rather than its content. The example `inurl:ftp -inurl:(http|https) filetype:pdf "osint"` finds FTP servers with PDF files containing the word "osint." The pipe symbol (|) means OR. Another use: `inurl:/blog/ site:inteltechniques.com` returns only pages within the /blog/ folder of that domain.

**intitle:** Filters by the page title rather than body content. `intitle:"osint video training"` with quotes finds only pages specifically titled that phrase. Without quotes the filter is less strict. `allintitle:training osint video` finds pages whose title contains all three words in any order. A useful form is `intitle:index.of OSINT`, which surfaces publicly accessible directory listings (open folders on web servers) that contain OSINT-related content, giving access to entire folder structures of files.

**OR:** Returns results containing term A, term B, or both. Must be uppercase. Example: `"Michael Bazzell" OR "Mike Bazzell" OSINT` catches both spellings simultaneously. Useful when a target has a name that is commonly misspelled.

**Asterisk (*):** Wildcard that stands for one or more words within a quoted phrase. `"osint * training"` matches "osint video training," "osint live classroom training," and similar phrases.

**Range (..):** Searches between two numbers or years. `OSINT Training 2015..2018` returns pages containing the terms OSINT and training along with any number between 2015 and 2018. `"bonnie woodward" "1..999 comments"` finds news articles about that missing person that have between 1 and 999 reader comments, surfacing community discussion.

**related:** Identifies online content related to a domain. `related:inteltechniques.com` returned not the domain itself, but associated Twitter pages, Black Hat courses, and Amazon listings. In investigations, this operator has turned a target's personal website into a list of their social network profiles and associates' websites.

### Google Search Tools (UI Filters)

The "Tools" link on any Google results page exposes additional filters. The "Any time" dropdown restricts results by time period: past hour, day, week, month, year, or a custom date range. A real-world application: when working missing persons cases, the author set the date filter to show only content posted before the date of disappearance, avoiding media noise and surfacing pre-incident online activity more relevant to identifying suspects.

The "All results" menu includes a "Verbatim" option, which searches exactly the typed query without query expansion. Verbatim mode often returns more results than standard mode because it bypasses Google's automatic synonym and related-term additions.

### Forcing Dates on All Results

Google only shows index dates next to search results when a time filter is active. To force dates to appear on every result without restricting the date range, append the following parameter to any Google search URL:

`&tbs=cdr:1,cd_min:1/1/0`

This instructs Google to display results from January 1, 1 BC to today, making the first-indexed date visible for each result. Results can then be sorted by date. The full URL form is: `https://www.google.com/search?q="michael+bazzell"&tbs=cdr:1,cd_min:1/1/0`

### Google Programmable Search Engines

Available at programmablesearchengine.google.com, this feature (formerly called Custom Search Engines) lets investigators create their own scoped search tools. A Google account is required to create an engine, but the resulting engine has a public URL that works without login.

The basic use is to enter one or more target domains and create an engine restricted to those domains. The author notes that many specialty sites claiming to search only social networks are built on this Google feature.

A more advanced use involves creating an engine that searches multiple social networks and then adding Refinements to separate results by network. The author's example engine covers facebook.com, twitter.com, instagram.com, linkedin.com, youtube.com, and tumblr.com. Adding a named Refinement for each domain and setting the option to "Search only the sites with this label" (not "Give priority") creates per-network tabs in the results. The investigator can then view all results combined or filter to a single network.

A second example creates a document-search engine scoped to the entire web. The steps are: create a new engine with google.com as a placeholder domain, enable the "Search the entire web" toggle in Setup, delete google.com from the sites list, and then add Refinements for each file type (PDF, DOC, PPT, and so on). This produces a bookmarkable search interface with file-type tabs, equivalent to running filetype: operators but more convenient for repeated use.
