## Overview

This unit covers two related topics. The first is a practical walkthrough of Recon-ng, a command-line reconnaissance framework for Linux. The second is an introduction to working with publicly available data sets, including voter registration databases and the Social Security Death Index (SSDI), alongside a discussion of the legal and practical considerations around breached credential data.

---

## Recon-ng: Workspaces and Core Workflow

Recon-ng organizes investigations through workspaces. A workspace is an isolated container for a single investigation, analogous to a case folder. All data collected during a session is stored in the active workspace. Commands for workspace management:

- `workspaces list` -- view all existing workspaces
- `workspaces create OSINT` -- create a new workspace named OSINT and automatically switch into it
- `workspaces load OSINT2` -- switch to a different workspace
- `workspaces remove OSINT` -- delete a workspace and all associated data and reports

Investigators may create one workspace per suspect or one per case. Deleting a workspace is permanent, so evidence must be exported first.

Before any module can be used it must be installed, then loaded. `marketplace install <module>` installs a module. `modules load <module>` loads it into the active session. The source input is set with `options set SOURCE <value>` (SOURCE must be uppercase). Typing `input` confirms what has been queued. Typing `run` executes the module. Typing `back` exits the current module and returns to the workspace prompt.

At any point, `marketplace info <module>` displays a module's description, version, author, last-updated date, required API keys, dependencies, and installation status.

## Module Examples

### Profiler (username search)

The `profiler` module queries dozens of online services for a given username and stores any confirmed profiles. Example session:

```
marketplace install profiler
modules load profiler
options set SOURCE inteltechniques
run
show profiles
```

A query for `inteltechniques` returned profiles on Gravatar, Reddit, and Twitter. Running the module again with `options set SOURCE humanhacker` appended results without overwriting the prior ones. The combined output for `humanhacker` included Blogspot, Disqus, Flipboard, GitHub, Instagram, Kongregate, Kik, Medium, Microsoft Technet, Minecraft (via namemc.com), Pornhub, Scratch, Reddit, Twitch, Twitter, and Xbox Gamertag. Recon-ng stores all results cumulatively and de-duplicates them automatically.

### Domain host enumeration (bing_domain_web, google_site_web)

```
marketplace install bing_domain_web
marketplace install google_site_web
```

Targeting `cnn.com` with `bing_domain_web` returned over 70 unique subdomains and hosts. Running `google_site_web` on the same domain found 38 total results, of which 15 were not in the Bing results. Together the two modules produced a more complete host list than either alone. Results are retrievable with `show hosts`.

### Top-level domain enumeration (brute_suffix)

```
marketplace install brute_suffix
modules load brute_suffix
options set SOURCE socialengineer.org
run
```

This module tests many TLDs (.net, .tv, .me, .se, .training, .us, .be, .ch, .com, .de, .dev, .info, and others) and records which ones resolve. In the example, 11 additional domains were found for the social-engineer.org base name, including social-engineer.me, social-engineer.net, social-engineer.se, social-engineer.training, social-engineer.us, and others.

### PGP key email harvesting (pgp_search)

```
marketplace install pgp_search
modules load pgp_search
options unset SOURCE
options set SOURCE cnn.com
run
show contacts
```

This module scans stored domains for email addresses associated with public PGP keys. Results are appended to the workspace contacts list. For `cnn.com`, the module returned addresses including `barsuk@cnn.com`, `tristan.helmich@cnn.com`, and `paul.p.murphy@cnn.com`.

A key design principle: Recon-ng's stored data is available as input to subsequent modules automatically. If a prior module found domains, the pgp_search module sees those domains in its input list without re-entry. Input sources can be cleared with `options unset SOURCE` and then reset.

## Reporting

Recon-ng can generate structured reports from all data in a workspace. Install and run the HTML reporting module:

```
back
marketplace install html
modules load html
options set CUSTOMER IntelTechniques
options set CREATOR M.Bazzell
run
```

The report is saved at `~/.recon-ng/workspaces/<workspace_name>/results.html`. The file requires the "Show Hidden Files" option to be enabled in the file manager because the `.recon-ng` folder is hidden. The report groups data by category: domains, companies, netblocks, locations, vulnerabilities, ports, hosts, contacts, credentials, leaks, pushpins, profiles, and repositories. Additional output formats include CSV, JSON, list, XLSX, and XML.

## Scale and API Keys

The same effort required to search one username, email address, or domain is effectively the same for thousands, because each module run processes the entire stored input list. Many modules require API keys from third-party services. The `marketplace info <module>` command shows required keys in the "required_keys" field. Many of these keys are free. The official Recon-ng repository is at https://github.com/lanmaster53/recon-ng, and a dedicated Slack group is available from that page.

## Data Breaches and Leaks: Legal Framework

This section opens with a clear disclaimer: the techniques described are for educational purposes only. Executing them may violate organizational policy. Possession of certain data may conflict with a security clearance or be deemed illegal under state or federal law. Distribution of this content is illegal in most cases. Readers are instructed to verify authority with legal counsel or supervisory personnel before acting.

The author notes he is not an attorney. Based on conversations with attorneys and prosecutors, the general position offered is that possessing publicly available data is likely legal, in the same way that reading a publicly posted stolen document on WikiLeaks or Medium would be. The critical line is use: searching data for investigative leads is legally distinct from using credentials to access someone's account. Accessing a target account without a valid search warrant or court order is never acceptable. For law enforcement with legal authority, the chapter describes the data as a useful strategy.

## Voter Registration Databases

Several U.S. states make voter registration data freely available, either through third-party FOIA requests or directly from official government domains. The chapter lists third-party download sites (all operated by the same individual who files FOIA requests) for Arkansas, Colorado, Connecticut, Delaware, Florida, Michigan, Oklahoma, Rhode Island, and Utah, with specific URLs for each state.

| State | URL |
|---|---|
| Arkansas | http://arkvoters.com/download.html |
| Colorado | http://coloradovoters.info/downloads/20170401/ |
| Connecticut | http://connvoters.com/download.html |
| Delaware | http://delawarevoters.info/downloads.html |
| Florida | http://flvoters.com/download/20171130/ |
| Michigan | https://michiganvoters.info/download.html |
| Oklahoma | http://oklavoters.com/download.html |
| Rhode Island | http://rivoters.com/downloads.html |
| Utah | http://utvoters.com/ |

Each record typically includes full name, home address, gender, date of birth, date of last registration change, party affiliation, and sometimes an email address and telephone number.

## Working with Large Data Sets in Linux: Ripgrep and Sed

Because these data sets are large, the chapter recommends using Linux with two command-line tools: Ripgrep (rg) and sed. Ripgrep does not work well on Windows, which is a reason for using the Linux VM.

### Combining files

After downloading multiple county files for Florida into a folder `~/Desktop/Voter-FL`, combine them:

```
cd ~/Desktop/Voter-FL
cat * > Voter-FL.txt
```

Move the combined file to a `Databases` folder and discard the originals.

### Installing Ripgrep

Ubuntu: Download the `.deb` file from `https://github.com/BurntSushi/ripgrep/releases/` and install it through the file manager. At the time of writing, the file was `ripgrep_12.1.1_amd64.deb`.

Mac: `brew install ripgrep` (requires Homebrew).

### Ripgrep flags

| Flag | Meaning |
|------|---------|
| `-a` | Search all data as text |
| `-F` | Treat the pattern as a literal string (no regex) |
| `-i` | Ignore case |
| `-N` | Exclude line numbers from output |

The standard search command form is `rg -a -F -i -N "target"`. Omitting `-F` enables regex matching across individual tokens. Omitting `-i` makes the search case-sensitive.

Examples:

```
rg -a -F -i -N Williamson           # find all records containing "Williamson"
rg -a -F -i -N 'NW 48Th TER'        # find all voters on a specific street (quote for spaces)
rg -a -F -i -N @gmail.com           # find all Gmail addresses in the files
rg -a -F -i -N rita@gmail.com       # find a specific email address
rg -a -F -i -N bazzell SSDI.txt     # search within a named file only
rg --help                            # show full help
```

Searches run against all files in the current folder unless a filename is specified at the end.

### Cleaning tab-delimited data with sed

Florida voter files use tab characters as delimiters, which makes raw output hard to read. Replace tabs with colons using sed. The tab character in the command is entered by pressing Ctrl+V then Tab at the terminal:

```
sed -i 's/	/:/g' Voter-FL.txt
sed -i 's/::/:/g' Voter-FL.txt
```

The `-i` flag modifies the file in place. The first command replaces every tab with a colon throughout the file. The second eliminates double colons left by empty fields. After cleaning, a Florida voter record looks like:

```
ALA:100397608:Williamson:Glenda:Dianne:N:217218 NW 48Th TER:Gainesville:32606:F:5:08/17/1951:08/14/1980:DEM:22:0:22C3:ACT:3:21:8:0:0:
```

Fields are county code, voter ID, last name, first name, middle name, suffix, address, city, zip, gender, and registration details including date of birth, date of registration change, and party.

The `sed` command form explained:

- `sed` -- the command
- `-i` -- modify the file in place
- `'s/::/:/g'` -- replace every occurrence of `::` with `:` throughout the file
- `Voter-FL.txt` -- the file to modify (using `*` instead of a filename modifies all files in the folder)

### Social Security Death Index (SSDI)

A publicly available copy of the SSDI can be downloaded from `http://cancelthesefunerals.com`. After downloading and combining the files into `SSDI.txt` and placing it in the Databases folder, search it with:

```
cd ~/Desktop/Databases
rg -a -F -i -N bazzell SSDI.txt
```

A result entry has the format `433220353 BAZZELL DOROTHY S 0118201303191921`, which encodes a Social Security number, last name, first name, middle initial, and dates.

## Strategic Value

The underlying argument is that building a local collection of these publicly available data sets makes certain searches possible that cannot be replicated on web-based query tools. Searching hundreds of people on a street, all Gmail accounts in a state voter file, or a specific email address across multiple state databases are examples of queries only practical with local data and fast search tools. The effort to search one record is nearly the same as searching thousands once the data is loaded and the tooling is in place.
