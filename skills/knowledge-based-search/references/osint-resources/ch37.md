title: Video Intelligence: YouTube Techniques, Metadata, Reverse Video Search, and Related Platforms

This chapter covers the collection of intelligence from online video platforms. The primary focus is YouTube, with additional coverage of Vimeo, Internet Archive, TV News Archive, and social network video search. The chapter explains how to extract metadata, bypass access restrictions, locate deleted or unlisted content, conduct reverse video searches, and download video evidence.

## YouTube Search and Filtering

YouTube search returns vast results. The "Filter" button above the first result allows sorting by upload date, type (video vs. channel), duration, and features such as video quality. Applying an upload date filter ("uploaded this week") can reduce hundreds of thousands of results to a manageable set. Every video page includes a link to the uploader's profile, which displays all videos from that user along with additional profile information.

## Bypassing Age and Login Restrictions

YouTube sometimes blocks videos behind a login or age-verification wall. The chapter recommends against researching while logged into any personal or covert Google account, because Google records all activity for logged-in users. To bypass the restriction, prepend the video URL with `https://keepvid.works/?url=`, for example:

```
https://keepvid.works/?url=https://www.youtube.com/watch?v=SZqNKAd_gTw
```

Clicking "Download" on the resulting page plays the video directly from YouTube without requiring a login.

## Bypassing Commercials

Replacing `watch?v=` in a YouTube URL with `embed/` forces the video to play in full-screen mode and bypasses pre-roll commercials. For example:

```
https://www.youtube.com/embed/IEIWdEDFlQY
```

## Extracting Video Thumbnails

Every YouTube video has static thumbnail URLs derived from the video ID. Given a video ID such as `lnmljEJmOTQ`, the following URLs are available:

- Main thumbnail: `https://i.ytimg.com/vi/lnmljEJmOTQ/hqdefault.jpg`
- Maximum resolution: `https://i.ytimg.com/vi/lnmljEJmOTQ/maxresdefault.jpg`
- Four frame captures: replace the filename suffix with `0.jpg`, `1.jpg`, `2.jpg`, or `3.jpg` at `https://img.youtube.com/vi/lnmljEJmOTQ/`

These still images can be downloaded without playing the video and are used as inputs for reverse image searches.

## Identifying and Bypassing Country Restrictions

Some videos are restricted by country. To identify which countries can view a video, paste the video ID into:

```
http://polsy.org.uk/stuff/ytrestrict.cgi?ytid=cgEnBkmcpuQ
```

This returns a world map with allowed countries shown in grey and blocked countries in red. WatanNetwork offers the same function at `https://watannetwork.com/tools/blocked/#url=cgEnBkmcpuQ`. Even when playback is blocked, thumbnail images are accessible via the standard `hqdefault.jpg` and `maxresdefault.jpg` URLs. A VPN set to an allowed country allows full playback. "YouTube Proxy" websites that promise to play any blocked video are described as unreliable.

## YouTube Metadata via the API

Detailed metadata is available through the Google YouTube Data API. A free API key can be obtained at `developers.google.com` by creating a project and enabling a YouTube API key. The chapter provides a sample key (`AIzaSyDNALbuV1FZSRy6JpafwUaV_taSW12wZw`) used in its search tools, with a note that the key may be disabled if abused and that creating a personal key prevents outages. The API query format is:

```
https://www.googleapis.com/youtube/v3/videos?id=VIDEO_ID&part=snippet,statistics,recordingDetails&key=API_KEY
```

The response includes precise publication timestamps, channel ID, view count, like count, dislike count, favorite count, and comment count. The chapter recommends documenting all metadata for every YouTube investigation.

## YouTube Profiles

Clicking an uploader's name below a video shows their profile, but that page shows only a portion of available data. A more complete view is available through the RSS/XML feed:

```
https://www.youtube.com/feeds/videos.xml?user=USERNAME
```

This text-only page reveals the channel's real name, Channel ID, and the exact date and time the account was created. It also shows precise creation and modification timestamps for each video, plus viewer statistics. Using the Channel ID with the API returns additional data including the user's country, custom YouTube URL, and a high-resolution (800x800) profile photo URL, compared to the 160x160 icon visible on the profile page. The chapter demonstrates this with the profile `SnubsieBoo`, whose real name is Shannon Morse and whose Channel ID is `UCNofX8wmSJh7NTklvMqueOA`.

## Reverse Image Search on Video Thumbnails

Because YouTube thumbnails have static URLs, they can be submitted directly to reverse image search engines. For example:

```
https://www.google.com/searchbyimage?site=search&sa=X&image_url=https://i.ytimg.com/vi/cgEnBkmcpuQ/maxresdefault.jpg
```

This identifies additional copies of a video hosted on other platforms. The chapter's Videos Tool automates this across Google, Bing, Yandex, and TinEye using all available frames.

## Downloading Videos

The preferred method is yt-dlp (successor to YouTube-DL), covered in Chapter Four for Linux, Mac, and Windows OSINT machines. As an alternative without installed software, prepending `deturl.com/` to a YouTube URL presents options to download the video, download only the audio, or convert to another format, and also bypasses age restrictions. Additional web-based services mentioned are yout.com, keepvid.com, and y2mate.com.

## YouTube Comments

The Video Download Tool for Linux, Mac, and Windows includes YouTube-Tool, which extracts all comments from a video page. The chapter states this documentation should be part of every YouTube video investigation.

## YouTube Channel Crawler (channelcrawler.com)

Native YouTube channel search returns only high-subscriber channels. Investigators are more likely to find targets in low-visibility channels. YouTube Channel Crawler allows filtering by subscriber count and total view count, making it possible to surface channels with few subscribers or views that would not appear in standard search results.

## Unlisted Videos

YouTube videos can be public, private, or unlisted. Unlisted videos do not appear in search results but are accessible to anyone with the direct URL. Two methods to find them are described. A Google query using `site:youtube.com "This video is unlisted" intitle:KEYWORD` can return results but is unreliable. The site Unlisted Videos (unlistedvideos.com) is described as more reliable for keyword-based searches of unlisted content.

## Deleted Videos

Removed YouTube videos may still be accessible through the Internet Archive. The Archive has mirrored YouTube videos for years. The archived HTML pages can be found at:

```
https://web.archive.org/web/https://www.youtube.com/watch?v=VIDEO_ID
```

These archives preserve comments but do not allow video playback. To play the actual archived video, use:

```
https://web.archive.org/web/2oe_/http://wayback-fakeurl.archive.org/yt/VIDEO_ID
```

The video can then be right-clicked and saved locally.

## Broader Video Search

### Google Videos

Available at `google.com/videohp` or via `https://www.google.com/search?tbm=vid&q=TERM`. Results cover YouTube plus videos hosted on news sites and other platforms. Filters include duration, date, and video source.

### Bing Videos

Available at `videos.bing.com` or via `https://www.bing.com/videos/search?q=TERM`. A distinctive feature is instant playback by hovering the cursor over a result thumbnail, eliminating the need to navigate to each video page. Filtering by length and source is available. The chapter recommends disabling safe search in both Google and Bing to avoid filtering out videos with adult content that may be relevant to investigations.

### Yandex Videos

Available at `https://yandex.ru/video/search?text=TERM`. Described as a contender for OSINT use since 2020. Unlike Google and Bing, Yandex does not consistently remove videos that violate policies around violent or inappropriate content, making it valuable for finding content that has been removed elsewhere.

## Social Network Video Search

Search engines do not replicate internal search within social networks. Direct query URLs for video content within networks are:

- Twitter: `https://twitter.com/search?q=TERM&f=video`
- Facebook: `https://www.facebook.com/search/videos/?q=TERM`
- Reddit: `https://www.reddit.com/search?q=site:v.redd.it%20AND%20TERM`
- TikTok: `https://www.tiktok.com/tag/TERM`

For downloading embedded social network videos, the chapter recommends starting with the Video Download Tool, then the Video Stream Tool for live streams, then browser extensions, and finally third-party web tools such as Twitter Video Downloader (twittervideodownloader.com), FDown (fdown.net), and Instagram Downloader (igram.io).

## Reverse Video Searching: Methods and Use Cases

Because no native reverse video search exists, the technique is to extract still frames from videos and submit those images to reverse image search engines. This identifies other websites hosting the same video. The chapter gives three concrete investigative use cases:

1. School resource officers can find additional copies of fight or bullying videos to understand how widely they have spread.
2. Security analysts monitoring protest groups can find additional copies of threat-related videos, often accompanied by commentary and discussions not visible at the primary source.
3. Human trafficking investigators can find escort advertisement videos reposted across multiple geographic areas, revealing travel patterns of those involved.

### Reverse Search by Platform

**YouTube.** Use the thumbnail and frame URLs described earlier, submitted to Google, Bing, Yandex, TinEye, and Baidu.

**Vimeo.** Vimeo does not expose multiple frame URLs directly. To find a still image, query the Vimeo oEmbed API at `https://vimeo.com/api/oembed.json?url=https://vimeo.com/VIDEO_ID`. This returns a JSON response that includes a `thumbnail_url` field with a direct image URL (for example, `https://i.vimeocdn.com/video/513053154_295x166.jpg`). Removing the `_295x166.jpg` suffix yields a full-size image at `https://i.vimeocdn.com/video/513053154`. The API response also includes the exact upload date and time, compared to the approximate relative date shown on the video page itself.

**Other platforms.** Most video sites display a still image before playback. That image URL is typically visible in the page source code. Searching the source for `.jpg` or `.png` quickly identifies it. Submitting that image URL to reverse image search tools finds additional copies.

## Internet Archive Video (archive.org)

The Internet Archive permanently stores open-source movies including commercial and amateur releases. Searching the "community video" section returns amateur content. Unlike YouTube, Internet Archive does not surface the uploader's other videos through the video page itself. To find them, navigate to the uploader's profile at `http://www.archive.org/details/USERNAME`. On any individual video page, clicking "Show All" below the video player reveals all associated files. One of these files is the metadata XML (named `*_meta.xml`), which contains the title, description, creator, the email address used to upload the content, and the exact date and time of upload and publication. The chapter provides an example where the metadata for a video at `https://archive.org/details/Awlaki_to_americans` identifies the uploader email as `ibnumar@islamumma.com` and shows that the uploader waited over an hour between the added date (2012-03-31 22:47:36) and the public date (2012-04-01 00:09:10). The chapter notes that since 2016 the Internet Archive has become a popular host for international video content that may be blocked on American services.

## TV News Archive (archive.org/details/tv)

At the time of writing, the TV News Archive held 2,094,000 television news broadcast videos spanning 2009-2020. It extracts closed captioning text from each broadcast and provides keyword search across that text. A search for any spoken name or phrase returns videos where that word was said on air. Results can be filtered by show title, station, date, language, and topic. The chapter notes this resource is useful for vetting potential hires.

## Video Closed Captions (downsub.com)

YouTube and other providers generate automatic closed captions for many videos by transcribing spoken audio to text. These captions are stored in small text files with timestamps linking each phrase to a specific frame. YouTube does not provide direct access to these files. Downsub (downsub.com) accepts a YouTube video URL and returns download links for the caption file in each available language as `.srt` files. The chapter notes that automated captions are not always accurate, particularly for slang or mumbled speech, but recommends obtaining the caption file as part of any video submission to a report, because it can assist in official proceedings.
