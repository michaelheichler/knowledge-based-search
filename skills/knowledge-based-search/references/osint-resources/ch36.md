This unit covers the latter portion of Chapter 21 (Images) and the opening of Chapter 22 (Videos). The material focuses on finding images through social networks and photo-sharing platforms, extracting and interpreting Exif metadata, detecting image manipulation, decoding barcodes, and enhancing low-quality images. A custom IntelTechniques tool consolidates the methods.

## Social Network Image Searches

Most major platforms support URL patterns that filter results to images only, removing the need to navigate menus manually.

- Twitter: `https://twitter.com/search?q=osint&f=image` returns only images from posts or hashtags matching the keyword.
- Facebook: `https://www.facebook.com/search/photos/?q=osint` queries photos from posts.
- Tumblr: `https://www.tumblr.com/search/osint` searches a platform where image-heavy blogs are common and where general search engines often index associated keywords poorly.

## Flickr

Flickr, originally purchased by Yahoo and now owned by SmugMug, holds a large archive of photographs uploaded mainly by amateur photographers. The main site supports search by topic, location, username, real name, or keyword. A found profile may reveal a username, camera information, interests, user comments, and location-tagged photos. A search for Occupy Wall Street images returned over 157,000 results.

Flickr Map (flickr.com/map) attempts to geolocate photos using Exif GPS data or user-provided location tags and renders them on a map. The author considers it useful mainly for researching past events at large venues or understanding the physical layout of a popular location.

### Flickr API

The Flickr API offers three investigative functions, each requiring an API key (free keys are available at flickr.com/services/api/). A sample throwaway key used in the book is `27c196593dad58382fc4912b00cf1194`.

1. Query by email address to find associated accounts. The method `flickr.people.findByEmail` with the `find_email` parameter returns a username and a permanent user ID (for example, `8104823@N02`).
2. Query by username using `flickr.people.findByUsername` to retrieve the permanent user ID.
3. Query by user ID using `flickr.people.getInfo` to retrieve the username, photos URL, profile URL, and mobile URL. The permanent user ID never changes, making it a stable link across investigations.

There is no native email search on the Flickr website. The API is the only route to this information. Older targets who have abandoned Flickr may still have years of photographs there.

## Exif Data

Every digital photograph contains embedded metadata called Exif data. This layer of code is written into the image file by the camera and is not visible when viewing the photo. An Exif reader is required to extract it.

Key facts:

- Facebook removes Exif data before storing images. Flickr does not.
- Compressed or resized images often lose Exif data. The largest available version of an image is most likely to have it intact.
- Images taken directly from a camera memory card always retain the data.

Typical Exif fields include camera make and model, lens used, exposure settings, flash status, date and time of capture, and file size. Some SLR cameras also embed the camera's serial number. A matching serial number across two images is strong evidence that the same camera produced both, including cases where one image was posted anonymously. This data can be modified with software such as ExifTool, so it is evidence to consider rather than definitive proof.

GPS-equipped cameras and nearly all smartphones record coordinates in the Exif data if geotagging is not disabled. Jeffrey's Exif Viewer translates those coordinates into a Google Maps satellite view with a direction indicator based on the device accelerometer.

### Jeffrey's Exif Viewer (exif.regex.info/exif.cgi)

The recommended online tool for Exif analysis. It accepts either an image URL or a file uploaded from a local drive. Output includes camera make and model, lens, exposure, flash, date and time, GPS coordinates with a satellite map view, serial number when present, and a thumbnail if one exists.

### Cropped Images and Hidden Thumbnails

Digital cameras store a small thumbnail inside the Exif data. When a user crops an image, some software (including Photoshop and Microsoft Photo Editor) overwrites the thumbnail to match the cropped version. Other programs, including many online cropping tools, do not overwrite it. The result is that the original uncropped image remains accessible inside the Exif data of the cropped file. Law enforcement has used this to identify child exploitation material producers who cropped themselves out of images. In 2003, fans of television personality Catherine Schwartz examined a cropped photo on her blog and found the uncropped original in the Exif thumbnail. The author cites this as a reminder to consider what Exif data may reveal before posting images.

Real-world example: a civil litigation subject claimed an injury that prevented work and normal activity. A scan of his online photo album showed fishing trips, softball games, and family vacations. Exif data confirmed exact dates, times, locations, and camera details. The subject withdrew the lawsuit.

### Camera Trace (cameratrace.com/trace)

Designed for stolen camera recovery, this site takes a camera serial number and searches its indexed collection of Flickr and 500px photos for other images taken with the same device. The workflow is to extract a serial number from Jeffrey's Exif Viewer, then enter it at Camera Trace. A sample search using "123" returned several results. The site offers a premium alert service but the author has not needed it.

## Barcode Decoding

Modern barcodes can encode substantial text data in a small image. The author advises against scanning unknown barcodes with a mobile device because malicious links could open automatically. An online reader allows safe decoding. While on a plane, the author photographed an abandoned boarding pass and extracted hidden text from its barcode that was not printed on the document.

Online Barcode Reader (online-barcode-reader.inliteresearch.com) accepts PDF, TIFF, JPEG, BMP, GIF, or PNG files up to 4 MB and supports 1D, PDF417, Postal, DataMatrix, and QR barcode formats.

Additional barcode tools: Online Barcode (onlinebarcodereadercr.com), Zxing (zxing.org), Cognex (manateeworks.com/free-barcode-scanner), Online Decoder (online-barcode-readcr.com).

## Image Manipulation Detection

Manipulated photos are common online and often indistinguishable from originals by eye.

### Foto Forensics (fotoforensics.com)

Accepts an image URL or file upload. The tool displays a darkened duplicate in which highlighted areas indicate possible manipulation. The author cautions that it should be used for intelligence purposes only, not as definitive proof. Images uploaded to the site receive a public URL and become part of its collection, which poses a risk for sensitive files.

### Forensically (29a.ch/photo-forensics)

A browser-based tool with a broad set of forensic modules. Images are processed locally in the browser and are not uploaded to any remote server, which addresses the confidentiality concern raised by Foto Forensics. The author directs readers to a full color walkthrough at inteltechniques.com/blog/2016/12/21/internet-search-resource-foresically/ because the book is printed in black and white.

Analysis modules:

- Magnifier: enlarges pixels and increases contrast to reveal fine detail. Enhancement modes are Histogram Equalization (the most robust option), Auto Contrast, and Auto Contrast by Channel.
- Clone Detector: identifies copied regions within the image, a common indicator of manipulation. Configurable parameters include Minimal Similarity, Minimal Detail, Minimal Cluster Size, Blocksize, and Maximal Image Size.
- Error Level Analysis: compares the original image to a recompressed version. Manipulated regions often appear darker or brighter than unaltered areas of similar content. JPEG Quality should be set to match the original image quality.
- Noise Analysis: isolates image noise by running a reverse de-noising algorithm (a separable median filter). Useful for detecting airbrushing, deformations, warping, and perspective-corrected cloning. Works best on large, high-quality images.
- Level Sweep: allows mouse-wheel navigation through histogram brightness levels to find discontinuities.
- Luminance Gradient: analyzes brightness changes along the x and y axes to find illumination anomalies. Edges in the same region under similar lighting should have similar gradients. A significantly sharper gradient at one edge suggests content was pasted in.
- PCA (Principal Component Analysis): provides an alternate mathematical view of image data to surface certain manipulations. The author notes it is single-threaded and slow on large images.
- MetaData: displays any Exif metadata in the image.
- Geo Tags: shows GPS location from Exif if present.
- Thumbnail Analysis: extracts any hidden preview image and compares it to the displayed image, which can reveal original uncropped content.

## Image Enlarging and Upscaling

Image enhancement may be warranted when a blurry image contains identifiable details (for example, a partial license plate or a partially visible address). The author notes that enhancing images is not generally advised because it modifies evidence.

- IMG Enlarger (imglarger.com): requires a free account and simply doubles the image dimensions. The author finds it minimally useful.
- IMG Upscaler (imgupscaler.com): requires no account and uses more advanced processing to genuinely improve clarity. In 2021, the author used it to recover two additional digits from a blurry license plate, which led to a full vehicle registration.

## IntelTechniques Images Tool

The author provides a consolidated web tool that automates all image search and Flickr API techniques from the chapter. It offers one-click reverse image searches across Google, Bing, TinEye, Yandex, Baidu, and KarmaDecay. Keyword image searches run in parallel across Google Images, Bing Images, Yandex Images, Twitter, Facebook, Instagram, LinkedIn, Flickr, and Tumblr, each opening in a separate browser tab. Flickr API lookups by email address, username, and user number are also included.

## Chapter 22 Opening: Videos

The unit closes with the opening of Chapter 22, which frames online video as a comparable or more common source of intelligence than photographs. YouTube reports 500 hours of video uploaded every minute, totaling nearly 80 years of content uploaded per day, with over a billion videos viewed daily. Users organize their uploads into a channel, which can be located by username or keyword search. The chapter treats video as an investigative source on equal footing with images.
