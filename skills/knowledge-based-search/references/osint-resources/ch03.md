Chapter 3 covers the selection, configuration, and extension setup of web browsers for OSINT work. The central argument is that the default browsers supplied by Windows (Internet Explorer, Edge) and Apple (Safari) are inadequate for investigative use, and that Firefox is the correct primary choice. Chrome is used only when a specific tool requires it.

## Firefox as the Primary Browser

Firefox is chosen because it has stronger built-in privacy controls than its competitors, supports a wide range of add-ons essential for OSINT, and does not share as much usage data with a parent company by default. The chapter applies to any recent version of Firefox on Windows, Mac, or Linux. On the Ubuntu VM described in the previous chapter, Firefox is pre-installed.

When first installing or launching Firefox, the user should decline to import any settings from other browsers, which would introduce unwanted stored data. The version can be checked at Menu > Help > About Firefox.

## Firefox Privacy Settings (Preferences Menu)

The chapter walks through the Preferences (or Settings) menu in detail. Key changes include setting the homepage and new tabs to a blank page, disabling extension and feature recommendations, enabling "Delete cookies and site data when Firefox is closed," disabling all login and password saving, configuring history to use custom settings with browsing and form history unchecked, enabling "Clear history when Firefox closes," and enabling HTTPS-Only Mode in all windows.

One warning is explicit: do not check "Always use private browsing mode." That setting breaks Firefox Containers, which are used extensively later.

Permissions for Location, Camera, Microphone, and Notifications should each be set to block new requests. All Firefox Data Collection options should be unchecked. The "Deceptive Content and Dangerous Software Protection" options should also be unchecked. Unchecking them prevents Firefox from sending potential malicious site visits to Google, at the cost of some malware warning coverage.

## Firefox about:config Settings

The about:config page provides more granular control than the Preferences menu. The user navigates to it by typing `about:config` into the URL bar and accepting a risk warning. Settings are changed by double-clicking to toggle between true and false, or by entering a number.

The settings listed cover several categories.

Privacy and fingerprinting: `geo.enabled` to FALSE (disables location sharing), `dom.battery.enabled` to FALSE (blocks battery level information from being transmitted), `privacy.resistFingerprinting` to TRUE, `webgl.disabled` to TRUE, `network.http.sendRefererHeader` to 0 (stops the browser from notifying sites of where you came from).

Pocket and sync: `extensions.pocket.enabled` to FALSE, two related Pocket highlight settings to FALSE, `identity.fxaccounts.enabled` to FALSE.

Telemetry: `browser.newtabpage.activity-stream.feeds.telemetry` to FALSE, `browser.ping-centre.telemetry` to FALSE, `toolkit.telemetry.server` URL deleted, `toolkit.telemetry.unified` to FALSE, `browser.tabs.crashReporting.sendReport` to FALSE.

Behavior: `media.autoplay.default` to 5 (disables auto-playing audio and video), `dom.webnotifications.enabled` to FALSE, `pdfjs.enableScripting` to FALSE (blocks some malicious PDF actions), `network.dns.disablePrefetch` to TRUE, `network.dns.disablePrefetchFromHTTPS` to FALSE, `network.prefetch-next` to FALSE.

WebRTC settings address IP address leakage through browser-based audio/video connections: `media.peerconnection.enabled` to FALSE, `media.peerconnection.turn.disable` to TRUE, `media.peerconnection.use_document_iceservers` to FALSE, `media.peerconnection.video.enabled` to FALSE, `media.navigator.enabled` to FALSE. These break browser-based conferencing tools and are noted as less critical if the machine is already behind a VPN on the home network.

## Firefox Add-ons

Firefox add-ons (also called extensions) are installed through the Add-ons page reached from the browser menu, or directly from the add-on website. The chapter covers each recommended add-on in order of stated importance.

### Firefox Multi-Account Containers (addons.mozilla.org/addon/multi-account-containers)

This Mozilla add-on separates browsing activity into isolated containers. Each container has its own storage slice: cookies, logged-in sessions, and tracking data do not carry over between containers. The practical result is that multiple accounts on the same service can be open simultaneously in different containers without logging out. The author's investigation setup uses containers named Personal, Alias 01 through Alias 04, Leaks, Google, and Harmful. Specific sites can be pinned to always open in a designated container. The chapter uses google.com as the example, so all Google traffic stays isolated from other activity. A "Limit to Designated Sites" option can further restrict a container to only approved domains.

### uBlock Origin (addons.mozilla.org/firefox/addon/ublock-origin)

uBlock Origin replaces all prior recommendations (NoScript, Adblock Plus, Privacy Badger, Disconnect). After installation, default behavior blocks most known ads, tracking code, and malicious content. Enabling "I am an advanced user" in the dashboard expands the per-site control menu. The author also enables "Block access to LAN" under the Privacy filter list.

The advanced per-site menu uses three columns: the first identifies the script type or domain, the second applies changes globally, the third applies changes to the current site only. The plus/minus indicators show how many scripts were allowed or blocked. Key usage patterns: clicking the grey (left) section of the top cell in the third column allows all scripts on the current page only, useful when evidence must show an unmodified page. Clicking the red (right) section of the top cell in the second column blocks all scripts across all sites, useful when visiting a potentially malicious target. Blocking third-party scripts on a specific site can bypass subscription paywalls on some news sites, because those sites use third-party scripts to detect whether a visitor is logged in. Blocking inline scripts can eliminate auto-playing video and pop-ups on news sites while reading articles, though it distorts the page for evidence capture.

To reset all custom rules, go to the My Rules tab in the dashboard, delete all temporary rules, save, and commit.

### DownThemAll (addons.mozilla.org/firefox/addon/downthemall)

DownThemAll identifies all linked files on a page and downloads them in bulk. The example given is an archived dataset at a specific web.archive.org URL containing hundreds of CSV and TXT files with marketing data. The extension presents a window listing all detected links, with filter options for file type. The author considers it the preferred bulk downloader but recommends keeping Bulk Media Downloader as a fallback.

### Bulk Media Downloader (addons.mozilla.org/firefox/addon/bulk-media-downloader/)

Functions similarly to DownThemAll but is targeted at audio and video files. The example shows downloading all videos from a Twitter search results page by selecting the Video type in the pop-up panel and scrolling the page to load results.

### VideoDownloadHelper (addons.mozilla.org/en-US/firefox/addon/video-downloadhelper/)

Downloads individual media files from sites like Vimeo. The icon turns from grey to color when a page contains downloadable media. Configuration changes recommended: set Max concurrent downloads to 20, Max Variants to 99, and enable "Hide ADP Variants." The ADP format requires additional conversion software and can produce files that are not pure source extractions, which is undesirable for evidence purposes. Hiding ADP options leaves only direct-format downloads. For evidence use, downloading all available sizes is recommended. For personal archiving, only the largest size is needed.

### FireShot (addons.mozilla.org/en-us/firefox/addon/fireshot/)

Captures entire web pages (not just the visible viewport) and saves them as PDF files. The PDF format is harder to edit than an image file, which is beneficial during testimony. The recommended filename template is `%n-%u-%t-%y-%m-%d-%H-%M-%S`, which produces a name that includes a sequential number, the URL, the page title, and the date/time of capture. Setting `%n` to 0 with a padding of 3 ensures captures are always numbered starting from 000 and are sortable chronologically.

### Nimbus (used as first backup to FireShot)

Nimbus captures visible portions, entire pages, or custom selections, saving as PNG. PNG is more universally readable than PDF but is easier to edit, which can complicate evidence integrity. Recommended configuration: filename pattern `{url}-{title}-{date}-{time}`, "Enable Quick Screenshot" on, "Entire Page" selected, "Download" as the action. With these settings, clicking the icon captures and downloads without additional prompts. FireShot performs better on large Twitter pages. Nimbus performs better on large Facebook pages, though neither reliably handles long social network pages.

### Firefox Screenshot (built-in)

When both FireShot and Nimbus fail on long pages, the built-in Firefox screenshot tool is used: right-click on the page, select "Take Screenshot," choose "Save full page," then click "Download." The process can take several minutes on large pages and saves a PNG file with a default name that includes the word Screenshot, the date, and the page title.

### Exif Viewer (addons.mozilla.org/en-us/firefox/addon/exif-newer)

Adds a right-click menu option "View Image Exif Data" on any image. A new window displays embedded metadata such as camera make and model. Most social network photos have been stripped of metadata, but many blog and personal website images still contain it.

### User-Agent Switcher and Manager (addons.mozilla.org/firefox/addon/user-agent-string-switcher/)

Allows the browser to report a different identity to websites, such as a mobile operating system, a different browser, or a different OS. Use cases include accessing sites that restrict content to specific browsers or mobile devices. The menu allows selecting a browser (such as Edge), an OS (such as Windows 10), and a specific version, then clicking "Apply (container on window)." Clicking "Test UA" opens a page that confirms the active agent. Clicking "Restart" returns to the native default. The author notes that JavaScript-based fingerprinting on some sites can detect underlying hardware (touch points, video cards) and bypass the spoofing. A demonstration page at `https://inteltechniques.com/logger/` can be used to test what sites can observe.

### Image Search Options (addons.mozilla.org/firefox/addon/image-search-options/)

Adds reverse image search to the right-click menu on any image. Services available include Google, Bing, TinEye, Yandex, Baidu, Karma Decay (searches Reddit for image copies), imgOps, SauceNAO, IQDB, and WhatAnime.

### Resurrect Pages (addons.mozilla.org/en-US/firefox/addon/resurrect-pages/)

Adds a right-click option "Resurrect this page" that links to archived versions of the current URL from six sources: Google Cache, Google Cache Text Only, The Internet Archive, Archive.is, WebCite, and Memento Timetravel.

### Copy Selected Links (addons.mozilla.org/en-US/firefox/addon/copy-selected-links/)

After selecting text on a page and right-clicking, "Copy selected links" extracts all hyperlinks from the selection and places them in the clipboard. Applications include copying all friend profile links from a Facebook page, copying all external links from a Twitter profile, copying all video links from a YouTube channel page, and copying all auction links from eBay search results.

### OneTab (addons.mozilla.org/en-US/firefox/addon/onetab/)

Collapses all open tabs into a bookmark list on a management page. Groups are displayed in reverse chronological order with editable titles and timestamps. Tabs can be restored individually or all at once. "Share as web page" sends the group to OneTab servers and is not recommended. The export feature (plain text URLs) is preferred for transferring data. In Options, "Keep them in your OneTab list" prevents bookmarks from being deleted when restored.

### Stream Detector (addons.mozilla.org/en-US/firefox/addon/hls-stream-detector)

Detects embedded video streams in M3U8 (playlist) and TS (transport stream) formats that cannot be directly downloaded by right-clicking. When a page contains a stream, the extension icon shows detected stream URLs. Copying the master M3U8 URL allows download via VLC or Python tools discussed in the next chapter. The example used is a CNN video embedded in a Twitter event page. A secondary extension, The m3u8 Stream Detector (addons.mozilla.org/firefox/addon/the-m3u8-stream-detector), is mentioned as a fallback for sites where the primary extension does not pick up the stream.

### KeePassXC-Browser (addons.mozilla.org/en-US/firefox/addon/keepassxc-browser)

Connects Firefox to the KeePassXC offline password manager. When visiting a site with stored credentials, the extension presents matching entries from the local database and can auto-populate login fields. The extension only works when KeePassXC is installed on the same machine as the browser. Setup requires enabling Browser Integration in KeePassXC settings, specifying which browsers may access it, then connecting from the browser extension. Each entry in the database must include the exact URL with `https://` for the matching to work. All password transfer happens locally, never over the internet.

## Exporting and Importing Firefox Profiles

After configuring all add-ons, the full Firefox profile can be exported and imported into other Firefox installations to replicate the setup. The process: open the configured Firefox, go to Menu > Help > Troubleshooting Information, click Open Folder, close Firefox, and copy the profile files to a removable drive. On the destination machine, open Firefox, repeat the Troubleshooting Information path to find the profile folder, close Firefox, and paste the copied files, overwriting when prompted. This overwrites all existing bookmarks, extensions, and settings on the destination installation.

A pre-configured profile is also available for download from `https://inteltechniques.com/osintbook9/ff-template.zip` (username: `osint9`, password: `book143wt`). For Ubuntu Linux, Terminal commands using curl and unzip install it directly into the Firefox profile directory. For Windows and Mac, the zip is extracted and its contents are pasted into the Firefox profile folder found through Troubleshooting Information.

## Chrome

Chrome is included as a secondary option used only during live training events or when a Chrome-specific tool is required. Its speed and tab stability under load are cited, but it sends more usage data to Google than Firefox. Recommended hardening: use the "Clear browsing data" function regularly, disable Autofill and password saving. uBlock Origin should be installed on Chrome as well. The author recommends the Brave browser as the most privacy-respecting Chrome alternative if Chrome must be used at all.

## Tor Browser (torproject.org)

Tor (The Onion Router) routes traffic through relay servers, typically in other countries, masking the user's real IP address from websites visited. It runs as a modified Firefox browser. On launch, it connects to a Tor server and assigns a new IP for that session. Closing the browser disconnects from Tor. Speed is reduced and improves over time during a session. The author notes Tor is unnecessary for common services like Facebook, Twitter, or YouTube, but is appropriate when visiting personal websites or blogs of technically aware targets. Linux installation is covered in the next chapter. Windows and Mac use the Tor bundle from torproject.org with minimal setup.

## Bookmarklets

Bookmarklets are short JavaScript snippets saved as browser bookmarks that execute commands on the current page without navigating away. The pre-configured Firefox profile includes a "Bookmarklets" toolbar shortcut. Each bookmarklet is designed for a specific task.

FacebookID: Displays the Facebook User ID of the current profile.
FacebookGroupID: Displays the Facebook Group ID.
FacebookExpand: Attempts to expand all comments (may be slow or crash on large pages).
FacebookScroll: Loads and scrolls a Facebook feed before page capture.
TwitterScroll: Loads and scrolls a Twitter feed before page capture.
InstagramScroll: Loads and scrolls an Instagram feed before page capture.
PageScroll-Slow, PageScroll-Fast, PageScroll-Feed: Scroll variants for different page types for video capture.
ModifiedDate: Displays the last modification date of a static web page.
Cache-Google: Opens the Google Cache version of the current page.
Cache-Archive: Opens the Archive.org version of the current page.
Images: Opens a new tab showing all images from the current page.
Links: Opens a new tab showing all URL links from the current page.
WordFrequency: Lists all words on a page sorted by frequency.
Paywall: Opens a blocked news article via Outline.com in a new tab.
Right-Click: Enables right-click on sites that block it.
TextSelect: Enables copy-paste on sites that block it.
BugMeNot: Checks BugMeNot for public login credentials for the current site.
Tools: Opens the offline OSINT search tools on the Linux desktop.
Notes: Opens a blank note page whose content is stored locally and tied to the current URL, persisting across visits to that same URL. Rebuilding the VM or Firefox profile removes all note data.
