## Chapter 19: Online Maps (closing section)

### IntelTechniques Maps Tool

The author's custom Maps Tool accepts a physical address or GPS coordinates and submits queries to multiple satellite and street-view providers at once. Entering an address converts it to GPS coordinates, which populate fields for Google Map, Google Satellite, Google Street (all four cardinal directions), Bing Map, Bing Bird's Eye, and other providers. A "Populate All" button fills every coordinate field, and "Submit All" opens every imagery result in a separate browser tab. The tool eliminates the need to visit each provider individually. The author uses it in nearly every investigation where a location matters.

### Apple Maps via satellites.pro

The site satellites.pro is not an official Apple product but provides Apple Maps aerial imagery. A direct URL encodes the target coordinates and zoom level:

    https://satellites.pro/USA_map#41.94721,-87.656502,18

### Imagery Sources Demonstrated

Using Wrigley Field in Chicago as the example, the chapter shows results from: Google Satellite, Google Globe, Google Globe 3D (north, east, south, west), Google Street View (four directions), Bing Satellite, Bing Bird's Eye (four directions), Bing Street (four directions), Here Satellite, Zoom Earth, Zoom ESRI, Yandex Satellite, Descartes, Satellite Pro (Apple via satellites.pro), Mapillary, and Snapchat.

### Analyzing Shadows to Estimate Capture Date and Time

Shadows visible in satellite or any other images reveal approximately when the image was captured. The recommended tool is Shade Map (shademap.app). The analyst loads the target location in Shade Map, then drags a month slider until the simulated shadow direction matches the direction visible in the target image. After finding the matching month, the time-of-day slider is adjusted until shadow length and position align. In the Wrigley Field example, shadows extended directly east-west with no north-south component, consistent with late March at approximately 7:28 am Central time. Results should be reported as a range rather than a precise moment (for example, "shadows indicate capture between February and April from 7:00 to 8:00 am local time"). The same method applies to social media photographs when the approximate location and season are known.

### Scribble Maps (scribblemaps.com)

When a plain map is not enough (for a court case, client report, or documentation of social media posts tied to a location), Scribble Maps provides a free interface for annotating satellite or hybrid map tiles. The user navigates to the area of interest by typing an address, then adds shapes, lines, text, and images from a toolbar at the top of the map. The finished product can be printed, saved, or exported via the Menu button. Free Map Tools (freemaptools.com) is also recommended for advanced features such as drawing a radius around a point of interest.

## Chapter 20: Documents

### Three Classes of Document Intelligence

Documents fall into three categories. The first is documents that contain information about the target, such as PDFs the target may not know are publicly accessible. The second is documents created by the target that entered public view unintentionally. The third is document metadata, which is embedded data invisible in the file content but potentially revealing the computer name, username, software version, and network details of the creator.

### Google File-Type Searching

Google's "ext:" operator (Bing requires "filetype:") limits results to a specific file extension. Examples:

    site:inteltechniques.com ext:doc
    site:inteltechniques.com ext:docx
    ext:xls "OSINT"
    ext:xls OR ext:xlsx "John Doe"

To search all common document types at once:

    "OSINT" filetype:pdf OR filetype:doc OR filetype:xls OR filetype:xlsx OR filetype:docx OR filetype:ppt OR filetype:pptx OR filetype:wpd OR filetype:txt

Common extensions by application: Microsoft Word (DOC, DOCX), Microsoft Excel (XLS, XLSX, CSV), Microsoft PowerPoint (PPT, PPTX), Adobe Acrobat (PDF), Text (TXT, RTF), Open Office (ODT, ODS, ODG, ODP), WordPerfect (WPD).

The author recommends understanding manual queries rather than relying exclusively on the Google Custom Search Engine (CSE), because CSEs cap the number of results.

### Google Docs and Google Drive (docs.google.com, drive.google.com)

Google does not offer public native search of Drive files, but Google's search engine indexes most publicly shared files. Users who set a document's sharing to "anyone with the link" or fully public may not anticipate that the file will appear in search results. Queries run on google.com:

    site:docs.google.com "resume"
    site:docs.google.com "resume" "Williams"
    site:docs.google.com "Corey Trager"
    site:docs.google.com 865-274-2074

Document subtypes can be isolated:

    site:docs.google.com/presentation/d
    site:docs.google.com/drawings/d
    site:docs.google.com/file/d
    site:docs.google.com/folder/d
    site:docs.google.com/open

Since 2013, Google also stores user documents at drive.google.com, so every query should be repeated with that domain:

    site:drive.google.com 865-274-2074

### Microsoft Docs (docs.microsoft.com)

Less popular than Google Drive but hosts thousands of publicly visible files searchable via Google or Bing:

    site:docs.microsoft.com "resume"

### Amazon Web Services (amazonaws.com)

AWS servers host a large volume of corporate and individual files. The author notes this source produced much of the voter data discussed during the 2016 election. Search structure on Google:

    site:amazonaws.com ext:xls "password"
    site:amazonaws.com ext:pdf "osint"

Amazon CloudFront (cloudfront.net) is a content delivery network also searchable the same way:

    site:cloudfront.net OSINT

### Gray Hat Warfare (buckets.grayhatwarfare.com)

Gray Hat Warfare maintains a searchable index of over one billion files stored in publicly accessible AWS S3 buckets. Free users can search the first 350 million files. A search for "password" returns over 41,000 results. A search for "password xls" has produced files containing active credentials. Results must be opened carefully because files can be large. Direct search URL pattern:

    https://buckets.grayhatwarfare.com/results/password

### Google Cloud Storage (storage.googleapis.com)

Google Cloud Platform hosts business and personal files, with a growing number of publicly accessible sensitive documents. Example queries:

    site:storage.googleapis.com ext:xlsx OR ext:xls
    site:storage.googleapis.com "confidential"
    site:storage.googleapis.com "confidential" ext:pptx

### Presentation Repositories

Several platforms host publicly shared slide decks. SlideShare (slideshare.net) and ISSUU (issuu.com) offer native search. Prezi (prezi.com) does not. For all platforms, the recommended approach is a Google site: query:

    site:prezi.com "osint"

Other platforms in this category: Slidebean (slidebean.com), Slide Search (slidesearchengine.com), Author Stream (authorstream.com).

### Scribd (scribd.com)

Scribd shifted toward e-book sales after 2014 but its document archive remains accessible. It is particularly useful for business-related documents, including files that were never intended to be public. Searching "FOUO" (for official use only) returns hundreds of results. The uploader's profile is linked from every document page and shows other files that user has uploaded. Result filters allow sorting by language, size, file type, and upload date.

### PDF Drive (pdfdrive.com)

PDF Drive continuously crawls the internet and archives PDF files, including documents whose original sources have been removed. Search URL format:

    https://www.pdfdrive.com/search?q=osint

### WikiLeaks (search.wikileaks.org)

WikiLeaks publishes leaked sensitive and classified documents and provides native search. It became widely known after Army soldier Bradley Manning was arrested in 2010 for uploading classified government information to the site. Both government agencies and private organizations should monitor what appears on the site under their names.

### Cryptome (cryptome.org)

Cryptome publishes documents related to freedom of speech, cryptography, spying, and surveillance. It offers no internal search, so queries must go through Google or Bing:

    site:cryptome.org "osint"
    site:cryptome.org "bradley manning"

### Paste Sites

Paste sites were designed for programmers to share code via links, but hacking groups have repurposed them to publish stolen credentials, passwords, credit card numbers, and personal data. Most paste sites lack native search, so the Google site: operator is the primary access method. A previous Pastebin release included home addresses of police officers near Ferguson, Missouri during protests. Another release contained stolen bank credentials from Venezuela.

Pastebin no longer allows direct URL-based search, so Google indexing is required:

    site:pastebin.com "osint"

A full list of paste sites to query with the site: operator (format: `site:doxbin.org "osint"`): 0bin.net, clip.net, codepad.org, controlc.com, doxbin.org, dpaste.com, dpaste.de, dpaste.org, dumpz.org, friendpaste.com, gist.github.com, hastebin.com, heypasteit.com, ideone.com, ivpaste.com, jsbin.com, justpaste.it, justpaste.me, paste.debian.net, paste.ee, paste.centos.org, paste.frubar.net, paste.lisp.org, paste.opensuse.org, paste.org, paste.org.ru, paste.ubuntu.com, paste2.org, pastebin.ca, pastebin.com, pastebin.fr, pastebin.gr, pastefs.com, pastehtml.com, pastelink.net, pastie.org, p.ip.fi, privatebin.net, slexy.org, snipplr.com, sprunge.us, textsnip.com, tidypub.org, wordle.net, zerobin.net. New sites appear and disappear frequently.

### Document Metadata

Every document file contains embedded metadata not visible in the file body. This data commonly includes: the computer name where the document was created, the user account name, the software application and version, network information, creation and modification timestamps, and total editing time. Extracting this data can identify the author of a document even when no name appears in the visible content.

Online tools accept either an uploaded file or a URL pointing to a file already online. Files that are sensitive, locally stored, or contain classified information should not be uploaded to any online service. Online tools: Extract Metadata (extractmetadata.com), Jeffrey's Viewer (exif.regex.info/exif.cgi), ExifInfo (exifinfo.org), Get Metadata (get-metadata.com).

### ExifTool (exiftool.org)

ExifTool is a command-line utility pre-installed in the author's custom Linux virtual machine. It processes entire folders of files and outputs a CSV spreadsheet. Workflow for a folder of downloaded Word documents at ~/Desktop/Evidence:

    cd ~/Desktop/Evidence
    exiftool * -csv > ~/Desktop/Evidence/Report.csv

The resulting spreadsheet includes, for each file, the creator name, last-modified-by name, company field, application name and version, creation and modification dates, and total editing time. The example in the chapter shows four documents downloaded via a Google search for `ext:docx "osint"`, with one file attributed to an individual at a company listed as United States Army. The author describes this as valuable information that should be collected during every investigation involving obtained documents.

### FOCA (github.com/ElevenPaths/FOCA)

FOCA is a Windows-based GUI tool designed to search for, download, and extract metadata from documents in one workflow. Google and other search engines have blocked its automated search and download behavior, but local file metadata analysis still works. Installation: navigate to https://github.com/ElevenPaths/FOCA/releases, download the most recent zip file, extract it, and run the application. FOCA is appropriate when a GUI is preferred over ExifTool's command-line interface.
