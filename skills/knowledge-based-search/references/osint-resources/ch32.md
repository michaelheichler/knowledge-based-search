This chapter (Chapter 18 of the book) covers the full workflow for investigating an unknown telephone number using open-source methods. The approach moves from carrier-level data, to subscriber name lookup via caller ID services, to crowd-sourced and historical databases, and finally to search engine enumeration.

## Carrier and Line-Type Identification

The first step is determining the carrier and line type of a target number before attempting subscriber lookup. The tool scouttel/phone-number-lookup returns fields including administrative area levels (township, county, state), the operating company name, the line type (mobile, landline, or VOIP), and a ported flag. A ported value of false means the number has not moved from its original carrier. A risk rating and risk level are also returned. Higher risk scores indicate VOIP, call forwarding, or masked numbers that may not be assigned to a real individual.

## Reverse Caller ID: What It Is and Why It Works

Caller ID databases were originally maintained so that telephone systems could display the name of an incoming caller. Legacy landline systems received this data natively from carriers, but VOIP systems do not. Businesses using VOIP must purchase caller ID data from resellers. These resellers operate commercial lookup APIs, and many offer free trials that an investigator can use to query subscriber names. Bazzell reports that this technique, in his experience, has eliminated the need for court subpoenas to discover subscriber information for cellular numbers. He began using it in 2013 and found the accuracy on cellular numbers surprising.

The chapter notes that cellular numbers increasingly carry name data extracted directly from the cellular carrier. The name reflects the billing account, not always the person who uses the phone. In one case a subject was found under the name "Jennifer S," which she confirmed was exactly how she identified her account on a shared family plan. She did not know that name was transmitted with her outgoing calls.

## Caller ID Services: Ranked by Reliability

**Twilio** (twilio.com/lookup) is ranked first. It requires a free trial account. Google Voice numbers are accepted for the phone verification step during signup. The account begins with $15 credit. Searches cost $0.01 each, allowing approximately 1,500 queries per trial. After logging in, navigate to "Explore Products," find the "Lookup" feature, and bookmark that page. Selecting "Include caller name" is usually sufficient. Results include the CALLER NAME, CALLER TYPE, CARRIER NAME, and CARRIER TYPE. Bazzell considers this the single most reliable option.

**Telnyx** (telnyx.com) is ranked second. It provides a free trial with $5.00 credit, which Bazzell notes could last several years at typical investigation volume. Unlike Twilio, it cannot be queried through a simple URL. A curl GET request through Terminal is required, structured as follows:

    curl -X GET \
      --header "Content-Type: application/json" \
      --header "Accept: application/json" \
      --header "Authorization: Bearer XXXX" \
      "https://api.telnyx.com/v2/number_lookup/+1$data?type=carrier&type=caller-name"

The API key replaces XXXX, and the target 10-digit number replaces $data.

**Caller ID Service** (calleridservice.com) is ranked third. It offers a free account with approximately $0.12 credit (about 25 queries). Empty results are not charged. A temporary email and a Google Voice number are accepted during signup. After registration, a Username, Password, and Auth KEY are emailed. Queries are submitted as a URL in the browser:

    https://cnam.calleridservice.com/query?u=USERNAME&k=AUTH_KEY&n=PHONENUMBER

Bazzell recommends bookmarking this URL without the trailing number so that loading the bookmark does not consume a credit. This service tends to return older information, which can still be useful for historical context.

Several formerly recommended services have been removed. EveryoneAPI and OpenCNAM were acquired by Neustar and no longer offer free trials. BulkCNAM became Bulk Solutions with the same result. CIDName rarely approves new accounts. Service Objects offers only a one-week trial with poor results. Bazzell's conclusion is that numbers not found via Twilio or Telnyx are unlikely to appear in any of those removed services.

**Apeiron** (https://apeiron.io/cnam) is presented as a free, no-account alternative. Results are less comprehensive but useful when no trial accounts are available.

**Spy Dialer** (spydialer.com) and **Caller ID Test** (calleridtest.com) are also mentioned. Spy Dialer draws on crowd-sourced data and is useful for historical number information. Caller ID Test occasionally returns unique results but has unreliable availability and is described as a last resort.

## Caller ID Automation Script (cid.sh)

To avoid maintaining and manually modifying multiple browser bookmarks, Bazzell created a Bash script that queries Twilio, Telnyx, and Caller ID Service from the command line. Installation on a Linux OSINT VM:

    cd ~/Documents/scripts
    curl -u osint9:bookl43wt -O https://inteltechniques.com/osintbook9/cid.sh
    chmod +x cid.sh
    curl -u osint9:bookl43wt -O https://inteltechniques.com/osintbook9/cid.desktop
    chmod +x cid.desktop
    sudo cp cid.desktop /usr/share/applications/
    rm cid.desktop

After installation, open cid.sh and replace every instance of XXXX with actual API keys for each service. The script is then accessible from the Activities menu as "CallerID Tool." When run, it presents a numbered menu (Twilio, Telnyx, Caller ID Service), accepts a target number, issues the appropriate API call, and prints the result to Terminal. Multiple queries in sequence are supported without restarting.

## People Data Labs

The People Data Labs (peopledatalabs.com) API key used for email investigations also accepts telephone number queries. The query format is:

    https://api.peopledatalabs.com/v5/person/enrich?pretty=true&api_key=XXXX&phone=+16184620000

Results can include full name, birth year, gender, LinkedIn URL and ID, Facebook URL and ID, Twitter URL, work email, personal email addresses, education, and location history across multiple cities. Bazzell identifies this as the only service that reliably returns Facebook profile data from a telephone number. The free trial allows 1,000 lookups without expiration.

## Truecaller

Truecaller (truecaller.com) is a smartphone app that displays caller ID for incoming calls. Its database is crowd-sourced: when users install the app, they grant permission for their contact lists to be uploaded. The web interface allows searching this data using a covert Microsoft or Google account. The results show exactly how the number is labeled in other people's contacts. Bazzell tested this against his own government-issued cellular number and found "Mike Bazell" in the results, traced to another government employee who had his contact information. A real-world case cited in the chapter found "Drug Dealer Matt" when querying a homicide suspect's number, which narrowed three potential suspects to one and led to an arrest.

## Sly Dial

Sly Dial allows an investigator to reach a target's outgoing voicemail without ringing their phone. There is no website or account required. The method is to call 267-759-3425 (267-SLYDIAL) from any phone (landline, cellular, or VOIP), listen to a brief advertisement, and then hear the target's outgoing voicemail message. The call cannot be downloaded as audio. In Bazzell's testing, fewer than 5 percent of attempts cause the target phone to ring even once. The target cannot identify who called. The chapter cautions that if even this small risk of detection could compromise an investigation, the technique should be avoided.

## Old Phone Book

Old Phone Book (oldphonebook.com) provides historical White Pages landline listings from 1994 to 2014. The data originates from telephone CD-ROMs purchased by companies over several decades. Results include historic addresses tied to specific years, which can reveal when a person moved. Queries are submitted by year and number via direct URL:

    http://www.oldphonebook.com/searchphone2.php?syear=1994&sphone=6184620000

The chapter lists specific years available: 1994 through 1998, then 2001 through 2003, 2007, 2008, 2013, and 2014. The target 10-digit number replaces 6184620000.

## Telephone Search Websites

A large set of people-search websites accept telephone number queries. Data on these sites originates from property tax records, marketing databases, phone books, and data breaches. The chapter presents direct query URLs for 27 sites including 411.com, 800notes.com, Advanced Background Checks, America Phonebook, Caller Smart, Cyber Background Checks, Dehashed, Fast People Search, Info Tracer, John Doe, Numpi, Nuwber, OK Caller, People Search Now, Phone Owner, Reveal Name, Reverse Lookup, Search People Free, Spytox, Sync.me, That's Them, True People Search, US Phonebook, White Pages, WhoseNo, Yellow Pages, and Zabasearch. Bazzell also includes Google, Bing, and Yandex as direct query targets. He advises treating the results as "what you see is what you get" and not paying for data that free queries already provide.

## Search Engine Enumeration

Standard search engines are a useful but imprecise tool for telephone number research. A hyphen in a phone number can be parsed as an exclusion operator, and different websites format numbers differently, so a simple query misses many results. The recommended approach is to search all formatting variants, individually and combined with OR operators. For a target number such as 202-555-1212, numeric variants include the number with no separators, hyphens, dots, spaces, and parentheses in various combinations. Because some users spell out digits to evade spam filters or platform posting rules, spelled-out variants must also be searched:

    "two zero two five five five one two one two"
    "two zero two 555 1212"
    "202 five five five 1212"

The chapter's custom search tool compiles these into four combined OR queries run on both Google and Bing, opening eight browser tabs simultaneously.

## Craigslist Phone Search

Craigslist prohibits telephone numbers in certain post types, so users spell out digits to work around the restriction. Effective searches against craigslist.org must include both numeric and spelled-out variants:

    site:craigslist.org "314-555-1212"
    site:craigslist.org "314" "555" "1212"
    site:craigslist.org "three one four" "five five five" "one two one two"
    site:craigslist.org "314" "five five five" "1212"

The chapter notes this list extends further, with a custom tool to automate the variations.

## Overall Approach

The chapter argues that combining multiple caller ID services yields higher confidence than relying on any one source. Twilio and Telnyx are the primary workhorses. People Data Labs and Truecaller add profile depth. Sly Dial provides a voice fingerprint. Old Phone Book and the people-search sites add historical breadth. Search engine enumeration catches anything that has been posted publicly in any format. Spending a small amount (Bazzell spent $10 per service in 2019, yielding over 1,000 queries each) provides more lookup capacity than most investigations will exhaust.
