## Overview

This unit covers the final portion of Chapter 7 (Android Emulation) and the opening of Chapter 8 (Custom Search Tools). Chapter 7 details which mobile apps to install in a virtual Android device for investigations, explains the Genymotion emulator as an alternative to native VirtualBox Android, describes a contact exploitation technique, and covers cloning and exporting virtual devices for evidence control. Chapter 8 introduces self-hosted offline search tools as a replacement for third-party aggregator sites.

## Mobile Apps for Investigations (Chapter 7 continued)

### Snapchat

Snapchat is unreliable inside Genymotion. Connection may work with one account but not another. If the goal is only to search public posts, a traditional browser approach covered later in the book is preferable. Direct covert communication through the app requires testing and is hit or miss.

### Kik Messenger

Kik is a mobile-only instant messaging app modeled after BlackBerry Messenger. It transmits messages, photos, sketches, and web content over Wi-Fi or a data plan. A free account is required, after which any username or Kik number is searchable. Because Kik has no web version, an Android emulator is the only way to access it from a desktop investigation environment. The app has been documented as a venue for child exploitation. The author used an Android emulator to log in as a minor victim, continue conversations with a suspect, and capture screen recordings as prosecution evidence.

### TikTok

TikTok surpassed 2 billion mobile downloads by October 2020. Its website does not support native keyword search, but the mobile app does. Installing the app on the Android VM in advance prepares the investigator for techniques explained later in the book.

### TextNow

Virtual Android devices have no cellular connection and no phone number. TextNow assigns a virtual telephone number to the device and allows sending and receiving standard SMS messages. This keeps all communications inside the VM and consolidates evidence in a single archive.

### Truecaller

Truecaller is a reverse caller ID service accessible only through the mobile app. It identifies subscriber information for both cellular and landline numbers, with no limit on the number of searches. Alternatives include Mr. Number and Showcaller.

### Tinder

Tinder is a location-based dating app that recommends nearby users within a set radius. Login requires a Facebook account or a VOIP phone number. An investigator can spoof the device GPS to a target's known address, then search for users of the appropriate age and gender within one mile. If the target's profile appears, the target is near that location. If not, the GPS can be changed to other known locations (workplace, frequent bar) and the search repeated. This technique works from anywhere in the world. If the app cannot detect the spoofed location, a different GPS spoofing app may resolve the issue.

### Badoo, Blendr, Bumble, Skout, Down

These dating apps use separate user databases and apply the same location-based search method as Tinder. Some do not require a Facebook account or phone number, providing additional options when Tinder is unavailable. The author used the Down app during a cheating spouse investigation by connecting through a covert female Facebook profile that had already been accepted as a friend by the subject. Swiping "Down" on the subject's profile triggered a chat later used in litigation. Beyond individual targets, these apps can document everyone present near a specific location, which has been used to contradict denials of presence at a crime scene.

### Secure Communications Apps

Suspects in sensitive investigations often refuse to communicate by standard SMS. Familiarity with ProtonMail and Wire, which are common in criminal and trafficking communities, allows an investigator to make contact through channels the subject trusts. Installing these apps inside the Android VM keeps evidence contained and the host machine protected. Multiple accounts can be maintained, with login occurring only after cloning the machine.

### Secure Eraser

As apps update, the VM accumulates deleted files that consume space without contributing data. Secure Eraser removes these files. The process: on the master copy, after all software is updated, open Secure Eraser, change the wipe mode from "Random" to "0000-0000", click Start, and let it complete. Then restart, clone, or export. The original remains large but the clone reflects the reduction. The author's example: an 18 GB original produced a 6.5 GB clone that was functionally identical.

## Genymotion Setup

Genymotion is an application-based Android emulator that works on Windows, Mac, and Linux. Many readers report that it loads faster and feels smoother than a native VirtualBox Android build. It introduces privacy and licensing considerations that native VirtualBox does not. Both approaches are worth maintaining.

### Installation

1. Create a free account at genymotion.com (alias information is acceptable). Login is required to use the application.
2. Download Genymotion Personal Edition from genymotion.com/fun-zone. Choose the version without VirtualBox if VirtualBox is already installed.
3. Install on the HOST operating system, not inside a VM.

### Creating a Device

1. In the left menu, expand "Android API" and select the highest number (10.0 at the time of writing).
2. Choose a device on the right (for example, "Google Pixel XL"). Click "Add custom device".
3. Rename the device (for example, "Android 10.0 Original"). Set Android Version to the highest option. Click "Install".
4. Double-click the device to launch it. Click OK to any feature notifications.

### Initial Configuration

- Display > Sleep: 30 Minutes.
- Security > Screen Lock: None.
- In VirtualBox, set Video Memory to maximum and RAM to half of system resources.

### Installing Google Play (OpenGApps)

1. Inside the running device, click the "Open GzXPPS" icon in the upper right. Accept the agreement and allow Google Apps to install. Restart.
2. The browser opens to https://opengapps.org/?source=genymotion. Select ARM64, the Android version created (for example, 10.0.0), and "Stock". Download the zip file. Do not open or unzip it.
3. Drag and drop the zip file into the running Android device. Accept any warnings. Restart.
4. Google Play Store appears in the applications menu. Log in with an anonymous Google account created beforehand on a traditional computer. Creating a new Google account from inside the VM typically triggers a phone verification requirement. Once synced, all core Google services are available.

If an app refuses to install due to device incompatibility, the F-Droid and Aurora Store technique described in the previous chapter is an alternative.

### Genymotion GPS Spoofing

Click the GPS icon in the right-side panel and toggle it on. Enter exact coordinates or click "Map" to pick a location on an interactive Google map. Set altitude, accuracy, and bearing to "0". A green check mark confirms the spoofed location is active. Apps that use location will report the spoofed position.

### Genymotion Panel Features

Free-tier features: GPS spoofing, GAPPS indicator (confirms Google Services are installed), battery indicator (cosmetic only), webcam passthrough, screen rotate, volume up and down, Back, Home, Recent Apps, Menu, and Power buttons.

Paid-only features: Screen Capture, Remote Control, Identifiers, Disk I/O, Network Configuration, Phone, App Sharing, and Pixel Configuration.

Non-commercial use of the free personal edition is unlimited. The paid license is required only when designing apps for profit through the product.

## Contact Exploitation Technique

Many apps prompt users to invite friends and request access to the device address book to find existing users. Investigators can exploit this by adding a target's cellular number (or email address) to the Android VM's contact list under any name. Apps then treat the target as a known contact and surface account connections that would otherwise be blocked.

Information that can be revealed through this technique:

- The Facebook account name linked to the phone number (via Facebook "Find Friends").
- Google Play purchases and reviews linked to the account.
- The Twitter account name linked to the number (via Twitter "Find Friends").
- WhatsApp username and number registered to that cellular number.

Example with Signal: register Signal using a Google Voice number, add the target's cellular number to the contacts, then use Signal's "Find Friends" feature. Signal confirms whether the target has an active account. Opening a message compose window to that number (without sending) may display the name the target chose for the account.

## Virtual Device Cloning

A fresh clone should be used for each investigation so that prior activity from one case does not contaminate another. The master copy is only opened to apply updates.

### Clone Procedure

1. Configure the master Android VM with all desired apps. Run Secure Eraser to reduce file size. Shut down the machine.
2. Open VirtualBox, right-click the machine, and choose "Clone".
3. Provide a name (for example, the case number "2021-1234"). Select "Full Clone" and "Current machine state". Click Clone.
4. VirtualBox creates an exact duplicate. Right-click the new machine and choose "Show in Finder" (Mac) or "Show on disk" (Windows) to locate the file.

Changes made inside a clone have no effect on the original.

### Evidence Export for Discovery

In legal proceedings, investigators may be required to produce the entire digital investigation environment. VirtualBox supports this through appliance export.

1. In VirtualBox, select the VM. Choose File > Export Appliance. Select the device, provide a save location and file name.
2. Click Export. The result is a single file containing the complete virtual OS, applications, and all investigation data.
3. The file can be archived to DVD or flash media.
4. Another investigator imports it via File > Import Appliance to view the exact environment used during the investigation.

## Alternative Android Emulators

BlueStacks (bluestacks.com), Andy (andyroid.net), and NoxPlayer (bignox.com) offer similar functionality. Most rely on VirtualBox on the back end. Native VirtualBox is preferred by the author because its import and export process is transparent and more readily accepted in court. The author maintains both a native VirtualBox Android 9.0 and a Genymotion 10.0 device.

## Summary Note on Mobile OSINT

Many social network services now exist only as mobile apps with no web equivalent (Kik is the primary example). Accessing them requires an Android emulator. Apps may block access from virtual devices due to fraud detection. Occasional failures are expected, but investigation successes through virtual Android environments justify the effort. The author recommends practicing with non-essential apps before using these techniques in a real investigation.

## Custom Search Tools (Chapter 8 Introduction)

### Background

From 2010 through 2019, the author offered a set of free public online search tools. These were removed in June 2019 due to abuse and legal demands. The author then produced an offline version distributed with the previous edition of this book. Chapter 8 revisits and enhances those tools, providing a way for investigators to create and maintain their own search tools that run locally without reliance on any third-party site.

The core problem with third-party aggregated search tools: they can disappear without notice, they may collect data about every search, and they typically embed tracking cookies and analytics. Self-hosted local tools eliminate the middle layer. Queries still go to the final data source (the target service), but not through an intermediate aggregator.

### Obtaining the Tool Templates

URL: https://inteltechniques.com/osintbook9/tools.zip
Username: `osint9`
Password: `bookl43wt` (without quotes, if a login prompt appears)

The zip file contains a folder titled "Tools" with multiple HTML files. The Linux, Mac, and Windows OSINT builds described earlier in the book already include these files on the Desktop. Extract all files to the Desktop or any consistent location.

### How the Tools Work

Double-clicking any HTML file opens it in the default web browser. No server is required. Each file is a self-contained offline form that submits queries directly to the target service. The Email tool, used as a demonstration, accepts an email address and provides individual search buttons for each source as well as a "Submit All" button that queries all sources at once.

### Editing the Tools

Open any `.html` file in a plain text editor: TextEdit on Mac, Notepad on Windows, Text Edit on Linux, or Atom (atom.io) as a cross-platform option.

Key sections of the HTML:

- The `<!DOCTYPE htmlxhtml>` declaration opens the page and informs the browser it is a web page.
- The `<style>` block controls colors, sizes, and layout. Modifying it does not affect function. Example properties define background colors for navigation elements and vertical alignment for table cells.
- The `<head>` section follows the style block (the file is truncated at this point in the source text).

Investigators are expected to maintain these files over time: removing broken links, adding new query targets, and updating URLs when third-party sites change their structure.
