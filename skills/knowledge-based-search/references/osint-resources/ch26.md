## Reddit: Recovering Deleted Content

### Pushshift Archive

Pushshift (files.pushshift.io) archives Reddit data including most posts that have since been deleted. Its API allows targeted queries without downloading the full archive.

Core query patterns (substitute "submission" for "comment" to switch between post types):

- All archived comments by a user: `https://api.pushshift.io/reddit/search/comment/?author=inteltechniques`
- Sort ascending: append `&sort=asc`
- Keyword search across all Reddit: `https://api.pushshift.io/reddit/search/comment/?q=inteltechniques`
- Restrict to a single subreddit: `https://api.pushshift.io/reddit/search/comment/?q=inteltechniques&subreddit=privacy`
- Time-bounded search (5 to 30 days before the query): `https://api.pushshift.io/reddit/search/comment/?author=inteltechniques&after=30d&before=5d`

Results return the full text body, subreddit location, author, and a Unix timestamp (convert at unixtimestamp.com). A user who posted on Twitter that they deleted their Reddit account was confirmed via Pushshift: the deleted comment and its full context were both recoverable.

An online front end, RedditSearch (redditsearch.io), provides a simpler interface for the same data.

### Imgur and Reddit Images

Most Reddit image posts link to Imgur (imgur.com). When a Reddit post is deleted, the linked Imgur image often remains live. Browse all images associated with a subreddit at `https://imgur.com/r/netsec` (replace "netsec" with any subreddit name). Scrolling loads older images in reverse chronological order.

To trace an image back to a deleted Reddit post, extract the image filename (e.g., J0C7Mi9 from `https://i.imgur.com/J0C7Mi9.jpg`) and search it through Pushshift:

- `https://api.pushshift.io/reddit/search/submission/?q=J0C7Mi9`
- `https://api.pushshift.io/reddit/search/comment/?q=J0C7Mi9`

This returns author, timestamp, and the original Reddit link for deleted posts.

### Reddit-Specific Reverse Image Search

Karma Decay (karmadecay.com) performs reverse image searches restricted to Reddit. Supply an Imgur URL directly in the browser or use the URL format `http://karmadecay.com/imgur.com/r/funny/ODnElaB`. Karma Decay blocks pornographic content. For adult images, use NSFW Reddit Reverse Image Search (i.rarchives.com) via URL submission: `http://i.rarchives.com/?url=http://i.imgur.com/mhvSa.jpg`.

## Investigation Subreddits

Three communities provide direct value for investigators.

**Reddit Bureau of Investigation (reddit.com/r/rbi)** is an active community where users help solve crimes and locate people. In 2013, the author helped a northern Illinois police department in a fatal hit-and-run case by posting three vehicle fragments to RBI. Community members traced them to a specific year and model within minutes, leading to an arrest. In a separate case, a blurry photo of a suspect vehicle was posted and a Reddit user identified the license plate through digital correction.

**Pic Requests (reddit.com/r/picrequests)** connects requesters with digital photo experts who enhance, repair, and clarify images. The author has used this subreddit to identify digits in blurred license plates and to lighten dark surveillance footage into usable evidence.

**What Is This Thing (reddit.com/r/whatisthisthing)** identifies unknown objects from photos, including tattoos, graffiti, mailed items, and vehicle parts. In a 2012 death investigation, the author submitted a sanitized photo of a tattoo with Chinese symbols. Within five minutes a user identified the symbols, their meaning, and their regional origin in China. A reverse image search of that output led to information about a human trafficking ring linked to the victim.

When posting to any of these communities, use an established account rather than a brand-new one, never be demanding, and only share images already in the public domain or already released to the press.

## 4chan (4chan.org)

4chan is an anonymous image-board split into topic-specific boards, modeled after Japanese image-boards. The "/b/" (Random) board is the oldest and most trafficked. The site has no native search. Third-party search options using "OSINT" as an example query:

- Active boards: `http://4chansearch.com/?q=OSINT&s=4`
- Archives: `http://4chansearch.com/?q=OSINT&s=7`
- Archive alternative: `https://archive.4plebs.org/_/search/text/OSINT/order/asc/`
- Google: `https://www.google.com/search?q=site:4chan.org%20OSINT`

## Hacker News (news.ycombinator.com)

Hacker News is a tech-oriented community with millions of daily users. Direct URL patterns for targeted queries:

- Text search: `https://hn.algolia.com/?query=OSINT&type=all`
- User profile: `https://news.ycombinator.com/user?id=inteltechniques`
- User submissions: `https://news.ycombinator.com/submitted?id=inteltechniques`
- User comments: `https://news.ycombinator.com/threads?id=inteltechniques`
- User favorites: `https://news.ycombinator.com/favorites?id=inteltechniques`
- Google: `https://www.google.com/search?q=site:news.ycombinator.com+OSINT`

## TikTok (tiktok.com)

TikTok is a Chinese-owned video-sharing platform with 3-to-60-second clips. Comments require login. The native search is unreliable and URL-based queries are more reliable.

Direct URL patterns (using "osint" or "inteltechniques" as examples):

- User profile: `https://www.tiktok.com/@inteltechniques`
- Username search (partial match): `https://www.tiktok.com/search/user?q=osint`
- Hashtag search: `https://www.tiktok.com/tag/osint`
- General keyword search: `https://www.tiktok.com/search?q=osint`
- Video-only search: `https://www.tiktok.com/search/video?q=osint`
- Google (can surface deleted posts): `site:tiktok.com osint`
- Current live streams: `https://www.tiktok.com/live`

Each TikTok profile source code contains three identifiers: `authorld` (a numeric user ID), `uniqueId` (the handle), and `nickname` (a vanity display name that is not unique and can be reused). The numeric user ID is stable across username changes and is useful for search-engine queries.

Individual post URLs follow the format `https://www.tiktok.com/@willsmith/video/7032216839878905134`. To find the exact upload timestamp, view the page source and search for "tplv". The number immediately before that string is a Unix timestamp (convert at unixtimestamp.com). For example, the value `1637781925~tplv` converts to Wed Nov 24 2021 19:25:25 GMT+0000.

To export comments, use Export Comments (exportcomments.com), which retrieves the first 100 comments without a premium account.

Analytics services that accept a username in the URL include mixemo.space, exolyt.com, and mavekite.com. These return follower count, following count, total likes, average post comments, average plays, average shares, engagement rate, bio details, profile image, recent posts, and follower growth charts.

TikTok appears in investigations involving targets under approximately 20 years of age.

## Nextdoor (nextdoor.com)

Nextdoor is a geographically restricted community. Residents of one neighborhood cannot see posts from other neighborhoods. Joining requires either an invitation from a neighbor or a verification letter sent by postal mail to a neighborhood address. To expand coverage, log in, navigate to Settings, then Neighborhoods, and click "Explore Neighborhoods" to join surrounding areas. In the author's experience, joining all available adjacent groups allows viewing most of a county.

## Meetup (meetup.com)

Meetup connects users around in-person events grouped by interest and location. Group pages list members, upcoming events, past events, and attendee feedback. User profiles often link to social networks and list future planned events, which has made the site useful for civil process servers, detectives, and journalists locating people who are avoiding contact.

Meetup no longer offers a native username search. Use Google instead:

- Name search: `site:meetup.com inurl:member john morrison`
- Event search: `site:meetup.com inurl:events Protest`
- Discussion search: `site:meetup.com inurl:discussions Protest`
- General keyword: `site:meetup.com OSINT`

Membership is free and does not require real personal information.

## Dating Websites

Dating profiles often contain personal information a target keeps off mainstream social networks. A free account is typically sufficient to browse profiles. A paid account is usually needed to contact anyone. Targets who use one dating service often use others.

Three search techniques apply across all dating platforms:

**Username search.** Dating sites require a username, which is searchable. Many users reuse usernames from other accounts. A dating profile hiding a real name may share a username with a Twitter account that reveals name, location, and contacts.

**Text search.** Profile bio fields are freeform and often contain distinctive phrasing or grammatical errors. Many users copy the same bio across multiple platforms. In a 2013 sexual assault case, the author found the suspect's real Match.com profile (with his real name and high-quality photos) by pasting a unique, poorly worded sentence from his fake Plenty of Fish profile into a Google quoted search.

**Photo search.** Reverse image searching a dating profile photo across multiple platforms frequently converts an anonymous profile into an identified social media account.

Common dating platforms: Match (match.com), Plenty of Fish (pof.com), eHarmony (eharmony.com), OKCupid (okcupid.com), Christian Mingle (christianmingle.com), Ashley Madison (ashleymadison.com), Adult Friend Finder (adultfriendfinder.com), Farmers Only (farmersonly.com), Elite Singles (elitesingles.com), Zoosk (zoosk.com), FriendFinder-X (friendfinder-x.com), Badoo (badoo.com).

## Tinder

Tinder matches users by geographic proximity. It was originally mobile-only and a web interface now exists but is difficult to use covertly.

Web access requires either a Facebook account (not recommended for covert accounts) or a mobile phone number. Google Voice numbers are usable but trigger extra verification steps. Tinder's captcha for VPN users involves completing a series of 20 small tasks and fails nearly 100% of the time even after correct completion. Tinder also blocks GPS spoofing within the browser. The web interface is therefore largely ineffective for investigative use.

The author's preferred method uses a dedicated Android device with the Tinder app and the "Fake GPS Location" app installed, logged in with a covert Google Voice number. Before opening Tinder, set the spoofed GPS location. Then limit the search radius to a few miles around the target's known location. This method does not work on iPhone (GPS spoofing is restricted) and does not work through emulators such as VirtualBox or Genymotion (Tinder actively blocks them).

Web-based account setup, if attempted: connect via public Wi-Fi without a VPN near the target location, choose "Log In With Phone Number," supply a Google Voice number, confirm the SMS code, and complete registration with an alias and photo.

For profile photos, the author uses Fiverr (fiverr.com) to pay real people a few dollars for unique photos of themselves.

Two cases illustrate the method. In a human trafficking case, the author spoofed GPS to a motel address, found apparent minor profiles being promoted by a pimp, initiated a conversation, received a price and room number, and local officers made arrests. In a cheating spouse case, the author spoofed GPS to the suspect's office, posed as a woman, matched with the target, and collected evidence from the conversation.
