Chapter 12 covers Instagram as an OSINT target, with over one billion active monthly users. The platform centers on photo and video sharing and is owned by Facebook. The chapter addresses how to find and extract data from Instagram profiles, posts, followers, and third-party tools, and explains why manual source-code methods matter for legal investigations.

## Native Search Limits

Instagram has no keyword search on its homepage. Searching within Instagram only matches usernames and hashtags, not post content. Bazzell recommends Google with site-specific queries instead.

The query `site:instagram.com "OSINT"` returns indexed posts mentioning that term in titles or comments. The same search inside Instagram returns only users with the term in their username.

Finding a person by name works better with Google. Searching `site:instagram.com darren hak5` surfaces the profile `@hak5darren`, while searching the full name on Instagram returns unrelated accounts. Once a username is known, `site:instagram.com "hak5darren"` finds all indexed pages containing it. The query `site:instagram.com "@hak5darren"` narrows results to posts where others address the target directly. Adding keywords finds specific content, for example `site:instagram.com "hak5darren" "pager"`. Repeating all queries on Bing and Yandex improves coverage.

## Twitter Cross-Reference

Many users share Instagram posts on Twitter. Instagram only protects accounts as private, not individual posts. A private account holder who shares a post URL on a public Twitter account exposes that post to anyone with the link. The query `site:twitter.com "hak5darren" "instagram.com/p"` finds Instagram post links shared on Twitter by or about a target.

## Hashtags

A hashtag is a word or phrase preceded by `#` used to group content by topic. Direct hashtag searches are available at `https://www.instagram.com/explore/tags/osint/`. Bazzell gives little weight to hashtag searches because people frequently omit the `#` symbol, so a hashtag-only approach misses those posts. Keyword search via Google is more reliable.

## Retrieving High-Resolution Images

Instagram compresses displayed images and blocks standard right-click access to image files. Obtaining higher-quality versions requires reading page source code.

For a profile image, open the page source (via "View Page Source" or `view-source:https://www.instagram.com/hak5darren/`), search for `og:image`, and copy the CDN URL found there. That URL contains the segment `s150x150`, indicating a 150-pixel thumbnail. Search the same source for the number appearing just before `.jpg` in that URL (for example, `1916767107`). The third match containing that number holds a URL with `s320x320`. Copy that URL and replace every instance of `\u0026` with `&`. The modified URL loads a 320-pixel version of the profile image.

For post images, view page source of a post URL and search for `1080`. This identifies a CDN URL containing `s1080x1080`. After replacing `\u0026` with `&`, the URL loads the full 1080-pixel image, which can be right-clicked and saved. Three third-party sites automate this process: `instadp.org`, `instadownloader.co`, and `instaoffline.net`. Bazzell recommends understanding the manual method regardless, because courts may require an explanation of how evidence was captured.

## Metadata in Page Source

Instagram allows users to change their username but not their user ID number. To find the user ID, view the profile page source and search for `"owner": {"id"`. The numbers following that string are the permanent user ID. For `@hak5darren` the user ID is `340416780`.

If a username has changed and only the user ID is known, the Instagram API can return current account details, but it requires spoofing a mobile user-agent first. In Firefox with the User-Agent Switcher and Manager extension, set the second drop-down to "Android" and the first to "Instagram", select the first option, click "Apply", then navigate to `https://i.instagram.com/api/v1/users/340416780/info/` (substituting the target's user ID). The response includes `username`, `full_name`, `is_private`, `media_count`, `follower_count`, `following_count`, `external_url`, `has_videos`, and `is_business`.

Instagram displays only the date of a post, not the time. The exact timestamp is embedded in page source as a Unix timestamp under `taken_at_timestamp`. The value `1549225611`, for example, converts to February 3, 2019 at 8:26:51 PM UTC at `epochconverter.com`. The timestamp of an individual comment is stored under `"created_at":` and is findable by searching for a text fragment of the comment. The site `unixtimestamp.com` performs the same conversion. Bazzell notes that user ID and exact timestamps are critical for legal process.

## Followers and Following Lists

Viewing follower and following lists requires a logged-in account. After clicking "Followers" or "Following" on a target profile, scroll down completely to load all accounts. The window displays only ten at a time and caps at 1,000 entries. Press `Ctrl+A` on Windows or Linux, or `Cmd+A` on Mac, to select all content in the window. Right-click and choose "Copy selected links" to copy all profile URLs to the clipboard, then paste into Excel or LibreOffice Calc. Each row is one account URL.

A GraphQL API alternative exists using the target's user ID, but it returns only 50 random profiles and is less reliable than the manual approach.

## Likes and Comments

Clicking the like count below the heart icon on a post (for example, "557 Likes") opens a list of every account that liked it. Scrolling through loads the complete list. The same `Ctrl+A` and copy method captures it for a spreadsheet. The same procedure applies to comments. Bazzell cautions against clicking the heart icon itself, which would like the post from the investigator's account.

Comment timestamps are not displayed in the standard view. Instagram shows relative time such as "102w" (102 weeks ago). The exact time is in the post's page source. Search for a text fragment of the comment to locate `"created_at":` followed by a Unix timestamp.

## Tagged Posts

Posts in which a target has been tagged by others are accessible at `https://www.instagram.com/hak5darren/tagged/`.

## IGTV Video Channels

Instagram's video channel feature (IGTV) is accessible at `https://www.instagram.com/ambermac/channel/`. To download a video without third-party tools, open the video page in Firefox or Chrome, open Developer Tools by right-clicking and selecting "Inspect Element", click the Network tab, play or reload the video, and type `mp4` in the filter field. One URL should remain. Right-click it and select "Open in New Tab". The new tab loads the video in full resolution, where it can be saved by right-clicking.

## Complete Post Analysis Workflow

For a high-priority post Bazzell outlines a full manual process. The investigator first downloads all profile images using Instaloader or Instalooter (described in earlier chapters), then continues with the following steps.

Extract the 1080-pixel post image from page source. Scroll through all comments and expand collapsed ones by clicking `+`. Click the like count, scroll until all accounts are loaded, select all (`Ctrl+A` or `Cmd+A`), copy, and paste into a spreadsheet tab named after the post's short ID (for example, `BKlKWEthQkb`). Navigate to the target's profile and click "Followers". Load, select all, copy, and paste into a tab labeled "Followers". Repeat for "Following". On the target profile, scroll until all posts load, select all, right-click and choose "Copy selected links", and paste into a tab labeled "Posts".

The result is a spreadsheet with tabs covering one post's likes and comments, the account's followers, the accounts it follows, and every post URL. Bazzell notes this level of effort is not warranted for every investigation and that no reliable automated solution extracts all of this data.

## Third-Party Search Tools

Search My Bio (`searchmy.bio`) indexes Instagram account biographies and makes them searchable. Bios often include email addresses, Snapchat usernames, locations, and other contact details. A search for `gmail.com` in this tool returned over 312,000 profiles with an email address in the bio.

For Instagram Stories (photos or videos up to 15 seconds that disappear after 24 hours), two tools are noted. InstaFollowers (`instafollowers.co/download-instagram-stories`) displays active Stories and Stories Highlights (content that has already expired from the standard Stories slot) and provides a Download button per item that links to the Instagram CDN host. Ingramer (`ingramer.com/tools/stories-viewer/`) offers similar functionality but limits users to three free searches per day.

## API Restrictions and Tool Stability

Instagram tightened its API on June 1, 2016, eliminating most useful third-party search tools at that time. Further restrictions in 2018 and 2020 again disrupted third-party tools. The landscape of available tools changes frequently, and Bazzell's own Instagram tools page required rebuilding multiple times after these changes.
