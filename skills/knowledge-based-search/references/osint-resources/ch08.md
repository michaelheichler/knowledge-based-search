## Overview

This unit covers custom Bash scripts that wrap Terminal-based tools into graphical menus within an Ubuntu OSINT virtual machine. Zenity provides the dialogue windows, file pickers, and progress indicators so that investigators can run complex commands without typing in Terminal. The chapter covers three major tool groups: video manipulation and conversion via FFmpeg, live and pre-recorded stream archiving via Streamlink, and Instagram data collection via Instalooter, Instaloader, Toutatis, and Osintgram. The unit also begins coverage of bulk image collection via Gallery-DL.

## Script and Shortcut Structure

Each tool group follows the same pattern. A Bash script (`.sh`) resides in `~/Documents/scripts/`. A desktop entry file (`.desktop`) is copied to `/usr/share/applications/` to make the tool appear in the Applications menu. Users pin tools to the Dock by right-clicking the entry and selecting "Add to favorites." These files are included in the "vm-files" download archive and are placed automatically by the setup commands described earlier in the chapter.

Installation warnings: some applications fail to install on the first attempt due to missing dependencies. Repeating the commands often resolves the issue. Pip version warnings displayed during installation typically do not affect function. All Pip commands from this point in the book append the `-I` flag (`--ignore-installed`) to bypass errors from previously cached older dependencies.

## Video Utilities (FFmpeg)

FFmpeg is a Terminal utility that can manipulate video files in ways that standard players cannot. The unit presents each capability as a manual command, then explains how a script called `ffmpeg.sh` wraps all of them in a single Zenity radio-list menu. Assume the target file is named `evidence.mpg` and the working directory is `~/Desktop`.

**Play a video:** `ffplay evidence.mpg`
Forces FFmpeg to attempt playback with multiple codecs. This can open videos that Windows Media Player and VLC cannot, including some surveillance formats and corrupt files. The author used this to play a corrupt homicide video that standard players could not read.

**Convert to MP4:** `ffmpeg -i evidence.mpg -vcodec mpeg4 -strict -2 evidence.mp4`
Converts the file to a universally playable format. Used to send surveillance video copies to prosecutors on Windows machines.

**Extract frames:** `ffmpeg -y -i evidence.mpg -an -r 10 img%03d.bmp`
Saves one uncompressed bitmap file per frame at 10 frames per second to a new folder alongside the original. The author uses this for every crucial prosecution video to allow frame-by-frame examination.

**Shorten video, low activity:** `ffmpeg -i evidence.mpg -strict -2 -vf "select=gt(scene\,0.003),setpts=N/(25*TB)" evidence.mp4`
Removes frames that are nearly identical to the preceding frame, keeping only frames with visible change. Suited to static surveillance scenes with long periods of no movement.

**Shorten video, high activity:** same command with threshold `0.005` instead of `0.003`
More aggressive removal. Better for outdoor surveillance with people in the distance or video with a time counter printed on the feed.

**Extract audio:** `ffmpeg -i evidence.mpg -vn -ac 2 -ar 44100 -ab 320k -f mp3 evidence.mp3`
Saves a 320k MP3 alongside the original. Used for audio from video confessions, interviews, and downloaded online videos.

**Rotate video:** `ffmpeg -i evidence.mpg -vf transpose evidence.mp4`
Rotates 90 degrees counterclockwise and flips vertically, correcting mobile device portrait video for courtroom presentation.

**Download a stream:** `ffmpeg -i http://somesite.org/867asfjhg87.m3u8 -c copy evidence.mp4`
Downloads a video file from an embedded stream URL. This requires knowing the exact stream URL in advance.

The `ffmpeg.sh` script opens a Zenity notification, then a file picker, then a menu. It generates timestamps via `$(date +%Y-%m-%d::%H:%M)` and saves all output to `~/Videos/`. After completion it opens the Videos folder in Nautilus. The corresponding `.desktop` file sets the script as the executable and points to an icon at `~/Documents/icons/ffmpeg.png`.

## Video Stream Tool (Streamlink)

FFmpeg's stream download option requires the exact M3U8 URL. Streamlink provides a complementary approach: given a platform page URL, it can often identify the stream automatically without needing the direct URL.

**Install:** `sudo -H pip install streamlink`

**Display a live stream (Twitch example):** `streamlink https://www.twitch.tv/shroud best`
Plays the best available quality through VLC.

**Record to file without playback:** `streamlink https://www.twitch.tv/shroud best -o shroud-stream`

**Play and record simultaneously:** `streamlink https://www.twitch.tv/shroud best -r shroud-stream`
(Uses `-r` instead of `-o`.) After the stream ends or the user presses Ctrl-C, the raw file can be converted: `ffmpeg -i shroud-stream -c copy ~/Videos/shroud-stream.mp4`

The unit demonstrates both failure and success with KTLA's news stream. Providing the generic page URL (`ktla.com/on-air/live-streaming`) returned "No plugin can handle URL." Providing the direct M3U8 URL captured by the Stream Detector Firefox extension (from `anvato.net`) succeeded immediately. The recommended workflow is to use Stream Detector to capture the underlying URL, then pass that URL to Streamlink.

Streamlink works well with Twitch and Vimeo but fails on some sites. The author treats it as one of the best available options while acknowledging it is not perfect.

The `streamlink.sh` script presents four Zenity options: Display Live Stream, Record Live Stream, Play and Record Live Stream, and Convert Stream to MP4. All recordings are saved to `~/Videos/`.

## Instagram Tool

Instagram actively blocks automated, unauthenticated access and delivers lower-resolution images to unauthenticated requests. The unit installs four programs to provide redundant options when individual tools fail or are blocked.

**Instalooter:** `sudo -H pip install instalooter`
Downloads media from a user's profile. Saves individual images to the current directory.

**Instaloader:** `sudo -H pip install instaloader`
Similar to Instalooter but creates a folder named after the target. Both tools support optional credential flags for authenticated access.

Without login:
```
cd ~/Desktop
instalooter user mikeb
instaloader user mikeb
```

With login (higher resolution, fewer blocks):
```
instalooter login -u [username] -p [password] user mikeb
instaloader --login [username] -p [password] user mikeb
```

**Toutatis:** `sudo -H pip install toutatis`
Extracts account details including an obfuscated phone number. Requires an Instagram Session ID rather than a password.

To find the Session ID: log in to Instagram in Firefox, right-click the page and choose Inspect, click the Network tab, navigate to any user's page, click a "200 GET www.instagram.com" entry in the Network list, click the Cookies tab in the right pane, scroll to `sessionid:`, and copy the alphanumeric value.

Command: `toutatis -u mikeb -s 24316:Lh59ygrmY4N:4`

Example output:
```
Full Name: Mike Brandon | userID: 1144153003
Verified: False
Is business Account: False
Is private Account: False
Follower: 70  Following: 31
Number of posts: 18
Obfuscated phone: +44 **** ****77
```

**Osintgram** is described as the most powerful of the four. Installation requires cloning from GitHub and running `make setup`, which prompts for Instagram credentials once and stores them.

```
cd ~/Downloads/Programs
sudo apt install -y git
git clone https://github.com/Datalux/Osintgram.git
cd Osintgram
sudo apt-get install libncurses5-dev libffi-dev -y
sudo -H pip install -r requirements.txt -I
make setup
```

Osintgram commands run from `~/Downloads/Programs/Osintgram/` using `python3 main.py -c [command] [username]`. Available commands: `photos`, `stories`, `comments`, `captions`, `followers`, `fwersemail`, `fwersnumber`, `followings`, `fwingsemail`, `fwingsnumber`, `info`. The email and phone number extraction options for followers and following can take a long time and often fail. The author uses them only when the target has a small follower count.

The `instagram.sh` script wraps all four tools in a single Zenity menu with 17 options, including an option to add Instagram credentials for Osintgram. This credential option matters when the VM was built via the automated single-command setup rather than manual installation. Credentials are stored only within the VM and are not transmitted to any service other than Instagram.

The author notes that the Twitter equivalent (using Twint) was dropped from this edition because Twitter blocked all functionality before publication. Instagram may do the same. The author directs readers to his website, blog, Twitter, and podcast for updates when tools break.

## Gallery-DL (introduction)

Gallery-DL (`github.com/mikf/gallery-dl`) downloads entire image galleries from over 150 platforms including Tumblr, 4chan, Flickr, Imgur, and Reddit.

**Install:**
```
sudo snap install gallery-dl
sudo snap connect gallery-dl:removable-media
```

**Download from a Tumblr blog:** `gallery-dl "parakeettle.tumblr.com"`
In a test this retrieved 235 images.

**Download from a 4chan board:** `gallery-dl "https://boards.4channel.org/g/"`
In a test this retrieved 1,503 images in three minutes.

The "Gallery Tool" icon in the OSINT VM prompts for a target URL and executes the command automatically. Coverage of additional bulk image tools continues in the following unit.
