This unit continues Chapter 3 of the book, covering Firefox browser extensions used in OSINT investigations. It picks up after the Bulk Media Downloader section (Figure 3.09) and works through a series of extensions for media download, page capture, metadata inspection, identity management, and session organization.

## Video DownloadHelper

URL: `addons.mozilla.org/en-US/firefox/addon/video-downloadhelper/`

This extension downloads embedded video from Vimeo and similar hosts. It is not ideal for YouTube (a better YouTube option is covered in the next chapter). When enabled, the icon in the menu bar shows three grey circles that turn to full color when downloadable media is detected on the current page.

Recommended configuration:

- Click the icon, open Settings.
- Under the "Behavior" tab, set "Max concurrent downloads" to 20 and "Max Variants" to 99.
- Select "Hide ADP Variants" and click "Save".

The reason to hide ADP variants is that the ADP format requires secondary conversion software. The author does not want to install unnecessary software or convert video evidence. Hiding ADP narrows the menu to appropriate direct-download options. For evidence that may be used in court, download all available sizes. For a personal archive, download only the largest size. The result is a pure digital extraction rather than an analog screen recording, which preserves more data.

## Full Web Page Screenshots (FireShot)

URL: `addons.mozilla.org/en-us/firefox/addon/fireshot/`

FireShot captures the entire web page, not just the visible viewport, and saves the result as a PDF. The PDF includes the page URL and title and is difficult to edit, which is useful during testimony. A standard screen capture only captures the visible area, requires pasting into another program, and produces a more editable file.

Usage: click the blue "S" icon in the upper right, select "Capture entire page", then "Save to PDF".

Recommended filename template (set under Options, "Show filename template settings"):

```
%n-%u-%t-%y-%m-%d-%H-%M-%S
```

Setting `%n` to 0 with Pad set to 3 causes captures to start at 000 and ascend in order. Each filename contains a sequential number, the page URL, the page title, and the date and time of capture. This lets an investigator quickly determine the order in which evidence was retrieved.

FireShot may fail on large Facebook pages because the rendering exhausts video memory.

## Nimbus

Nimbus is the first backup when FireShot fails. It can capture only the visible portion, the entire page, or a custom selection. Output is a PNG file, which is more universal than PDF but easier to edit, making integrity verification harder.

Configuration:

- Click the Nimbus icon, then the gear icon in the lower-right.
- In "File name pattern", enter `{url}-{title}-{date}-{time}`.
- Check "Enable Quick Screenshot", select "Entire Page" in the first row, and "Download" in the second row.

After these changes, clicking the Nimbus icon captures the entire page immediately without presenting a menu, applies the filename pattern, and downloads a maximum-quality PNG to the Desktop.

The author notes that FireShot tends to work better on large Twitter profiles while Nimbus tends to work better on large Facebook pages. Having both available is recommended.

## Firefox Built-in Screenshot

When both FireShot and Nimbus fail on long pages, Firefox includes its own screenshot tool.

Steps:

1. Right-click within the page and select "Take Screenshot".
2. Choose "Save full page".
3. Click "Download".

The output is a PNG file saved to the default downloads directory. The default filename includes the word "Screenshot", the date, and the page title. On a long page this process may take several minutes and produce a file several megabytes in size.

## Exif Viewer

URL: `addons.mozilla.org/en-us/firefox/addon/exif-newcr`

This extension provides right-click access to EXIF metadata embedded in images on web pages. The right-click menu option is "View Image Exif Data". A new window opens and displays available metadata such as camera make and model, orientation, resolution, and the last-modified date and time.

Most social network photos have had metadata stripped to protect user privacy. Blogs and personal websites often still contain metadata. The extension makes it practical to check every image encountered rather than navigating to a separate tool.

## User-Agent Switcher and Manager

URL: `addons.mozilla.org/firefox/addon/user-agent-string-switcher/`

Websites identify the browser and operating system of visitors and can alter or refuse content based on that identity. This extension spoofs the reported identity so that Firefox can impersonate other browsers or devices.

Usage:

1. Click the menu bar icon.
2. Select the desired browser to emulate (e.g., Edge), the desired operating system (e.g., Windows), and the exact version (e.g., Edge 92.0.1 Windows 10).
3. Click "Apply (container on window)".
4. Click "Test UA" to visit a confirmation page.
5. To revert, click "Restart" and refresh the page.

A test page is available at `https://inteltechniques.com/logger/`.

The author gives two practical examples. In one investigation, a hacking forum appeared blank because the site only served content to Linux browsers. Switching the user-agent to Firefox on Linux made the content visible. In a second case, government-mandated online training required Internet Explorer. Setting the user-agent to Internet Explorer within Firefox resolved the access problem.

Important limitation: user-agent spoofing will not fool every website. Sites that use JavaScript to scan for additional identifiers such as touch points and video cards may still detect the real environment. Changing from a Windows/Firefox combination (common in government) to a mobile device or Google Chromebook may reduce suspicion.

## Image Search Options

URL: `addons.mozilla.org/firefox/addon/image-search-options/`

This extension adds a right-click submenu on any image to perform reverse image searches across multiple services. Available services include Google, Bing, TinEye, Yandex, Baidu, SauceNAO, IQDB, WhatAnime, KarmaDecay (searches Reddit for image copies), and imgOps. KarmaDecay is noted specifically for finding copies of images posted on Reddit. The add-on removes any reason to skip reverse image checks during an investigation.

## Resurrect Pages

URL: `addons.mozilla.org/en-US/firefox/addon/resurrect-pages/`

Right-clicking on any page and selecting "Resurrect this page" offers links to archived versions of that page across multiple services: Google standard cache, Google text-only cache, The Internet Archive, Archive.is, WebCite, and Memento Timetravel. This extension provides no content that could not be found manually from those same sources. It exists for speed and convenience.

## Copy Selected Links

URL: `addons.mozilla.org/en-US/firefox/addon/copy-selected-links/`

This extension extracts all hyperlinks within selected text on a page and copies them to the clipboard. The links can then be pasted into any application such as Notepad or Excel.

Usage: select any or all text on a page, right-click, and choose "Copy selected links".

Specific applications the author describes:

- Facebook: select all text on a target's friends list to extract every profile URL. Repeating this later and comparing to a previous capture identifies contacts who were unfriended.
- Twitter: capture all external links and photo links from a profile.
- YouTube: paste the full set of video links from a channel's videos page into a report.
- eBay: copy all active auction hyperlinks from a fraud search result into a report in seconds.
- Human trafficking investigations: copy all ad result hyperlinks directly into a report, email, or memo.
- Open directories and FTP servers: copy native file links for documentation after downloading all data.

Screenshots alone never capture the underlying URLs of linked content. Combining screenshots with link collection produces more comprehensive evidence.

## OneTab

URL: `addons.mozilla.org/en-US/firefox/addon/onetab/`

OneTab collapses all open browser tabs into a labeled, timestamped list of bookmarks stored locally on the workstation. Clicking the blue funnel icon closes all open tabs and opens the OneTab management page. Each group of collapsed tabs is displayed with an editable title (defaulting to the tab count), a date and timestamp, and individual bookmark links.

Key operations:

- Click the group title to rename it (e.g., "Username Subject X").
- Drag and drop bookmarks to reorder them or move them between groups.
- "Restore all" reopens all tabs in that group. By default this deletes the group. To prevent that, open Options and select "Keep them in your OneTab list".
- "Delete all" permanently removes the group.
- "Star this tab group" pins the group to the top of the management page.
- Export links via the upper-right menu to copy them as plain-text URLs for pasting into a more secure platform.

The "Share as web page" feature uploads the tab list to OneTab servers and is not recommended. All other data is stored locally. Right-clicking on any page presents a context menu for more granular tab selection, such as sending only the current tab or only tabs to the left or right.

## Stream Detector

URL: `addons.mozilla.org/en-US/firefox/addon/hls-stream-detector`

Many websites now deliver video as embedded streams rather than downloadable files. The relevant stream protocols are M3U8 playlists and TS (transport stream) segments. Right-clicking such a video usually offers no download option. Stream Detector intercepts and lists all detected streams on a page with their type, host, and timestamp.

Workflow: click the extension icon, locate the "master" M3U8 entry, and click it to copy the URL to the clipboard. That URL can then be opened in VLC media player for playback or passed to Python-based tools for offline download.

Example of a captured master M3U8 URL format:

```
https://cnnios-f.akamaihd.net/i/cnn/big/entertainment/2020/10/31/sean-connery-dead-james-bond-vpx..._ios_,650,1240,3000,5500,.mp4.csmil/master.m3u8
```

Evidence value: the captured URL documents the exact digital source of the stream. If the originating website is later removed or altered, the media may remain accessible through the CDN URL, and the URL itself can be disclosed as evidence. An alternate extension for sites that Stream Detector misses is The m3u8 Stream Detector at `addons.mozilla.org/firefox/addon/the-m3u8-stream-detector`.

## KeePassXC-Browser

URL: `addons.mozilla.org/en-US/firefox/addon/keepassxc-browser`

This extension connects Firefox to the KeePassXC offline password manager. The author chooses KeePassXC because it is secure and entirely offline. Covert account credentials are never sent to a third-party online service.

Setup requirements:

1. KeePassXC application and the browser extension must reside on the same machine. A database on a host computer cannot serve a browser extension installed inside a virtual machine.
2. In KeePassXC, go to Preferences (or Options or Tools, depending on OS and version), open "Browser Integration", enable it, and specify which browsers have access.
3. In the Firefox extension, click "Connect" and approve the connection when prompted in KeePassXC. Provide a name for the configuration.
4. In each KeePassXC entry, include the exact URL of the website (with `https://`) in the URL field so the extension can match the current page to the correct entry.

Operation: when visiting a login page, clicking the username field displays a list of matching covert accounts from the KeePassXC database. Credentials are populated automatically. Because the database is entirely offline, credentials are never stored in a third-party online service.
