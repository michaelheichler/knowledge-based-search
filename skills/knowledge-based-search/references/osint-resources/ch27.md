This unit (a windowed segment of Chapter 14 in the print edition) covers investigative techniques for Tinder, Discord, forum search tools, Craigslist, eBay, OfferUp, and related classified or auction platforms. It also addresses online prostitution resources and escort review sites as a distinct investigative domain.

## Tinder

Tinder users can create optional usernames, which generate publicly visible web profiles at `https://www.gotinder.com/@USERNAME`. These profiles are often unknown to the user. Viewing the page source of such a profile exposes the field `birth_date` (exact date of birth) and `_id` (a permanent Tinder user ID). The user ID remains stable even if the person changes their display name or username, giving investigators a persistent identifier.

## Discord

Discord is a free voice, video, and text application originally built for gaming. It is now widely used in hacking, doxing, and cybercrime communities. The author describes it as a modern IRC replacement. Key characteristics for investigators:

- Discord servers are not indexed by conventional search engines (treated as "deep web").
- Access requires an invite URL. Generic invite links are often findable in related forums or by asking members.
- Administrators see who joins but only the details provided at registration, so covert details are accepted.
- All channel history from a server's inception is available to any member who joins.

**Finding servers.** Disboard (disboard.org) indexes Discord servers with open invitations and supports keyword search. Discord Me (discord.me) is an alternative if Disboard yields nothing.

**Account creation precautions.** Creating a Discord account from a VPN or a hardened browser often triggers a phone-number verification demand. The author recommends creating accounts using Chrome (not Firefox) on public Wi-Fi (hotel, library) without a VPN, inside a Windows virtual machine. Accounts created this way can be stored until needed.

**Exporting server content.** The preferred workflow uses the official Discord Windows application inside a dedicated VM alongside DiscordChatExporter (from `https://github.com/Tyrrrz/DiscordChatExporter/releases`). Steps:

1. Install Discord and DiscordChatExporter on the Windows VM.
2. Log in to Discord and join the target server.
3. Open Discord developer tools with Ctrl+Shift+I, navigate to Application, then Local Storage, then `https://discord.com`, and press Ctrl+R to locate the authentication token.
4. Paste the token into DiscordChatExporter, select the target server and channel, choose CSV export with no date restrictions, and export.
5. Repeat for every channel in the server.

CSV is preferred over HTML because the text is easier to import and manipulate. The author notes that in 2019, a Discord server sharing data-breach file links was removed for policy violations the day after he exported it, demonstrating the value of timely archival.

**Related platforms.** Slack (slack.com) is similar but targets professionals. Riot (about.riot.im) and Tox (tox.chat) offer encrypted communications and better security but have lower adoption. The author keeps a dedicated investigation VM with all four applications installed.

## Forum Search Tools

**Board Reader (boardreader.com)** queries forum communities, message boards, and discussion threads that may be excluded from general search engine indexing. It supports keyword, language, date range, and domain filtering.

**Craigslist Forums (forums.craigslist.org)** are categorized by topic with location filtering. They are not indexed by most search engines. A username-based search is available via URL even though the on-site search field for usernames was removed in 2020:

`https://forums.craigslist.org/?act=su&handle=USERNAME`

This URL returns all posts by that user in the past 31 days, the account creation date, and what percentage of that user's posts have been deleted in the last 31 days. The deletion rate can be an investigative signal. Because people reuse usernames across platforms, finding a username on Craigslist forums and then searching it elsewhere can yield substantial additional information.

## Online Prostitution and Escort Review Sites

After Craigslist removed its Erotic Services section in 2009 and Backpage was seized in 2018, prostitution advertising migrated to a range of alternative sites. The author lists a large number of current platforms: 5escorts.com, bedpage.com, cityoflove.com, cityxguide.com, eros.com, escort-ads.com, escortfish.ch, humaniplex.com, skipthegames.com, slixa.com, stripperweb.com, theotherboard.com, tsescorts.com, and tnaboard.com, among others. Investigators should research which services are dominant in their specific cities.

**Escort review sites** are forums where clients leave detailed reviews of sex workers, covering price, appearance accuracy, and experience. These sites are relevant to law enforcement for several reasons: they are the first place that will publicize an undercover police operation (creating officer safety concerns and revealing when a covert identity has been burned), and reviews provide evidence documentation for prosecution. The Erotic Review (theeroticreview.com) is cited as a broadly available starting point covering most metropolitan areas, though much content requires a paid membership. At the time of writing, the site was blocking U.S. IP addresses, which a non-U.S. VPN location bypassed.

A real-world application: during an FBI operation focused on juvenile prostitution and trafficking, the author searched phone numbers through multiple escort sites. Numerous city postings tied to one number indicated the person was a full-time traveling sex worker likely controlled by a pimp. All contact with traveling prostitutes in the operation led to identification of their traffickers.

## Online Newspaper Comments (Disqus)

Most news websites now use third-party comment platforms. Facebook-hosted comments tend to use real names. Disqus-hosted comments use usernames and are searchable through Google. To search Disqus content, the author uses Google with these operators:

- `"keyword" "disqus" "comments"` finds pages with the Disqus system referencing the keyword.
- `"keyword" "disqus" "1..999 comments"` narrows results to pages that actually contain comments (using Google's numeric range operator to exclude zero-comment pages and pages with over 1,000 comments).

## Craigslist Classified Ads

Craigslist is a major venue for locating stolen goods and identifying criminals.

**Live search.** Searching within the "for sale" section allows filtering by price range, image presence, and title-only matches. Results can be viewed in list, gallery, or map format. Gallery view works as a photo lineup for stolen items. Map view shows approximate city location rather than GPS coordinates.

**Archived and deleted posts.** Once a thief sells an item, the post is deleted and disappears from Craigslist's own search. Google and Bing cache Craigslist posts. Searching `site:craigslist.org KEYWORDS` on Google or Bing retrieves both active and recently deleted posts. Narrowing to a specific regional subdomain (e.g., `site:stlouis.craigslist.org`) filters by geography. Deleted posts return a "page not found" error on Craigslist but may still show an email address or phone number in the Google/Bing result snippet. Bing generally returns more archived Craigslist results than Google.

**Phone numbers.** Most Craigslist sellers include a cell phone number in the post. Criminals who buy prepaid phones with cash often unknowingly post that number publicly alongside a name. A post with both a cell and a landline lets investigators associate the two numbers. A standard lookup can then identify the landline owner.

**Obfuscated email addresses.** Craigslist filters email addresses in posts. Users work around this by inserting spaces (e.g., "JohnDoe911 at gmail com"). This text is still indexed by Craigslist and search engines, so searching the username portion retrieves the posts.

**Search operators.** Craigslist supports quotation marks for phrase search, hyphens to exclude terms, the pipe symbol (|) for OR searches, parentheses for grouping, and wildcards. The hyphen excludes: `honda black -red` returns honda and black but not red. The pipe finds either: `honda | toyota`. Parentheses group complex queries: `red (toyota | honda) -2000 -2001`. Wildcards match partial words: `wood floo*` matches "floors" and "flooring". `iphone*` matches "iphone", "iphones", and "iphone5".

**Third-party tools.** totalcraigsearch.com, adhuntr.com, and searchalljunk.com search all live Craigslist posts across all regions simultaneously. Search Tempest (searchtempest.com) searches Craigslist, eBay, and Amazon together with location and perimeter filters, a 24-hour recency filter, and duplicate reduction. The author recommends understanding manual methods rather than depending entirely on third-party tools, which may disappear.

**Red flags in posts.** Language like "hurry", "must sell today", and "I will come to you" has been observed as an indicator of stolen goods. Multiple posts sharing identical backgrounds in item photos (tables, flooring) is another suspicious pattern.

## eBay

eBay requires financial information to list items, which discourages many thieves and pushes them toward Craigslist. eBay's advanced search supports location filtering by zip code and radius (minimum 10 miles) using the "items near me" option. The "Completed listings" filter searches past (expired) auctions. Direct URL structures for common searches:

- Keyword search: `ebay.com/sch/i.html?&LH_TitleDesc=1&_nkw=TERMS`
- Sold items: `ebay.com/sch/i.html?_from=R40&_nkw=TERMS&LH_Sold=1&LH_Complete=1`
- Completed items: `https://www.ebay.com/sch/i.html?_from=R40&_nkw=TERMS&LH_Complete=1`
- User profile: `https://www.ebay.com/usr/USER`
- User feedback: `https://feedback.ebay.com/ws/eBayISAPI.dll?ViewFeedback2&userid=USER`
- User items: `https://www.ebay.com/sch/USER/rn.html`
- User followers: `https://www.ebay.com/usr/USER/followers#followers`
- User following: `https://www.ebay.com/usr/USER/all-follows?priflwtype=people#people`

**Flippity (flippity.com)** provides map-based eBay location search with an adjustable radius.

**GoofBid (goofbid.com)** takes a correctly spelled keyword and searches eBay using the most common misspelled variations of that term. Fat Fingers (fatfingers.com) is an alternative.

## OfferUp

OfferUp (offerup.com) is growing as a Craigslist alternative for local buying and selling. It includes seller usernames and ratings similar to eBay. A distinctive capability: viewing the page source of any post and searching for `place:location:latitude` and `place:location:longitude` (using Ctrl+F or Command+F) reveals GPS coordinates associated with the listing. These coordinates often identify the target's exact location or nearby neighborhood.
