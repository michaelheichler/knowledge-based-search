This unit covers the final sections of Chapter 1 (antivirus, antimalware, VPN, and password management) and the opening of Chapter 2 (Linux virtual machines as an investigation environment). Together they form the recommended baseline setup before any online OSINT work begins.

## Antivirus on Windows

For Windows 7, Bazzell recommends Microsoft Security Essentials. For Windows 8 and 10, Windows Defender, which ships with the operating system, is sufficient. The reasoning is pragmatic: Windows already collects usage data for Microsoft, so using Microsoft's own antivirus adds no meaningful new exposure.

## Antivirus on Mac

Mac architecture reduces virus risk compared to Windows, but Bazzell argues that running no security tools is irresponsible, particularly for investigators who may be called to testify in court about the integrity of their workspace. He recommends three free, open-source tools, each executed manually on a weekly basis, none running persistently in the background.

Task Explorer (objective-see.com/products/taskexplorer.html) lists all running processes and queries them against VirusTotal. A red flag in the lower-right corner signals a suspicious file. It does not remove infections.

KnockKnock (objective-see.com/products/knockknock.html) scans for persistent programs configured to launch at boot, catching threats that were not running at scan time and would therefore be missed by Task Explorer. It also does not remove infections.

ClamAV (clamav.net) is a community-driven, open-source antivirus database. It runs only when invoked and does not remove threats by default. Its practical value on a Mac is detecting Windows-targeted malware present on the system (commonly as email attachments) before those files can infect a Windows virtual machine.

Installing ClamAV on Mac requires first installing the Brew package manager. The install command for Brew is:

```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

After Brew is installed, the following terminal commands complete the ClamAV setup:

```
brew analytics off
brew install clamav
sudo mkdir /usr/local/sbin
sudo chown -R 'whoami' admin /usr/local/sbin
brew link clamav
cd /usr/local/etc/clamav/
cp freshclam.conf.sample freshclam.conf
sed -ie 's/AExample/#Example/g' freshclam.conf
```

A reference page with all commands is at https://inteltechniques.com/clamav.

To use ClamAV, update the virus database with `freshclam -v`, then scan the full system with `clamscan -r -i /`. The scan reports only infected files and may appear idle while running. To scan and automatically delete suspicious files, use `clamscan -i --remove=yes /`, but Bazzell warns this can permanently remove necessary files and should only be used after researching the flagged files first. False positives occur and should be investigated before acting.

## Antimalware

Malwarebytes (malwarebytes.com) is recommended for Windows users and described as mandatory on Windows. The free version is sufficient. Premium trial prompts should be declined. The procedure is to download and install with defaults, then update the database and run a full scan at least weekly. Unlike ClamAV, Malwarebytes removes detected issues automatically. Bazzell does not use it on Mac.

## Virtual Private Network (VPN)

A VPN routes all traffic through an encrypted tunnel to a remote server. Websites see the IP address of the VPN server, not the user's actual IP or location. Bazzell's policy is to use a VPN on every internet-connected device at all times.

Corporate VPNs are not appropriate for investigations because they expose activity to the organization. Free VPNs are not recommended because they are slow and may route other users' traffic through the investigator's connection. Browser extension VPNs protect only browser traffic, leaving all other host traffic exposed. A dedicated VPN application that covers the entire host is required, which also protects any virtual machines running on that host.

Tor is not recommended as a substitute for everyday VPN use. Tor is too slow for continuous browsing, and many sites (including banks and social networks) block or restrict Tor connections. Tor is appropriate only when hiding the complete connection path is critical.

Bazzell recommends ProtonVPN and PIA (Private Internet Access), with current purchase links at https://inteltechniques.com/vpn.html. He prefers ProtonVPN for investigations because PIA's large user base has led many sites to block its IP ranges due to abuse and fraud. Both providers offer dozens of exit servers worldwide, allowing an investigator to appear as a user in a specific country or region.

## Password Manager

Investigators create and maintain numerous covert accounts across different services. Bazzell recommends KeePassXC (keepassxc.org), an open-source, cross-platform password manager that stores its database locally and does not synchronize to the internet. This offline approach eliminates the attack surface present in cloud-based managers such as LastPass or Dashlane, even though those services encrypt passwords locally before syncing.

Setup involves creating a new database, moving the encryption strength slider to maximum, and setting a strong master password that contains letters, numbers, and special characters and has never been used elsewhere. The database file should be backed up to an encrypted USB drive. The master password is the only credential that must be memorized. All others are generated and stored by KeePassXC.

For each covert account, the workflow is to create a new group in KeePassXC (named for the service), add an entry with the account name, username, and URL, and use the built-in random password generator. Bazzell recommends a length of at least 40 characters, or 50 or more if the site permits. The generated password is pasted into the site's password field and saved in the database. Going forward, every site password is changed to a KeePassXC-generated value on the next login. This ensures that a breach of any single site does not expose credentials used elsewhere.

Bazzell notes that KeePassXC offers a browser extension for automated password entry, but he no longer uses it, preferring to treat each password entry as a deliberate manual act.

## Linux Virtual Machines

Chapter 2 argues that Linux virtual machines are the correct environment for OSINT investigations. Linux is lightweight, free, runs on nearly any hardware, and provides security that Windows cannot match. Because malicious code almost always targets Windows, a Linux VM greatly reduces the risk of infection. When a VM is reverted or a session ends, all viruses, tracking cookies, and activity history disappear. Each VM is isolated from other VMs and from the host, so a compromised investigation environment cannot affect others.

### History: Buscador

In 2016, Bazzell collaborated with David Westcott to build a custom OSINT Linux distribution. Released in 2017 and named Buscador (Spanish for "seeker"), it was modeled on the approach of Kali Linux for cybersecurity but designed for OSINT work. Web browsers came pre-configured with OSINT extensions and settings. Every included tool had a clickable icon in the Dock, removing the requirement for command-line knowledge and making the system accessible to investigators without Linux experience.

Bazzell no longer recommends or distributes Buscador. Security patches were last applied in 2019, many included applications generate errors because they are outdated, and there is no online repository for updates. He draws a broader principle from this: investigators should never depend on a single third-party source for their OSINT environment. Building and maintaining a personal VM provides full control and a complete understanding of the tools installed.

### VirtualBox

VirtualBox (virtualbox.org) is the recommended virtualization platform. It is free and functions equivalently to paid alternatives such as VMWare. Installation requires downloading the appropriate installer for the host OS from virtualbox.org/wiki/Downloads (a `.dmg` for Mac or `.exe` for Windows), selecting the highest non-beta version, and also downloading the Extension Pack for the same version (file extension `.vbox-extpack`). The Extension Pack is added by double-clicking it after the main application is installed. Virtualization must be enabled in the BIOS on some Windows machines. Netbooks, old machines, and low-end hardware are unlikely to work.

### Ubuntu Linux

Bazzell recommends Ubuntu as the base operating system for an OSINT virtual machine, though he acknowledges this choice is debated among Linux enthusiasts. The chapter content in this unit ends at the start of the Ubuntu section, with installation and configuration covered in the remainder of Chapter 2.
