Chapter 1 argues that any online investigation must begin with a clean, dedicated, and properly secured host computer. Bazzell frames this as a forensic hygiene requirement: a contaminated machine can compromise evidence, expose personal activity during legal discovery, and introduce investigative artifacts that an opposing expert could exploit in court. The chapter covers how to decontaminate a host, install antivirus and antimalware software, configure a VPN, and set up an offline password manager.

## The Clean Host

A computer used for daily personal activity carries persistent contamination: tracking cookies, session data, logged-in account associations, cached files, and browser history. If an investigator browses a subject's Amazon wishlist while logged into a personal Amazon account, the investigator's name may appear in a screen capture, and Amazon's cookies will continue associating the investigator's identity with subsequent browsing. Bazzell describes a situation in which an opposing party was granted a forensic clone of the investigation computer, surfacing personal purchases and communications.

The rule is to maintain a physically separate, dedicated machine used exclusively for investigations, with no personal browsing, email, or account activity. For investigators working with existing hardware, the chapter prescribes a full reformat and clean operating system reinstallation, not just file deletion or a cleaning utility.

**Windows reset:** Back up important data from the Desktop, Downloads, and Documents folders. Go to Start > Settings > Update and Security > Recovery, click "Get started" under "Reset this PC", select "Remove everything", then choose "Remove files and clean the drive". During post-installation setup, refuse any Microsoft account creation prompts (preferably by disconnecting the network first) and provide only a vague username and password.

**Mac reset:** Back up the same standard folders. Restart and hold Command and R until the Apple logo appears to enter Recovery Mode. In the macOS Utilities window, open Disk Utility, select the startup disk, click Erase, choose Mac OS Extended (Journaled), and complete the erase. Then choose Reinstall macOS from the same Utilities window and create a generic login account.

## Antivirus

**Windows:** Bazzell recommends Microsoft's built-in solutions: Microsoft Security Essentials for Windows 7, and Windows Defender (included by default) for Windows 8 and 10. He acknowledges that Microsoft collects usage data, but notes that Windows itself already does this, so using its antivirus does not meaningfully increase data exposure.

**Mac:** The Mac software architecture is described as more secure, with viruses rare but not impossible. Bazzell discourages always-on commercial products such as Avast and Kaspersky because they are intrusive and their business practices can be questionable. He recommends three free, on-demand tools from Objective-See:

- **Task Explorer** (objective-see.com/products/taskexplorer.html): identifies all running processes and queries them through VirusTotal, flagging suspicious files. It does not remove threats.
- **KnockKnock** (objective-see.com/products/knockknock.html): scans for persistent programs set to launch at boot, catching threats that Task Explorer may miss if they were not running at scan time. It also does not remove threats.
- **ClamAV** (clamav.net): a free, community-driven, open-source antivirus database. It runs only on demand. On Mac, its main practical value is detecting Windows-targeting malware present as email attachments, preventing their spread to Windows virtual machines. It does not remove viruses by default.

ClamAV installation on Mac requires the Homebrew package manager. Install Brew from brew.sh using the curl command on that page, then run the following Terminal commands in sequence:

```
brew analytics off
brew install clamav
sudo mkdir /usr/local/sbin
sudo chown -R `whoami`:admin /usr/local/sbin
brew link clamav
cd /usr/local/etc/clamav/
cp freshclam.conf.sample freshclam.conf
sed -ie 's/#Example/#Example/g' freshclam.conf
```

To update the virus database and scan:

```
freshclam -v
clamscan -r -i /
```

To scan and automatically remove (use with caution, as it may delete necessary files):

```
clamscan -i --remove=yes /
```

All commands are also available at https://inteltechniques.com/clamav.

## Antimalware

Bazzell recommends Malwarebytes for additional protection, calling it mandatory for Windows users and optional for Mac users who want it. Download the free version from malwarebytes.com, install with defaults, and run weekly updates and full scans. Decline any premium trial prompts. Malwarebytes removes threats it finds, unlike ClamAV.

## Virtual Private Network (VPN)

A VPN is described as essential for every OSINT researcher. It routes traffic through a remote server, so websites see the IP address of the VPN server rather than the investigator's real IP and ISP. Bazzell recommends purchasing a paid VPN rather than using free services (which are slow and sometimes route other users' traffic through your connection) or a corporate VPN (poor for privacy and inappropriate for investigations).

Tor is acknowledged as valid for high-risk anonymous connections, but described as too slow and too frequently blocked by social networks and financial sites for routine browsing.

Recommended providers are **ProtonVPN** and **PIA (Private Internet Access)**, both reviewed at https://inteltechniques.com/vpn.html. Both offer desktop applications for Windows and Mac and allow connection to servers in dozens of countries. At the time of writing, ProtonVPN was producing fewer access blocks than PIA, because PIA's large user base had led many sites to block its IP ranges.

Browser-only VPN extensions are discouraged because they protect only browser traffic, not the full host. The recommendation is a dedicated VPN application protecting the entire operating system, which will also cover virtual machines running on that host.

## Password Manager

Investigators create many online accounts and profiles in the course of their work. KeePassXC is the recommended solution. It is free, open-source, cross-platform (Mac, Windows, Linux), and stores the password database locally rather than syncing to the internet, eliminating the attack surface of cloud-based managers such as Lastpass or Dashlane.

Setup procedure within KeePassXC:

1. Select Database > New Database.
2. Provide a database name (for example, "Passwords").
3. Move the encryption settings slider fully to the right and click Continue.
4. Set a strong, unique master password not used anywhere else.
5. Click Done and save the database file to a safe location.
6. Close and reopen to verify the password works.

To create a password entry for a covert account (the chapter uses a covert Facebook profile as the example):

1. Right-click in the right column and select New Group. Name it (for example, "Facebook") and click OK.
2. Select the group, right-click in the right panel, and select New Entry.
3. Enter the account name, username, and URL.
4. Click the dice icon next to the Repeat field, then the eyeball icon.
5. Slide the password length to at least 40 characters (50 if the site allows).
6. Copy the generated password into both the Password and Repeat fields.
7. Apply the new password to the account, then click OK and save the database.

The master password must be unique and memorized, but written down in a safe place until memorized. The database file must be backed up to an encrypted USB drive. Losing the file without a backup means losing all stored credentials.

The chapter advises against the KeePassXC browser extension (which automates password entry) in favor of manual copy-paste, on the grounds that credential entry should be a deliberate act. The offline database is preferred because cloud-synced alternatives expose credentials to breach risk at the provider level.

## Chapter Position

These steps (clean host, antivirus, antimalware, VPN, and offline password manager) are presented as mandatory preparation before any search activity in the rest of the book. Investigators who skip them risk contaminating evidence, exposing personal data in legal proceedings, being tracked by targets, and introducing malware into investigation infrastructure.
