This unit is Chapter 23, covering a broad set of free and low-cost tools for extracting investigative intelligence from domain names. The chapter moves through historical site data, change monitoring, email discovery, tracker analysis, domain analytics reversal, SSL certificates, source code examination, subdomain enumeration, robots.txt files, search engine marketing data, social sharing metrics, backlinks, plagiarism detection, site mapping, and threat data. The running examples use real domains, primarily phonelosers.org, inteltechniques.com, and cnn.com, to show concrete outputs.

## Historical Site Data and Change Monitoring

**Carbon Dating** (carbondatc.cs.odu.edu) estimates when a domain first appeared online based on the earliest available cache. A direct URL query takes the form `http://carbondate.cs.odu.edu/#inteltechniques.com`. The tool also returns direct links to historical snapshots within the Wayback Machine and other archive services. The example produced an estimated creation date of "2013-11-16T08:47:11".

**DomainIQ** provides registration history, IP address history, and DNS change history. A screenshot in the chapter shows IP and DNS records across multiple dates from 2016 to 2019, demonstrating how the service reveals infrastructure changes over time.

**Follow That Page** (followthatpage.com) monitors a target page and emails the investigator when content changes. New or modified content is highlighted and deleted text is struck through. The service handles public Twitter pages but does not work reliably on Facebook.

**Visual Ping** (visualping.io) offers more robust monitoring. It generates a snapshot of a page and lets the investigator draw a selection box around a specific area to watch, which avoids false alerts from advertisements or dynamic data. The recommended setting is hourly inspection with notification on "tiny change."

## Email Discovery from Domains

**Hunter** (hunter.io) accepts a domain name as a query and returns email addresses scraped from public web pages. The free version redacts a few characters from each address but the address structure remains identifiable. Hunter was introduced in an earlier chapter for email verification and is reused here for domain-level email enumeration.

## Tracker and Malicious Activity Analysis

**Blacklight** (themarkup.org/blacklight) reveals invasive activity embedded in a target website. A query of cnn.com returned 34 advertisement trackers, 52 third-party cookies, Facebook notification integrations, and interactions with Adobe and Google.

## Domain Analytics: Reverse Analytics

Website owners install analytics codes to track visitors. Because the same owner often reuses the same IDs across multiple sites, a reverse lookup of any ID reveals additional domains controlled by the same person. Relevant ID types include Google Analytics (prefix "UA-"), Google AdSense (prefix "ca-pub-"), Amazon Affiliate IDs, and Amazon product IDs. None of this technique relies on Whois data.

**Spy On Web** (spyonweb.com) performs Whois lookup, identifies the server IP and location, and cross-references analytics IDs. A query of phonelosers.org returned a Google AdSense ID of ca-pub-3941709854725695 and five domains sharing that account: notla.com, oldpeoplearefunny.com, phonelosers.com, phonelosers.org, and signhacker.com.

**Analyze ID** (analyzeid.com) performs the same type of reverse lookup and often surfaces IDs not found by Spy On Web. The phonelosers.org query also revealed an Amazon Affiliate ID of phonelosersof-20 and an Amazon product ID of 1452876169. A Google search for "Amazon product 1452876169" identified the product as the target's self-published book, Phone Losers of America. Clicking the Amazon Affiliate ID showed five domains with that code. Clicking the Amazon product ID showed seven domains advertising that specific product. Analyze ID also found a Clickbank affiliate ID tied to five additional domains, one of which was unique to any other result. Any ID beginning with "UA-" is a Google Analytics identifier and can be searched through these same tools.

**DomainIQ** (domainiq.com/reverse_analytics) provides dedicated search pages for specific ID types: a page for Google Analytics IDs and a separate page for AdSense IDs (domainiq.com/reverse_adsense#). When results on the page are redacted, exporting to CSV reveals full data. In the example, submitting Analytics ID UA-1946201-13 produced a redacted results page, but the CSV download revealed an IP address (74.208.175.23), a name (Brad Carter), and an email address (brad@notla.com). The free tier is limited to three searches per day, tracked by IP address. A VPN can be used to switch IPs and bypass this limit.

**Hacker Target** (hackertarget.com/reverse-analytics-search) is notable for its access to historic analytics IDs across multiple subdomains. A query of cnn.com returned dozens of Google IDs mapped to subdomains, including UA-289507 for cnnworldlive.cnn.com, UA-96063853 for center.cnn.com, and UA-74063330 for games.cnn.com.

**DNSLytics** (dnslytics.com/reverse-analytics) is an additional reverse analytics option that may surface associations missed by the others. Direct URL formats:
- `https://dnslytics.com/reverse-analytics/inteltechniques.com`
- `https://dnslytics.com/reverse-adsense/inteltechniques.com`

## SSL Certificates

Most websites have an SSL certificate enabling HTTPS, and the history of these certificates is searchable at **CRT.sh** (crt.sh) using a direct URL such as `https://crt.sh/?q=inteltechniques.com`. The "Subject Alternative Name" field within a group certificate lists all domains secured together under the same purchase. In the example, inteltechniques.com was bundled with privacy-training.com, yourcomputernerds.com, and computercrimeinfo.com, each of which then becomes a domain to investigate further.

## OSINT.sh

**OSINT.sh** (osint.sh) is a multi-function service with dedicated direct-URL endpoints for common domain queries:
- `https://osint.sh/subdomain` - all subdomains of a target domain
- `https://osint.sh/stack` - technologies in use by a target domain
- `https://osint.sh/email` - email addresses publicly associated with a domain
- `https://osint.sh/ssl` - SSL certificates associated with a domain
- `https://osint.sh/whoishistory` - historic registrations for a domain
- `https://osint.sh/analytics` - domains sharing a Google Analytics ID
- `https://osint.sh/adsense` - domains sharing a Google AdSense ID
- `https://osint.sh/domain` - domains associated with keywords
- `https://osint.sh/reversewhois` - domains publicly associated with an email address
- `https://osint.sh/ocr` - text extraction from documents stored at a domain URL

## Website Source Code Analysis

**Nerdy Data** (search.nerdydata.com) indexes website source code and allows searches by code strings. The chapter's example used the JavaScript function name "function doSearch01(Search01)" to find a competitor site that had copied the author's search tool scripts and was selling access to them. Searching a known Analytics ID, AdSense ID, or Amazon ID through Nerdy Data can reveal additional domains containing that same code. Results can be exported as CSV.

**Built With** (builtwith.com) identifies technologies used to build a site, including operating system (Linux in the phonelosers.org example), email provider (DreamHost), web framework (PHP and WordPress), WordPress plugins, analytics tools, video services, and mailing list providers. Embedded services not visible on the page may point to accounts on other platforms to investigate. **Stats Crop** (statscrop.com) is listed as an alternative.

A real-world case is described in the chapter: while investigating an anonymous website displaying photo evidence of a reported felony, standard registration data was intentionally inaccurate. A domain analytics search revealed a Google Analytics ID that was also present on the suspect's personal blog, leading to an arrest the same day.

## Subdomains

**PentestTools** (pentest-tools.com/information-gathering/find-subdomains-of-domain) attempts a DNS zone transfer (which usually fails), then brute-forces common subdomain names from a list, and scans all 254 IP addresses in any identified range. A query of phonelosers.org, which appeared to be a simple blog, revealed five subdomains: webmail.phonelosers.org, ssh.phonelosers.org, ftp.phonelosers.org, www.phonelosers.org, and mail.phonelosers.org. This disclosed the presence of a webmail server, SSH access, FTP server, and mail server. The chapter notes this method has uncovered hidden forum pages.

**SubDomain Finder** (subdomainfinder.c99.nl) is a backup option for when PentestTools is unavailable.

**DNS Dumpster** (dnsdumpster.com) uses host records from the domain registrar to find potential subdomains. It has surfaced hidden blogs during stalking investigations.

## Robots.txt

Nearly every professional website has a robots.txt file at the domain root listing directories search engines should not index. Viewing it exposes paths the site owner considers sensitive. Access format: `http://www.cnn.com/robots.txt`. The CNN example shows:

```
Disallow: /cnnbeta
Disallow: /development
Disallow: /partners
```

These directories suggest a beta site, a development environment, and a partner list. Each disallowed path can be appended to the domain and browsed directly:
- `https://www.cnn.com/cnnbeta`
- `https://www.cnn.com/development`
- `https://www.cnn.com/partners`

To find all robots.txt files across a site via search engine: `site:cnn.com robots ext:txt`. To view historical versions via the Wayback Machine: `https://web.archive.org/web/*/cnn.com/robots.txt`. Robots.txt files rarely reveal passwords or directly incriminating content, but they direct attention toward areas the site owner wanted to keep out of search engines.

## Search Engine Marketing and Traffic Intelligence

Search Engine Optimization (SEO) and Search Engine Marketing (SEM) services collect traffic and ranking data about websites. Investigators can read this data as intelligence about a target's audience, reach, and network.

**Similar Web** (similarweb.com) provides comprehensive traffic estimates. A query of inteltechniques.com produced the following data: the majority of traffic came from the USA, followed by UK, Germany, and France. There was no paid advertising. The site had 56 backlinks with 15 visible. "Buscador" was the top search term, followed by OSINT. Over 50,000 people visited monthly. Five competitors were identified, with onstrat.com as the largest. 71% of traffic was direct, 12% came from referrals (including computercrimeinfo.com), and 3% came from Facebook and Twitter.

**Alexa** (alexa.com) ranked inteltechniques.com as the 104,033rd most popular site globally, with three average pages per visit, "OSINT Links" and "IntelTechniques" as top search terms, and Facebook, Twitter, and Google as the top referral sources.

Additional SEM tools mentioned: Search Metrics (suite.searchmetrics.com), SpyFu (spyfu.com), and Majestic (majestic.com).

## Social Sharing and Community References

**Shared Count** (sharedcount.com) reports how many times a domain has been shared on social networks. A query of labnol.org showed: Facebook Likes 348, Facebook Shares 538, Facebook Comments 148, Facebook Total 1034, Twitter Tweets 0, Pinterest Pinned 1. This output guides investigators toward the social platforms most active around the target.

**Reddit domain search**: Any domain's Reddit post history is accessible by navigating to `reddit.com/domain/[target-domain]`. The phonelosers.org example produced 16 Reddit posts, which can be analyzed for discussion threads and contributing usernames.

## Backlinks

**Small SEO Tools Backlink Checker** (smallseotools.com/backlink-checker) identifies sites linking to a target domain. A query of inteltechniques.com returned 264 linking pages. Results include internally self-linking pages (inflating the count), but external results may reveal sites owned by colleagues and associates of the subject.

**Host.io** (host.io) provides backlinks, redirects, and a full domain summary via direct URLs:
- `https://host.io/backlinks/inteltechniques.com` (returned 45 unique linking domains in the example)
- `https://host.io/redirects/inteltechniques.com` (shows domains forwarding traffic to the target, useful for finding older domains the subject previously operated)
- `https://host.io/inteltechniques.com` (full domain summary)

## Plagiarism and Duplicate Content Check

**Small SEO Tools Plagiarism Checker** (smallseotools.com/plagiarism-checker) compares pasted text against the web to find identical or similar content. The chapter describes cases where investigators were alarmed by apparent threats on a blog that turned out to be copied song lyrics. The tool structures multiple Google queries from the supplied content and returns variations. Clicking a result opens the corresponding Google search page. **Copy Scape** (copyscape.com) is listed as an alternative.

## Site Structure Mapping

**Visual Site Mapper** (visualsitemapper.com) generates an interactive graph of internal links within a domain. Highlighting any page shows which internal pages connect to it. This helps identify the most-linked pages and reveals content not reachable from the homepage.

**XML Sitemaps** (xml-sitemaps.com) crawls a domain and produces an XML list of all public URLs. A scan of the author's site returned 493 unique pages. The output can be exported and imported into reporting systems. This tool pairs with the visual mapper: the visual tool shows structure, and the XML text output supports documentation.

## Threat Data

The chapter introduces a category called "Threat Data," covering services that monitor for malicious content. Network security analysts use these services to blacklist dangerous sites. OSINT investigators use them to surface domain intelligence not available elsewhere.

**VirusTotal** (virustotal.com) is described as the most useful of the four services for OSINT. Key areas within the "Details" menu include the "Categories" section (which identifies the general topic of the site and can reveal information about domains that have gone offline), the "HTTPS Certificate" section (particularly the "Subject Alternative Name" field, which lists additional domains and subdomains sharing the target's SSL certificate), the "Relations" tab (which surfaces additional subdomains), and the "Files" section (which displays unique content served from the domain).

A cnn.com search in VirusTotal's SSL Subject Alternative Name returned: dev.client.appletv.cnn.com, dev.cnnmoney.ch, dev.content.cnnmoney.ch, and dev.hypatia.api.cnn.io. This revealed that cnn.io is directly associated with the target. The Relations tab returned additional subdomains including customad.cnn.com, go.cnn.com, and store.cnn.com.

The chapter's text is cut off at this point. Three additional threat data services are referenced but not detailed in the available text.
