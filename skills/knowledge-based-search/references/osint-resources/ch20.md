This unit covers the latter portion of Chapter 10 (Facebook) and the opening of Chapter 11 (Twitter). The Facebook section concludes with Base64-based URL construction, a custom search tool, and several extraction techniques for friends lists, phone numbers, and email addresses. The Twitter section introduces the platform's search capabilities and the basics of locating a target's account.

## Facebook: Base64 Search URLs

Facebook's filtered search relies on Base64-encoded parameters appended to standard search URLs. The Base64 string encodes a JSON object that tells Facebook what filter to apply, such as restricting results to a specific author or date range. The technique was first published by researcher NEMEC (twitter.com/djnemec), and Bazzell credits virtually all tools that generate these URLs, including his own, to that work.

The pattern for a date-filtered posts query takes the form:

```
https://www.facebook.com/search/posts/?q=OSINT&epa=FILTERS&filters=<base64string>
```

The same pattern applies to photos and videos by substituting the search type in the path. Constructing these strings manually is complex enough that Bazzell recommends using the custom tool described below rather than building them by hand.

## Locating Facebook User ID Numbers

Every Facebook query that filters by person or place requires a numeric ID, not a username.

For personal profiles, search the page source for `userID`. For location pages (cities, places), the ID appears as the final number group in the URL. The City of Chicago example yields ID `108659242498155` from the URL `https://www.facebook.com/places/Things-to-do-in-Chicago-Illinois/108659242498155/`. For business pages, search the page source for `"pageID"` (including the quotes). Harvard's page produces `"pageID":"105930651606"` and Pepsi's produces `"pageID":"56381779049"`. For event pages, search the source for `eventID`. For group pages, search the source for `groupID`.

Third-party Facebook ID lookup tools can also retrieve these numbers for business, event, and group pages, though Bazzell prefers manual extraction from source code.

## IntelTechniques Facebook Tool

Bazzell provides a custom interactive HTML tool, distributed with the book's downloaded archive, that automates all of the Base64 URL construction. The tool is organized into three sections.

The first section, "Facebook Profile Data," accepts a username (such as `zuck`) and populates it into a set of query links covering Timeline, About, Photos, Videos, Employment, Education, Locations, Contact Info, Basic Info, Relationships, Family, Communities, Friends, Photo Albums, Checkins, Sports, Music, Movies, Books, Apps and Games, Likes, Events, Reviews, and Notes. There is no "Submit All" button, because sending too many simultaneous requests to Facebook risks account suspension.

The second section, "Facebook Search Data," provides keyword-based search across twelve content categories including Posts, Photos, Videos, People, Places, Pages, Groups, Apps, Events, Links, and Marketplace. Entering a keyword here sends the query directly to Facebook's category-specific search rather than relying on the generic search bar.

The third section, "Base64 Conversion Queries," is the core of the tool. It includes:

Posts, photos, and videos by user (enter a user ID, optionally filter by year). This often surfaces content that does not appear on the target's own profile.

Posts, photos, and videos by location (enter a location ID such as `108659242498155` for Chicago, optionally filter by year). This often surfaces content that does not appear through traditional search techniques.

Posts, photos, and videos by keyword (enter a user ID and a keyword, optionally filter by year). Bazzell demonstrates this with user ID `4` (Zuckerberg) and the keyword `OSINT`.

Events by location (enter a location ID and a keyword such as `protest`). This returns active and future events matching the criteria.

People by employer, city, and school (enter the numeric ID for an organization and a partial name). The tool generates two distinct result sets: people who work at the organization and people who attended it. Bazzell demonstrates this with Harvard's ID `105930651606` and the name `Tom`, and notes the search can identify a target even when you only know a small amount about them or they are using a false last name.

Common friends (enter two user IDs to retrieve mutual friends). This requires at least one target to have a public friends list. Bazzell notes the feature breaks often.

Posts, photos, and videos by date (enter a keyword and a date range via an interactive calendar). This allows filtering to a specific calendar day, which exceeds what the official Facebook site offers.

Tool updates, if needed, will be announced at inteltechniques.com/osintbook9.

## Where the Tool Outperforms the Official Site

Bazzell identifies three specific capabilities the tool has that the official Facebook website does not:

Videos by date. The official site limits video date filtering to "Today," "This Week," or "This Month." The tool supports exact date filtering back to any year, as demonstrated with a 2015 video from Zuckerberg's page.

Posts by location. The official site only shows a location's own page content. The tool allows querying posts by any person at a specific location ID, filtered by year. Bazzell demonstrates this with location ID `74286767824` filtered to 2018.

Posts by date. The official site's keyword search only filters by year. The tool supports filtering to a single calendar day. Bazzell uses this to find posts mentioning his site on the specific day it was briefly shut down due to legal demands.

## Facebook Account Creation Date Estimation

Digital forensics researcher Josh Huff (LearnAllTheThings.net) established that Facebook ID numbers were assigned in chronological order until approximately 2018, when Facebook began issuing random numbers. The transition from 32-bit to 64-bit IDs (beginning with `100000`) occurred between April and December of 2009. Any ID below `100000000000000` indicates creation before April 2009. A 15-digit ID indicates creation after December 2009.

The approximate year ranges, described as rough estimates for general guidance only, are:

## Facebook Phone Number Search

Submitting a target's phone number at `https://mbasic.facebook.com/login/identify/?ctx=recover` will confirm whether a Facebook account is associated with that number. If an account exists, Facebook displays a heavily redacted email address such as `n***@*******`. This is the only remaining method after previous phone-number lookup capabilities were removed.

## Facebook Friends List Extraction

Facebook's 2016 Terms of Service change blocked all scraping tools, and the Facebook API no longer provides friend data either. The only working method is manual extraction into a spreadsheet.

Open the target's friends page (Bazzell uses `facebook.com/darya.pino/friends` as the example) and hold the space bar to load the complete list. Highlight everything from the first friend to the last and copy it with Ctrl+C (or right-click, copy).

Open Microsoft Excel and click the column B header to select the entire column. Paste with Ctrl+V. The content will be disorganized, with profile images layered on top of text. Press F5 to open the "Go To" dialog, click Special, choose Objects, and click OK to select all images. Press Delete to remove them. Column B now contains only text with hyperlinks.

Click the column A header and paste the friend content again with Ctrl+V. Right-click any cell in column A and choose Clear Contents. This removes the text but keeps the images in that column.

Resize column A to be slightly larger than one profile image. Resize column B to fit the text. Use Find and Replace to remove every instance of "Add Friend." Under the Home menu, choose Format then Auto Fit Row Height to eliminate excess spacing. Select column B and left-justify the text.

The result is a spreadsheet with profile images in column A and names with active profile links in column B. Bazzell acknowledges this is not the cleanest approach but confirms it works.

## Facebook Email Search via the Page Role Trick

Standard Facebook email search was removed in 2019. The Page Role method remains available. It works because when assigning a manager role to a Facebook business page, Facebook displays the name and profile photo associated with the email address entered as a confirmation step. The investigator can see the associated profile and then cancel without completing the assignment and without notifying the target.

While logged into a covert Facebook account, click Create then Page in the upper-right corner. Click Get Started under Business or Brand. Assign a random page name, select any category, click Continue, and skip all optional steps. On the new page, click Settings in the upper-right. In the left column, click Page Roles. Under "Assign a New Page Role," enter the target's email address. Facebook presents any associated profile. Cancel the request without adding the role.

Bazzell notes that Facebook's scrutiny of covert accounts, VPN-protected networks, and overall account behavior means results will vary.

## Closing Observation on Facebook

Bazzell describes Facebook as the OSINT source most likely to change its features over time. He frames this positively: when Graph Search was removed in 2019, the Base64 method emerged as a replacement. When current methods break, new ones typically appear. Consistent daily practice with available resources is more important than any single technique.

## Chapter 11: Twitter Investigation Fundamentals

Twitter is a social network and microblogging service limiting most posts to 280 characters. As of 2019, the platform reported over 500 million posts per day. Users create profiles and post tweets covering thoughts, current location, plans, and links. A user can follow other users and see their posts continuously. Unlike Facebook, no login is required to search twitter.com.

## Twitter Search

The standard search bar is available at `twitter.com/explore` and on every Twitter page. Navigating directly to twitter.com often produces a signup prompt without a search option, so using the explore URL bypasses that.

The Advanced Search page (`twitter.com/search-advanced`) provides structured fields:

"All of these words" ignores word order and requires all specified words to appear. "This exact phrase" is equivalent to quoting the phrase in the main search. "Any of these words" applies OR logic. "None of these words" excludes posts containing the specified terms. "These Hashtags" locates posts marked with a specific topic tag. "From these accounts" filters to posts by a specific user. "To these accounts" finds posts sent to the attention of a specific user, which helps identify associates and content directed at the target. "Mentioning these accounts" finds posts that reference a user without being direct replies. The Dates field restricts results to a date range.

Topic searches through Advanced Search are typically limited to the previous seven to ten days. Individual profiles display tweets as far back as the investigator is willing to scroll.

Bazzell states he does not use the Advanced Search page in practice. Manual search operators entered in the standard search bar replicate all the same options with two advantages: the results are easier to document for court use, and the same operators can be used to monitor live Twitter data, as explained later in the chapter.

## Locating a Twitter Profile

After searching a name, Twitter presents results in five tabs. Top displays popular tweets as curated by Twitter's algorithm. Bazzell advises avoiding it because it lets Twitter decide what evidence appears. Latest presents a reverse-chronological list of matching posts, which works well for topic searches but not for locating a specific profile. People is the best starting point for finding a target by real name or username. Photos searches for images matching the query and can surface posts by unknown people who mentioned the target by name. Videos works the same way for video content.

If a target does not appear through the People tab, the Twitter Directory (`twitter.com/i/directory/profiles`) allows alphabetical browsing through all profiles. The process involves drilling from a first letter, to a name range, to a subrange, until a page of actual profiles appears. Bazzell describes this as awkward but notes it can locate targets who use a misspelled version of their real name.

If searching by real name fails entirely, Bazzell recommends trying usernames from other platforms (Instagram, Snapchat, YouTube) directly in the format `twitter.com/username`.

## Twitter Email-to-Account Lookup

Twitter's website returns no results when an email address is used as a search query, even if an account exists for that address. The workaround uses the Twitter mobile app inside a virtual Android device. Using a physical device is possible but not recommended for operational security reasons.

Add the target's email address as a new contact in the Android Contacts application. Open the Twitter app, navigate to Settings and privacy, then Privacy and safety, then Discoverability and contacts, and enable contact syncing. Twitter will generate a notification in the Android notification bar reading "Find your friends on Twitter." Opening that notification presents a Suggested Followers screen. If the email is linked to a Twitter account, that account appears on this screen. Bazzell demonstrates this with the personal email address of Chris Hadnagy, which immediately identified his Twitter account.

The investigator should not follow or otherwise interact with the suggested accounts. Following a suggested account sends a notification from the investigator's account to the target.
