This chunk spans the end of Chapter 3 (web browsers) and the opening of Chapter 4 (Linux applications). It covers completing a hardened Firefox setup, browser alternatives, investigative bookmarklets, and the first steps of building a custom Linux OSINT virtual machine.

## KeePassXC Browser Integration

The KeePassXC browser extension connects the KeePassXC desktop application to Firefox so that stored credentials are automatically populated into login fields when a matching entry is selected. This is an offline solution. Passwords are never sent over the internet in plaintext or encrypted form, which is the key advantage over online password managers.

## Exporting and Importing a Firefox Profile

A configured Firefox profile can be copied from one machine to another so that every extension, setting, and bookmarklet is reproduced exactly. The process is the same on Windows, Mac, and Linux. From the configured browser, the user opens Help > Troubleshooting Information and clicks "Open Folder" under Application Basics. That folder holds the profile files. The user copies them to a removable drive, opens the same menu in the target Firefox installation, and pastes the files into the target profile folder, overwriting when prompted. Both installations must be the same Firefox version for this to work reliably. The process overwrites everything in the target profile (bookmarks, extensions, and settings), so it should only be done on a fresh install or a browser the user is willing to replace.

For readers who do not want to configure each extension manually, a pre-built profile is available at `https://inteltechniques.com/osintbook9/ff-template.zip` with username `osint9` and password `bookl43wt`. ## Chrome

Chrome is fast and sandboxes tabs securely, but it sends substantial browsing data to Google. The author uses Chrome only for live training events (where stability under many open tabs matters) or when a Chrome-specific tool requires it. Hardening steps include clearing browsing data daily, disabling autofill and password saving, and removing any unverified extensions. uBlock Origin is recommended on Chrome just as on Firefox. For situations where Chrome-based rendering is needed but Google telemetry is a concern, Brave is the preferred alternative. Brave is built on Chrome but removes most of its privacy-invasive behavior. For investigations that can be done entirely in Firefox, the author considers Firefox the better choice.

## Tor Browser

Tor stands for The Onion Router. The Tor Browser routes all traffic through a relay server in another country, so every website the investigator visits sees the relay's IP address rather than the investigator's real one. On Windows and Mac the Tor bundle is downloaded from torproject.org and requires only a default installation. On launch it connects to a Tor server and opens a custom version of the Firefox browser. Closing that window ends the session. Browsing speed drops noticeably while connected, which is normal and tends to improve the longer the session runs.

The author does not recommend Tor for routine searches on platforms like Facebook, Twitter, or YouTube. It is appropriate when visiting the personal websites or blogs of technically sophisticated subjects who might analyze visitor IP data. Any activity through the Tor browser appears to originate at a foreign IP and is not linked to the investigator's actual connection.

## Bookmarklets

Bookmarklets are saved as browser bookmarks but execute JavaScript on the current page without navigating away from it. They add functionality to sites that do not expose it natively. The Firefox profile described above includes them pre-configured in a "Bookmarklets" toolbar folder.

A concrete example: loading a Facebook profile and clicking the FacebookID bookmarklet produces a popup showing the account's numeric user ID. Mark Zuckerberg's account returns "4". That ID is used in later investigative techniques. The full list of bookmarklets bundled in the profile is:

- **FacebookID**: displays the numeric Facebook User ID for the current profile
- **FacebookGroupID**: displays the Facebook Group ID for the current group page
- **FacebookExpand**: expands all comments on a profile (may be slow or crash on large pages)
- **FacebookScroll**: loads and scrolls a Facebook feed to prepare it for page capture
- **TwitterScroll**: loads and scrolls a Twitter feed for capture
- **InstagramScroll**: loads and scrolls an Instagram feed for capture
- **PageScroll-Slow**: slowly scrolls a static website for video capture
- **PageScroll-Fast**: faster scroll through a static website for video capture
- **PageScroll-Feed**: scrolls a feed-style social network page for video capture
- **ModifiedDate**: displays the date and time of last modification for a static page
- **Cache-Google**: opens the Google Cache version of the current page
- **Cache-Archive**: opens the Archive.org version of the current page
- **Images**: opens a new tab listing all images from the current page
- **Links**: opens a new tab listing all URLs from the current page
- **WordFrequency**: lists all words on the page sorted by frequency, useful for identifying keywords
- **Paywall**: opens a paywalled news article via Outline.com
- **Right-Click**: re-enables right-click on sites that block it
- **TextSelect**: re-enables copy-paste on sites that block it
- **BugMeNot**: checks BugMeNot for publicly shared login credentials to the current site
- **Tools**: launches the user's offline OSINT tools on the Linux Desktop (path needs adjustment on Windows and Mac)
- **Notes**: stores per-URL investigation notes in local browser storage, persistent for the life of the VM and profile

The author acknowledges that the code for these bookmarklets was collected from OSINT community sources over many years and does not claim sole authorship.

## Chapter 4: Linux Applications

Chapter 4 opens with the argument that Linux is the preferred platform for OSINT work. Three reasons are given. Many Windows-only applications from earlier editions have become outdated or unmaintained. Linux provides a more secure environment, particularly within a dedicated virtual machine kept separate from other cases. More OSINT-related applications are natively available for Linux than for Windows. The chapter is a manual walkthrough so readers understand every detail before a later chapter automates the same setup in minutes.

All scripts referenced in the chapter are downloadable from `https://inteltechniques.com/osintbook9` using credentials `osint9` / `bookl43wt`. A command reference file is kept at `https://inteltechniques.com/osintbook9/linux.txt` and is updated if anything changes.

The author discourages using Ubuntu's graphical software store because the selection is limited. All installations are done through the Terminal. The `sudo` prefix runs a command with administrator privileges. `sudo apt update` refreshes the package list. `sudo apt install -y` installs a package and automatically confirms prompts. `sudo snap install` uses Ubuntu's Snap package system. Passwords typed after `sudo` do not appear in the terminal but are recorded.

### VLC Media Player

VLC plays nearly any audio or video file format. It is installed with `sudo snap install vlc`. After installation it appears in the Applications menu and becomes the default media player for downloaded files.

### FFmpeg

FFmpeg is a set of command-line media tools required by other utilities to process video and audio. It is installed with `sudo apt update` followed by `sudo apt install -y ffmpeg`. FFmpeg is not used directly by the investigator but enables other tools to produce higher-quality output.

### YouTube-DL (Video Download Tool)

YouTube-DL is a Python script and the core of the video download workflow. It requires Python 3 and pip. Installation sequence:

1. `sudo apt install -y python3-pip` installs pip for Python 3.
2. `sudo -H pip install youtube_dl` installs YouTube-DL as the current home user rather than root, which prevents damage to the system's Python installation.

To download a single video, the user navigates to the Desktop in Terminal (`cd ~/Desktop`) and runs `youtube-dl` followed by the video URL. When FFmpeg is present, YouTube-DL downloads the separate high-quality audio and video streams that YouTube serves and merges them into a single playable file. Without FFmpeg, only a lower-quality combined stream is available.

To download an entire channel or playlist, the user passes the channel's videos page URL to the same command. YouTube-DL then downloads every video on that page. The `--all-subs` flag adds all closed-captioning subtitle files for each video. The `--all-formats` flag downloads every available quality level. Ctrl+C cancels any in-progress download.

### Custom Tool Suite

The chapter identifies the full set of custom OSINT tools the VM will contain by the end of Chapter 5. These are presented as a preview before the detailed installation steps:

- **OSINT Tools**: launches the custom OSINT tools through Firefox
- **Video Download Tool**: downloads single videos or entire channels with captions and extracts YouTube comments
- **Video Utilities Tool**: plays, converts, extracts, or compresses video and extracts audio from media
- **Video Stream Tool**: saves, converts, and archives live and pre-recorded video streams in real time
- **Instagram Tool**: extracts images using Instalooter and Instaloader, or full content using Osintgram, by username
- **Gallery Tool**: downloads all images from a photo gallery (Flickr, Tumblr) or launches RipMe
- **Username/Email Tool**: searches a username or email across multiple online platforms
- **Eyewitness**: accepts a URL or list of URLs and returns site data and a screenshot of each
- **Domain Tool**: runs Amass, Sublist3r, Photon, theHarvester, or Carbon14 against a domain
- **Metadata Tool**: analyzes or strips metadata from media files
- **HTTrack**: clones static websites through a browser GUI without using the terminal
- **Metagoofil**: finds documents on a domain and extracts their metadata
- **Breaches/Leaks Tool**: searches breach data, analyzes hashes, or queries Elasticsearch indexes
- **Reddit Tool**: extracts current and deleted posts for a username and archives subreddits
- **Internet Archive Tool**: retrieves source code and screenshots of archived pages from Archive.org
- **Spiderfoot**: automated OSINT reconnaissance framework launched through the custom Firefox build
- **Recon-ng**: modular reconnaissance framework
- **Update Scripts**: updates the operating system, pip programs, and all custom OSINT applications
