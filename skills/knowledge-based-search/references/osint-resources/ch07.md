This chapter covers video downloading utilities for OSINT investigations running on a Linux VM (Ubuntu). It explains youtube-dl, yt-dlp, and YouTube Tool, how to build shell scripts that wrap them into point-and-click desktop applications, and how to handle the two main failure cases: fragmented HLS video streams and referer-blocked downloads.

## youtube-dl

youtube-dl is a command-line tool that downloads videos, entire playlists, and whole channels from YouTube and most other video hosting services (Vimeo, LiveLeak, WorldStarHipHop, and others). By default it selects the highest available resolution. Key commands:

Download a single video with all subtitle tracks:

    youtube-dl https://www.youtube.com/watch?v=lLWEXRAnQdO --all-subs

Subtitles are saved as .vtt text files next to the video. Each line contains a timestamp and the spoken text. This enables bulk keyword search across a subject's entire video history: download all subtitles for a channel with one command, then search all .vtt files for a specific word to find every timestamp where it appears.

To limit download size when archiving large channels, cap resolution at 720p:

    youtube-dl <URL> -f 'bestvideo[height<=720]+bestaudio' --all-subs

## yt-dlp

yt-dlp (github.com/yt-dlp/yt-dlp) is a fork of youtube-dl with a more active development community. It accepts the same command syntax. The practical difference is that YouTube throttles youtube-dl downloads to below 50 kbps, making a five-minute video take over an hour. yt-dlp has patched around this throttle so the same download completes in seconds. Install with:

    sudo -H pip install yt-dlp

The chapter recommends keeping both tools installed because the situation can reverse as platforms and tools update. The final report for an investigation should document which tool was used.

## YouTube Tool

YouTube Tool (github.com/nlitsme/youtube_tool) exports structured data from YouTube pages. Install with:

    sudo -H pip install youtube-tool

Commands:

Export all comments from a video to a text file:

    yttool --comments https://www.youtube.com/watch?v=<ID> > comments.txt

One example produced over 20,000 lines of comments. Note that YouTube changes its comment pagination often, which breaks this feature until the tool is updated.

Export subtitles with timestamps:

    yttool -v --subtitles https://www.youtube.com/watch?v=<ID> > subs.txt

Export all video entries in a playlist:

    yttool --playlist https://www.youtube.com/playlist?list=<ID> > playlist.txt

Export page metadata for a video:

    yttool --info https://www.youtube.com/watch?v=<ID> > info.txt

## Scripted GUI Wrappers

The chapter describes building bash scripts that use Zenity to present graphical dialogs so investigators can operate these tools without opening a terminal. The script flow is: a Zenity radio-button menu presents download options, a second Zenity entry dialog collects the URL or ID, the chosen tool runs with appropriate flags, a Zenity progress bar is displayed while it runs, and the output folder opens automatically in Nautilus when done.

A .desktop file placed in /usr/share/applications/ creates an icon in the Ubuntu Applications menu and Dock. The resulting shortcut offers eight options: youtube-dl at best quality, youtube-dl capped at 720p, yt-dlp at best quality, yt-dlp capped at 720p, export comments, export subtitles, export playlist data, and export page info.

File naming uses a timestamp prefix (format: YYYY-MM-DD:HH:MM) followed by the video title, which prevents duplicate names and records when the evidence was captured.

## Fragmented Video Streams (HLS / m3u8)

Many sites deliver video as hundreds of small .ts fragment files streamed to the browser. Submitting the page URL to youtube-dl or yt-dlp fails because the tools cannot detect the actual stream. The correct approach:

1. Open the page in Firefox or Chrome and open Inspector (right-click, Inspect).
2. Click the Network tab, then press play on the video.
3. Watch the network requests for a file ending in .m3u8 (the HLS playlist that lists all fragments).
4. Right-click that entry, copy its URL.
5. Submit the .m3u8 URL directly to yt-dlp.

The tool downloads all fragments and assembles a single MP4 file. The chapter reports this method works for approximately 99% of streaming videos encountered.

## Blocked Downloads (Referer Spoofing)

Some sites enforce a referer policy: they allow streaming only when a request originates from an approved domain. Submitting the direct video URL to a download tool returns a small empty file because the tool appears as an unauthorized source. Resolution:

1. Play the video in the browser.
2. Open Inspector, Network tab, sort requests by Transferred size.
3. Find the video file (for example, v.mp4) and click it.
4. Locate the Referer header in the request details (for example, Referer: https://gomoplayer.com/).
5. Run yt-dlp with the --referer flag set to that value:

        yt-dlp <direct-video-URL> --referer https://gomoplayer.com/

The --referer flag tells the remote server that the request originates from the approved domain, bypassing the restriction. The chapter's worked example involved a 750 MB television episode that could not be obtained any other way.

## Locating Removed Videos

When a video no longer exists on its original host, a Google query combining the title and identifiers with the word "watch" can surface third-party sites that have archived it:

    "live pd" "s01e56" "watch"

Results may embed the video in a custom player requiring the fragmented or referer bypass techniques described above.
