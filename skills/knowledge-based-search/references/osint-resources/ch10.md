## HTTrack: Offline Website Archiving

HTTrack (httrack.com) creates an exact local copy of a static website. The primary use is preservation of online evidence before a site disappears or before presenting it in court where live internet access is inappropriate. Install with `sudo apt install -y webhttrack`, then launch by typing `webhttrack` in a terminal or clicking the httrack.desktop shortcut in the Applications menu.

The workflow is: give the project a title (preferably the website name), choose a save location, add the target URL, and do not enter any credentials. The application then downloads all public content. The result is a locally navigable copy. HTTrack only works reliably on small static websites and cannot handle large dynamic sites such as social networks. Despite being an old program, it performs well on small business sites and can extract substantial content from mid-size sites. The author used it to recover several gigabytes of scraped LinkedIn data, including profiles, names, email addresses, user IDs, and employment history, from a site that subsequently disappeared.

Some tools later in the chapter require a sound package: `sudo apt update` followed by `sudo apt install -y libcanberra-gtk-module`.

## Metagoofil: Document Discovery and Metadata Extraction

Metagoofil locates and downloads publicly indexed documents from a target domain using search engine results, then pairs with ExifTool to extract metadata. It is installed by cloning `https://github.com/opsdisk/metagoofil.git` into `~/Downloads/Programs` and running `sudo -H pip install -r requirements.txt -I`.

The basic command specifies a domain (`-d`), file type (`-t`), and output folder (`-o`):

```
python3 metagoofil.py -d cisco.com -t pdf -o ~/Desktop/cisco/
```

After downloading, ExifTool generates a metadata CSV:

```
cd ~/Desktop/cisco
exiftool * -csv > ~/Desktop/cisco/Report.csv
```

The author's decision protocol distinguishes three situations. If documents are already on the local machine, use ExifTool directly. If the target site has few documents, download them manually through a browser. If the site has hundreds of documents, use Metagoofil one file type at a time, cycling through pdf, doc, xls, ppt, docx, xlsx, and pptx. Running one type at a time reduces the chance of failure.

A known limitation: Metagoofil depends on search engines returning results. Google may block queries, particularly when the request comes from a VPN IP address that appears abusive. During testing the author could complete one full query before subsequent attempts were blocked. An automated shell script titled `metagoofil.sh` is included with the Linux downloads to simplify these tasks.

## Reddit Investigation Tools

Reddit has become a frequent source of online evidence. Three tools handle Reddit research at scale: Bulk Downloader For Reddit (bdfr), Reddit Finder (redditsfinder), and Downloader For Reddit. All three are installed together:

```
sudo apt install python3.9
sudo -H python3.9 -m pip install bdfr -I
sudo -H pip install redditsfinder -I
cd ~/Downloads/Programs
git clone https://github.com/MalloyDelacroix/DownloaderForReddit.git
cd DownloaderForReddit
sudo -H pip install -r requirements.txt -I
```

**Bulk Downloader For Reddit** requires Python 3.9 specifically (not available in Ubuntu 20.04 by default, hence the explicit install step). It retrieves up to 1000 posts from a subreddit or all posts by a user within a subreddit:

```
python3.9 -m bdfr download ~/Documents/Reddit/osint/ --subreddit osint
python3.9 -m bdfr download ~/Documents/Reddit/inteltechniques/ --user inteltechniques --subreddit osint
```

**Reddit Finder** queries the Pushshift API and returns metadata for current and deleted posts attached to a username. The basic command is `redditsfinder inteltechniques`. Adding `-pics -d` saves all posts (including deleted ones) along with any uploaded images and a documentation text file to `~/Documents/users/inteltechniques/`. The metadata returned includes datetime, id, created_utc, subreddit, score, link_id, parent_id, and body text.

**Downloader For Reddit** is a graphical application launched with `python3 main.py` from its directory. Users add accounts and subreddits, set the post limit to Max, and right-click entries to download. Results are viewable and exportable through the Database View panel.

A shell script titled `reddit.sh` (also launchable as "Reddit Tool" from the Dock or Applications menu) automates all three tools and provides menu options for Subreddit Download, User Download, User Archive, and launching the graphical downloader.

## Google Earth Pro: Geospatial and Historical Imagery Analysis

Google Earth Pro is a standalone application that extends Google Maps data with mapping tools, data import from spreadsheets, and historical satellite imagery. Install via:

```
cd ~/Downloads
wget http://dl.google.com/dl/earth/client/current/google-earth-stable_current_amd64.deb
sudo apt install -y ./google-earth-stable_current_amd64.deb
sudo rm google-earth-stable_current_amd64.deb
```

Enter an address or GPS coordinates in the upper-left search field to navigate to a target location. The left-side Layers menu allows enabling data overlays one at a time. Relevant layers for OSINT include Photos (digital images uploaded through social networking), Roads (road name text layer), 3D Building (alternative three-dimensional view), and Gallery (user-submitted content including YouTube videos). The recommendation is to disable all layers and enable them one at a time to assess each data set.

The Historical Imagery feature is activated by clicking the clock icon in the upper menu bar. A slider appears that moves between satellite image dates. Images extend back to at least 2000, though quality declines with age. This feature helps identify changes over time: building modifications, additional vehicles, land changes, and suspected drug cultivation sites. Drug enforcement agents use it to monitor locations over time. The author considers Google Earth Pro's historical satellite imagery irreplaceable, citing use on investigations spanning over a decade.

## Screen Capture and Evidence Documentation

The chapter establishes a rule: all screen captures should be executed within the VM, not from the host operating system. Capturing from the host can inadvertently expose other files visible on the host desktop. The author cites a real 2014 incident in which a detective's video recording from a Windows host briefly showed a file titled `Accounts.xlsx` containing covert online accounts. The defense successfully moved to have that file analyzed, forcing disclosure.

Ubuntu provides native screenshot shortcuts requiring no installation:

- PrtSc saves a screenshot of the entire screen to the Pictures directory.
- Shift + PrtSc saves a selected region.
- Alt + PrtSc saves the active window.
- Ctrl + PrtSc copies the entire screen to the clipboard.
- Shift + Ctrl + PrtSc copies a selected region to the clipboard.
- Ctrl + Alt + PrtSc copies the current window to the clipboard.

On Mac keyboards, F13 replicates PrtSc.

**Kazam** is a minimal screen recording tool installed with `sudo apt install -y kazam`. After launching from the Applications menu, clicking Capture begins a countdown followed by full-screen recording. Stopping the recording through the upper-right icon produces a high-resolution video with no branding or logos. Video capture is useful when a still screenshot cannot document a dynamic investigation step or when the recording needs to be shared as a replicable demonstration.

## KeePassXC

KeePassXC is an offline password manager with an optional browser plugin for automated credential entry into websites. It is installed inside the VM with `sudo snap install keepassxc`, which creates an Applications menu shortcut. Its behavior matches the descriptions given in earlier chapters.

## Miscellaneous Repairs and Updates

After installing many packages, three commands clean up any issues:

```
sudo apt update --fix-missing
sudo apt -y upgrade
sudo apt --fix-broken install
```

To force all pip-installed programs to use the most current versions of their dependencies, run:

```
sudo -H pip list --outdated --format=freeze | grep -v '^\-e' | cut -d = -f 1 | xargs -n1 sudo -H pip install -U
```

Warnings during this process can be ignored. Programs are more likely to function correctly with current dependency versions than with outdated ones.

## Troubleshooting Tips

- Tab completion in Terminal suggests or completes commands and paths.
- The up arrow navigates previous commands.
- Ctrl + C kills any running process. `ls` lists directory contents.
- Copy and paste in Terminal requires right-click, not Ctrl + V.
- Keyboard arrows move the cursor in a terminal command line. Mouse clicks do not.
- Dock icon size can be adjusted in Settings > Dock.

To grant execution rights to shell scripts in `~/Documents/scripts`:

```
cd ~/Documents/scripts
chmod +x *.sh
```

To show hidden system files in the Ubuntu Files application: open Files, click the three horizontal lines in the upper right, and select Show Hidden Files. The setting persists across reboots.

## Large File Transfer via USB

The VM includes a shared folder on the Desktop for transferring files between the VM and the host. For large transfers (hundreds of large videos), shared folders can fail, especially in VirtualBox. The preferred alternative is to transfer directly to a USB drive mounted inside the VM.

When a USB drive is inserted into the host, the host operating system claims it first. To hand it to the VM: eject the drive from the host, then in the VirtualBox menu choose Devices > USB > device name. If the USB is formatted for Mac or Windows only, Linux may not read it. The solution is to format the USB inside the VM using the Disks application: delete all existing volumes and create a new FAT volume. FAT is universally readable and writable across operating systems. The only limitation is that individual files cannot exceed 4GB.

- VM Tools-Basic: all tools covered up to this point in the book.
- VM Tools-Advanced: advanced Linux tools used later in the book.
