This unit covers the second half of Chapter 9 on search engines. It begins with foreign-language input, moves through newspaper archives and advanced search interfaces, surveys specialized and alternative search engines including Tor-based options, explains FTP server searching, and closes with source-code search.

## Foreign Language Input

Google Input Tools lets an investigator type a search term on a standard keyboard and convert it into characters for a chosen language. The primary value is on platforms like Twitter, where results are filtered by the literal characters submitted. Searching "Online Investigation" in English only returns English-character tweets. Submitting the Arabic transliteration returns tweets written in Arabic script. The same principle applies to any foreign-language username: find the native-script rendering, then search that.

## Newspaper Archives

**Google News Archive (news.google.com)** indexes both digital newspaper archives and content from the News Archive Partner Program. Filters include date, language, and publication. Useful for finding a target's previous locations, family members through obituaries, and associates through event or award mentions.

**Google Newspaper Archive (news.google.com/newspapers)** contains high-resolution scanned print newspaper pages. Its collection is smaller than third-party options but continues to grow.

**Newspaper Archive (newspaperarchive.com)** is a paid service claiming the world's largest newspaper collection, with high-resolution PDF scans dating from the 1800s to the present. Earlier editions of the book described methods to bypass the paywall. Those have all been patched.

A 14-day free trial with unlimited access is available but requires a credit card. A more durable free access method relies on public libraries that pay Newspaper Archive to host their collections publicly. A Google search isolates those library portals:

```
site:newspaperarchive.com "This archive is hosted by" "create free account"
```

To target a specific paper, add its name to the query:

```
site:newspaperarchive.com "This archive is hosted by" "cedar rapids gazette"
```

The result links to a library subdomain (example: crpubliclibraty.newspaperarchive.com). From that portal, a free account can be created with generic details and a throwaway email address. Access granted through one library portal extends to other library portals when the user navigates directly to them while still logged in, because the account is shared across the platform. Creating accounts on every freely available library collection during idle time gives persistent, broad access across many collections internationally.

Supplementary free newspaper archives:

- **Old Fulton (fultonhistory.com/Fulton.html):** 34 million scanned newspapers from the United States and Canada.
- **Library of Congress Chronicling America (chroniclingamerica.loc.gov):** Scanned US newspapers dated 1836 to 1922.
- **Library of Congress title directory (chroniclingamerica.loc.gov/search/titles):** US newspaper titles from 1690 to present.
- **Small Town Newspapers (stparchive.com):** Scanned and text versions of small-town papers since 1890.

Search features on all of these are weak. A Google site-operator search (example: `site:stparchive.com "michael bazzell"`) is often more effective.

## Advanced Search Interfaces

**Google Advanced Search (google.com/advanced_search)** presents the same operators available by typing (quotes, site:, filetype:) in a form interface. The filetype field in the form is limited to popular types. The manual `filetype:` operator handles many other extensions.

**Bing Advanced Search** is accessed through Yahoo's advanced search page (search.yahoo.com/web/advanced) because Bing has no equivalent of its own. Filters include individual terms, exact phrases, excluded terms, specific domains, file formats, and languages.

## Specialized Google Engines

Google segments some results into smaller focused engines. Most results from these do not appear in a standard Google search.

**Google Blogs** was a standalone engine removed in 2014 and is now a subsection of Google News. It surfaces personal websites and blogging platforms. Access via the Blogs option under the News Tools menu, or directly by constructing this URL (replace TEST with your search terms):

```
google.com/search?q=TEST&tbm=nws&tbs=nrt:b
```

**Google Patents (google.com/?tbm=pts)** searches the full patent database by inventor name, assignee, or content. Advanced patent search is at google.com/advanced_patent_search.

**Google Scholar (scholar.google.com)** indexes scholarly literature including peer-reviewed journals, conference papers, theses, and books. Court records and case law appear here at no cost, where private services would charge.

## Keyword Tool

**Keyword Tool (keywordtool.io)** displays autocomplete suggestion data from Google, Bing, YouTube, and the App Store, providing the ten most popular suggestions per query rather than Google's five. Country filtering is available. Practical uses include discovering misspelled variants of a product name that standard searches miss, and identifying what supplementary terms people associate with a target name or brand. Example output for the term "osint": popular Google queries include "osint meaning" and "osint websites"; YouTube searches include "osint tools" and "osint phone number"; Bing users search "osint resources" and "osint api."

## Alternative Search Engines

**Searx (searx.be)** is a meta-crawler that aggregates Google, Bing, and other results with duplicates removed. Three features distinguish it from a simple comparison site. First, next to each result is a "cached" link that opens the archived page through the Wayback Machine rather than Google or Bing cache. Second, a "proxied" link loads the target page through Searx's own servers, so the destination website receives Searx's data rather than the investigator's IP address. Third, the "Links" section on any results page offers download of results as CSV, JSON, or RSS files. The CSV contains all results with descriptions and direct links, useful when many searches must be analyzed later.

**Exalead (exalead.com/search)** is headquartered in Paris and performs well for finding documents in which a target is mentioned by text. It supports the `filetype:` operator. Voxalead, a related Exalead product, applies speech-to-text to audio and video files and returns a timeline view of results where the target term appears in the spoken content.

**DuckDuckGo (duckduckgo.com)** does not record user search history or visited sites. It augments results with Wikipedia and Wolfram Alpha data. Fewer results than major engines, but higher relevance. Appropriate when query logging is a concern.

**Start Page (startpage.com)** routes searches through its own servers and displays content within their site. The destination website receives Start Page's data rather than the investigator's IP address. Useful for sensitive investigations where connection-level monitoring is a concern.

**Qwant (qwant.com)** launched in 2013 and combines web, news, images, videos, maps, and music results into a column-based interface. Its tabs surface recent posts from Twitter, Facebook, LinkedIn, and Myspace about or by people matching a name search.

**Million Short (millionshort.com)** removes the most popular websites from results. Options are: top 100, 1,000, 10,000, 100,000, or 1,000,000 sites filtered out. This eliminates dominant domains and surfaces lesser-known sites that mention a target.

## Tor Search Engines

Tor is a volunteer network of more than six thousand relays that routes traffic to conceal the user's location and identity. Websites hosted on the Tor network use .onion addresses and cannot be reached from a standard browser without Tor software. These sites host both legal and illegal content, including drug markets, weapons sales, and child pornography. Several tools index them.

**Ahmia (ahmia.fi)** is accessible from a standard browser and is described as the most thorough publicly accessible Tor index. Results with .onion addresses require the Tor Browser to open natively.

**Dark Search (darksearch.io)** appeared in 2019. On a search for "OSINT," Ahmia returned 5 results while Dark Search returned 51. It indexes email addresses of targets effectively and has replaced Ahmia as the first choice for many Tor-based investigations.

**Onionland Search (onionlandsearchengine.com)** relies on Google's indexing of Tor sites via URL proxy links and occasionally surfaces sites not found by the other tools.

**Tor2Web** allows access to .onion sites without the Tor Browser by replacing ".onion" in an address with ".onion.ly." Example: libertygb2nyeyay.onion becomes libertygb2nyeyay.onion.ly. Tor2Web connects to the onion service via Tor and relays the response. This is useful when .onion links appear on standard sites such as Twitter.

**Not Evil** is a search engine that runs only on the Tor network at hss3uro2hsxfogfq.onion. It can be queried without the Tor Browser through Tor2Web. Submitting a query through the URL directly is more reliable than using the proxy's search form:

```
hss3uro2hsxfogfq.onion.ly/index.php?q=OSINT
```

**Haystack** is an alternative Tor-native engine at haystak5njsmn2hqkewecpaxetahtwhsbsa64jom2k22z5afxhnpxfid.onion. Query via Tor2Web by substituting .onion.ly and appending `?q=osint`.

**Tor66** is at tor66sewebgixwhcqfhp5inzp5x5uohhdy3kvtnyfxc2e5mxiuh34iid.onion with limited reliability.

Tor hidden services appear, disappear, and reappear frequently.

## Search Engine Collections

**Search Engine Colossus (searchenginecolossus.com)** indexes search engines organized by country. The main page lists countries alphabetically, each linking to active engines in that country. Most useful when a target has strong ties to a specific country, to identify which engines are dominant there.

**Fagan Finder (faganfinder.com)** provides an interactive page that populates a query into hundreds of search services simultaneously, covering many specialized and regional engines.

## FTP Search

File Transfer Protocol (FTP) servers are computers with public IP addresses used to store files. Though FTP usage has declined from a decade ago, servers remain abundant, are frequently unsecured, and are indexed by Google and Bing. A targeted search string is required.

To find files titled "confidential" on FTP servers:

```
inurl:ftp -inurl:(http | https) "confidential"
```

The `inurl:ftp` restricts results to FTP content. The `-inurl:(http | https)` excludes standard web pages. The quoted term mandates its presence. This search yielded 107,000 results in one documented example.

To find Cisco-related PDFs on FTP servers:

```
inurl:ftp -inurl:(http | https) "cisco" filetype:pdf
```

Once a file is found, directory browsing is possible by truncating the filename from the URL. For a file at ftp://ftp.swcp.com/pub/cisco/03chap01.pdf, navigating to ftp://ftp.swcp.com/pub/cisco/ displays the full folder contents. Paste FTP URLs directly into a browser to browse. This manual navigation reveals sensitive documents that keyword searches do not return. Sensitive files from companies, government agencies, and the military have been located this way.

Third-party FTP search engines supplement Google and Bing:

**Napalm FTP (searchftps.org)** shows the date each result was last confirmed at its location, which helps determine whether content is still present. It returned the most results in a comparison (3,384 for the query "Cisco" "PDF"), but many were no longer live. Google found 19,600 results for an equivalent operator search.

**Mamoht (mmnt.ru)** is a Russian FTP search engine that filters results by the country hosting the content. Its "Search within results" feature lets the investigator run a second term against an existing result set, returning only records that match both queries. It returned 789 results for "Cisco" "PDF."

**wenjian (s.wenjian.net)** is a Chinese FTP search service that is less comprehensive than the others but has produced unique results in cases others missed, including contracts in an international fraud investigation.

## Source Code Search: Nerdy Data

**Nerdy Data (nerdydata.com/reports/new)** searches the HTML, JavaScript, and CSS source code of websites rather than the visible text. Ordinary search engines index what users see on a page. Nerdy Data indexes the underlying programming code, which is not visible without viewing source.

Two specific use cases illustrate its value.

The first involves analytics identifiers. Google Analytics assigns a unique account number to each registered website (format: UA-XXXXXXXX-X). Every site that uses that account must contain that number in its source code. Searching the number on Nerdy Data previously returned all sites associated with the account, revealing connected web properties owned by the same person. In one documented example, searching a specific UA number identified three sites, including two maintained by a law firm, that were not publicly linked to the same owner.

The second involves code reuse and cloning. If a developer copies code from another site, that copied code can be searched on Nerdy Data to find all sites that contain it. This makes it possible to identify websites that share programming code with a target site, even when no visible connection exists between them.
