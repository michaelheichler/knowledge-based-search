## VirusTotal Domain Analysis (virustotal.com)

- "Files" tab: files hosted on or downloaded from the target domain that VirusTotal has scanned. Columns: scan date, detection count (e.g. "0/60"), file type, file name.
- "Files Referring" tab: files on other sites that mention the target domain. Positive detections indicate malware referencing the domain.
- "Community" tab: comments from researchers. May contain owner details, new phishing domains, or abuse history. Most targets have no comments, but always check.
- Open suspicious downloads in a VM with no network access.

## Threat Intelligence Platform (threatintelligenceplatform.com)

Three key sections:

1. "Connected Domains": external domains linked from the target. Can reveal hidden third-party services or additional domains owned by the suspect.
2. "Potentially dangerous content": historical view of malicious content on the domain.
3. "Malware detection": historical phishing or malware presence, even on currently blank domains.

## Threat Crowd (threatcrowd.org)

Visual graph of domains associated with the target. Displays server IP, primary domain, and additional domains previously tied to the same hosting account. Useful for finding associated domains owned by the same operator.

## Censys (censys.io)

Three uses:

**Subject Alternative Names (SANs).** Click "Details" on the summary page and search for `alt_name` in the results to find other domains sharing the same SSL certificate.

**HTTP body capture.** The "Details" page under HTTP/HTTPS contains the raw HTML source. Copy and save as `.html` to reconstruct a page that has gone offline.

**SSL certificate history for Cloudflare bypass.**
- Direct URL: `https://censys.io/certificates?q=inteltechniques.com`
- Results show historical SSL authorities (e.g., Sectigo 2020, Comodo/Namecheap 2018, GoDaddy 2016), revealing domain host history.
- Each certificate record has a SHA1 hash. Search that hash under the "Certificate" menu to find all domains sharing that certificate, revealing associated domains.

## Shortened URL Metadata Extraction

Shortened URLs contain click analytics, referrers, and sometimes visitor IP addresses.

| Service | Metadata method | Data available |
|---|---|---|
| Bitly | Append `+` to URL: `bitly.com/29A4U1U+` | Click count. With free account: referrers, country-level location. |
| Tiny.cc | Append `~` to URL: `tiny.cc/v973ez~` | Click count, unique visits, OS breakdown, browser breakdown, country. |
| Goo.gl | Append `+` to URL: `goo.gl/Ew9rlh+` | Click count, countries, browser/OS breakdown. |
| Bit.do | Append `-` to URL: `bit.do/cbvNx-` | All of the above plus actual IP addresses of each visitor. |
| Unknown service | Use `checkshorturl.com` to expand and resolve any shortened URL. | Destination URL. |

Offensive use: create a Bit.do link pointing to a benign page, send to suspect, retrieve their IP from the Bit.do stats page.

## Cloudflare Bypass Techniques

When a domain hides its real host or IP behind Cloudflare:

1. **Historical Whois records.** Check historical domain registration records. Pre-Cloudflare records may show the real host.

2. **Crimeflare (crimeflare.org:82).** Attempts to uncover the real IP behind Cloudflare's free protection. Direct query: `crimeflare.org:82/cfs.html`. Enter domain, may return real IP. Reliability is hit or miss.

3. **Censys SSL certificate search.** `https://censys.io/certificates?q=TARGET-DOMAIN`. Historical SSL records may predate Cloudflare use and reveal the actual host. See SSL certificate history section above.

4. **Third-party tracking identifiers.** Even behind Cloudflare, targets may use Google Analytics IDs or other trackers that also appear on other domains they own. Search the Analytics ID and unique identifiers to correlate ownership across sites.

## Advanced DNS: DMARC Email Address Extraction (dmns.app)

Domains App surfaces email addresses hidden in DMARC DNS records that other tools miss.

Direct URL pattern: `https://dmns.app/domains/TARGET-DOMAIN.com/dns-records`

Example output:
```
"protonmail-verification=f84a8f78b21c92a4493fe5d9d5cb1150385846e9"
"v=spf1 include:_spf.protonmail.ch mx ~all"
"v=DMARC1; p=none; rua=mailto:donotspamme@michaelbazzell.com"
```

The `rua=mailto:` field in DMARC records often reveals a real email address not discoverable by any other method. Also confirms the email provider (Protonmail in this example).

## IP Address Investigation

### ViewDNS.info (viewdns.info)

All queries accept direct URL format. Replace `IP` with the target address (e.g. `70.39.110.82`).

| Tool | URL pattern |
|---|---|
| Reverse IP (other domains on same IP) | `https://viewdns.info/reverseip/?host=IP&t=1` |
| IP geolocation | `https://viewdns.info/iplocation/?ip=IP` |
| Port scan | `https://viewdns.info/portscan/?host=IP` |
| IP Whois | `https://viewdns.info/whois/?domain=IP` |
| Traceroute | `https://viewdns.info/traceroute/?domain=IP` |
| Reverse DNS (hostname) | `https://viewdns.info/reversedns/?ip=IP` |

Port reference: 21=FTP, 53=DNS, 80=HTTP, 443=HTTPS.

Reverse IP interpretation: many co-hosted unrelated domains indicates a shared host. A small number of co-hosted domains may indicate those sites also belong to the target.

### UltraTools (ultratools.com)

Redundant cross-check for IP data:
- `https://www.ultratools.com/tools/ipWhoisLookupResult?ipAddress=IP`
- `https://www.ultratools.com/tools/geoIpResult?ipAddress=IP`
- `https://www.ultratools.com/tools/pingResult?hostName=IP`

### Bing IP Search

Finds all websites hosted on a specific IP. Only works on Bing.

Search operator: `ip:54.208.51.71`

Direct URL: `https://www.bing.com/search?q=ip%3A54.208.51.71`

Most useful when the target self-hosts. If hosted on a large provider, results will be unrelated sites.

### IPLocation (iplocation.net)

Queries five services in one search. Returns: business name, general location (country, region, city), ISP. GPS coordinates typically resolve to the ISP's location, not the user.

Useful indicators: if the result shows Starbucks, Barnes & Noble, or a VPN provider (e.g., Private Internet Access), that characterizes the network type.

Direct URL: `https://www.iplocation.net/ip-lookup?query=IP&submit=IP+Lookup`

### That's Them (thatsthem.com/reverse-ip-lookup)

Aggregates marketing data linked to IP addresses. Can return name, home address, company, email, and age range for static business IPs. Less reliable for dynamic residential IPs.

Direct URL: `https://thatsthem.com/ip/IP`

### I Know What You Download (iknowwhatyoudownload.com)

Monitors torrent traffic and associates downloads with IP addresses. Returns file names and timestamps.

Direct URL: `https://iknowwhatyoudownload.com/en/peer/?ip=IP`

Test case: search PIA VPN address `173.244.48.163` to see torrents attributed to a shared VPN node.

Best results with static IPs (business, organization, public Wi-Fi). VPNs mask activity from this service.

### Exonerator: Tor Network Check (metrics.torproject.org/exonerator.html)

Determines whether an IP address was part of the Tor network at a given date. Provide IP and date. Most IPs are consistently on or off the Tor network. Use this when no other data is found for an IP, because the address may be a Tor exit node with no attribution to a real user.

### Wigle (wigle.net)

Crowdsourced database of wireless access points (SSIDs, MAC addresses, GPS locations, encryption type, channel, first and last seen dates). Free account required for search features (generic registration info acceptable).

Search capabilities:
- Search by address or map area to see local routers and their SSIDs.
- Search by SSID name to locate a specific router and retrieve its MAC address, location, and dates.
- Search by target's real name to find routers with that name in the SSID (may locate home address).
- Search by username: many users name their router the same as their online handle. A match can locate the target's physical address.

Results include: router SSID, MAC address, encryption type, channel, first/last seen dates, and GPS-pinned location.
