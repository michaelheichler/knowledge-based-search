## Core Search Pattern

Search the full address in quotes across engines, then search the username portion alone.

```
Google Email:   https://google.com/search?q="john.wilson.77089@yahoo.com"
Google User:    https://google.com/search?q="john.wilson.77089"
Bing Email:     https://bing.com/search?q="john.wilson.77089@yahoo.com"
Bing User:      https://bing.com/search?q="john.wilson.77089"
Yandex Email:   https://yandex.com/search/?text="john.wilson.77089@yahoo.com"
Yandex User:    https://yandex.com/search/?text="john.wilson.77089"
```

## Email Validation Tools

### TruMail (trumail.io)
Checks whether an address is active and deliverable. Returns JSON with fields: `validFormat`, `deliverable`, `fullInbox`, `hostExists`, `catchAll`, `disposable`, `free`.

Direct API URL:
```
https://api.trumail.io/v2/lookups/json?email=book@inteltechniques.com
```

`catchall: true` may indicate a burner domain address. `disposable: true` signals a throwaway provider.

### Emailrep.io (emailrep.io)
Richer than TruMail. Returns: reputation score, suspicious flag, reference count, blacklist status, malicious activity flags, credentials leaked (and recent flag), data breach presence, first-seen and last-seen dates, domain age, spam flag, free/disposable/deliverable status, and linked profiles (YouTube, Google, GitHub, Twitter).

The `profiles` field reveals accounts tied to the address. Use this first for investigations.

### Verify Email (verify-email.org)
Minimal. Returns OK or BAD. Rate-limited by IP and cookies.

### Email Hippo (tools.verifyemailaddress.io)
Minimal. Batch export available. Rate-limited by IP and cookies.

## Constructing an Unknown Address

If you know a target name and employer domain, generate candidates:
```
jstewart@medicaldistrict.org
jay.stewart@medicaldistrict.org
j.stewart@medicaldistrict.org
stewartj@medicaldistrict.org
```
Validate each against TruMail or Emailrep.

### Email Format (email-format.com)
Search a domain to discover the organization's email naming convention from confirmed live examples. If `medicaldistrict.org` returns a pattern of first-initial plus last-name, use that pattern to build your candidate list.

If you already know a username (e.g., a Twitter handle), generate variants across providers:
```
username@gmail.com
username@yahoo.com
username@hotmail.com
username@live.com
```

## Gravatar Lookup

Retrieve the avatar image tied to any email address, then run a reverse image search on it:
```
https://en.gravatar.com/site/check/test@gmail.com
```

## Data Breach Lookup

### Have I Been Pwned (haveibeenpwned.com)
Returns named breaches with dates and data types. Text-only direct query URL (copy-paste friendly for reports):
```
https://haveibeenpwned.com/unifiedsearch/test@test.com
```
JSON result includes: `Name`, `Title`, `Domain`, `BreachDate`, `PwnCount`, `Description`, `DataClasses`, `IsVerified`, `IsFabricated`.

Red flag: an address in a Dropbox plus LinkedIn breach indicates a real professional with years of activity.

### Dehashed (dehashed.com)
Complements HIBP. Finds breaches not yet public on HIBP. Free tier shows breach presence but not passwords. Premium tier claims to reveal passwords (check your employer's policy). Requires free account login even for basic queries.

Always run both HIBP and Dehashed together. They return non-overlapping results.

### Spycloud (spycloud.com)
Free API returns breach count and recency without naming sources. Use to confirm an address exists in breaches:
```
https://portal.spycloud.com/endpoint/enriched-stats/test@email.com
```
Result fields: `discovered` (months ago), `records` count, company name if domain match.

### Leaked Source (leakedsource.ru)
Shows breach source name and approximate hack date.

### Cybernews Personal Data Leak Check (cybernews.com/personal-data-leak-check)
Returns `true` or `false` only. Text-only direct URL:
```
https://check.cybernews.com/chk/?lang=en_US&e=test@test.com
```

## Password Exposure Tools

Check your organization's policy before using these.

### Leak Peek (leakpeek.com)
Displays partially redacted passwords from an 8-billion-credential combo list. Accepts email, username, password, keyword, or domain queries. Example output:
```
test@email.com:55Ji*******
test@email.com:Big6****
```

### We Leak Info (weleakinfo.ro)
Clone of the seized original. Free account required. Shows redacted passwords plus breach source domain.

### Breach Directory (breachdirectory.org)
Similar to We Leak Info. Also returns SHA-1 hashes of full passwords. Decrypt hashes at MD5 Decrypt:
```
https://md5decrypt.net/en/Sha1
```
Enter the hash to retrieve the full plaintext password (no account required if the hash is in the rainbow table). Example:
```
dc3245ecdcf2e40b140e121a014cc37f70239f41 : Ex71ayer
```

## Pastebin Monitoring

### PSBDMP (psbdmp.ws)
Archives Pastebin posts that contain email addresses and passwords. No free search UI. Use Google to find indexed entries:
```
site:psbdmp.ws "test@gmail.com"
```
If the PSBDMP link is dead, swap the domain to reach the original Pastebin archive:
```
Dead:  https://psbdmp.ws/WjwCkNL4
Live:  https://pastebin.com/WjwCkNL4
```
Premium API retrieves deleted Pastebin content by paste ID. Free trial gives 10 credits. URL pattern:
```
https://psbdmp.ws/api/v3/dump/PASTEID?key=APIKEY
```

## Tools to Avoid or Use With Care

**Avast Hack Check (avast.com/hackcheck):** Immediately emails the target address when searched and enrolls it in Avast's newsletter. Do not use the main search. Use the Friends Check URL instead:
```
https://www.avast.com/hackcheck/friend
```

**IntelligenceX (intelx.io):** Free tier gives partial results. Paid services are expensive and results are replicable via the free tools above.

## Site Profile Search via Search Engine

Many sites block internal profile search. Use Google with a site operator:
```
site:amazon.com "Target Name"
site:targetwebsite.com "John Doe"
```
Amazon profiles surfaced this way include photo, location, and product reviews.

## Pinterest Direct Access URLs

Pinterest blocks username search from its own interface. Use direct URL construction or Google:
```
Profile:       https://www.pinterest.com/USERNAME/
Pins:          https://www.pinterest.com/USERNAME/pins
Boards:        https://www.pinterest.com/USERNAME/boards
Followers:     https://www.pinterest.com/USERNAME/followers/
Following:     https://www.pinterest.com/USERNAME/following
Pins Search:   https://www.pinterest.com/search/pins/?q=KEYWORD
Boards Search: https://www.pinterest.com/search/boards/?q=KEYWORD
Google:        https://www.google.com/search?q=site:pinterest.com+KEYWORD
```

## BugMeNot (bugmenot.com)

Provides user-shared credentials for sites behind login walls. Search the target site URL to retrieve shared logins. Check departmental policy before use. Terms-of-service risk applies.

## FakeSpot (fakespot.com)

Identifies products on Amazon whose reviews are likely inflated or fabricated by seller-connected accounts. Also covers Yelp and TripAdvisor. Now requires a browser extension. Install only if you frequently need this type of analysis.

## IntelTechniques Communities Tool

Aggregates community search URLs (Reddit, TikTok, Hacker News, Imgur, Meetup, 4Chan, eBay, Pinterest) into one interface. Community data tends to be more personal than data from major social networks.

## Verification Workflow

1. Validate address existence with TruMail API, then Emailrep.io.
2. Search address in quotes across Google, Bing, Yandex.
3. Search username portion alone across the same engines.
4. Check Gravatar for avatar image (use for reverse image search).
5. Run HIBP and Dehashed together.
6. Run Spycloud and Cybernews for additional breach confirmation.
7. If no results, check Email Format for the correct domain naming pattern, rebuild the candidate list, and revalidate.
8. If a breach is found, note which services were breached to guide account discovery on those platforms.
