## Overview

This chapter (labeled Chapter 26 in the source text) covers the full workflow for investigating a target telephone number. The three-phase approach is: (1) identify the number type and carrier, (2) identify subscriber information such as name and address, and (3) locate online content connected to the number.

---

## Phase 1: Carrier Identification

The goal is to determine whether a number is a landline, cellular, or VOIP line, and which company provides service. Knowing the carrier is essential before seeking legal process, to avoid wasting effort on companies that hold no relevant data.

**Free Carrier Lookup** (freecarrierlookup.com) is the recommended starting point. It accepts domestic and international numbers and returns country, service type, and provider. It handles VOIP numbers better than most alternatives. Example results from the author's own testing:

- Verizon: Mobile / Verizon Wireless
- AT&T: Mobile / AT&T Wireless
- Google Voice: VOIP / Google/Level 3
- Sudo: VOIP / Twilio/Level 3 (SMS-Sybase) (MMS-SVR)
- Blur: Landline / Twilio/Level 3 Communications
- TextNow: VOIP / Enflick/Bandwidth.com (SVR)
- On/Off: VOIP / Peerless Network

Backup options include Carrier Lookup (carrierlookup.com) and Phone Carrier Check (phonecarriercheck.com). If those disappear, a Google search for "carrier lookup" should surface new alternatives.

**NANPA** (nationalnanpa.com) is the North American Numbering Plan authority for the US, Canada, and the Caribbean. Searching the first six digits of a number (the number block) in the Central Office Code used Report at nationalnanpa.com/reports/reports_cocodes.html identifies the original assigned carrier. Law enforcement can call 877-416-6551 to learn whether a number has been ported to a different carrier. Because this data comes from the numbering authority directly, it tends to be the most accurate carrier source.

**Scout** (scout.tel/phone-number-lookup) returns additional details not commonly found elsewhere, including administrative area (township, county, state), operating company, line type, whether the number was ported, and a numeric risk rating. A risk rating increases for VOIP, forwarding, and masked numbers, suggesting the number may not be assigned to a specific individual. Access requires a free API key from RapidAPI.

## Phase 2: Subscriber Identification via Caller ID Databases

Caller ID databases hold name and billing information that telephone systems use to display caller identity. VOIP systems do not receive this data natively, so companies must purchase it from resellers. This creates publicly accessible lookup services.

**Twilio** (twilio.com/lookup) is described as the single best individual lookup option. Registration requires a free trial account. A valid email and a Google Voice number (accepted for verification) are sufficient. The trial provides a $15 credit, and each lookup costs $0.01, allowing approximately 1,500 queries. On the lookup page, selecting "Include caller name" returns the billing name. The author cautions against describing the purpose in terms of OSINT. Framing it as a small business evaluating VOIP transition, or as a developer testing the API, is suggested. An example result:

```
PHONE NUMBER    +16180000000
NATIONAL FORMAT (618) 000-0000
COUNTRY CODE    US
CALLER NAME      M Bazel
CALLER TYPE        null
CARRIER NAME     Google (Grand Central) - Level3 - SVR
CARRIER TYPE      voip
```

**Apeiron** (apeiron.io/info) holds similar data to Twilio and is completely free with no registration, though its results are less comprehensive.

**Truecaller** (truecaller.com) is crowd-sourced. When users install the mobile app, they consent to upload their entire contact list to Truecaller's database. The website allows searching that aggregated database. A covert Microsoft or Google account is needed to sign in. On first login, "Enhanced Search" should be left unchecked and "I reside in California" should be selected to reduce data collection. The author discovered his own government-issued cellular number in the database under his real name because a colleague had installed the app. In a homicide investigation, a target number returned the label "Drug Dealer Matt," which helped focus suspicion on one of three named suspects and led to an arrest.

**Spy Dialer** (spydialer.com) appears to draw on crowd-sourced databases and may provide historical data about a number even if it is no longer assigned to the target.

**Caller ID Test** (calleridtest.com) is a standard lookup service with occasionally unique data. It is unreliable in availability but worth checking when other sources have failed.

These are people-search and reverse-phone-lookup sites whose data originates from property tax records, marketing leaks, phonebooks, and data breaches. The author provides direct static URLs formatted for immediate query submission, replacing the demo number 618-462-0000 with the target number. The sites listed include:

## Search Engine Queries for Telephone Numbers

Search engines can index pages containing a number in many formats. A hyphen in a query may be interpreted as an exclusion operator, so numbers must be quoted. The author recommends searching all reasonable formatting variants, including:

- "2025551212", "202 555 1212", "(202) 555.1212", "(202)555.1212"
- "202-555-1212", "(202) 5551212", "(202)5551212"
- "202.555.1212", "(202) 555-1212", "(202)555-1212"

Because some platforms prohibit posting phone numbers and users work around the restriction by spelling digits out, the following written-number variants should also be searched:

- "two zero two five five five one two one two"
- "202 five five five one two one two"
- "two zero two five five five 1212"
- "202 555 one two one two"

Searches should run on both Google and Bing. The IntelTechniques telephone tool automates this by opening eight browser tabs (four Google, four Bing) with combined OR queries using the target's numeric and written formats. An example combined query:

```
"2025551212"OR"202-555-1212"OR"202.555.1212"OR"202 555 1212"
```

## Craigslist Search

Craigslist posts often include telephone numbers, but the platform restricts them in certain categories, and users spell numbers out to avoid spam scrapers. A combined Google query using the pipe operator (|, meaning OR) covers most variants:

```
site:craigslist.org "314"|"three one four" "555"|"five five five" "1212"|"one two one two"
```

This covers combinations such as "314-555-1212", "three one four 555-1212", and "314 555 one two one two." Variants not caught include phrases like "twelve twelve" for the last four digits. Searching only the last four digits may surface relevant posts at the cost of more false positives. The IntelTechniques tool includes automated Craigslist search.

## Sly Dial

Sly Dial (slydial.com) connects to a target's cellular voicemail without ringing the phone, allowing the investigator to hear the outgoing message, which may include the target's name and voice. To use it, call 267-759-3425 (267-SLYDIAL) from any telephone service (landline, cellular, or VOIP) and follow the automated prompts. There is a brief advertisement before the call connects.

In testing, fewer than 5 percent of attempts cause the target's phone to ring once. Even if it rings, the target cannot identify who called. The author notes that if accidental notification would compromise an investigation, this technique should be avoided.

## Old Phone Book

Old Phone Book (oldphonebook.com) provides historical White Pages landline data from 1994 to 2014, sourced from telephone CD-ROMs. Results include addresses linked to specific years. The site supports direct URL queries by year:

```
http://www.oldphonebook.com/searchphone2.php?syear=1994&sphone=6184620000
```

Supported years include 1994 through 1998, then 2001 through 2003, 2007, 2008, 2013, and 2014. Historical address data makes this useful for background investigations and tracing a person's movements over time.

## Grocery Store Loyalty Cards

Grocery reward and loyalty programs associate a customer's cellular number with their membership account. Many stores let customers use their phone number at checkout instead of a physical card. If all other methods fail to identify a number's owner, the investigator can enter the target number as the loyalty number during a purchase. The receipt will print the account holder's name. The author demonstrated this with a fictional number that had been registered widely and showed name results on both a store receipt and a gas pump payment terminal.

## The Other Board and The Erotic Review

The Other Board (theotherboard.com) aggregates prostitution classifieds and review sites and allows telephone number searches. It extracts phone numbers from escort and classified pages. The author notes that one training search returned 37 photos, 20 escort ads, client reviews, ages used, and location history all linked to a single number. The direct URL format is:

```
https://theotherboard.com/escort-reviews?phone=6185551212
```

The Erotic Review (theeroticreview.com) provides similar searches with a slightly different URL structure separating area code from the number:

```
https://www.theeroticreview.com/reviews/newreviewsList.asp?Phone=5551212&AreaCode=618
```

## Contact Exploitation via Android Emulator

If conventional lookups fail, adding the target number as a contact on an Android emulator and then using apps to "find friends" can link the number to social media or messaging profiles. Apps such as Twitter, Instagram, dating apps, WhatsApp, and Signal can surface accounts tied to the number. The author describes two cases: one in which a cheating husband's dating profile was identified this way, and another in which a burner phone was linked to a WhatsApp account whose profile photo was then identified through reverse image search.

---

## Calls.ai

Calls.ai (sync.ai/calls-ai) is an Android app available through Google Play or Aurora Store that queries a crowd-sourced contact database. It typically returns a first name but results are described as highly accurate. The author searched three of his former government-issued numbers and received results of "Mike," "Michael," and "Bazell." Running it requires launching an Android virtual machine through Android Studio.

---

## WhatsApp Mobile Tools

The site whatsapp.checkleaked.cc accepts a telephone number (including VOIP numbers) and returns WhatsApp account details if the number is registered. An example response includes fields for isUser, isGroup, localized_display_name, isBlocked, about (the profile description), and public name. The URL format for direct submission is:

```
https://whatsapp.checkleaked.cc/12025551212
```
