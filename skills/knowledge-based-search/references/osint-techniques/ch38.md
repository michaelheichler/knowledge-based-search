## Overview

This chapter (labeled Chapter 31 in the text) covers four categories of live broadcast streams useful to investigators: live television news, live commercial radio, web-controlled analog radio receivers, and web-controlled scanner radios. The central argument is that accessing raw stream URLs and embedding them in custom tools provides cleaner, more controllable, and less traceable access than visiting broadcaster websites directly, which expose the investigator to tracking scripts, forced advertisements, and geo-targeted content substitutions.

## Live Television News Streams

Most local, national, and international news stations stream live video on their websites. The problem with visiting those sites directly is web trackers, advertising scripts, forced pre-roll ads, and blocked full-screen playback.

The recommended approach is to extract the raw stream URL using the Firefox add-on Stream Detector. The investigator starts a live stream on the broadcaster's site, then reads Stream Detector's output from bottom to top, looking for the first `m3u8` file in the list. That URL is the stream's playlist file.

To play the stream cleanly, the URL is embedded in a small HTML file using Video JS (videojs.com). The key elements of that file are a `<video>` tag with `autoplay="true"`, a `width` and `height` setting, and a `<source>` tag pointing to the m3u8 URL with `type="application/x-mpegURL"`. CBS News national provides an example URL: `https://dai.google.com/linear/hls/event/Sid4xiTQTkCT1SLu6rjUSQ/master.m3u8`.

For YouTube-based live streams (such as Al Jazeera at `https://www.youtube.com/watch?v=bNyUyrR0PHo` or DW News at `https://www.youtube.com/watch?v=tZT2MCYu6Zw`), the YouTube video ID is extracted and embedded using a `youtube-nocookie.com/embed/<ID>?controls=0&autoplay=1` iframe. Changing the ID string is all that is required to create a page for any other YouTube live stream.

Multiple HTML stream files can be collected into a single dropdown-menu page using an iframe to load the selected file. The author maintains such a tool at `https://inteltechniques.com/tools/Video.html` and distributes an offline version with the book's tool package.

Additional stream aggregators for locating raw URLs:

- **TubiTV** (tubitv.com/live): free, hundreds of channels. Example ABC national stream: `https://live-news-manifest.tubi.video/live-news-manifest/csm/extlive/tubiprd01,ABC-News.m3u8`
- **Pluto** (pluto.tv/en/live-tv): free, hundreds of channels including international news. Blocks cross-site embedding from remote servers but plays correctly from local offline tool files.
- **USTV247** (tv247.us): includes some free streams (e.g. PBS) alongside possibly unlicensed premium streams. The same offline workaround applies if cross-site blocking occurs.
- **LocalNow** (localnow.com/channels): local news channels. Use Stream Detector to extract feed URLs.
- **Roku** (therokuchannel.roku.com): limited live content.

## Live Commercial Radio

Commercial AM and FM stations generally publish internet streams, but their websites often insert extra advertisements or require video pre-rolls. Extracting raw stream URLs and playing them in a custom tool avoids these annoyances and enables better mobile access.

BBC World Service provides a simple direct stream: `http://stream.live.vc.bbcmedia.co.uk/bbc_world_service`, which plays directly in a browser.

Many radio streams use m3u8 format, which a browser downloads rather than plays. The solution is to prepend the HLS Player prefix: `https://www.hlsplayer.org/play?url=<stream_url>`. Al Jazeera Radio's stream (`https://live-hls-audio-web-aje.getaj.net/VOICE-AJE/index.m3u8`) serves as a worked example.

Radio Browser (www.radio-browser.info) is a crowd-sourced database of direct stream URLs for radio stations worldwide, searchable by call letters, name, station number, or location. It powers Radio Garden (radio.garden) and its own map view (radio-browser.info/map). Its API is used in the author's audio tool to query by search term, call letters, state, or country, returning JSON results that include the stream URL.

The author's Live Audio Streams tool at `https://inteltechniques.com/tools/Radio.html` includes a Radio Browser API query form and a preconfigured "Radio News Stream" dropdown. Each entry in that dropdown is an HTML `<option value="...">` element whose value is the stream URL. BBC-type direct URLs are used as-is, while m3u8 streams are wrapped in the HLS Player prefix. Pre-configured entries include Al Jazeera News, BBC World Service, CBC News, CBS News, and Ukraine News.

## Live Web-Controlled Radios

KiwiSDR (kiwisdr.com) is a network of internet-connected software-defined radio receivers operated by volunteers worldwide. At the time of writing, 651 receivers were publicly listed at kiwisdr.com/public. Each receiver is a KiwiSDR SDR board attached to a BeagleBone minicomputer with an antenna, tunable from 1 KHz to 30,000 KHz (the entire longwave, AM, and shortwave spectrum). Up to four users can connect and independently control tuning simultaneously.

An earlier alternative is WebSDR (websdr.org), which the author still visits occasionally but considers less capable.

Connecting to a receiver (example: a West Wales unit at `http://sdrwales.hopto.org:8073/`) opens a waterfall display showing signal strength across all frequencies. The user enters a frequency in the frequency field, then selects a demodulation mode. Receivers default to LSB (Lower Side Band); AM mode is preferred for standard broadcasts. The author recommends typing the string `xayyyVVVVVzzzzz` immediately upon connecting to clean up the interface:

| Key | Action |
|-----|--------|
| x | Close all popup windows |
| a | Select AM mode |
| yyy | Remove all three top banners |
| VVVVV | Amplify volume five times |
| zzzzz | Zoom into the chosen frequency |

Shift-Z zooms back out. Alt plus right arrow steps up in frequency.

The same settings can be encoded directly in the URL. To connect to the West Wales radio tuned to BBC longwave at 198 KHz with all menus closed, banners removed, volume amplified, and view zoomed: `http://sdrwales.hopto.org:8073/?f=198am&keys=xyyyVVVVVzzzzz`. These bookmarkable URLs are what the author's Live Audio Streams tool generates when a receiver and frequency are selected from the "Remote Radio Access" menu.

The site at `http://rx.linkfanel.net/` displays all online KiwiSDR receivers on a world map with darkness overlays, useful for shortwave reception planning (nighttime areas support better shortwave propagation).

Investigative applications described in the chapter: listening to local radio stations in any country for a local perspective on current events, receiving shortwave broadcasts from state broadcasters, accessing Citizens' Band (CB) frequencies in any U.S. city, and monitoring HAM (amateur) radio frequencies where operators often relay real-time incident information that has not reached news outlets, including wildfire updates, missing-person searches, and police activity.

## Live Web-Controlled Scanners

KiwiSDR covers up to 30 MHz. Emergency services, aviation, marine, and VHF amateur radio operate above that range (25 MHz to over 1 GHz), requiring scanner-type receivers. No remote-tunable scanners are available on the internet as of the chapter's writing, but pre-tuned scanner feeds are widely available.

Broadcastify (broadcastify.com) is the primary resource. The chapter describes it as the largest platform for live and archived streaming of public safety, aircraft, rail, and marine radio in the United States. Users browse by state and county to find feeds contributed by volunteers running scanners connected to the internet. Every feed is continuously recorded. Archives are accessible with a paid membership ($30 annually). The premium tier also provides commercial-free listening, non-stop streaming, custom listening templates, and scanner software integration. The free tier allows limited streaming with commercials. The author notes that journalists can use the archive to obtain dispatch recordings without a subpoena or FOIA request.

The author's Live Audio Streams tool includes a scanner section that links to the corresponding Broadcastify page for a selected state or country.

Scanner to Text (copcrawler.com) applies AI speech-to-text to scanner audio, producing timestamped text transcripts of transmissions. Audio quality affects accuracy, but the tool allows text queries across recordings to find transmissions matching a term of interest and play the associated audio.

## Community Watchdog Feeds and Public Webcams

Groups focused on police accountability and social justice have created dashboards aggregating public camera feeds, particularly Department of Transportation cameras. An example is `https://www.pig.observer/nyc/`, which presents a map-driven interface for New York City DOT cameras. The author notes that many such sites log visitor IP addresses and that their operators are often hostile to law enforcement, recommending the use of a VPN and a hardened browser when accessing them.

EarthCam advanced search (www.earthcam.com/search/advanced_search.php) indexes publicly accessible webcams and allows search by location, camera name, or category. It is presented as useful for analysts needing a live visual on a disaster or large-scale event.
