## Overview

Chapter 24 covers how to use a known username to expand an investigation. The central claim is that active internet users reuse the same username across many services, so one identifier found on a single platform can lead to accounts, breach records, and personal pages on dozens of others. The chapter describes automated lookup services, manual platform checks, breach database queries, an email-assumption technique, Skype username extraction, university and ISP personal web pages, and a Gmail verification tool. It also documents the custom IntelTechniques Username Tool that automates many of these searches.

## Username Reuse and Email Derivation

If a target's email is `mpulido007@gmail.com`, the local part `mpulido007` is a strong candidate for screen names elsewhere. Older addresses at other providers should also be tested (`mpulido007@yahoo.com`, `mpulido007@hotmail.com`, `mpulido007@aol.com`) because the Gmail account may not have been the first one the person created.

The chapter lists services that accept a username directly in the URL. Replacing the placeholder `inteltechniques` with the target username queries that service immediately, avoiding a home page. If a service reports a username as "taken," "exists," or "unavailable," someone holds that handle and manual follow-up on that platform is warranted. Services listed:

## Manual Platform Checks

For a quick profile check across the most common networks, direct URL patterns exist for X (Twitter), Facebook, Instagram, TikTok, Tinder, Tumblr, Snapchat, Medium, YouTube, and Reddit. The IntelTechniques Username Tool generates these links automatically.

## Search Engine Queries

Google, Bing, and Yandex can each be queried by URL with the username in quotation marks (e.g., `google.com/search?q=%22inteltechniques%22`).

## Breach Database Searches

Dehashed (`dehashed.com`) works well for username queries and now requires a burner account to display results. The direct URL is `dehashed.com/search?query="inteltechniques"`. Other breach resources that accept manual username entry include Have I Been Pwned (`haveibeenpwned.com`), LeakPeek, Breach Directory, and `psbdmp.ws`. HIBP does not always work well with usernames, while Dehashed is more reliable for this purpose.

## Gravatar

Gravatar (`en.gravatar.com`) links profile images to email addresses and can also be queried by username at `en.gravatar.com/inteltechniques`. This may surface account images tied to the username.

## Linktree

Linktree (`linktr.ee`) is a link aggregation service where members list all their social profiles on one page. It can be queried directly at `linktr.ee/username`.

## Email Assumption Technique

A username may have been used as the local part of an email address at various providers. The custom tool takes a username and appends common email domains, then opens a separate browser tab for each combination queried against HIBP and Dehashed. The eleven domains tested by default are: gmail.com, yahoo.com, hotmail.com, protonmail.com, live.com, icloud.com, yandex.com, gmx.com, mail.com, mac.com, and me.com.

The underlying JavaScript uses `setTimeout` with 1000-millisecond gaps between tab openings to avoid overloading the target server. Investigators outside the United States are advised to substitute or add region-appropriate providers. The chapter shows adding `qq.com` as an example, placed at a 35000-millisecond offset.

A parallel approach runs the same assumed-address combinations through a Google search using quotation marks and the `OR` operator, querying all eleven variants in one search string. Bing and Yandex can receive the same query but are noted as producing less reliable results.

## Skype Username Extraction

Skype does not display usernames prominently when searching by real name or email. When a search result appears in the Skype web interface or application, right-clicking the profile photo (or the silhouette placeholder if no photo is set) and opening the image in a new browser tab reveals the Skype username embedded in the image URL.

## University Personal Pages

Universities assign students email addresses and personal web pages on predictable naming conventions. Identifying the convention through a `site:university.edu firstname` Google search allows the investigator to infer both the email address and the personal page URL for any named target.

The chapter uses Southern Illinois University Edwardsville (`siue.edu`) as a concrete example. A Google search `site:siue.edu laura` returned a page for "Laura Swanson" at `www.siue.edu/~lswanso/`. This reveals the convention: a tilde followed by the first initial and the first six letters of the surname. Applying this to a target named Scott Golike yields the predicted URL `www.siue.edu/~sgolike/` and the predicted email `sgolike@siue.edu`.

When a personal page no longer shows content (universities typically remove it when students graduate), the Wayback Machine (`wayback.archive.org`) often holds archived versions dating back years. The chapter gives a real-world example where a deleted student page located through this method contained a list of friends, roommates, family members, and interests that had not been discoverable through conventional searches, and the information led to locating a priority fugitive within hours.

Some institutions do not follow uniform naming conventions. When two students would produce the same username, a number suffix such as "2" is commonly appended.

## ISP and Legacy Personal Pages

Internet service providers historically offered subscribers personal web space. Using Comcast as the primary example, a customer with `crazycheetah70@comcast.net` would have a page at `home.comcast.net/crazycheetah70`. The chapter lists analogous URL patterns for Yahoo (360.yahoo.com), Webs, Weebly, Charter (webpages.charter.net), Google Sites, About.me, Angelfire, Geocities, Reocities, Tripod, and Earthlink. Pages that no longer exist live can be retrieved through the Wayback Machine, Google Cache, Bing Cache, Yandex Cache, and related services discussed elsewhere in the book.

## GHunt Gmail Verification

The service at `gmail-osint.activetk.jp` (powered by GHunt, installed in the investigator's VM) confirms whether a username is tied to a Google or Gmail account. It can also return the profile image, last edit date, Gaia ID, account type, gaming connections, and Maps or review activity. The query URL is `gmail-osint.activetk.jp/inteltechniques`.
