## Overview

This chapter covers methods for investigating Facebook profiles and content in an environment where the platform has systematically reduced external access since 2019. The authors frame the chapter as a moving target: techniques disappear and sometimes return, so understanding the underlying logic matters more than memorizing any specific URL.

## Timeline of Facebook Restrictions

Key dates explain why many older techniques no longer work:

- **June 6, 2019**: Facebook broke all previous Graph API profile queries and URL-modification methods for viewing "hidden" content.
- **June 17, 2019**: Researchers rebuilt functionality via online tools and browser extensions.
- **August 1, 2019**: Facebook implemented new encryption that killed all browser extensions using the Graph.
- **August 2-3, 2019**: Facebook began blocking the IntelTechniques username-to-user-ID conversion tool on successive web servers.
- **September 8, 2019**: Phone number and most email search options disappeared.
- **2020**: Facebook removed the wildcard (`*`) search operator, changed their layout, and began blocking some Base64 query methods.
- **2022**: Many methods came and went repeatedly. Video queries were blocked at certain points.
- **2024 (update note)**: Most Base64 photo queries failed. The book retains the instructions because some profiles still return results and the methods may return.

## Official Facebook Search

Once logged in, Facebook's search field supports two conceptual modes: a keyword search (name, term, location, entity) and a filter search (narrowing results by employer, school, city, and similar attributes).

Searching a common name like "Tom Johnson" returns many unrelated profiles. Adding left-menu filters for city, school, and employer can reduce thousands of results to one, though the filters themselves require careful selection because ambiguous entries (multiple Vashon High Schools, dozens of Foot Locker pages) exist.

## Obtaining the Facebook User ID Number

Many advanced queries require a numeric user ID, not just a username. The ID is a unique, permanent identifier assigned to every account, page, group, and event.

**For personal profiles**: View the page source of the target's Facebook profile page (right-click in Firefox or Chrome, "View Page Source"), then search the source code for the term `userID`. The result looks like `"userID":"4"` (Mark Zuckerberg's ID is 4). Your own account's ID will also appear in search results. Knowing it lets you filter your own entries out.

**For business and organization pages**: Search the source code for `pageID`, `page_ID`, or `delegate_page_id`. Example: Harvard's page returns `"pageID":"105930651606"`. Pepsi's page (pepsiUS) returns `"pageID":"56381779049"`.

**For events**: Search source for `eventID`.

**For groups**: Search source for `groupID`.

**For city or place profiles**: The ID appears at the end of the URL. The City of Chicago profile URL is `https://www.facebook.com/places/Things-to-do-in-Chicago-Illinois/108659242498155/`, so its ID is `108659242498155`.

The tool at `https://findidfb.com/` attempts to automate this lookup, but the authors prefer manual extraction from source code as more reliable. Until July 2019, dozens of online tools performed this conversion. Almost all were blocked by Facebook. The authors also advise against looking for the user ID in photo URLs because the ID is often hidden in photo displays and cannot be found this way if the account has no photos.

## Facebook Base64 Encoding Queries

Meta introduced Base64 encoding into certain URL structures, most likely to obstruct content scraping. These queries are primarily required when the target's numeric user ID is included in the search.

The base URL structure is:

```
https://www.facebook.com/search/posts/?q=posts&epa=FILTERS&filters=<Base64string>
```

The filter payload before encoding takes this form (for a user search):

```
{"rp_author":"{\"name\":\"author\",\"args\":\"[USERID]\"}"}
```

For user ID 4 (zuck), this becomes:

```
{"rp_author":"{\"name\":\"author\",\"args\":\"4\"}"}
```

Encoding this at `https://codebeautify.org/base64-encode` produces:

```
eyJycF9hdXRob3IiOiJ7XCJuYW1lXCI6XCJhdXRob3JcIixcImFyZ3NcIjpcIjRcIn0ifQ==
```

The trailing `==` is optional. The full URL then becomes:

```
https://www.facebook.com/search/posts/?q=posts&epa=FILTERS&filters=eyJycF9hdXRob3IiOiJ7XCJuYW1lXCI6XCJhdXRob3JcIixcImFyZ3NcIjpcIjRcIn0ifQ
```

The same Base64 value works across posts, photos, and videos queries. Only the path segment and the `?q=` parameter change between them.

The credit for discovering and publishing this Base64 method belongs to the online researcher **NEMEC** (`https://x.com/djnemec`). The authors state that effectively every tool generating these URLs, including the IntelTechniques tool, is built on that researcher's work.

### Query Types Supported

The following categories of searches can be constructed through Base64-encoded URLs:

- Posts, photos, or videos by a specific user (optionally filtered by year)
- Posts, photos, or videos from a specific location (optionally filtered by year)
- Posts, photos, or videos matching a keyword from a specific user (optionally filtered by year)
- Events by location (filtered by keyword)
- People profiles by employer
- People profiles by city
- People profiles by school
- Posts, photos, or videos by keyword filtered to an exact date range

For date-range queries (introduced in 2022), the authors found single-date searches unreliable but date-range queries (even start and end set to the same day) more stable. Video queries were blocked at the time of writing. Searching the `top` content type (`/search/top/`) instead of `videos` was producing mostly video results.

## The IntelTechniques Facebook Tool

The custom tool, available at `https://inteltechniques.com/tools`, automates all of the above query construction. It includes three main sections:

1. **Facebook Profile Data**: Enter a username. The tool populates all profile-section URLs and provides individual submit buttons for each. There is deliberately no "Submit All" button because simultaneous automated requests risk account suspension.

2. **Facebook Search Data**: Replicates all twelve sitewide keyword search categories (Posts, Photos, Pages, etc.) with direct URLs.

3. **Base64 Conversion Queries**: Accepts a user ID or location ID, generates the encoded URLs, and supports year and date filtering without manual Base64 conversion. Also covers People searches by employer, city, and school (requiring at least one additional piece of information such as a first name).

Advantages of the tool over the official Facebook site include: date filtering to a specific day (the site only offers "Today," "This Week," or "This Month" for videos); location-based post searches (the site cannot retrieve posts from other users at a given location); and exact-date filtering for keyword post searches.

Updates to the tool's source queries will be announced at `https://inteltechniques.com/osintbook11`.

## Phone Number Search

The URL `https://mbasic.facebook.com/login/identify/?ctx=recover` allows submission of a phone number to the Facebook account recovery flow. If an account is associated with that number, Facebook may display the profile image. Clicking "Try Another Way" within the same flow may reveal partial email addresses tied to the account (for example, `n***@g******`). This can confirm that an account exists, how many email addresses are linked, the first character of each address, and the domain prefix of the email provider.

This technique should only be run from a browser and IP address that is not already logged into Facebook. Repeated attempts on the same number may notify the account holder. Breach data sets that include Facebook records can also be used to match phone numbers to accounts, subject to policy and scope of the investigation.

## Email Address Search via Page Role Trick

Direct email search was removed from Facebook in 2019. One remaining method exploits the business page management flow:

1. Create a Facebook business page (any name).
2. Go to the page dashboard, then "Page Access" in the left column.
3. Under "People with Facebook access," click "Add new."
4. Enter the target's email address.

Facebook attempts to confirm the correct person before granting access, so it displays the name and profile associated with that email address. Cancel the request afterward. No notification goes to the target. This method only works if the target's account settings allow their email to be used for lookup.

## Facebook Friends List Extraction

Facebook's Terms of Service changed in 2016 to block automated scraping of friends list data, and the API no longer exposes this data. A manual workaround using Excel:

1. Load the target's friends page (`https://www.facebook.com/[username]/friends`) and hold the space bar until the full list loads.
2. Select and copy the entire friends list area.
3. Paste into column B of a new Excel spreadsheet.
4. Use F5 (Go To > Special > Objects) to select all images, then delete them.
5. Paste the same copied content into column A.
6. Right-click column A and choose "Clear Contents" to remove text but keep images.
7. Resize columns A and B to fit images and text respectively.
8. Use Find and Replace to remove all instances of "Add Friend."
9. Apply Home > Format > Auto Fit Row Height and left-justify column B.

The result is a spreadsheet with profile images, names, and active links for every friend. The authors also recommend searching the friends list for the target's own name variations or known aliases, as people often follow a newly created account with their existing accounts.

## General Observations

Facebook investigations require persistence and creativity. A failed technique does not confirm that a target is absent from the platform. The platform's restrictions have consistently introduced new side channels: the loss of Graph search in 2019 led to the Base64 method. Future restrictions will likely open other avenues. Consistent practice and familiarity with the underlying URL structures and ID systems matter more than knowing any single current technique.
