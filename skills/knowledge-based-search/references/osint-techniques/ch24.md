title: Search Engines for OSINT Investigations
source: OSINT Techniques (Bazzell, Edison, 11th ed.)

This chapter covers how to use search engines, web archives, translation tools, newspaper archives, FTP servers, source-code search, and alternative or specialized engines for investigative research. The focus is practical: how to form queries that find what a standard search misses, and how to combine multiple tools.

## Google: Core Operators

**Quotation marks** force Google to treat a phrase as an exact string. Searching `Michael Bazzell` without quotes returns 147,000 results. With quotes it drops to 31,800, each containing those words adjacent. Adding modifiers such as an employer name or city narrows further. Email addresses and usernames should always be quoted.

**site:** restricts results to one domain. `site:forbes.com "Michael Bazzell"` returns every page on that domain containing the name. The same operator with no search terms, such as `site:inteltechniques.com`, lists every indexed page on a site, exposing content that may be hard to find by clicking through the site manually.

**filetype:** (or the shorthand **ext:** on Google) filters by file extension. Searching `"Cisco Confidential" filetype:pptx` returns only PowerPoint files containing that phrase. The operator supports a wide range of extensions including doc, docx, xls, xlsx, pdf, txt, rtf, odt, ods, odp, zip, rar, 7z, kml, kmz, and image types (jpg, jpeg, png, bmp, gif). Because older and newer formats differ (ppt vs. pptx), running both variants is advisable.

**Hyphen (-)** excludes a term immediately following it, with no space. Successive exclusions can reduce a large result set to a manageable one: `"Michael Bazzell" -police -FBI -osint -books -open -source` drops from 31,800 to 604.

**inurl:** matches text within the URL itself. Combined with negation and filetype, it identifies FTP servers: `inurl:ftp -inurl:(http|https) filetype:pdf "osint"` finds only FTP-hosted PDFs containing the term.

**intitle:** matches text within a page's HTML title tag. `intitle:"osint video training"` finds pages where that exact phrase is the title. The variant `allintitle:training osint video` requires all three words in any order in the title. `intitle:index.of OSINT` finds publicly browsable web directories containing OSINT-related files.

**OR** (uppercase) returns pages matching either term. Useful for names with variant spellings: `"Michael Bazzell" OR "Mike Bazzell" OSINT`.

**Asterisk (*)** is a wildcard representing one or more words: `"osint * training"` matches "osint video training" and "osint live classroom training".

**Range operator (..)** searches between two values: `"bonnie woodward" "1..999 comments"` finds pages about a subject that also contain a comment count in that range.

**related:** returns content Google associates with a given domain. `related:inteltechniques.com` may surface the author's other sites, social profiles, and linked resources.

## Google: Date and Display Controls

The **Tools** menu on the results bar reveals time-range filters (past hour, day, week, month, year, custom range) and an "All results / Verbatim" toggle. Verbatim bypasses synonym expansion and sometimes returns more results than a standard query.

To force Google to display a date next to every result regardless of date filter, append `&tbs=cdr:1,cd_min:1/1/0` to the search URL. Example: `https://www.google.com/search?q="michael+bazzell"&tbs=cdr:1,cd_min:1/1/0`. This surfaces the indexing date for each result and enables date sorting.

For missing-person investigations, setting the date filter to show only content before the disappearance was public helps locate pre-incident information more relevant to suspect leads.

## Google Programmable Search Engines

Google lets anyone build a custom search engine (Programmable Search Engine) at `programmablesearchengine.google.com`. Two main uses are described.

A **social network engine** adds Facebook, X (Twitter), Instagram, LinkedIn, YouTube, and TikTok as the sites to search, then adds per-network Refinements. Each refinement creates a tab so results from each platform can be viewed separately. The option "Search within sites with this refinement" is recommended over the priority-weighting option.

A **file-type engine** creates an engine that searches the entire web (enable the "Search the entire web" toggle, delete the placeholder domain) and adds refinements using rewritten query words: `ext:pdf` for PDF, `ext:doc OR ext:docx` for Word, `ext:xls OR ext:xlsx OR ext:csv` for Excel, `ext:ppt OR ext:pptx` for PowerPoint, `ext:txt OR ext:rtf` for plain text, `ext:wpd` for WordPerfect, `ext:odt OR ext:ods OR ext:odp` for OpenOffice, and `ext:zip OR ext:rar OR ext:7z` for compressed files. This produces a tabbed interface to filter any search to a specific document type.

## Google Alerts

Google Alerts (`google.com/alerts`) monitors for new content matching a query and delivers email notifications on a chosen schedule. Useful for tracking a target's name, a personal website, or any repeating subject of interest. A runaway-youth investigation example in the text: an alert for the subject's name and city produced a blog post identifying her location within three days.

## Bing

Bing shares most Google operators (site, filetype, quotes, hyphen) and adds two unique ones.

**LinkFromDomain:** `LinkFromDomain:inteltechniques.com` lists every external site to which any page on that domain links. This extracts outbound links from the site's source code, including links that are not visually obvious when browsing.

**contains:** `contains:ppt site:cisco.com` returns pages on cisco.com that link to PowerPoint files, including files stored on other domains. `filetype:ppt site:cisco.com` returns only PPT files hosted directly on that domain. The contains operator typically returns more results (36,200 vs. 13,200 in the example given) and is considered complementary to filetype, not a replacement.

Yahoo search uses the Bing engine, making it redundant when Bing has already been searched. Bing's AI-generated result summaries are rarely useful for investigative purposes.

## Yandex

Yandex (`yandex.com`) indexes content with different prioritization than Google and sometimes surfaces unique results. Its operators are entered directly in the search field rather than through menus.

Exact phrase: quotation marks, same as Google. Missing word wildcard: `"Open Source * Techniques"` finds the phrase with any word in the asterisk position. Words within the same sentence: `Hedgehog & Flamingo` (no quotes) finds both words in one sentence. `Hedgehog /2 Flamingo` requires them within two words of each other. Words within the same page: `Hedgehog && Flamingo` finds both on the same page. `Hedgehog && /3 Flamingo` limits to within three sentences. Mandatory word: `+Bazzell` forces that word to appear. OR across multiple forms: `+Bazzell Michael|Mike|M` (pipe is OR). Exclude a word: the official operator is tilde (`~`), but hyphen also works. One tilde excludes only when the unwanted term is in the same sentence as the keyword. Repeated identical words: `!Carina !Abad !Abad` finds the three words regardless of spacing or punctuation, useful for names that repeat. Date-specific: `date:20111201..20111231 OSINT` for a range, `date:2011* OSINT` for a whole year, `date:>20111201 OSINT` for after a date.

The full operator list is at `https://yandex.com/support/search/query-language/search-operators.html`.

## International Search Engines and Translation

When a target has ties to another country, searching that country's local engine can surface results not present on Google or Bing. Engines listed in order of usefulness for international investigations: Baidu (China, `http://www.baidu.com/s?wd=osint`), Sogou, So, Mail.ru, Goo (Japan), Daum (South Korea), Parseek (Iran), Naver (South Korea), Coccoc (Vietnam), Seznam (Czech Republic), Rediff (India).

**I Search From** (`isearchfrom.com`) simulates a Google search as if from a specified country and device, which changes result ordering and news emphasis.

**2Lingual** (`2lingual.com`) runs one query across two Google country versions side by side, with automatic English translation of foreign results.

Translation services: Google Translator (`translate.google.com`) and Bing Translator (`bing.com/translator`) can translate both pasted text and entire websites by URL. DeepL (`deepl.com/translator`) is described as more accurate than either. Additional options: PROMT Online Translator, Libre Translate, Lingva, MyMemory.

**Google Input Tools** (`google.com/inputtools/try`) converts typed text to a target language character set, enabling searches in Cyrillic and other non-Latin scripts from a standard keyboard.

## Web Archives and Caches

Cached and archived pages are described as "one of the most vital resources" in online research. They reveal deleted or altered content. The author's practice is to check caches immediately upon finding any website, profile, or blog, looking for changes that indicate deliberate removal. Most people have no idea this technique exists.

**Google Cache**: The direct cache URL format is `https://webcache.googleusercontent.com/search?q=cache:` followed by the target URL. The `cache:` operator is no longer officially supported and Google may remove this access entirely.

**Bing Cache**: Available directly from search results. Click the small green down arrow next to a result's domain name, then select "Cached".

**Yandex Cache**: Click the three vertical dots next to a result and select "Saved copy". Yandex caches are sometimes older than Google's or Bing's, which can be useful in an investigation.

**The Wayback Machine** (`web.archive.org`): The most comprehensive option. The example given is phonelosers.org with 1,280 captures spanning from December 21, 1997 through August 14, 2024. Users can click through archived pages as if on a live site. Keyword search is also available via URL: `https://web.archive.org/web/*/phone losers` finds all archived sites containing those terms. This method surfaces domains other than the directly searched one, which a domain-only search would miss.

Automated tools that claim to reconstruct entire cached websites are considered unreliable because Bing and Yandex generate unique codes that block automated collection.

## Newspaper Archives

**Google News Archive** (`news.google.com`): Searches digital newspaper content with filters for date, language, and publication. Useful for finding previous addresses, family members through obituaries, and associates through events and awards.

**Google Newspaper Archive** (`news.google.com/newspapers`): Scanned printed newspapers. Less extensive than Newspaper Archive but free.

**Newspaper Archive** (`newspaperarchive.com`): A paid service with high-resolution PDF scans of newspapers from the 1800s to the present. A 7-day free trial is available. Many public libraries have paid to make their collections freely searchable without a credit card by hosting sub-portals. These are found with: `site:newspaperarchive.com "This archive is hosted by" "create free account"`. Adding a specific newspaper name narrows to that collection. Creating a free account on each library portal, using the same credentials each time, provides cumulative free access across many collections.

Free alternatives:
- Old Fulton (`fultonhistory.com/Fulton.html`): 57,000,000 scanned U.S. and Canadian newspapers.
- Library of Congress Chronicling America (`chroniclingamerica.loc.gov`): Scanned U.S. newspapers dated 1756-1963. Separate title directory covers 1690 to present.
- Small Town Newspapers (`stparchive.com`): Scanned and text versions since 1890.

The search interfaces on these alternatives are described as mediocre. Using a Google `site:` operator against them is recommended: `site:stparchive.com "michael bazzell"`.

## FTP Server Search

FTP servers are public file stores often overlooked by investigators. Google and Bing index their contents. The base query pattern is: `inurl:ftp -inurl:(http|https) "search term"`. Adding `filetype:pdf` narrows to PDFs. Once a file is found, manually editing the URL path and removing the filename reveals the directory, which may contain many additional documents. Sensitive files have been located this way on company, government, and military servers.

**Napalm FTP** (`searchftps.net`): Highest result count among the FTP-specific engines. Shows the date each result was last confirmed present. Example result for "Cisco" "PDF": 3,384.

**Mamoht** (`mmnt.ru`): Russian FTP search with country filtering and a "Search in found" option to narrow within prior results. Example: 789 results for "Cisco" "PDF".

**FreewareWeb** (`freewareweb.com/ftpsearch.shtml`): Less robust but occasionally finds content the others miss.

For comparison, Google returned 19,600 results for `inurl:ftp -inurl:(http|https) "Cisco" "PDF"`.

## Source Code Search: NerdyData

NerdyData (`nerdydata.com/reports/new`) searches the HTML, JavaScript, and CSS source code of websites rather than visible page text. Uses include finding all websites that share a Google Analytics tracking ID (such as `UA-8231004-3`), which can tie multiple sites to one owner. It also identifies websites that have copied proprietary or distinctive code, and discovers related services that use shared infrastructure code. NerdyData limits queries to 35 characters but accepts multiple strings connected automatically with AND logic.

## Privacy-Focused and Alternative Engines

**Searx / baresearch.org**: A meta-crawler combining Google, Bing, and others, deduplicating results. Provides a cached link (via Wayback Machine) and a proxied link (via Searx's servers, hiding the investigator's IP address) next to each result. A self-hosted instance is preferred for privacy.

**DuckDuckGo** (`duckduckgo.com`): Does not track users or store search history. Uses Wikipedia and Wolfram Alpha to augment results. Fewer total results but described as more accurate.

**Start Page** (`startpage.com`): Passes queries to Google without revealing the user's IP. Supports Google's date, image, and video filters. Each result offers an "Anonymous View" proxy link. Recommended for sensitive queries where the investigator does not want the search associated with their computer or connection, such as investigations involving tech-savvy stalker suspects.

**Qwant** (`qwant.com`): Combines multiple engines into column-organized results (All, News, Images, Videos, Shopping). Results include social media posts from X, Facebook, LinkedIn, and others.

**Million Short** (`millionshort.com`): Removes the top N most popular websites from results (options: top 100, 1,000, 10,000, 100,000, or 1,000,000). Requires free registration (accepts forwarding/masking email). Useful for surfacing lesser-known pages that popular results obscure.

## Tor Search Engines

Tor hosts websites that are not accessible from the standard internet. Tor-network sites include illegal drug shops, child exploitation material, and weapon sales, which is the investigative relevance.

Surface-web Tor search engines (accessible from a standard browser): Ahmia (`ahmia.fi`, most thorough), Tor Link (`tor.link`, appeared 2022, often returns sites not in Ahmia), Onionland Search (`onionlandsearchengine.net`, uses Google's indexing of Tor proxy links).

Tor-native engines (require Tor Browser or Brave's Tor mode): Torch at `http://torchdeedp3i2jigzjdmfpn5ttjhthh5wbmda2rr3jvqjg5p77c54dqd.onion`, Haystack at `http://haystak5njsmn2hqkewecpaxetahtwhsbsa64jom2k22z5afxhnpxfid.onion`, Tor66 at `http://tor66sewebgixwhcqfnp5inzp5x5uohhdy3kvtnyfxc2e5mxiuh34iid.onion`. These sites appear and disappear frequently.

## Search Engine Collections

**Search Engine Colossus** (`searchenginecolossus.com`): Index of active search engines organized by country. Useful when a target has ties to a specific country.

**Fagan Finder** (`faganfinder.com`): Interactive page that forwards a query to hundreds of engines and niche search services simultaneously.

## Keyword Tool

Keyword Tool (`keywordtool.io`) exposes Google autocomplete suggestions, providing up to ten popular completions per query (Google's interface shows only five). Supports filtering by country and displays results for Bing, YouTube, and the App Store. Useful for discovering misspellings and variant terms that standard searches miss. A product recall investigation example: the ninth most popular search for a product name used a spelling variant that had been missed entirely by standard queries.

## IntelTechniques Search Engines Tool

The author's custom tool at `https://inteltechniques.com/tools` consolidates queries across Google, Bing, Yahoo, Searx, Yandex, and others. A "Submit All" option sends any query to all services simultaneously, each opening in a new browser tab. Pop-ups must be permitted. Search operators including quotation marks work within the tool.

## Artificial Intelligence Engines

The text states explicitly: AI services are not recommended for OSINT investigations. The stated reasons are that most online AI tools use entered data to further train their models, potentially exposing a target's details to other users, and the information is frequently inaccurate. An example given: a query about the author to a local model returned a wrong city of residence, a book he did not write, and an incorrect firm name.

Offline large language models (LLMs) are presented as an acceptable alternative for privacy because no data leaves the user's system. The recommended client is **Jan** (`https://www.jan.ai`), an open-source application. The author downloaded the Mistral Instruct 7B Q4 model (4 GB). Offline LLMs are considered appropriate for organizing data, creating sorted lists, and generating scripts, but not for factual claims about investigation targets. An example is using Jan with the Codestral 22B Q4 model to generate a Windows installation script for OSINT applications.
