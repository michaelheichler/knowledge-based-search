## Overview

This chapter (labeled Chapter Nine in the source) treats the web browser as the most important application in an OSINT virtual machine. The author argues that default browsers (Internet Explorer, Edge, Safari, Chrome) are inferior for investigative work. Firefox is the recommended primary browser. A secondary Chromium-based browser (Brave) and Tor Browser for .onion sites round out the toolkit.

## Firefox Security Configuration

The first step is tightening Firefox settings before adding extensions. Key changes:

- Set homepage, new windows, and new tabs to blank page. Disable all Firefox Home Content options and all Address Bar suggestions.
- Set Privacy and Security protection to "Strict".
- Enable "Tell websites not to sell or share my data" and "Do Not Track". The more aggressive "Global Privacy Control" signal is not recommended for the OSINT browser because it can cause a target site to present different content than it would to an ordinary visitor.
- Delete cookies and site data when Firefox closes.
- Disable all password saving, autofill, address saving, and payment method saving.
- Set history to custom settings. Uncheck browsing, download, search, and form history. Check "Clear history when Firefox closes". Do not enable Always Use Private Browsing Mode because it breaks Containers.
- Block new requests for location, camera, notifications, and virtual reality in Permissions.
- Uncheck all Firefox Data Collection and Website Advertising Preferences options.
- Uncheck all Deceptive Content and Dangerous Software Protection options (prevents sharing site visit data with third parties).
- Enable HTTPS-Only Mode in all windows.
- Enable DNS over HTTPS at "Max Protection" using NextDNS.

The author removed all advanced "about:config" hardening steps that appeared in earlier editions. The reasoning: over-protective settings caused investigative failures, as some sites needed as evidence could not be viewed. The OSINT machine should present a common browser configuration capable of viewing any website. The advanced Firefox hardening described in the author's separate book "Extreme Privacy" remains appropriate for personal machines but is out of scope here.

## Default Search Engine: SearXNG

SearXNG is an open-source metasearch engine that aggregates results from Google, Bing, and other engines without sharing user information with those engines. It can be used via a public instance (https://searx.space lists options) or self-hosted.

To set a public instance as the Firefox default: navigate to the instance, run any search, right-click the URL bar, select "Add" next to the magnifying glass icon, then change the default search engine in Firefox Settings under Search.

Preferred SearXNG settings: disable auto-complete, disable SafeSearch, use light theme, open results in new tabs, enable additional search engines. To preserve these preferences across Firefox restarts, add the instance domain as a cookie exception under Privacy and Security ("Manage Exceptions" next to "Delete cookies...").

Public instance trade-offs: queries reach search engines from the server's IP rather than the user's IP, and queries are not easily linked to one user. But the host could monitor queries, popular instances may get blocked by search engines, and outages remove service.

Self-hosted instance advantages: tracking code on engine sites is removed from the SearXNG result pages, all options remain reliable, and there is no third-party uptime dependency. The user's own IP is sent with each query to the underlying engines. The author runs behind a VPN and considers this acceptable.

Installation on Debian Linux (copy in its entirety):

```
sudo -H apt-get install -y \
python3-dev python3-babel python3-venv \
uwsgi uwsgi-plugin-python3 \
git build-essential libxslt-dev zlib1g-dev \
libffi-dev libssl-dev

mkdir ~/Documents/searxng
cd ~/Documents/searxng
git clone "https://github.com/searxng/searxng"
python3 -m venv searxngEnvironment
source searxngEnvironment/bin/activate
pip install -U pip
pip install -U setuptools
pip install -U wheel
pip install -U pyyaml
cd searxng
pip install -e .
sudo -H mkdir -p "/etc/searxng"
sed -i "s|ultrasecretkey|$(openssl rand -hex 32)|g" searx/settings.yml
sudo -H cp searx/settings.yml /etc/searxng/settings.yml
export SEARXNG_SETTINGS_PATH="/etc/searxng/settings.yml"
deactivate
```

Launch commands:

```
cd ~/Documents/searxng
source searxngEnvironment/bin/activate
cd searxng
python searx/webapp.py
```

The instance runs at `http://127.0.0.1:8888`. Minimizing the terminal window keeps the service running. Updates: `git pull "https://github.com/searxng/searxng"` from the searxng directory.

## Firefox Extensions

Extensions are installed via Firefox menu, Add-ons and Themes, then the search field. The author lists 15 extensions in order of importance.

**Firefox Multi-Account Containers** (addons.mozilla.org/addon/multi-account-containers): Isolates each container tab into a separate storage slice. Cookies, logged-in sessions, and tracking data do not cross between containers. This lets an investigator log in to multiple accounts on the same service simultaneously (for example, two Facebook accounts in two different containers). Sites can be assigned to always open in a designated container. The author recommends creating at least four containers named "Alias 01" through "Alias 04". The "Limit to Designated Sites" option prevents a secure container from accidentally loading unintended sites. Suspicious external links can be right-clicked and opened in a separate container to isolate them from the active session's cookies. Note: do not create a blanket rule forcing all pages of a given service into one container if you need multiple logins to that service.

**uBlock Origin** (addons.mozilla.org/firefox/addon/ublock-origin): Replaces NoScript, Adblock Plus, Privacy Badger, and Disconnect. In the Dashboard, enable "I am an advanced user". Under Filter lists, enable "Block outsider intrusion into LAN" (Privacy section) and "EasyList/uBO-Cookie Notices" (Annoyances section), then apply and update.

The advanced per-site menu has three columns. Column one lists script types and domain names. Column two applies rules globally to all sites. Column three applies rules to the current site only. A grey cell means default rules apply. A red cell means block all. A green state (power button in upper-right) means allow all.

Practical uses: clicking the left (grey) area of the top cell in column three allows all scripts on the current page only, which is useful when a site is not loading correctly. Clicking the right (red) area of the top cell in column two blocks all scripts globally, useful before visiting a dangerous site. Before capturing evidence, allow all scripts so the page appears exactly as an ordinary visitor would see it (blocking scripts technically modifies the page). Blocking "3rd party scripts" in column three (red, then padlock, then reload) can bypass subscription paywalls on many news sites. Blocking "inline scripts" similarly removes autoplay video and pop-ups. To reset all custom rules: return column two to grey, then in Dashboard, My Rules tab, delete all text in the Temporary Rules column, save, and commit.

**DownThemAll** (addons.mozilla.org/firefox/addon/downthemall): Downloads all linked files from a page in bulk. Click the toolbar menu, select DownThemAll, check "All Files", and click Download.

**Bulk Media Downloader** (addons.mozilla.org/firefox/addon/bulk-media-downloader): Backup to DownThemAll for embedded audio and video. Scroll the page while the extension collects detected stream links, then click Download.

**FireShot** (addons.mozilla.org/en-us/firefox/addon/fireshot): Captures the full web page as a PDF. The blue "S" icon in the toolbar opens a menu. Select "Capture entire page" then "Save to PDF". A PDF captures the entire page (not just the visible area) and is difficult to edit, which aids evidentiary integrity. Recommended filename template set in Options ("Show filename template settings"): `%n-%u-%t-%y-%m-%d-%H-%M-%S` (sequence number, URL, title, date, time). Set %n to 0 and Pad to 3 so file names ascend chronologically from 000.

**Nimbus** (addons.mozilla.org/firefox/addon/nimbus-screenshot): Backup screenshot tool that saves as PNG. Configure by clicking the gear icon. Set file name pattern to `{url}-{title}-{date}-{time}` and enable Quick Screenshot with "Entire Page" and "Download" options. After configuration, a single click captures and downloads the full page automatically. FireShot works better on large X (Twitter) profiles. Nimbus works better on large Facebook pages. PNG files are easy to edit, and establishing their integrity as evidence can be difficult.

**Firefox Screenshot** (built-in): The fallback when both FireShot and Nimbus fail on long pages. Right-click the page, select "Take Screenshot", choose "Save full page", and download.

**SingleFile** (addons.mozilla.org/en-US/firefox/addon/single-file): Saves a page as a single HTML file with Base64-embedded images, bypassing the memory limits that cause PDF rendering failures. Recommended settings (Manage Extension, Preferences tab): enable "Open saved pages in a new tab" under User Interface. Disable "Remove hidden elements" under HTML Content. Enable "Save original URLs of embedded resources". A single click archives the page. Multiple tabs can be archived at once. The HTML source captures additional data beyond what appears in a screenshot.

**Exif Viewer** (addons.mozilla.org/en-us/firefox/addon/exif-viewer): Right-click any full-size image on a web page and select "View Image Exif Data" to see embedded metadata in a new window. Most social network photos have been stripped of metadata. Blogs and personal websites are more likely to retain it.

**User-Agent Switcher and Manager** (addons.mozilla.org/firefox/addon/user-agent-string-switcher): Changes the browser identity reported to websites. Allows emulation of specific mobile devices, desktop browsers, and operating systems. Used to access content restricted to certain browsers, view mobile versions of sites, or present a less distinctive fingerprint. To apply: click the icon, choose browser, OS, and exact version, then click "Apply (container on window)". Click "Test UA" to verify. Click "Restart" to revert. Limitation: JavaScript fingerprinting can detect touch points and video card identifiers, bypassing UA spoofing. The author hosts a test page at `https://inteltechniques.com/logger` to verify what a site can detect.

**Image Search Options** (addons.mozilla.org/firefox/addon/image-search-options): Adds reverse image search to the right-click menu for any image on a page. Services include Google, Bing, TinEye, Yandex, Baidu, and Karma Decay (searches Reddit for copies of images).

**Search By Image** (addons.mozilla.org/en-US/firefox/addon/search_by_image): Alternative reverse image search extension. Key advantage: allows cropping a visible portion of the page and searching it, bypassing sites that restrict right-click access or embed images in non-accessible ways. Steps: click the icon, change the drop-down to "Capture", select a service, draw a rectangle around the target image, click "Search". Also works on protected PDF files opened in Firefox. The author keeps both Image Search Options and Search By Image installed because each offers services the other lacks.

**Web Archives** (addons.mozilla.org/en-US/firefox/addon/view-page-archive): Queries multiple web archive services for previous versions of the current page. Enable all search engines in options. The "All" option opens one new tab per service simultaneously.

**Copy Selected Links** (addons.mozilla.org/firefox/addon/copy-selected-links): Copies all hyperlinks within selected text to the clipboard. Press Ctrl+A to select all, right-click, and choose "Copy selected links". Used to extract profile URLs from a Facebook friends list, external links from X (Twitter) profiles, video links from YouTube channels, auction links from eBay results, links from PDF files opened in Firefox, and hyperlinks from trafficking ad result pages for direct inclusion in reports.

**OneTab** (addons.mozilla.org/en-US/firefox/addon/onetab): Collapses all open tabs into a saved group list. Click the blue funnel icon to collapse. Groups have editable titles, timestamps, and drag-and-drop ordering. Individual tabs or groups can be restored. Do not use "Share as web page" because it uploads data to OneTab servers. Export via the built-in export feature as plain text. Enable "Keep them in your OneTab list" in Options to prevent deletion when restoring tabs. All data is stored locally.

**Stream Detector** (addons.mozilla.org/en-US/firefox/addon/hls-stream-detector): Detects embedded video streams in M3U8 (playlist) and TS (transport stream) formats, which are common on modern video platforms where right-click download is no longer possible. Click the extension icon while on a page containing video, then refresh the page. The extension lists detected M3U8 URLs. The URL labeled "master" is usually the primary video stream. Clicking a URL copies it to the clipboard for pasting into VLC for playback, or for use with Python download tools. The exact stream URL can be documented as digital evidence even if the hosting page is later removed. A companion extension, "The m3u8 Stream Detector" (addons.mozilla.org/firefox/addon/the-m3u8-stream-detector), catches streams the primary extension misses.

## Firefox Toolbar Customization

Right-click any empty spot on the toolbar, select "Customize Toolbar", drag undesired icons (such as Pocket and Account) off the toolbar, arrange the remaining items in the preferred order, and click Done. By default many extensions are hidden inside the puzzle-piece icon, and the author recommends pinning each to the toolbar for immediate access.

## Exporting and Importing a Firefox Profile

A fully configured Firefox profile can be transferred to other machines. From the configured machine: open Firefox, navigate to Help, More Troubleshooting Information, click "Open Directory" under Application Basics, close Firefox (leaving the directory window open), and copy all profile files to a removable drive. On the target machine: open Firefox, navigate to the same location, close Firefox, paste the profile files into the folder (overwrite when prompted), and restart Firefox. Both Firefox versions must match. The profile carries all extensions and their settings.

The author also provides a downloadable pre-configured profile for Debian. Launch Firefox once, close it, then run the following commands in Terminal:

```
sudo apt update
sudo apt install -y curl
cd ~/Desktop
curl -O https://inteltechniques.com/data/osintvm/ff-template.zip
unzip ff-template.zip -d ~/.mozilla/firefox/
cd ~/.mozilla/firefox/ff-template/
cp -R * ~/.mozilla/firefox/*.default-esr*
cd ~/Desktop && rm ff-template.zip
```

If Firefox resets its profile or extensions go missing, the same commands (preceded by `rm -r *` inside the profile directory) rebuild the installation. The Debian default is the ESR (Extended Support Release) build of Firefox, which receives updates less frequently but is stable enough for VM use.

## Secondary Browser: Brave

Brave is the recommended Chromium-based secondary browser. It removes most connections back to Google (unlike Chrome), and works identically on both x86 and ARM systems. It is used when the customized Firefox blocks needed content, when a site requires a standard browser fingerprint, when a Chromium-only extension is needed, or when the investigator wants to see how an intrusive site appears to an average user without any blocking active.

Installation on Debian:

```
sudo curl -fsSLo /usr/share/keyrings/brave-browser-archive-keyring.gpg \
  https://brave-browser-apt-release.s3.brave.com/brave-browser-archive-keyring.gpg

echo "deb [signed-by=/usr/share/keyrings/brave-browser-archive-keyring.gpg] \
  https://brave-browser-apt-release.s3.brave.com/ stable main" \
  | sudo tee /etc/apt/sources.list.d/brave-browser-release.list

sudo apt update && sudo apt install brave-browser -y
```

Skip all onboarding and disable diagnostic data sharing. Keep Brave installed but use it only when Firefox is insufficient.

## Tor Browser

Tor (The Onion Router) masks the user's IP address and enables access to .onion sites on the Tor network. Installation is managed through Flatpak:

```
sudo apt update && sudo apt install flatpak -y
flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak install flathub org.torproject.torbrowser-launcher -y
flatpak run org.torproject.torbrowser-launcher
```

Reboot after installation, then launch "Tor Browser" from applications. The browser routes all traffic through Tor nodes, presenting a different IP address to every site visited. Speed decreases noticeably and does not fully recover. Closing the browser stops all Tor services. Update Tor Browser and all Flatpak applications with `flatpak update`.

Tor Browser is only needed for .onion sites. For investigations of ordinary websites, even those belonging to technically sophisticated targets, a VPN is sufficient. Tor Browser does not currently support ARM hardware. On ARM machines, Brave's "New Private Window with Tor" option (available from the far-right menu) provides access to .onion sites as a fallback.

## Hard Page Refresh

Internet browsers cache page files locally. A standard reload may serve cached content rather than fetching fresh data from the server. A hard refresh forces the browser to reload all resources from the network.

- Brave or Firefox on Linux and Windows: Shift+Ctrl+R
- Brave or Firefox on macOS: Shift+Command+R
- Most browsers: hold Shift while clicking the reload icon

The author recommends making this a routine habit before capturing any page as evidence.
