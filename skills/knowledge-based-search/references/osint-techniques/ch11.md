## Overview

This chapter covers installation and configuration of virtualization software on a Linux host. VirtualBox is the primary tool. VMWare Workstation Pro is presented as an alternative. The chapter also addresses Windows 11 VM creation, USB passthrough, VM preservation strategies, disk management, and common errors.

## Installing VirtualBox on Linux

The author recommends VirtualBox (virtualbox.org) for VM creation on Linux hosts. The default site instructions tend to install an outdated version, so manual steps are needed. The following Terminal commands install VirtualBox 7 on a Debian-based Linux system:

```
wget -O- https://www.virtualbox.org/download/oracle_vbox_2016.asc | sudo gpg --dearmor --yes --output /usr/share/keyrings/oracle-virtualbox-2016.gpg
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/oracle-virtualbox-2016.gpg] http://download.virtualbox.org/virtualbox/debian $(lsb_release -cs) contrib" | sudo tee /etc/apt/sources.list.d/virtualbox.list
sudo apt update
sudo apt install virtualbox-7.0
sudo apt upgrade
```

The Extension Pack is installed separately. Download it from the VirtualBox downloads page, then go to File > Tools > Extension Pack Manager and click Install. VirtualBox is free for personal use, but users must confirm they meet the license requirements, including for the Extension Pack. The installation prompts a two-screen acknowledgment in Terminal (Tab then Enter on the first screen, left arrow then Enter on the second).

VirtualBox requires a computer that supports hardware virtualization. Most mid-range and higher machines made within the past five years qualify, though some may need virtualization enabled in the BIOS. Netbooks and low-end machines are likely to have problems.

## Creating a Windows 11 VM in VirtualBox (Optional)

This section is described as completely optional for those who need or want Windows. Windows 11 is installed not for OSINT investigations but as a primer on the process and for running Windows-only software. The Windows 11 ISO is downloaded from microsoft.com/software-download/windows11 using the 64-bit option. Microsoft may block VPN connections during the download.

To create the VM in VirtualBox: select Machine > New, name the VM, attach the ISO, choose Windows 11 Pro edition, deselect EFI, allocate half of system RAM and half of available CPUs, and set a maximum disk size of 150 GB.

Windows 11 enforces hardware checks (Secure Boot, TPM, CPU, RAM) that block VM installation by default. These are bypassed by editing the Windows registry during setup. When the installer appears, pressing Shift+F10 opens a command prompt. Typing `regedit` and navigating to `HKEY_LOCAL_MACHINE\SYSTEM\Setup` allows creating a new key named `LabConfig`. Four DWORD (32-bit) values are added there, each set to `1`: `BypassSecureBootCheck`, `BypassTPMCheck`, `BypassCPUCheck`, and `BypassRAMCheck`. After closing the registry editor, installation proceeds normally.

During Windows setup, choose "I don't have a product key", select Windows 11 Pro, use the custom installation option, and avoid creating a Microsoft account by selecting the "work or school" option, then "Sign-in Options", then "Domain". All privacy settings should be disabled.

After Windows is installed, VirtualBox Guest Additions must be installed via Devices > Insert Guest Additions CD Image. This enables clipboard sharing, drag-and-drop, and display scaling (configured in VM settings under the Advanced tab). On the Linux host, run `sudo gpasswd -a $USER vboxusers` in Terminal.

The resulting Windows installation is a trial. Microsoft permits replicating the process to generate a new machine when the trial expires. A license and traditional media are needed for a permanent copy.

## VirtualBox USB Connection

USB device access in VMs requires configuration. In VM settings, select the USB option and create a new filter using the first blue icon. When a USB drive is attached to the Linux host, use Devices > USB in the VirtualBox menu to pass it through to the VM. VirtualBox defaults to a USB 3.0 driver. If an older drive is not recognized, switch to USB 2.0 (or vice versa) in VM settings under the USB tab.

## VirtualBox Exports

VMs can be exported to preserve investigation environments. This matters for legal cases where the exact operating environment may need to be reproduced for court or discovery. Two methods exist.

The first is to copy the entire VM folder directly: right-click the VM while shut down, select Show in File Manager, and copy the folder to an external drive. The second method, which the author prefers, is to export the VM to a single file via File > Export Appliance. Select the VM, click Next twice, then Finish. This creates a file in the Documents folder that can be imported into any VirtualBox instance.

The author exports every case VM at the end of work and adds it to digital evidence on an external drive, enabling exact recreation of the environment used during the investigation.

## VirtualBox Clones

Cloning a VM produces an identical copy with its own data folder. The original VM stays uncontaminated while investigations are conducted in the clone. The workflow recommended by the author is:

1. Launch the original VM weekly to apply updates, then shut it down.
2. Right-click the original VM and select Clone.
3. Name the clone (for example, with a case number) and complete the process.

The clone can be exported for evidence preservation or deleted when work is complete, without affecting the original. The approach is compared to having a fresh computer for each case.

## VirtualBox Snapshots

Snapshots capture a frozen state of a VM, allowing reversion to a prior configuration. After initial setup and updates, shut down the VM, open the Snapshots menu (three-line icon next to the VM), click Take, name the snapshot, and click OK. Restoring a snapshot reverts all changes since it was taken. Deleting a snapshot removes the ability to return to that state.

The author notes that snapshots are prone to user error and prefers clones and exports. Snapshots also accumulate wasted space if many are created in one VM.

## VM Disk Size and Shrinking

VM disk files grow over time even as content is deleted inside them. Shrinking a Windows VM involves several steps:

1. Remove undesired files and empty the Recycle Bin.
2. Open Drive Optimization (search for "Defrag") and optimize the C drive.
3. Open Command Prompt and run the following commands in order:
   - `curl https://download.sysinternals.com/files/SDelete.zip -o SDelete.zip`
   - `tar -xf SDelete.zip`
   - `sdelete64.exe c: -z`
4. Shut down the VM.

On the Linux host, navigate to the VM folder and run VBoxManage to compact the virtual disk:

```
cd '/home/osint/VirtualBox VMs/Windows11'
VBoxManage modifymedium disk Windows11.vdi --compact
```

This fills free space with zeros and then compacts the file. The author performs this after every major VM update.

## Troubleshooting VirtualBox

**VT-x is Disabled**: This is the most common error preventing VMs from starting. It means the processor does not support virtualization or the feature is not enabled. The fix is done in the BIOS before the operating system loads (typically accessed by pressing Delete, F2, or F10 at startup). For Intel processors, enable "Virtualization (VT-x)" under the Advanced tab. For AMD processors, navigate to M.I.T. > Advanced Frequency Settings > Advanced Core Settings and set SVM Mode to Enable. If these options are not present, a model-specific web search for "virtualization" should provide guidance.

**Display Resize Issues**: If the Auto-resize Guest Display option is greyed out, run the following commands inside the Linux VM:

```
sudo apt update
sudo apt install -y build-essential dkms gcc make perl
sudo rcvboxadd setup
reboot
```

## VMWare Workstation Pro (Alternative)

VMWare Workstation Pro is offered as a polished alternative for those who encounter frustration with VirtualBox. VMWare now provides the full Workstation Pro for personal use at no cost, but commercial entities must obtain a license.

Installation steps bypass the need for an online VMWare account by downloading from techspot.com rather than VMWare directly. If an older VMWare Workstation Player is present, it can be upgraded to Pro from within the app, or removed first with `vmware-installer -u vmware-player`. After downloading the installer bundle, make it executable with `chmod +X VM[tab]` and run it with `sudo ./VM[tab]`. Errors about missing modules can be resolved by cloning `https://github.com/mkubecek/vmware-host-modules`, checking out the appropriate branch (for example, `workstation-17.5.1`), and running `sudo make` then `sudo make install`.

Creating a Windows 11 VM in VMWare Workstation Pro follows a similar process to VirtualBox. Key differences: VMWare uses a TPM password field to handle Windows hardware restrictions (no registry editing required) and the overall configuration is more direct. VMWare Tools (the guest additions equivalent) are installed via Virtual Machine > Install VMWare Tools. The main drawback compared to VirtualBox is that file sharing between host and guest is difficult and frequently fails. The author recommends having both programs installed and using each according to preference.

## VPN Kill Switch Issue

Users running the Linux Proton VPN application with Kill Switch mode enabled will find that all internet access is blocked inside VirtualBox and VMWare Workstation Pro VMs. The recommended solution is to disable Kill Switch mode in the Proton VPN host application while working with VMs.
