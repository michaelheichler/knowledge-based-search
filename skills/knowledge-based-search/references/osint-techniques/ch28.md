## Overview

This chapter (labeled Chapter 21 in the text) covers TikTok as an investigative source. TikTok is a Chinese-owned short-video platform that has grown rapidly to the point where it is likely used by any target under 30 who is active on social media. Posts are public by default and include comments, but some features require a logged-in account.

## URL-Based Access

TikTok's native search is unreliable, so the chapter recommends constructing URLs directly.

- Profile page: `https://www.tiktok.com/@snubsie` (replace the username)
- Username search (partial match): `https://www.tiktok.com/search/user?q=osint`
- Hashtag/tag search: `https://www.tiktok.com/tag/osint`
- Full post search (requires account): `https://www.tiktok.com/search?q=osint`
- Video-only search (requires account): `https://www.tiktok.com/search/video?q=osint`
- Current live streams: `https://www.tiktok.com/live`
- Google search for deleted posts: `site:tiktok.com osint`

Google indexes individual TikTok posts, so a site-scoped Google search can surface deleted content.

## Profile Identifiers

Each TikTok profile contains three identifiers in its HTML source code. For the example account `@willsmith`:

- `"id"`: `6727327145951183878` (unique numeric ID, persistent)
- `"uniqueId"`: `willsmith` (the @ handle)
- `"nickname"`: `Will Smith` (display name, not unique and can be reused)

Searching the numeric ID in search engines can surface posts that no longer appear on TikTok.

## Downloading Videos and Metadata

Right-clicking a video in the player view and saving it natively produces an MP4, but TikTok can remove that ability at any time and may serve a lower-resolution file if it detects a mobile device.

The preferred method is the command-line tool `yt-dlp`:

```
yt-dlp https://www.tiktok.com/@willsmith/video/7032216839878905134
```

Adding `--write-info-json` to the command writes a JSON metadata file alongside the video. That file contains fields including: channel, channel_id, uploader, uploader_id, uploader_url, track, artists, duration, title, description, Unix timestamp, view_count, like_count, repost_count, comment_count, upload_date, file extension, video codec (h265), audio codec (aac), filesize, width, and height. This metadata is generated directly by TikTok.

## Extracting Exact Upload Date and Time

Videos may show a date on screen, but the exact timestamp comes from the page source. Steps:

1. Right-click the post and view the page source.
2. Search (Ctrl-F / Cmd-F) for `~tplv`.
3. The digits immediately before that string are a Unix timestamp (for example, `1637781925`).
4. Convert at `unixtimestamp.com` to get the precise UTC date and time.

## Creating a TikTok Account for Investigation

Some content requires login. The chapter recommends a "burner" account linked to a dedicated (clean, activity-free) Gmail address or social network connection, opened in a Firefox container. Trying to register with only an email often triggers a demand to install the app, which the chapter advises against. Linking to a clean Google account typically bypasses the app requirement and enables full browser functionality.

## Extracting Comments

The commenting system resembles Facebook and Instagram. Each comment shows: username with hyperlink, comment text, date, like count, and nested replies.

Three methods for extracting comments:

1. **exportcomments.com**: Extracts up to 100 comments from any post for free. A premium account is required for larger exports. Browser extension scrapers exist but are described as unreliable.
2. **Browser Network Inspector**: Load the video, right-click outside the video area, choose Inspect, open the Network tab, play the video, then search the inspector pane for `comment/list`. Right-clicking that entry and opening it in a new tab shows a JSON view of the comments with granular fields, including `comment_language`, `create_time` (Unix timestamp), `text`, `nickname`, and `uid`.
3. The JSON inspector approach is the same method that online extraction services use internally.

## Retrieving the Largest Profile Image

Saving the avatar by right-clicking the icon typically yields a 720p JPEG. To obtain the 1080p version:

1. Navigate to the profile page.
2. View page source and search for `jpeg`.
3. Locate the URL containing `~c5_1080x1080.jpeg`.
4. That URL will fail if opened directly because its query parameters differ from the signed 720p URL.
5. Copy the filename and path portion beginning with the shared image ID (for example, `62fcd657...`) from the 1080p URL and replace the corresponding portion in the working 720p URL.
6. The resulting combined URL opens the 1080p image.

The online tool `ttsave.app` performs this extraction automatically. The chapter notes a preference for the manual method because it can be fully articulated in a report.

## Third-Party Analytics Tools

Several sites accept a username in the URL and return profile analytics:

- `https://tokcount.com/?user=vancityreynolds`
- `https://tokcounter.com/?user=vancityreynolds`
- `https://exolyt.com/user/vancityreynolds/full`

These surfaces aggregate follower count, following count, total likes, average post comments, average plays, average shares, daily engagement rate changes, follower growth charts, and daily performance scores.

## Investigative Value

TikTok is described as a fertile intelligence source across many demographics. The chapter cites a law enforcement case involving underground street racing where targets had set their other social media accounts to private but were publicly posting on TikTok under the same usernames, providing video evidence of crimes and intelligence about upcoming events. Searching known usernames across platforms, with TikTok included, is described as a key technique for finding alternate accounts and public postings.

The chapter closes by emphasizing the importance of understanding how to capture content as evidence: correct screen captures and full video exports using the methods described.
