## Overview

Online video has become at least as common as online photography. Smartphones make recording and uploading effortless, and social networks now host video natively. For investigators, any abnormal event is likely captured on video by bystanders. This chapter covers techniques for finding, extracting, analyzing, and preserving online video as evidence, with emphasis on YouTube and then broadening to other platforms.

## YouTube

YouTube is the dominant video-sharing platform. According to the official site, 500 hours of video are uploaded every minute, producing roughly 80 years of content per day, with over one billion views per day. Every video belongs to a user channel. Channels, comments, and profiles are all investigatively relevant.

### Searching and Filtering

The main search bar accepts any term or username. The Filter button above search results allows sorting by upload date, type (video vs. channel), duration, and features such as video quality. A search for "school bus fight" returns over 500,000 results unfiltered. Adding "uploaded this week" cuts that to about 700, a manageable set. The uploader's profile link appears at the lower left of any video page and leads to all videos that user has uploaded.

### Bypassing Age and Login Restrictions

Some videos are gated by age verification or mandatory Google login. To bypass this, prepend `nsfw` to the domain portion of the YouTube URL. For example:

```
https://www.youtube.com/watch?v=SZqNKAd_gTw
```

becomes:

```
https://www.nsfwyoutube.com/watch?v=SZqNKAd_gTw
```

The download techniques described in Chapter Ten of the book also bypass this restriction. The chapter advises against browsing any Google product while logged into a personal account, because Google records every action taken under that account.

### Bypassing Commercials

Changing the URL structure from `/watch?v=` to `/embed/` forces the video to play in full-screen embedded mode and bypasses pre-roll commercials. Example:

```
https://www.youtube.com/watch?v=IEIWdEDFlQY
https://www.youtube.com/embed/IEIWdEDFlQY
```

### Extracting Still Frames (Thumbnails)

Every YouTube video has a static thumbnail URL built around its video ID. For a video with ID `1nm1jEJmOTQ`:

- Main thumbnail: `https://i.ytimg.com/vi/1nm1jEJmOTQ/hqdefault.jpg`
- Maximum resolution: `https://i.ytimg.com/vi/1nm1jEJmOTQ/maxresdefault.jpg`
- Four unique frames: `https://img.youtube.com/vi/1nm1jEJmOTQ/0.jpg` through `.../3.jpg`

These URLs work without playing the video and are useful for reverse image searching.

### Country Restrictions

To identify which countries can and cannot view a video, paste the video ID into either of the following:

```
http://polsy.org.uk/stuff/ytrestrict.cgi?ytid=<video_id>
https://watannetwork.com/tools/blocked/#url=<video_id>
```

Both services return a world map showing restricted (red) and permitted (grey) countries. When a video is blocked in your location, the still frames described above are still accessible directly by URL. A VPN connecting through a permitted country will allow playback. Free "YouTube Proxy" sites are described as unreliable.

### YouTube Metadata via API

The native video page shows approximate figures. For precise metadata, use the Google YouTube Data API. A free API key can be created at `developers.google.com` by creating a project and enabling a YouTube API key. The query structure for a video with ID `cgEnBkmcpuQ` is:

```
https://www.googleapis.com/youtube/v3/videos?id=cgEnBkmcpuQ&part=snippet,statistics,recordingDetails&key=<API_KEY>
```

This returns exact fields including `publishedAt`, `channelId`, `viewCount`, `likeCount`, `dislikeCount`, `favoriteCount`, and `commentCount`. The chapter states that every YouTube investigation should document all available metadata.

### YouTube Profile Data

Every video links to an uploader's channel page, but the channel page shows only partial data. An RSS feed URL provides additional detail:

```
https://www.youtube.com/feeds/videos.xml?user=<username>
```

This returns the channel's assigned Channel ID and the exact date and time the account was created. Each video entry within the feed includes exact creation and modification timestamps. Using the Channel ID with the API reveals the account's country, custom URL, and a high-resolution profile image (800x800 pixels) that is otherwise only available as a 160x160 icon. The demonstration example uses the channel `SnubsieBoo`, which resolves to Shannon Morse, Channel ID `UCNofX8wmSJh7NTklvMqueOA`, account created `2006-08-16T23:23:03+00:00`.

### Reverse Image Search from YouTube Thumbnails

Because YouTube exposes static thumbnail URLs, those images can be fed directly to reverse image search engines (Google, Bing, Yandex, TinEye, Baidu) without ever playing the video. Example Google reverse image search URL:

```
https://www.google.com/searchbyimage?image_url=https://i.ytimg.com/vi/cgEnBkmcpuQ/maxresdefault.jpg&client=app
```

This can surface dozens of additional platforms hosting the same video. The chapter's Videos Tool automates this across multiple engines.

### Downloading YouTube Videos

The preferred method is yt-dlp (or youtube-dl) within a Linux, Mac, or Windows OSINT machine, covered in Chapter Ten. As a fallback when no software is available, prepend `deturl.com/` to the YouTube URL:

```
https://deturl.com/www.youtube.com/watch?v=t2mU6USTBRE
```

This provides options to download the video, download audio only, convert format, and bypass age restrictions. Alternative services include `yout.com` and `y2mate.com`.

### YouTube Comments

Comments below a video include the username and link to that user's profile. The YouTube Comment Finder tool at `ytcomment.kmcat.uk` allows keyword search across all comments on a specific video. For a video with over 42,000 comments, a search for a single term instantly returns matching results with poster name, full comment text, like count, reply count, a link to the native comment, and exact timestamp.

The underlying API query structure is:

```
https://www.googleapis.com/youtube/v3/commentThreads?part=id,snippet&videoId=<video_id>&pageToken=&order=Relevance&maxResults=100&searchTerms=<term>&textFormat=plainText&key=<API_KEY>
```

This returns raw JSON including `authorDisplayName`, `authorChannelUrl`, `authorChannelId`, `textDisplay`, `likeCount`, `publishedAt`, and `updatedAt`.

### YouTube Channel Crawler

`channelcrawler.com` finds low-visibility YouTube channels that official YouTube search does not surface. YouTube's own channel filter heavily favors channels with large subscriber counts. Channel Crawler allows filtering by maximum subscriber count and maximum total views, returning channels that would otherwise be invisible. The chapter demonstrates finding "Guns" channels with fewer than 40 subscribers and fewer than 40 total views.

### Unlisted Videos

YouTube videos can be Public, Private, or Unlisted. Unlisted videos do not appear in YouTube search results but are viewable by anyone with the direct URL. Two methods for finding them:

1. Google dork: `site:youtube.com "This video is unlisted" intitle:<keyword>` (described as unreliable)
2. `unlistedvideos.com`, described as more reliable for keyword-based discovery

## Broader Video Search

### Google Videos, Bing Videos, Yandex Videos

A YouTube search for "school bus fight" returns over 500,000 results. The same search on Google Videos returns 3 million, including results from news sites and social networks. Google Videos supports filtering by duration, date, and video source. Bing Videos features hover-to-preview playback without navigating away from the results page, plus filtering by length and source. Yandex Videos is noted as particularly useful because Yandex, unlike Google and Bing, does not actively remove violent or otherwise policy-violating content. Safe search should be disabled on all three when conducting investigations. Direct query URL patterns:

```
https://www.google.com/search?tbm=vid&q=<term>
https://www.bing.com/videos/search?q=<term>
https://yandex.com/video/search?text=<term>
```

### Social Network Video Search

Search engines do not replicate internal search on social platforms. Direct URL patterns for video searches:

- Twitter/X: `https://x.com/search?q=<term>&f=media`
- Facebook: `https://www.facebook.com/search/videos/?q=<term>`
- Reddit: `https://www.reddit.com/search?q=site:v.redd.it%20AND%20<term>&type=media`
- TikTok: `https://www.tiktok.com/tag/<term>`

For downloading videos found on social networks, the chapter recommends the Video Download Tool first, then the Video Stream Tool for live streams, then browser extensions, and finally third-party services including Twitter Video Downloader (`twittervideodownloader.com`), FDown (`fdown.net`), and Instagram Downloader (`igdown.net`).

## Deleted Videos

When a YouTube video has been removed, the Internet Archive may have a copy. To check for archived captures of a video page:

```
https://web.archive.org/web/https://www.youtube.com/watch?v=<video_id>
```

These are HTML snapshots and do not play the video, but they preserve comments. To play the actual video content from the archive:

```
https://web.archive.org/web/2oe_/http://wayback-fakeurl.archive.org/yt/<video_id>
```

The video can then be right-clicked and saved locally.

## Reverse Video Searching

No dedicated reverse video search tool exists, but applying reverse image search to a video's still frames produces strong results. The chapter outlines three investigative scenarios where this is valuable: identifying the spread of school fight videos, tracking protest-related videos across platforms to find additional commentary and threats, and identifying human trafficking activity by finding identical escort videos posted across multiple geographic areas.

For YouTube, the thumbnail and frame URLs described earlier are submitted to Google, Bing, Yandex, TinEye, and Baidu. For Vimeo, the API endpoint at:

```
https://vimeo.com/api/oembed.json?url=https://vimeo.com/<video_id>
```

returns a JSON object that includes a `thumbnail_url`. Removing the size suffix from that URL (for example, removing `_295x166.jpg`) yields a full-size image suitable for reverse image searching. For any other video platform, the still frame image is typically referenced in the page source code and can be identified by searching the source for `.jpg` or `.png` extensions.

## Internet Archive Video Collections

The Internet Archive (`archive.org`) permanently hosts open-source movies including commercial and amateur releases. The "community video" section is most relevant for amateur content. Unlike YouTube, the site does not prominently link to other videos from the same uploader. To find a user's uploads, navigate to `http://www.archive.org/details/<username>`. On any individual video page, the "Show All" link below the video frame displays associated file metadata, including the uploader's email address and exact upload and publication timestamps. The chapter's demonstration shows user `Enver_Awlaki` at `archive.org/details/Enver_Awlaki`, with a video at `archive.org/details/Awlaki_to_americans` that reveals the upload email `ibnumar@islamumma.com` and an upload time of `2012-03-31 22:47:36` with publication at `2012-04-01 00:09:10`, over an hour later.

## TV News Archive

The TV News Archive at `archive.org/details/tv` held over 2,094,000 television news broadcast recordings from 2009 onward at the time of writing. It extracts closed captioning text from every broadcast and makes it searchable. A keyword search for "Bazzell" returned 35 broadcasts that verbally mentioned that name. Results can be filtered by show, station, date, language, and topic. The chapter notes this resource is useful for vetting job candidates.

## Video Closed Captions

`downsub.com` extracts the closed captioning text file from any YouTube video (or other captioned video). Pasting the video URL into the site produces download links for each available language as `.srt` files, which include word-level timestamps. The automated captions are imperfect with slang and unclear speech, but the files can help identify specific moments in a video during official proceedings. The chapter recommends including the caption file whenever a YouTube video is submitted as part of a report.

## Live Video Streams

Live streaming platforms allow a smartphone to broadcast immediately to a large audience with roughly a five-second delay. Platforms listed in order of investigative preference:

- YouTube (`youtube.com/live`)
- TikTok (`tiktok.com/live`)
- Twitch (`twitch.com`)
- Bitchute (`bitchute.com`)
- LiveU (`liveu.tv/resources/tv`)
- YouNow (`younow.com`)
- UScreen (`uscreen.tv`)

Each has a keyword search. The Video Stream Tool from Section One is recommended for viewing and capturing live streams. The chapter describes a real investigation in which monitoring live streams during a violent protest provided actionable intelligence for law enforcement, fire, and EMS responders, including the location of new confrontations, injured civilians, and arson fires.

## Listen Notes

`listennotes.com` searches across millions of audio podcasts by keyword. An email address search returns any podcast episode whose show notes include that address. The chapter positions this as a growing resource as podcast volume increases and audio-to-text technology improves.

## Video Frame Analysis

`anilyzer.com` allows frame-by-frame analysis of YouTube and Vimeo videos by entering the URL and selecting the provider. The viewer can step through individual frames or adjust playback speed. The chapter describes using it for quick scrutiny of a small number of frames, particularly from surveillance video.

## YouTube Handles

In 2022 YouTube introduced user-defined handles as an alternative way to link to channels, using the `@` prefix. The two URL forms are equivalent:

```
https://www.youtube.com/ambermac
https://www.youtube.com/@ambermac
```

The chapter notes limited investigative value beyond using the handle as an additional username query.
