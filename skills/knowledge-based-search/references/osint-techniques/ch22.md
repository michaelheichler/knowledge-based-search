## Overview

This chapter (labeled Chapter 16 in the converted text) covers how to create, host, and maintain your own offline HTML-based search tools for OSINT investigations. The central argument is that investigators cannot safely rely on third-party search aggregators: those tools can disappear due to takedown demands, and they collect analytics about every query you run. Building your own tools eliminates the middleman while preserving the ability to automate multi-site searches.

## Why Self-Hosted Tools

The author ran public tools at inteltechniques.com from 2010 through 2019, removed them in June 2019 due to abuse and legal demands, then restored them in 2022. The lesson drawn is that any externally hosted tool can vanish at any time. Beyond availability, aggregator sites carry tracking cookies and embedded analytics that record investigator activity against sensitive targets. A locally stored HTML file runs in the browser without phoning home to anyone except the final query destination.

## Getting the Template Files

A zip archive of all search tool templates used throughout the book is available at:

    https://inteltechniques.com/data/osintbook11/tools.zip

Users of the Linux, Mac, or Windows OSINT builds already have these files on the Desktop. The archive extracts to a folder called "Tools" containing one HTML file per investigative category. The file "index.html" serves as the main menu and is suitable as a browser home page. Clicking any left-menu item opens that category's tool.

## HTML Structure of a Tool

Each tool is a plain HTML file that can be opened by double-clicking (opens in the browser) or in a text editor for modification. Recommended editors are TextEdit (Mac), Notepad (Windows), Text Edit (Linux), or VSCodium (vscodium.com, cross-platform and free).

A tool file has the standard sections: DOCTYPE declaration, a style block for colors and sizing, a head and title block, and a body containing a table. Each search option is a form that captures one input value and a JavaScript line that opens a new browser tab pointed at the constructed URL.

A typical single-search script looks like:

    {window.open('https://www.whoxy.com/search.php?email=' + Search22, 'Search22window');}

This opens a new tab at the Whoxy URL with the user's input appended, naming the tab "Search22window" so subsequent searches do not overwrite it.

When a target site requires the query string wrapped in quotation marks (Dehashed is the example given), the extra characters are concatenated with the plus operator:

    {window.open('https://dehashed.com/search?query="' + Search05 + '"', 'Search05window');}

Each search input element is assigned a unique id such as "Search01", "Search02", and so on. The final numbered slot in the default Email tool is Search25, so any new option added by the user should begin at Search26.

## Discovering URL Structures

Many sites do not advertise their direct-query URLs. The method for finding them uses Firefox's Network Inspector:

1. Right-click the target page and choose "Inspect Element."
2. Click the "Network" tab in the inspector panel.
3. Execute a search on the site.
4. In the network log, find the relevant file (for Whoxy the file is named "search.php").
5. Copy the full URL shown under "Headers" on the right side.

The Whoxy example produces `https://www.whoxy.com/search.php?email=test@test.com`. This URL, not the site's front page, is what goes into the tool's window.open call. The API endpoint is free even though the paid API is separate.

## Adding and Modifying Search Options

To add a new service, open the HTML file in a text editor, find the block for an existing option (for example Search24), copy that block, paste it before the Submit All section, and edit three things: the target URL, both occurrences of the Search identifier (incrementing to the next unused number, such as Search26), and the label text. The identifier numbers do not need to be sequential, but every one on a single page must be unique.

To update a broken option when a site changes its URL structure, only the URL string inside window.open needs to change. The example shows Dehashed moving from `https://dehashed.com/search?query=` to `https://dehashed.com/?query=` with an added `&trial` parameter. The corrected script becomes:

    {window.open('https://dehashed.com/?query="' + Search05 + '"&trial', 'Search05window');}

## Submit All and Populate All

The "Submit All" button at the bottom of most tools runs every search in the tool from a single input. Its code contains multiple window.open calls in sequence, one per service. If a manual search option is updated, the corresponding line inside Submit All must also be updated.

The "Populate All" feature copies whatever is typed into the first field into every field on the page whose id begins with "Search" followed by digits. This avoids repeated copy-paste when running individual queries one at a time.

Firefox blocks pop-ups by default. When Submit All opens many tabs at once, only the first will succeed on the initial attempt. To resolve this per tool, click the notification banner that appears and allow pop-ups for that specific file URL. To resolve it globally across all tools, go to Firefox Settings, Privacy and Security, Permissions, and uncheck "Block pop-up windows." The author leaves pop-ups blocked on personal browsers but disables the blocker inside the dedicated OSINT VM, where the reduced risk is acceptable.

## Easy Access

After downloading and extracting the tools, open "Search.html" in Firefox and bookmark it. Press Ctrl+D (Cmd+D on Mac), name the bookmark "Tools," and save it to the Bookmarks Toolbar. If the Bookmarks Toolbar is not visible, enable it under View, Toolbars. The bookmark then provides one-click access to the full tool set from any session.

## Online Version

A live copy of all tools is maintained at `https://inteltechniques.com/tools/`. The underlying code is identical to the offline files. The author updates the online copy as sources change, but those updates do not propagate to a user's downloaded offline copy. Users must apply changes to their own files manually or re-download from `https://inteltechniques.com/osintbook11` (the book's Updates page). The online version is subject to the same takedown risk as before.

## Maintenance Philosophy

The author acknowledges the HTML is not sophisticated. Readers who find it lacking are still encouraged to use the tools as-is and limit modifications to URL updates when specific searches break. Any sources that fail can simply be replaced when alternatives emerge. The tools are released for free, provided "as is" without warranty, and the license details are in the "License.txt" file included in the download.
