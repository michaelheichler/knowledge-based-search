## Overview

This chapter covers methods for researching a target email address, starting with basic search-engine queries and progressing through breach data, password exposure, Pastebin monitoring, domain registration lookups, and account-existence probing. The core argument is that an email address is a more precise identifier than a real name: there may be thousands of people named John Wilson, but only one john.wilson.77089@yahoo.com. Every technique described flows from that premise.

## Basic Search-Engine Queries

The first step is to place the full email address in quotation marks and run it through Google, Bing, and Yandex. The username portion (the part before the @) should also be searched separately, in case it appears on other platforms such as Gmail, Hotmail, Twitter, or LinkedIn. Direct URL patterns accelerate this process:

- Google email: `https://google.com/search?q="john.wilson.77089@yahoo.com"`
- Google username: `https://google.com/search?q="john.wilson.77089"`
- Bing email: `https://bing.com/search?q="john.wilson.77089@yahoo.com"`
- Bing username: `https://bing.com/search?q="john.wilson.77089"`
- Yandex email: `https://yandex.com/search/?text="john.wilson.77089@yahoo.com"`
- Yandex username: `https://yandex.com/search/?text="john.wilson.77089"`

## Email Verification and Reputation

**Emailrep.io** (emailrep.io) is described as the top priority for every investigation. A single free query returns reputation score, suspicious flag, number of online references, blacklist status, malicious activity indicators, whether credentials have been leaked (and whether recently), breach presence, first and last seen dates, domain validity, whether the domain is new, days since domain registration, spam flags, whether the provider is free or disposable, deliverability, catch-all status, valid MX record, SPF and DMARC enforcement status, and a list of associated profiles (for example, YouTube, GitHub, Twitter). An explanatory summary accompanies the raw fields. A result with no identifiable history suggests a burner address, which is common in threat and extortion investigations.

**Email Hippo** (tools.verifyemailaddress.io) provides a simple OK/BAD deliverability check with minimal additional data. Results accumulate in a list during a session and can be exported in bulk. Free daily queries are limited by IP address and browser cookies.

**CleanTalk** (cleantalk.org/email-checker/) reports whether an address is real, disposable, or blacklisted, with a timestamp of the last update. The URL accepts the address directly: `https://cleantalk.org/email-checker/michael@inteltechniques.com`.

**Hunter** (hunter.io/email-verifier) verifies validity and sometimes surfaces historical internet links that contained the address, drawn from Hunter's own database. Those links may no longer be live on the web but remain as evidence in Hunter's index. The URL query format is `https://hunter.io/verify/test@gmail.com`.

## Email Assumptions and Format Discovery

When only one address is known, variations at other providers should be tested. If a target uses jay112003@yahoo.com, checking jay112003@gmail.com, jay112003@hotmail.com, and jay112003@live.com may reveal additional accounts. For a target known to work at a specific organization (for example, medicaldistrict.org), candidate addresses such as jstewart@, jay.stewart@, j.stewart@, and stewartj@ can be constructed and then verified with the tools above.

**Email Format** (email-format.com) searches a domain name, identifies confirmed employee addresses under that domain, and infers the standard naming convention used. The result for medicaldistrict.org, for example, would tell an investigator that the format is first-initial plus last-name, pointing to jstewart@medicaldistrict.org. This output can be combined with names gathered from social networks to build a candidate list.

## Gravatar Profile Images

The Gravatar service (gravatar.com) associates a small image icon with any registered email address. The homepage has no search field, but a direct URL returns the image if one exists: `https://en.gravatar.com/site/check/test@test.com`. A returned image can then be submitted to a reverse image search.

## Breach and Compromise Data

**Have I Been Pwned** (haveibeenpwned.com) accepts an email address and returns a list of named public breaches containing it, with descriptions of the service type, the number of users affected, and relevant dates. The site relies on data voluntarily contributed by researchers, including some who sell stolen credentials on black markets. HIBP's vetting of a dataset raises its black-market value, a practice some researchers criticize. Confirming breach presence also confirms that an address was valid and active.

**Dehashed** (dehashed.com) pursues breach databases more aggressively and often surfaces smaller or newer breaches not yet present in HIBP. The two services complement each other and should always be used together. A free account is required for any query. Passwords are visible only on a premium account.

**Spycloud** (spycloud.com) holds many datasets not in HIBP. Searching via their main website sends an email to the target address, alerting them. The correct method is the free API: `https://portal.spycloud.com/endpoint/enriched-stats/test@email.com`. The JSON result reports the number of records discovered and how recently. This tool is used only to confirm breach presence and verify an address.

**Hudson Rock** (hudsonrock.com) checks whether an address appears in stealer log data. Presence in stealer logs indicates that malware on the owner's machine captured credentials. API query: `https://cavalier.hudsonrock.com/api/json/v2/preview/search-by-login/osint-tools?email=test@email.com`.

**Cybernews** (cybernews.com/personal-data-leak-check) returns a simple true/false for breach presence via URL: `https://check.cybernews.com/chk/?lang=en_US&e=test@test.com`.

## Password Exposure

**Leak Peek** (leakpeek.com) holds roughly 8 billion credentials and displays partially masked passwords, for example `55Ji*******` or `Big6****`. It accepts queries by email address, username, password, keyword, or domain.

**Breach Directory** (breachdirectory.org) returns similar partially redacted passwords but also provides SHA-1 hash values of the full passwords alongside the masked version. Those hashes can be submitted to a hash-lookup service such as MD5 Decrypt (md5decrypt.net/en/Sha1) to recover the plaintext password without any account or payment. The worked example shows that the hash `dc3245ecdcf2e40b140e121a014cc37f70239f41` resolved to the plaintext `Ex7layer`.

## Pastebin Monitoring

**PSBDMP** (psbdmp.ws) archives Pastebin posts that contain email addresses or passwords. The API accepts an email address or any keyword: `https://psbdmp.ws/api/search/test@test.com` or `https://psbdmp.ws/api/search/password1234`. Each result includes a Pastebin ID, file length, timestamp, and a text excerpt. The original post is accessible at `https://pastebin.com/[id]`. If Pastebin has deleted the post, PSBDMP may still hold the full archived text, retrievable via its own URL with the same ID. A Google query of `site:psbdmp.ws "target@gmail.com"` can surface indexed results that a direct Pastebin search misses.

## Additional Data Sources

**IntelligenceX** (intelx.io) provides partial results on the free tier and full results on a trial or paid basis.

**LeakIX** (leakix.net) indexes exposed data across the internet, including WordPress user tables and misconfigured servers. URL query: `https://leakix.net/search?scope=leak&q=%22test@test.com%22`.

**OCCRP** (data.occrp.org) is described as a global archive of investigative journalism research material. A direct email query returns documents containing that address. A keyword search can be filtered by the "Email" category to surface additional addresses mentioned in the same documents. URL structure: `https://data.occrp.org/search?test@test.com`.

**Spytox** (spytox.com) is a white-pages style lookup that may return a name, city, and phone number. Paid options are not considered worth the cost.

**That's Them** (thatsthem.com) rarely returns results for email queries but occasionally provides full name, address, phone number, and vehicle information.

**Search People Free / Cyber Background Checks** (searchpeoplefree.com, cyberbackgroundchecks.com) draws on marketing database leaks and typically returns full name, age, current and past addresses, phone numbers, family members, and business associations.

**XLEK / USA-Official** (xlek.com, usa-official.com) indexes email addresses but does not offer a direct email search field. Google can substitute: `site:xlek.com "mike" "gmail.com"` or `site:usa-official.com "mike" "gmail.com"`.

**OSINT Rocks** (osint.rocks) provides browser-based access to tools including Ghunt, Sherlock, and Holehe, but requires sending target data to a third party. Gmail OSINT (gmail-osint.activetk.jp) replicates Ghunt features with the same limitation. Castrick (castrickclues.com) serves as a fallback if the above are unavailable.

## Proton Mail Account Dating

Proton Mail is identified as the most commonly encountered encrypted email provider in criminal investigations. The creation date of a Proton Mail account can be found in two ways.

The more reliable method requires a free Proton Mail account. Create a new contact with the target address, open it, click "Email Settings," then "Show advanced PGP settings." The public key creation date is typically the account creation date. Generating new security keys is rare, so a wrong date from this method is uncommon.

Without logging in, existence can be confirmed at: `https://api.protonmail.ch/pks/lookup?op=get&search=target@protonmail.com`. A browser prompt to download a file named pubkey.asc confirms the address exists. If it does exist, the creation timestamp is retrievable at: `https://api.protonmail.ch/pks/lookup?op=index&search=target@protonmail.com`. The response contains a Unix epoch timestamp (for example, 1623879788) that converts to a human-readable date at unixtimestamp.com. This example timestamp corresponds to Wednesday, June 16, 2021 at 21:43:08 GMT. VPN connections or rapid repeated queries can produce false positives with these two URLs.

For custom-domain addresses hosted through Proton Mail, the query `https://mail-api.proton.me/pks/lookup?op=index&search=test@domain.com` reveals which Proton inbox actually receives the mail. If the uid in the response differs from the queried address (for example, returning office@michaelbazzell.com when the query was for another address at the same domain), the queried address is a catch-all forwarder rather than a dedicated account.

## Domain Registration Lookups

Every domain registration is linked to an email address. Reverse WHOIS services accept a target email and return all domains ever registered with it, including expired ones.

- Whoxy (whoxy.com/reverse-whois) returns full name, mailing address, phone number, registrar details, and a list of owned domain names.
- Whoisology (whoisology.com) returns the same fields and often finds more domain entries.
- AnalyzeID (analyzeid.com) returns domain names along with Amazon affiliate IDs and AdSense IDs, which can tie an email address to monetized websites.

## Account-Existence Probing

Starting an account-creation flow on any website with the target email address reveals whether the address is already registered there, without completing any registration. If the site reports the address as already in use, the target has an account. If it allows proceeding, no account exists. This technique works across Apple (account.apple.com), Microsoft (signup.live.com), Yahoo, Gmail, Facebook, and local utilities such as cable, power, and water companies. Knowing which local cable provider a suspect uses can constrain the geographic search area substantially. The method must never go beyond the initial screen, and submission must never be completed.

## Email Provider Identification

For business addresses with custom domains, the email provider is identified through the domain's MX record. MX Toolbox (mxtoolbox.com) accepts the domain portion of an address and returns the mail server hostname and IP address, which identify the hosting company. Every thorough OSINT report should document the email provider. A change in provider during an investigation may indicate an attempt to conceal evidence. Law enforcement can use this information to determine the correct target for a search warrant.
