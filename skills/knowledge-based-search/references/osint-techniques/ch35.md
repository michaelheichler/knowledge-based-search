## Overview

This chapter (labeled Chapter 28 in the text) covers a category of open source intelligence that investigators frequently overlook: documents. The chapter divides documents into three classes. The first class consists of documents that contain information about a target, such as PDF files the target may not know are publicly indexed. The second class consists of documents actually created by the target that have entered public view unintentionally. The third class focuses on metadata embedded inside documents, which can reveal the computer name, network username, software version, and other details that are not visible in the document's visible content.

## Searching for Documents with Google and Bing

The `ext:` operator in Google (and `filetype:` in Bing) restricts results to a specific file type. To find all Word documents on a specific domain: `site:inteltechniques.com ext:doc` and `site:inteltechniques.com ext:docx`. To find spreadsheets mentioning a topic: `ext:xls "OSINT"`. To combine multiple types in one query: `"OSINT" filetype:pdf OR filetype:doc OR filetype:xls OR filetype:xlsx OR filetype:docx OR filetype:ppt OR filetype:pptx OR filetype:txt`. Common file extensions to know are DOC and DOCX (Word), XLS, XLSX, and CSV (Excel), PPT and PPTX (PowerPoint), PDF (Acrobat), TXT and RTF (plain text), and ODT, ODS, ODG, ODP (Open Office). The chapter advises understanding manual query construction rather than relying on automated tools or Google Custom Search Engines, which limit results.

## Cloud Document Storage Services

**Google Docs and Google Drive.** Documents created in Google Docs are private by default, but users often make them public to share with colleagues and forget to restrict access. Google's own interface does not offer a search across public files, but Google indexes them. Example queries: `site:docs.google.com "resume" "Williams"`, or `site:docs.google.com 865-274-2074` to find a specific phone number. Subdomains to search include `docs.google.com/presentation/d` (presentations), `docs.google.com/file/d` (images, videos, PDFs), and `docs.google.com/folder/d` (file collections). Since 2013 Google also hosts files at `drive.google.com`, so searches should be repeated substituting "drive" for "docs".

**Microsoft Docs** (`docs.microsoft.com`). Stores and shares documents like Google Drive but is less popular. A query of `site:docs.microsoft.com "resume"` returned over 63,000 resume files on Google.

**Amazon Web Services** (`amazonaws.com`). Many companies rent AWS servers for cloud storage. The chapter emphasizes searching AWS because sensitive documents appear there regularly, including voter data discussed during the 2016 election. Example queries: `site:amazonaws.com ext:xls "password"` and `site:amazonaws.com ext:pdf "osint"`. Amazon CloudFront (`cloudfront.net`) is a content delivery network that can be searched the same way.

**Gray Hat Warfare** (`buckets.grayhatwarfare.com`). A specialized database of over one billion files publicly stored on AWS. Free users can search the first 350 million files. A search for "password xls" returned spreadsheets containing active credentials. Direct search URL format: `https://buckets.grayhatwarfare.com/files?page=1&keywords=password`.

**Google Cloud Storage** (`storage.googleapis.com`). Google's equivalent of AWS. Queries such as `site:storage.googleapis.com "confidential"` returned over 9,500 documents.

## Presentation Repositories

Services used to share presentations publicly include SlideShare (`slideshare.net`), Slidebean (`slidebean.com`), Power Show (`powershow.com`), ISSUU (`issuu.com`), and Prezi (`prezi.com`). SlideShare and ISSUU have native search. Prezi does not, so a Google site operator query such as `site:prezi.com "osint"` is needed.

## Additional Document Services

**Scribd** (`scribd.com`). Originally a cloud storage service, now focused on e-books, but its large archive of older documents remains accessible. Useful for finding business-related documents, including internal files that were posted without authorization. Searching "FOUO" (for official use only) returned hundreds of results for sensitive-labeled documents. Each document page identifies the uploader and links to their profile and upload history.

**Refseek** (`refseek.com`). A search engine claiming to search over five billion sites, books, journals, and newspapers. Query URL format: `https://www.refseek.com/documents?q=osint`.

**Searcholic** (`searcholic.com`). Returns PDFs and video content with thumbnail previews.

**Core** (`core.ac.uk`). A UK-based engine focused on research papers and academic documents. Query URL: `https://core.ac.uk/search/?q=osint`.

**Base** (`base-search.net`). Claims access to 400 million documents across 12,000 content providers. Query URL: `https://www.base-search.net/Search/Results?lookfor=osint`.

**PDF Drive** (`pdfdrive.com`). Scans the internet for PDF files and archives them, making it useful when an original source removes content.

**WikiLeaks** (`search.wikileaks.org`). Publishes sensitive and classified documents. The site became widely known when Army soldier Bradley Manning was arrested in 2010 for uploading classified government information to it. The site provides a working search.

**Cryptome** (`cryptome.org`). Publishes sensitive documents related to freedom of speech, cryptography, spying, and surveillance. Has no built-in search, so use a Google site operator query: `site:cryptome.org "osint"`.

**Internet Archive text collections** (`archive.org`). Searched with the `=TXT` parameter: `https://archive.org/search.php?query=inteltechniques&sin=TXT`.

**Google Books** (`books.google.com`). Indexes most books from the past decade. Query URL: `https://www.google.com/search?tbm=bks&q=inteltechniques`.

**Anna's Archive** (`annas-archive.org`). Provides a search interface over content aggregated from Library Genesis (a pirated e-book source). Allows searching within millions of books without downloading content, useful for finding whether a target's name appears in publications. The chapter cautions against downloading the pirated books.

**Book Sales** (`amazon-asin.com`). Uses a book's Amazon ASIN identifier to retrieve estimated daily sales, pricing, fees, and keywords. The chapter notes these figures are not always accurate but can indicate relative sales volumes.

## Paste Sites

Paste sites were designed for programmers to share code via a URL but are also used by hacking groups to publish stolen credentials, home addresses, credit card numbers, and other sensitive data. Few have native search. The recommended approach is to use a Google site operator query on each: `site:pastebin.com "osint"`.

**Pastebin** (`pastebin.com`) is the most popular in the United States. Criminal groups have used it to release stolen police officer addresses and stolen bank records. Law enforcement investigators can search the last four digits of a stolen credit card number to find a link to the thief.

A large list of additional paste sites is provided in the chapter, including `gist.github.com`, `dpaste.com`, `doxbin.org`, `justpaste.it`, `hastebin.com`, `paste.ee`, `privatebin.net`, and many others. These sites appear and disappear frequently. The chapter's custom Pastes tool at `https://inteltechniques.com/tools/Pastes.html` queries all of them simultaneously via a Google CSE.

## Document Metadata

Documents contain embedded metadata that is not visible in normal viewing. This metadata can include the name of the person who created or last modified the document, the computer name, the username on the computer or network, the software version used, the time spent editing, and network information.

**Online metadata viewers.** Several sites accept a document upload or a URL to a file and return its metadata: Extract Metadata (`extractmetadata.com`), Online Exif Viewer (`onlineexifviewer.com`), Exifdata (`exifdata.com`), ExifInfo (`exifinfo.org`), and Get Metadata (`get-metadata.com`). The chapter cautions against uploading sensitive or locally stored files that have never been on the internet, particularly classified documents.

**ExifTool** (`exiftool.org`). A terminal-based metadata extraction tool installed in the custom Linux VM. To extract metadata from all documents in a folder and produce a CSV report, navigate to the folder and run `exiftool * -csv > ~/Desktop/Evidence/Report.csv`. This reveals creator names, companies, software versions, and editing time for each file. The chapter recommends running this on every investigation involving downloaded documents.

**FOCA** (`github.com/ElevenPaths/FOCA`). A Windows application with a graphical interface for metadata extraction. Installation requires the Basic version of SQL Server Express from Microsoft, followed by downloading the FOCA zip from its GitHub releases page. The search and download features no longer work because search engines block that behavior, but the local document analysis feature remains functional. Documents are dragged into the window, and metadata is extracted and browsable via menus. ExifTool produces a more useful spreadsheet output. FOCA is more visually accessible.

**Real-world example.** Dennis Lynn Rader (the BTK killer) sent a floppy disk to the Wichita Police Department containing a Word document. Police examined the metadata, found it was created by a user named "Dennis" and linked to a Lutheran church. OSINT searches on those two details led to identifying and arresting the suspect.

**Manual metadata extraction from PowerPoint files.** Renaming a `.pptx` file to `.zip` and decompressing it exposes the internal components: embedded images (which can be analyzed for their own metadata), extracted text of all slide content, and XML files such as `app.xml` that reveal the software version (for example, PowerPoint from Microsoft Office 2016 appears as `AppVersion>16.0000`). Unique identifiers embedded across these files can be compared to other documents to confirm they share the same author.

**Free OCR** (`free-ocr.com`). Converts scanned PDF files that do not allow text selection into text documents using optical character recognition. Useful when a document's text cannot be copied and pasted.

## Rental Vehicle Records

Several car rental companies provide online receipt retrieval tools intended for customers, but they can be used to look up anyone's rental history given identifying information.

**Enterprise** (`enterprise.com`). The "Get a receipt" link on every page requires a driver's license number and last name, and returns rental history for the past six months to three years. Each receipt includes start and end dates and times, vehicle make and model, pick-up location, total mileage, lessee name, and form of payment.

**Hertz** (`hertz.com/rentacar/receipts/request-receipts.do`). Requires a driver's license number or reservation number plus last name.

**Alamo** (`alamo.com`). "Past Trips/Receipts" link in the page footer. Requires selecting a date range.

**Thrifty** (`thrifty.com/Reservations/OnlineReceipts.aspx`). Requires last name and either a driver's license number or credit card number.

**Dollar** (`dollar.com/Reservations/Receipt.aspx`). Same requirements as Thrifty.

The chapter presents these methods as techniques to evaluate for appropriateness in a given investigation.

## Government Document Archives

The National Archives (`archives.gov`) maintains a searchable repository of government documents. Example query URL: `https://search.archives.gov/search?query=osint&submit=&utf8=&affiliate=national-archives`. Additional research tools are listed at `https://www.archives.gov/research/start/online-tools`. The GovInfo service (`govinfo.gov`) is an alternative for locating federal government documents.

## Gender Analyzer

The uClassify Gender Analyzer (`uclassify.com/browse/uclassify/genderanalyzer_v5`) attempts to determine the gender of a text's author from the writing itself. The chapter notes mixed but generally reasonable accuracy.

## Custom IntelTechniques Tools

The chapter's custom document search tool at `https://inteltechniques.com/tools/Documents.html` (also available as a local `Documents.html` file) consolidates searches across file types (PDF, DOC, DOCX, XLS, XLSX, CSV, PPT, PPTX, KEYNOTE, TXT, RTF, XML, ODT, ODS, ODP, ODG, ZIP, RAR, 7Z, JPG, JPEG, PNG, MPG, MP4, MP3, WAV) and across hosting services (Google Docs, Google Drive, Microsoft Docs, Amazon AWS, CloudFront, SlideShare, Prezi, ISSUU, Scribd, PDF Drive, and others). A separate Pastes tool at `https://inteltechniques.com/tools/Pastes.html` queries all paste sites at once.
