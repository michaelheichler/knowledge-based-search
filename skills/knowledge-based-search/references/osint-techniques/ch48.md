## Core Tools

- **Ripgrep** (`rg`): primary search tool for large flat files
- **cat, cut, sed, awk, sort, find, gunzip, unzip**: standard shell data manipulation
- **jq** (stedolan.github.io/jq/): parse and extract fields from JSON data
- **Transmission**: torrent client for downloading large data sets
- **Internet Archive CLI** (`ia`): `brew install internetarchive` (macOS) or `sudo pip install -U internetarchive` (Linux)
- **Elasticsearch-Crawler** (github.com/AmIJesse/Elasticsearch-Crawler): Python script to dump open Elasticsearch databases
- **Shodan** (shodan.io): find open or misconfigured databases on the public internet

## Sources for Leaked Data

### Breach Forums and Aggregators
- **BreachForums** (breachforums.is): marketplace for breaches and leaks. Do not purchase credits. Earn free credits by posting or commenting.
- Google dork to find content: `site:breachforums.is voter`
- Google dork to find torrent links on the open web: `raidforums "magnet:?" database 2020`

### Telegram Channels (free, no credits required)
- Join channels: **Open Data**, **LEAKS AGGREGATOR**, **Data stream**
- Search within channels for: `voter`, `consumer`, `facebook dataset`, `instagram`, `IG`, `whois`, `cell`, `people data labs`
- Telemetry (telemetryapp.io): search for what Telegram rooms contain a term. Five free queries per day, account required.

### Archive.org
- **Wayback Machine** for Kyle Data / "Special K" spam list (178M email addresses):
  `https://web.archive.org/web/20151110195654/http://www.updates4news.com:80/kyledata/`
- **SSDI** (Social Security Death Index, public):
  `https://archive.org/download/SocialSecurityDeathIndex/2013-05-31/`
- **Snapchat breach** (4.6M usernames plus phone numbers, 2014):
  `archive.org/download/SnapChat.7z`
- **Usenet Giganews**: `https://archive.org/details/giganews`
- **Usenet Historical**: `https://archive.org/details/usenethistorical`
- Pre-built Usenet file (43M unique email addresses, name, newsgroup, 3 GB compressed):
  `https://mega.nz/file/mSJGGDYI#oNIeyaG2oIHcHQFfGeFuq3zxUp_cCgARVf6bQNqp9ls`

### Official Government Voter Data
- **Ohio** statewide voter file (public download, no registration):
  `https://www6.ohiosos.gov/ords/f?p=VOTERFTP:HOME::::::`
- **Washington state** voter file (requires agreement not to redistribute):
  `https://www.sos.wa.gov/elections/vrdb/extract-requests.aspx`

### Open Elasticsearch Databases via Shodan
- Shodan query pattern: `product:elastic port:9200 [target data]`
- Example: `product:elastic port:9200 customer`
- Example: `product:elastic port:9200 leads`
- Once you have an IP, list all indexes: `http://<IP>:9200/_cat/indices?v`
- View 100 records from an index: `http://<IP>:9200/<index>/_search?size=100`
- View 10,000 records (browser max): `http://<IP>:9200/<index>/_search?size=10000`
- Elasticsearch-Crawler bypasses the 10,000 browser limit. Works on Elasticsearch older than version 6.4.0.

## Shell Commands: Acquire, Clean, and Search

### Combine multiple files into one
```bash
cat SWVF* > Ohio.txt
cat USA* > Facebook-US.txt
cat * */* > 1.txt                          # includes one level of subfolders
find . -name '*' -exec cat {} \; > ~/Downloads/IntelX.txt   # when too many files for cat *
find . -name '*.txt' -exec cat > ~/Downloads/FB.txt {} \;
```

### View first N lines of a large file
```bash
rg -m2 "" Ohio.txt
```

### Extract specific columns (CSV)
```bash
# Ohio voter: extract name, DOB, address columns
cut -d, -f4,5,6,8,12,13,14,15,16,17 Ohio.txt > Ohio-clean.txt

# USA Consumer: extract name, address, state, phone, email, IP
cut -d, -f3,4,5,8,10,17,18,43,410,411,412 1.txt > 2.txt
```

### Remove quotes
```bash
sed -i "s/\"//gI" Ohio-clean.txt
```

### Replace tabs with commas (SSDI format cleanup)
```bash
# The spaces in the command are created with Ctrl+V then Tab
sed -i "s/	/\,/gI" SSDI.txt
```

### Extract only lines containing an email address
```bash
awk '/@/' IntelX.txt > IntelX2.txt
```

### Deduplicate and sort (case-insensitive, memory-efficient)
```bash
LC_ALL=C sort -u -b -i -f -S 80% --parallel=8 IntelX2.txt > IntelX3.txt
sort -u -f Giganews2.txt UsenetHistorical2.txt > UsenetFinal.txt
```

### Decompress recursively
```bash
gunzip -r .        # or: unzip (macOS fallback)
find . -name "*.zip" -exec unzip {} \;
```

### Combine all CSV files from nested folders, extracting specific columns
```bash
find . -type f -name \*.csv -print0 | xargs -0 cut -f1,3,4,5 > Giganews2.txt
```

### Search with Ripgrep
```bash
rg -aFiN <term> <file>           # -a: treat as text, -F: fixed string, -i: case-insensitive, -N: no line numbers
rg -aFiN Bazzell Ohio-clean.txt
rg -aFiN bazzell SSDI.txt
rg -aFiN robynsnest2006@yahoo.com SpecialK.txt
rg -aFiN mikenap115 SnapChat.txt
rg -aFiN 30351923XX SnapChat.txt
rg -aFiN "From: " > UsenetHistorical2.txt
rg -aFiN Bazzell                 # searches all files in current directory
```

### Move cleaned file and delete originals
```bash
mv 2.txt ~/Downloads/Consumer-Cleaned.txt
rm -r *
```

## JSON Parsing with jq

### Extract specific fields from JSON to a flat CSV
```bash
jq --raw-output '"\(.data.first_name),\(.data.last_name),\(.data.gender),\(.data.birth_year),\(.data.birth_date),\(.data.linkedin_username),\(.data.facebook_id),\(.data.twitter_username),\(.data.work_email),\(.data.mobile_phone)"' people.json > people.txt
```

### LinkedIn 2021 scrape extraction (files named part-*)
```bash
jq --raw-output '"\(.first_name),\(.middle_name),\(.last_name),\(.gender),\(.birth_date),\(.linkedin_username),\(.facebook_username),\(.twitter_username),\(.work_email),\(.mobile_phone),\(.location_name),\(.phone_numbers),\(.emails)"' part* > LinkedIn.txt
```

### Remove null fields from cleaned LinkedIn file
```bash
sed -i "s/null\,//gI" LinkedIn.txt
```

### Clean PDL JSON (remove brackets, quotes, field labels)
```bash
sed -i "s/[\{]//gI" PeopleDataLabs_416M.json
sed -i "s/[\}]//gI" PeopleDataLabs_416M.json
sed -i "s/[\[]//gI" PeopleDataLabs_416M.json
sed -i "s/[\]]//gI" PeopleDataLabs_416M.json
sed -i "s/\"//gI" PeopleDataLabs_416M.json
sed -i "s/a\://gI" PeopleDataLabs_416M.json
sed -i "s/t\://gI" PeopleDataLabs_416M.json
sed -i "s/e\://gI" PeopleDataLabs_416M.json
sed -i "s/liid\://gI" PeopleDataLabs_416M.json
sed -i "s/linkedin\://gI" PeopleDataLabs_416M.json
sed -i "s/n\://gI" PeopleDataLabs_416M.json
```

## Usenet Archive Download Procedure

```bash
# 1. Install Internet Archive CLI
brew install internetarchive         # macOS
sudo pip install -U internetarchive  # Linux

# 2. Create item lists for each collection
cd ~/Desktop
ia search 'collection:giganews' -i > giganews1.txt
ia search 'collection:usenethistorical' -i > usenethistorical1.txt

# 3. Download only the CSV files (name plus email plus newsgroup, not full messages)
ia download --itemlist giganews1.txt --glob="*.csv.gz"

# 4. Decompress
gunzip -r .

# 5. Combine CSV files, extracting columns 1, 3, 4, 5 (date, name, email, newsgroup)
find . -type f -name \*.csv -print0 | xargs -0 cut -f1,3,4,5 > Giganews2.txt

# 6. For Usenet Historical (zip format, mbox files)
ia download --itemlist usenethistorical1.txt --glob="*.zip"
find . -name "*.zip" -exec unzip {} \;
rg -aFiN "From: " > UsenetHistorical2.txt

# 7. Merge and deduplicate both collections
sort -u -f Giganews2.txt UsenetHistorical2.txt > UsenetFinal.txt
```

## Elasticsearch-Crawler Procedure

```bash
# Install
cd ~/Downloads/Programs
git clone https://github.com/AmIJesse/Elasticsearch-Crawler.git
cd Elasticsearch-Crawler
pip install nested-lookup
pip install release

# Run
cd ~/Downloads/Programs/Elasticsearch-Crawler
python crawl.py
# Prompts: IP address, index name, port (default 9200), then field names one per line, empty line to finish
# Output saved as: <IP>-<index>.txt in the script directory
```

Note: works on Elasticsearch versions older than 6.4.0. Newer versions block the script and return random text.

## Verification

- Cross-check a phone number found in the Facebook dataset against a reverse caller ID service to confirm data accuracy.
- Search your own name, email, or phone in each dataset after building it to validate the pipeline before relying on it for target queries.
- When data contains only partial phone numbers (Snapchat redacted last two digits), iterate all 100 combinations with existing phone search tools.

## Red Flags and Legal Cautions

- Purchasing credits on breach forums sends money to criminals and is unnecessary (free credits via posting).
- Accessing open Elasticsearch databases is a legal grey area. The Computer Fraud and Abuse Act (CFAA) is vague. Confirm local laws and internal policies before proceeding.
- Using the data to sell, extort, or publish is criminal.
- Some voter data republication may violate state laws even though the underlying data is public.
- Telegram data sets are often outdated (some from 2015 or earlier). Verify currency before relying on them for addresses.
- Redundant files with different names are common on Telegram. Identify duplicates before adding to your collection.

## Operational Notes

- Store cleaned files on a labeled external SSD (e.g., volume name "DATA") in organized folders: `Voter/`, `People/`, etc.
- Navigate to external drive on macOS: `cd /Volumes/DATA/Voter`
- Navigate to external drive on Linux: `cd /media/$USER/DATA/Voter`
- Ripgrep can search by name, email, partial email, domain, phone, SSN, or DOB across any of these flat files.
- Usenet data is most useful for targets over 40. It reveals old email addresses, newsgroup interests, and historical online identity.
- LinkedIn data maps Twitter handles and Facebook usernames to real identities and email addresses via the unique profile URL slug.
- IntelX scrape (Pastebin): search "Intelligence X (intelx.io) Leaked Data" on BreachForums (comment required, no credits), or check item `e6LEmohVwywg0z` on biteblob.com.
