This chapter (labeled Chapter 46 in the converted ebook) covers the full workflow for documenting and reporting OSINT investigations: note-taking tool selection, report structure, link analysis and timeline tools, PDF management, source annotation, document sanitization, case archiving, and managing long-running sensitive investigations with dedicated hardware.

## Note-Taking Tools

The author keeps both paper and digital notes throughout an investigation. Paper handles quick identifiers, reminders, and rough diagrams. Digital notes benefit from pre-structured templates that can receive pasted text, images, and files.

**Standard Notes** (standardnotes.org) is the recommended privacy-focused option. It uses AES-256 encryption, is open-source, and works offline on Mac, Windows, iOS, Android, Linux, and browsers. The free tier includes sync with end-to-end encryption. The premium tier adds multi-factor authentication and automated backups.

**OneNote** (onenote.com/download) suits organizations already running Microsoft Office. The standalone desktop version is preferred over the cloud-based Office 365 version. A fresh Microsoft account should be created to prevent cross-contamination with other projects. A Proton Mail address is preferable to the Outlook address Microsoft offers. OneNote organizes content as notebooks, sections, and pages, working like a physical case binder. Sections can represent suspects. Pages within each section represent investigative leads such as Bio, Facebook, Twitter, Vehicles, and Employment. Its key advantage is accepting virtually any digital file as a drag-and-drop attachment, either as a printed image or an embedded file. Notebooks, sections, and pages can be exported as PDFs, Word docs, and other formats. The Mac experience is clunky. Mac users may prefer the clone Outline (outline.app/mac). Linux users can use P3X (github.com/patrikx3/onenote) to create and edit OneNote files in a browser.

**CherryTree** (giuspen.com/cherrytree) is the author's Linux choice. It is open-source, offline, and supports hierarchical nodes and subnodes with limited image and table storage. Installation on the Linux VM: `sudo apt install -y cherrytree`. Nodes work as notebook sections. Subnodes work as pages within those sections. The node tree appears on the left side of the window. Its main drawback is weaker drag-and-drop support and inconsistent handling of non-text file types. A CherryTree template is available in the book's file download.

**Joplin** (joplinapp.org) is free and open-source, supporting iOS, Android, Mac, Linux, and Windows. It offers notebooks and pages, Markdown support, to-do formatting with checkboxes, and export to Markdown, HTML, and (for individual pages) PDF. Optional sync works with OneDrive, S3, Joplin Cloud, NextCloud, or a self-hosted Joplin server. When using any sync option, enable end-to-end encryption at Tools > Options > Encryption with a strong master passphrase.

**Obsidian** (obsidian.md) works like a basic text editor but adds limited graphical features including mind maps and a graph view showing connections between notes. It has an active plugin ecosystem. The free version is fully featured. A paid tier exists for commercial use.

**Cryptpad** (cryptpad.fr) is a privacy-respecting online office suite with built-in collaboration through comment and chat features. Documents are encrypted on Cryptpad servers by default. Guests can create and store documents for up to 90 days. A free account requires only a username and password and provides 1 GB of storage. The Cryptpad team does not collect contact information and cannot reset passwords. A local backup of any Cryptpad files is recommended.

### Advanced Text Editors (Light IDEs)

Interactive Development Environments built for programmers offer efficiency by combining note-taking, terminal access, script execution, and code editing in one interface.

**VSCode** (code.visualstudio.com) is a near-full IDE with a large extension catalog. It is a free proprietary Microsoft product with telemetry enabled by default. After installation, disable telemetry at File > Preferences > Settings (or Code > Preferences > Settings on Mac): search "telemetry" and uncheck "Telemetry: Enable Telemetry setting". Then search "@tag:usesOnlineServices" and review each setting that makes calls to online services. VSCode supports Markdown, includes a built-in terminal for CMD, PowerShell, or bash, handles large files without slowdown, and runs on macOS, Windows, and Linux.

**VSCodium** (vscodium.com) is an open-source build of VSCode's source code with Microsoft data collection removed. It is the preferred choice for anyone not already in a Microsoft environment. The tradeoff is a slightly less polished experience, some extensions requiring additional installation steps, and a smaller support community. All settings should still be reviewed for any that use online services.

## Anatomy of an OSINT Report

The author completes notes during the investigation and writes the formal report at the end. Report templates in Microsoft Word and Adobe Acrobat are available at inteltechniques.com/osintbook11. Every report shares a common structure: face-sheet, narrative, analysis, and appendix.

**Face-Sheet.** One to two pages. It communicates the case name or number, the collector's identity, the investigative timeframe, primary subject identifiers, and key findings in bullet or paragraph format (no more than half a page). A table of contents, if included, appears under the case title before the key findings.

**Narrative.** Tells the story of how the key findings were reached. The preferred order is chronological, or the order the findings appear on the face-sheet. Written in first person, as concisely as a police report or legal statement. The narrative should acknowledge exculpatory evidence, which is especially important in criminal justice and government contexts. For intelligence briefings, use confidence language such as "unsubstantiated", "likely", or "highly likely" rather than percentages. The narrative can include a section on best practices used during the investigation: compartmentalization, thoroughness, software and services used, and the investigator's training and qualifications.

**Link Analysis and Timelines.** An optional analysis section presenting link charts and timelines that support the narrative. Specialized analysts may use Maltego or I2 Analyst's Notebook. When those resources are not available, the following free tools are recommended.

- **Draw.io** (diagrams.net/integrations.html): The author's preferred tool for link charts. It runs browser-based or as an offline desktop application for macOS, Windows, and Linux (github.com/jgraph/drawio-desktop/releases). In the browser version, click "Change Storage" and select "Device" with "Remember this setting" to save work locally rather than to Google or Microsoft. Icons are dragged from the left panel into the chart. Connectors (lines and arrows) represent relationships. Double-clicking text opens it for editing. Export supports PDF, DOCX, PNG, and HTML. The default icon style looks dated. To improve it: open Extras and select a lighter or dark theme, then click "+More Shapes" at the bottom of the Shapes panel and enable "Web Icons" under "Other" and "Web Logos". Draw.io also works for timelines and event maps.
- **Gephi** (gephi.org): Alternative link visualization tool.
- **MindMup** (mindmup.com): Alternative link visualization tool.
- **NWU** (knightlab.northwestern.edu/projects): Alternative link visualization tool.

For dedicated timelines, two additional tools are described.

- **Event Viewpoint** (eventviewpoint.com): Free, browser-based, closed-source. Events include a location, time or date span, and notes. Views include list, timeline, and geographical map. A free account with a non-attributable email is required. The author avoids browser-based services for sensitive data.
- **Time Graphics** (time.graphics): Browser-based. Events support pictures, video, and notes. Export options include PDF, DOCX, and JSON. Privatized projects and watermark removal require a paid account.

**Appendix.** Contains supporting documentation and media: screen captures, video still frames, spreadsheets of social media contacts, and any other digital evidence that can be displayed in document form. These are working copies only. Digital originals are preserved separately on external media or per agency policy. PDFs can be combined with PDFsam Basic.

**PDFsam Basic** (pdfsam.org/pdf-merge): Free, open-source PDF merging application for Linux, Mac, and Windows. Linux installation: download the Deb package from pdfsam.org/download-pdfsam-basic, right-click the file, choose "Open with Software Install", and click "Install". To merge files, open the app, select "Merge" in the left menu, add the desired files, and click "Run". A combined PDF is created in the same directory as the source files. Additional features include removing or rotating individual pages. Premium versions of PDFsam are closed-source and add support for alternate file types.

## Sourcing and Annotation

Every piece of intelligence in a report should be annotated with its source. Methods include footnotes (professional and intuitive), tables (useful for organizing identifiers and for color-coded confidence ratings), embedded hyperlinks (convenient but lost when printing), combinations of the above, appendices with full captures or source lists, and supplemental zip archives for large captures. Archives should supplement proper in-report sourcing, not replace it. Do not embed links that could direct a client to a hostile site.

The quality and diversity of sources affects the confidence level assigned to a finding. A single address found on a people search engine such as truepeoplesearch.com is a low-confidence finding because people search engines are prone to inaccuracies. The same address sourced from a county tax parcel database carries higher confidence. Multiple independent sources for each data point are preferred.

**Hunchly** (hunch.ly): A paid tool the author uses daily. Its report builder can generate an appendix even when Hunchly is not used to write the full report. Exporting a case via "Export" > "Export Case" produces an archive for transfer to optical or other storage. The report builder exports relevant captures to a consolidated PDF and automatically adds the capture date, hash, and URL to each preserved page and image.

## Document Sanitization

Proprietary documents created in Word or Acrobat contain metadata that can expose the investigator's account details. Remove metadata from investigative reports before submission. Never remove metadata from evidentiary documents.

In Microsoft Office products: File > Info > Check for Issues > Inspect Document. Check all boxes, click "Inspect", then click "Remove All" next to any flagged sections such as Properties. This removes the author's username and similar metadata but is not a complete cleanse.

In Adobe Acrobat: Tools > Protect and Standardize > Protect > Remove Hidden Information. A window lists removable metadata types. Uncheck any item to preserve it. Clicking "Remove" permanently deletes everything checked.

Create a backup copy before any metadata removal because the process can break formatting or corrupt files. The Metadata Anonymization Toolkit (github.com/jubalh/MAT) is available for Linux but is more prone to breaking Microsoft and Adobe documents than the built-in tools. A low-tech alternative is printing the report and scanning it back to digital. The resulting file carries the scanner's metadata rather than the investigator's. Do not use enterprise copiers with internal hard drives for sensitive documents, as those machines retain data temporarily.

## Case Archiving and Cleanup

Retention periods depend on organization policy or client expectations. The author keeps handwritten notes for six months and digital documentation for at least three years, to support later adjudication and to assist if a target appears in a future investigation. Completed cases in OneNote are moved to yearly archive notebooks organized by month. At year-end, notebooks older than three years are considered for purging. Older notebooks can also be exported and saved to optical discs for long-term storage.

## Large-Scale Continuous Investigations

Investigations spanning weeks or months with high sensitivity require isolation beyond a clean virtual machine. They require dedicated social media, email, and other accounts, and providers may flag the behavior as suspicious.

The author's solution is to assign a dedicated physical mobile device and cellular data account to each such investigation. The process applies only to investigations that cannot afford case-contamination or suspended accounts.

1. Obtain an unlocked Android device, typically a refurbished unit from a local cell phone repair shop for approximately $20, or from grocery stores, pawn shops, eBay, or Amazon.
2. Purchase a Mint Mobile SIM card from Amazon or mintmobile.com for $2.00 each (includes a $5.00 service credit and a one-week free trial). Three months of service costs $15 per month ($45 total), running on the T-Mobile network.
3. Purchase phones and SIM cards using prepaid gift cards or Privacy.com virtual cards.
4. Insert the SIM, download the Mint Mobile app over Wi-Fi, register under an alias name, and start the trial. Prepaid service requires no verification or credit check.
5. Use the resulting local phone number for account verifications (Facebook, Gmail, and similar) throughout the investigation. This avoids the suspension problems common with VOIP numbers and VPN connections.
6. Install native mobile apps that block emulators, such as Snapchat or Tinder (which block Genymotion and other virtual Android environments). Run a GPS spoofer on the device as needed.

At the close of the investigation, remove the SIM and store the phone and SIM together in a sealable plastic bag with holes punched for a binder, treating them as part of the case file. The service expires on its own. The device and account details can be produced in discovery if needed. The author recommends acquiring the device and SIM before an investigation begins rather than waiting until it is underway.
