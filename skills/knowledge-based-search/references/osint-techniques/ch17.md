## Overview

This chapter teaches how to build and use a set of custom bash scripts that automate the Linux terminal commands covered in previous chapters. Instead of typing commands manually, an investigator clicks a desktop icon, is prompted for a target (a URL, username, file, or domain), and the script runs the appropriate tool and opens the results. The chapter covers script structure, the eight core scripts and their menu options, desktop shortcut configuration, Dock setup, and a master update script.

## Motivation and Philosophy

The authors argue that investigators should not depend on third parties to maintain preconfigured VM environments (including their own previously released tool, Buscador, which has provided pre-configured applications and desktop shortcuts since 2018). The goal is to teach investigators to build their own scripts, understand each line, and modify them as needed. Any clone of the VM created after this setup will inherit all scripts and shortcuts automatically.

## Downloading and Enabling the Scripts

Eight bash scripts are downloaded from `https://inteltechniques.com/osintvm/` using `curl` with credentials (`uvm:317`). The scripts are saved to `~/Documents/scripts/` and are named `api.sh`, `domain.sh`, `framework.sh`, `image.sh`, `metadata.sh`, `update.sh`, `user.sh`, and `video.sh`.

After downloading, each file is made executable with `chmod +x`. Scripts can then be run from Terminal as `cd ~/Documents/scripts && ./video.sh`. If downloaded files contain only "401 Unauthorized," the user is running an outdated version of the guide and must obtain the current revision (verifiable at `https://inteltechniques.com/book1b.html`) before downloading.

## Script Structure (video.sh as the teaching example)

The chapter walks through `video.sh` line by line to explain bash scripting conventions used across all scripts.

**Shebang line.** `#!/usr/bin/env bash` declares the file as a bash script so Terminal can execute it.

**Comment headers.** Lines beginning with `##` are ignored by Terminal but readable in a text editor. They record the update date, an error contact address (`errors@inteltechniques.com`), and copyright and license information.

**Menu construction.** The tool `zenity` generates a graphical menu. The `--list` flag creates a list-style menu, `--column` specifies one column, each menu option is quoted, and `--height` and `--width` control the dialog size. The result is stored in a variable called `menu`, and a `case` block routes execution based on the user's selection. The block ends with `esac` ("case" backwards).

**User input patterns.** Two patterns appear across functions. File selection uses `file=$(zenity --file-selection --title "Video Tool")`, which opens a file picker and stores the full path. To isolate just the filename without the path, `file2=$(basename "$file")` is used. URL entry uses `url=$(zenity --entry --title "Video Tool" --text "Enter Target URL")`, which presents a text field.

**Timestamps.** The Streamlink function stores the current date and time with `timestamp=$(date +%Y-%m-%d_%H_%M)` and names the output file accordingly, preventing accidental overwriting when the same stream is captured more than once.

**Return loop.** After each function completes, the script pauses with "Press Enter to return to menu," then re-executes itself (`exec /home/osint/Documents/scripts/video.sh`) so the menu reappears.

## Desktop Shortcuts and Icons

Nine `.desktop` files and nine `.png` icon files are downloaded (one set per script, plus a `search` entry for the IntelTechniques online tools). The `.desktop` files specify the shortcut name, the path to the `.sh` script, and the path to the icon. They are moved with `sudo mv *.desktop /usr/share/applications/` so the operating system can display them in the applications menu. A reboot may be required before they appear.

Example `.desktop` format for the Video Tool:

```
[Desktop Entry]
Type=Application
Name=Video Tool
Categories=Application;OSINT
Exec=/home/osint/Documents/scripts/video.sh
Icon=/home/osint/Documents/scripts/video.png
Terminal=true
```

## Dock Configuration

Two `gsettings` commands configure the GNOME Dock. The first clears existing icons and adds a specific ordered set including Firefox ESR, Tor Browser, Nautilus, Terminal, and all eight custom script shortcuts plus Google Earth Pro, Kazam, and Settings. The second sets the icon size to 32 pixels. Both order and size can be adjusted to personal preference.

## Update Tool

The Update Tool is described as the most important custom script. It handles both system-level and application-level updates in one run. System packages are handled with `sudo apt update`, `sudo apt upgrade -y`, `sudo apt update --fix-missing`, `sudo apt --fix-broken install`, and `sudo apt autoremove -y`. Then `pipx upgrade-all` and `flatpak update` handle packages installed through those managers.

After that, the script loops through a series of Python-based OSINT tools, running `git pull` and `pip install -r requirements.txt` inside each tool's virtual environment. Tools updated this way include: Sherlock, Blackbird, WhatsMyName-Python, Eyes, Osintgram, EyeWitness, Photon, Sublist3r, theHarvester, Carbon14, metagoofil, sherloq, spiderfoot, recon-ng, and Mr. Holmes. The script also re-downloads the latest Amass binary from GitHub releases, selecting the correct architecture automatically with `dpkg --print-architecture`, and re-downloads the latest `ripme.jar`. Running the script manually in Terminal (rather than via the shortcut) lets the investigator see any errors the script might otherwise hide.

## Search Tool

Launches Firefox and navigates directly to the IntelTechniques online search tools page. No local application is invoked.

## Video Tool

All video output is saved to `~/Documents/Videos/`. Tools used are FFmpeg, ffplay, yt-dlp, and Streamlink.

- **Play Video:** opens a file picker, plays the selected file with `ffplay`.
- **Convert Video:** converts any video file to MP4 using FFmpeg.
- **Extract Frames-All:** extracts every frame of a video as PNG files.
- **Extract Frames-Seconds:** extracts one frame per second as PNG files.
- **Extract Audio:** extracts audio and converts it to MP3.
- **Rotate Video:** rotates the video counter-clockwise 90 degrees.
- **Merge Videos:** prompts for two files and merges them.
- **Remove Redundant Frames:** removes frames identical to the preceding frame.
- **YT-DLP Best Quality:** downloads the highest available quality from a URL. Output filename format is `BEST-<title>.<ext>` with `--restrict-filenames`. Full flag: `-o ~/Documents/Videos/BEST-"%(title)s.%(ext)s" "$url" --restrict-filenames`.
- **YT-DLP 1080 / 720 / 480:** downloads at the specified maximum resolution.
- **YT-DLP Comments, Subs, & Info:** downloads comments, subtitles in all languages, and description without downloading the video itself, using `--write-comments --write-subs --sub-langs all --write-description --skip-download`.
- **YT-DLP Audio-Pure:** extracts raw audio from a URL.
- **YT-DLP Audio-MP3:** extracts audio and converts to MP3.
- **YT-DLP MP4 Conversion:** downloads and converts to MP4.
- **Streamlink Stream:** records a live stream using `streamlink "$url" best -r $timestamp` where `$timestamp` is set at launch with `date +%Y-%m-%d_%H_%M`.

## User Tool

All functions prompt for a username or email address and route to the specified tool, then display a report.

Username tools: Sherlock, SocialScan, Blackbird, Maigret, WhatsMyName, BDFR, H8Mail.

Email tools: Holehe, SocialScan, Eyes, GHunt, H8Mail.

Hash tools: NameThatHash (identifies the hash type) and SearchThatHash (attempts to look up or crack the hash).

## Image Tool

- **Gallery-DL:** prompts for a URL and downloads images.
- **RipMe:** launches the RipMe GUI application.
- **Instaloader:** prompts for an Instagram username and downloads associated content, then opens the results folder.
- **Toutatis:** prompts for an Instagram username and saves results to a file.
- **OsintGram:** prompts for an Instagram username, then prompts for the data type of interest, runs OsintGram, and opens the results folder. This is noted as unique because it requires two sequential prompts.

## Domain Tool

- **EyeWitness Single URL:** screenshots a single URL and saves results.
- **EyeWitness Multiple URL:** accepts a file containing multiple URLs and screenshots each.
- **HTTrack-Terminal / HTTrack-Browser:** mirrors a website, through Terminal or a Firefox-based interface respectively.
- **Waybackpy:** retrieves archived pages from the Wayback Machine for a URL and saves a results file.
- **Waybackpack:** downloads all archived versions of a URL and saves to a results folder.
- **Amass:** enumerates subdomains and related infrastructure for a domain and saves a results file.
- **Photon:** crawls a URL and collects links, emails, and other data into a results folder.
- **Sublist3r:** enumerates subdomains using multiple search engines and saves a results file.
- **TheHarvester:** harvests emails, names, and hosts and displays results in Firefox.
- **Carbon14:** estimates when content at a URL was created based on linked resource timestamps and saves a results file.
- **ChangeDetection:** starts a local ChangeDetection server and opens the Firefox frontend for monitoring page changes.
- **ArchiveBox:** starts a local ArchiveBox server and opens the Firefox frontend for archiving URLs.

## Metadata Tool

- **Exiftool File:** extracts and displays metadata from a single selected file.
- **Exiftool Folder:** extracts and displays metadata from all files in a selected folder.
- **Metagoofil:** queries a domain to collect publicly indexed documents, then stores them locally. The Exiftool Folder option can then extract metadata from those collected files.
- **mat2:** strips all metadata from a selected file and saves a clean copy next to the original.
- **xeuledoc:** accepts a full Google Docs URL and extracts document metadata.
- **Launch Sherloq:** opens the Sherloq image forensics tool.
- **Launch Mediainfo:** opens Mediainfo.

## Framework Tool

- **Launch Spiderfoot:** starts the Spiderfoot server and opens its Firefox frontend for automated OSINT aggregation.
- **Launch Recon-ng:** opens the Recon-ng reconnaissance framework in Terminal.
- **Configure Mr. Holmes:** runs the Mr. Holmes installation or update script. This is required after using the automated VM setup script or after an update.
- **Launch Mr. Holmes:** opens Mr. Holmes in Terminal.
- **Launch sn0int:** opens sn0int in Terminal.
- **Internet Archive Collection:** prompts for a collection name, downloads all content in that collection into a new folder, and opens the folder.
- **Internet Archive Collection Filetype:** same as above, but also prompts for a file extension to filter the download to matching files only.

## Key Principle

The chapter closes by emphasizing that while these scripts make research faster, the investigator must understand what is happening in the background. Using a menu option without knowing the underlying command removes the ability to troubleshoot, adapt, or verify results.
