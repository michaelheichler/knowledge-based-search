title: Windows Host Optimization
source: OSINT Techniques (Bazzell, Edison, 11th ed.)
---

This chapter covers how to prepare a Windows computer as a host machine for OSINT work. The author treats Windows as a less preferred but widely used platform and walks through a set of hardening steps: a clean reinstall, antivirus configuration, telemetry reduction, system cleaning, VPN setup, and password management.

## Clean Reinstall

Before doing anything else, back up documents, desktop files, and downloads to an external drive. Windows 11 includes a factory reset option reachable by searching "reset" and choosing "Reset this PC," then selecting the option to remove everything. On older systems without that partition, the original installation media or a manufacturer restore disc is required. During setup, refuse requests to create a Microsoft account. Disconnecting the machine from the internet before running setup usually prevents Microsoft from requiring an online account.

## Antivirus

The author recommends using the built-in Windows Defender rather than a third-party antivirus. The reasoning is that Windows itself already sends usage data to Microsoft, so adding another vendor's product does not meaningfully reduce exposure and introduces additional complexity. For a host machine used only to run Linux virtual machines, Defender is sufficient. Steps to update it: search "defender" in the taskbar, open Windows Security, go to the shield tab, select Protection Updates, and check for updates. Then separately search "updates" and apply any pending Windows updates.

## Telemetry

Microsoft's Telemetry service collects typed keyboard input, microphone transmissions, an index of all media files, webcam data, browsing history, search history, location activity, health data from HealthVault and Microsoft Band, and privacy settings across the Microsoft application ecosystem. The author describes this as invasive and recommends reducing it using a free tool called O&O ShutUp10++ (download at https://www.oo-software.com/en/shutup10).

Within O&O ShutUp10++, a red icon means data is being sent to Microsoft and a green icon means the service is blocked. The "Actions" menu offers three preset levels: "Recommended" (basic blocking such as disabling advertisement IDs), "Recommended and somewhat recommended" (blocks most things but leaves automatic Windows updates, Windows Defender, and OneDrive active), and "Apply all settings" (blocks everything possible).

The author's preference is "Recommended and somewhat recommended," with two additional manual changes: enabling "Disable sending URLs from apps to Windows Store" (Current User) and enabling "Disable Microsoft OneDrive" (Local Machine). This preserves Windows Update and Defender. After applying settings, reboot and reopen the application to confirm settings were retained. After any future Windows update, recheck the settings because updates can reset them.

## System Cleaner

The author previously recommended CCleaner but stopped using it due to the behavior of its owner Piriform, including versions found to contain adware that collected user metrics. The current recommendation is BleachBit (bleachbit.org), which is similar but more aggressive. Select all available options except "Wipe Free Space" (that option overwrites all free disk space, which is time-consuming). BleachBit removes browser history remnants, temporary files, and similar unwanted data. The author runs it weekly on any Windows or Linux host.

## VPN Configuration

A VPN routes internet traffic through an encrypted tunnel to a remote server, preventing anyone monitoring the local network from reading the data and making website connections appear to originate from the VPN server's location rather than the investigator's actual location. This prevents a target's website from logging the investigator's real IP address or employer network details.

VPNs provide privacy, not anonymity. The author uses and recommends Proton VPN (further information at inteltechniques.com/vpn.html). Proton VPN's Windows application is open-source, which makes it harder to hide malicious code within it. Download from https://protonvpn.com/download-windows, install, provide account credentials, and connect. The author's practice is to remain connected to the VPN any time the device is online. Virtual machines running inside the host share the same VPN IP address automatically.

The author pays for the VPN subscription with Bitcoin under an alias name but notes this level of caution is not necessary for most readers. At home the author protects devices through a firewall with Proton VPN built in (covered separately in "Extreme Privacy: VPNs & Firewalls") and does not run a VPN inside the computer itself.

## Password Manager

OSINT work requires maintaining many covert accounts across various services. A password manager stores credentials securely. The author recommends KeePassXC or Bitwarden, stored on the host machine rather than inside a virtual machine, because VMs are often rebuilt or deleted and any passwords inside them would be lost with them. Keeping credentials on the host ensures they are always available regardless of which VM is in use.

KeePassXC is open-source, free, cross-platform, and stores the database locally without syncing to the internet. Download for Windows from https://keepassxc.org/download/#windows. Setup steps:

1. Launch KeePassXC and select Database > New Database.
2. Provide a name (for example, "Passwords").
3. Move the encryption settings slider fully to the right and click Continue.
4. Assign a strong master password not used anywhere else.
5. Click Done and choose a safe storage location.
6. Close and reopen the database to verify the password works.

To create an entry for a covert account, right-click in the left column and select New Group, name it (for example, "Facebook"), select the group, right-click in the right panel, select New Entry, fill in the name, username, and URL, then click the dice icon next to the password field to generate a random password. The password length slider should be set to at least 40 characters (50 or more if the site allows). The generated password is stored in the database and used by copying and pasting at login. This approach means that when a site is breached, the leaked password cannot be used on any other site and cannot reveal real accounts.

The master password to the database should be unique and contain letters, numbers, and special characters. Write it down in a safe place until memorized. Make regular backups of the database file to an encrypted USB drive and keep a copy somewhere safe offline. Losing the database without a backup means losing access to every password that was generated and never memorized.

The author does not recommend the KeePassXC browser extension for OSINT work. While not insecure, it requires copying the master database into virtual machines, which creates unnecessary exposure and technically links one investigation to another inside the VM.

## Summary

A properly configured Windows OSINT host machine should have a fresh install, current Windows Defender, telemetry blocked via O&O ShutUp10++, BleachBit running weekly, Proton VPN always active, and KeePassXC holding all credentials for covert accounts. The host machine itself is intended primarily as a platform for running Linux virtual machines where the actual investigations take place.
