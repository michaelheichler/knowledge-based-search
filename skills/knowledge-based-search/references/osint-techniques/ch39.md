This chapter (labeled Chapter 32 in the text) covers the full range of techniques for investigating a domain name, from basic registration lookup through historical records, visual archives, analytics, threat data, breach data, and shortened URLs. The chapter uses cnn.com, phonelosers.org, and inteltechniques.com as recurring examples.

## What a Domain Investigation Covers

Every domain encountered in an investigation should be examined across multiple dimensions: current and historical registration (Whois), IP address history, subdomains, email addresses associated with the domain, website analytics identifiers, SSL certificates, archived content, source code, threat data, and breach databases. The chapter presents automated tools at inteltechniques.com/tools/Domain.html that submit queries to most of these services from a single interface.

## Current Registration and Whois

Whois data is public and includes registrant name, business name, address, phone, email, and dates of creation and update. ICANN requires this information but rarely enforces accuracy. Many domain owners use private registration services that replace real contact details with proxy information. Some hosts now offer this masking for free.

ViewDNS.info is the primary starting point. It supports direct URL submission, making it easy to integrate with automated tools. Key functions:

- Whois (viewdns.info/whois): Returns registration data including admin contact and creation date.
- Reverse IP (viewdns.info/reverseip): Translates a domain to its IP address and lists other domains on the same server. Shared servers host unrelated sites. A small set of related domains suggests a dedicated or semi-dedicated server.
- Reverse Whois (viewdns.info/reversewhois): Finds other domains registered to the same registrant. Fails when private registration is in use.
- Port Scanner (viewdns.info/portscan): Checks common open ports. Port 80 (HTTP) and 443 (HTTPS) are standard. An open port 21 indicates an FTP server (e.g., ftp.cnn.com).
- IP History (viewdns.info/iphistory): Lists previous IP addresses for the domain with dates and the organization that owned each IP.
- DNS Report (viewdns.info/dnsreport): Full DNS and mail server configuration.

An alternative Whois tool is who.is. ViewDNS sometimes blocks VPN connections.

The URL structure for each ViewDNS tool follows a consistent pattern, for example:

```
https://viewdns.info/whois/?domain=cnn.com
https://viewdns.info/reverseip/?host=cnn.com&t=1
https://viewdns.info/reversewhois/?q=cnn.com
https://viewdns.info/portscan/?host=cnn.com
https://viewdns.info/iphistory/?domain=cnn.com
https://viewdns.info/dnsreport/?domain=cnn.com
```

## Historical Registration Records

When a domain uses private registration, historical Whois records may reveal the real owner from a period before privacy protection was applied.

Whoxy (whoxy.com) is the top free recommendation. It displays historical records with dates. Searching a domain may reveal prior registrant names and email addresses. The "9 Domains" link shows other domains registered by the same person across years. It supports direct URL queries such as `whoxy.com/inteltechniques.com` and also accepts email address and keyword searches. Paid access is available for bulk queries.

Whoisology (whoisology.com) shows current Whois fields alongside the count of other domains sharing each data point, for example "88 domains registered to Brad Carter" or "7 domains registered to brad@notla.com". Clicking any count reveals the list of matching domains. It also maintains historical archives of Whois changes, so a phone number present in 2012 but removed later can still be retrieved. Free accounts are limited to one historical record and three searches per 24 hours, making Whoxy the preferred free option. Whoisology is considered the best choice for paid subscription use.

WhoisXMLAPI (whoisxmlapi.com) offers a limited free trial through their API.

Archive.org historical Whois: The Wayback Machine indexes Whois lookup pages from who.is, DomainTools, Whoxy, and Whoisology. Navigating directly to an archived Whois URL (for example, `web.archive.org/web/http://who.is/whois/phonelosers.org`) may display registration details from years when privacy protection was not applied. This approach requires no paid account.

URL patterns for Wayback Machine Whois lookups (replace cnn.com with your target):

```
https://web.archive.org/web/http://www.who.is/whois/cnn.com/
https://web.archive.org/web/https://whois.domaintools.com/cnn.com
https://web.archive.org/web/https://www.whoxy.com/cnn.com
https://web.archive.org/web/https://whoisology.com/cnn.com
```

## Historical Content Archives

The Internet Archive (web.archive.org) provides two views for a domain. The graphical timeline is accessed at `web.archive.org/web/*/cnn.com`. A text-only list of all archived URLs uses the CDX API:

```
https://web.archive.org/cdx/search/cdx?url=cnn.com/*&output=text&fl=original&collapse=urlkey
```

A site can opt out of Archive.org indexing by embedding a robots directive, but other providers ignore such requests.

Additional archive services:

- Archive Today (archive.is, archive.ph, archive.md): Ignores deletion requests. Accessed via a pattern such as `archive.is/*.inteltechniques.com`.
- Mementoweb (mementoweb.org): Aggregates archives from multiple providers via a "Time Travel" query, accessed via `timetravel.mementoweb.org/list/19991212110000/http://inteltechniques.com`.
- Library of Congress Web Archives (webarchive.loc.gov): Searchable by domain via `webarchive.loc.gov/all/*/http://inteltechniques.com`.
- Portuguese Web Archive (arquivo.pt): May hold captures not found elsewhere, via `arquivo.pt/url/search?hitsPerPage=100&q=inteltechniques.com`.

## Historical Screen Captures

Six services provide screenshots of a domain at various points in time:

- Website Informer (website.informer.com): Screenshot alongside search results. Query via `website.informer.com/inteltechniques.com#tab_stats`.
- URLScan (urlscan.io): Provides unique captures. Query via `urlscan.io/domain/inteltechniques.com`.
- Easy Counter (easycounter.com): Similar to Website Informer, slightly different crop. Query via `easycounter.com/report/inteltechniques.com`.
- Domain Tools (whois.domaintools.com): High-resolution current captures. Query via `whois.domaintools.com/inteltechniques.com`.
- Domains App (dmns.app): Highest resolution, full-page. Requires exact URL format: `files.dmns.app/screenshots/inteltechniques.com.jpg`.
- Hype Stat (hypestat.com): Lower quality, typically older image. Query via `hypestat.com/info/inteltechniques.com`.

Also check Bing and Yandex cache by clicking the green down arrow next to a search result.

For monitoring future changes, Follow That Page (followthatpage.com) sends email alerts when a page changes. New or modified content is highlighted and deleted content is struck through. Visual Ping (visualping.io) lets you select a specific region of the page to monitor, with hourly checking and a "Tiny Change" sensitivity setting. Dynamic ad areas can be excluded from the comparison region.

## Email Address Discovery

Three services find email addresses associated with a domain. Results rarely overlap completely, so all three should be queried:

- Hunter (hunter.io): Scrapes public web pages. Free results include source URLs but redact a few characters from each address. Query via `hunter.io/try/search/cnn.com`.
- Website Informer (website.informer.com): Fewer results but unredacted. Query via `website.informer.com/cnn.com/emails`.
- SkyMem (skymem.info): Also returns full email addresses. Query via `skymem.info/srch?q=cnn.com`.

## Embedded Tracking and Analytics

Blacklight (themarkup.org/blacklight) reveals trackers, third-party cookies, and third-party service connections embedded in a site. A scan of cnn.com found 34 advertisement trackers, 52 third-party cookies, Facebook notifications, and interactions with Adobe and Google.

Domain analytics identifiers (Google Analytics IDs, AdSense IDs) are assigned to individual websites. If a target uses the same analytics account across multiple sites, a reverse search on the analytics ID will reveal those sites.

- Spy On Web (api.spyonweb.com): Identifies Google Analytics and AdSense IDs for a domain and finds other domains sharing the same IDs. Requires registration for most use, with a limited free tier.
- Hacker Target (hackertarget.com/reverse-analytics-search): Shows historic analytics IDs across subdomains.
- DNSLytics (dnslytics.com): Accepts an analytics or AdSense ID and returns associated domains. Direct URLs: `dnslytics.com/reverse-analytics/inteltechniques.com` and `dnslytics.com/reverse-adsense/inteltechniques.com`.

A case example in the chapter describes an anonymous website hosting photo evidence of a felony. Accurate Whois data was not available, but the site's Google Analytics ID was shared with the suspect's personal blog. An arrest was made on the same day.

OSINT.sh (osint.sh) provides a multipurpose set of direct URL endpoints: subdomains, technology stack, SSL certificates, Whois history, analytics lookups by Google Analytics or AdSense ID, domain keyword search, reverse Whois by email, and OCR text extraction from documents at a target URL.

## SSL Certificates

CRT.sh (crt.sh) displays the full certificate history for a domain at a URL such as `crt.sh/?q=inteltechniques.com`. Group SSL certificates cover multiple domains simultaneously, so examining certificate records may reveal other domains owned by the same person. A group certificate at GoDaddy for inteltechniques.com also covered privacy-training.com, computercrimeinfo.com, and yourcomputernerds.com.

## Website Source Code

NerdyData (search.nerdydata.com) indexes the source code of websites. It allows searching for specific JavaScript functions, analytics IDs, or Amazon affiliate IDs. It is useful for finding sites that copied source code and for finding other sites run by the same owner. Large result sets can be exported as CSV.

Built With (builtwith.com) identifies the technology stack of a domain including operating system, email provider, web framework (for example PHP and WordPress), installed plugins, analytics tools, video services, and mailing list provider. An alternative is Stats Crop (statscrop.com).

## Subdomains

Subdomains may host content not visible from the main page.

- PentestTools (pentest-tools.com/information-gathering/find-subdomains-of-domain): Attempts a DNS zone transfer, then tests a list of common subdomain names, and scans the IP range of any found subdomains. Revealed webmail, FTP, SSH, and mail subdomains for phonelosers.org.
- Columbus Project (columbus.elmasy.com): Fast web-based search. Also offers an API command: `curl -H "Accept: text/plain" "https://columbus.elmasy.com/lookup/cnn.com"`. Append `> cnn.com.txt` to save the output as a text file.
- SubDomain Finder (subdomainfinder.c99.nl): Uses host records from the registrar.
- DNS Dumpster (dnsdumpster.com): Uses host records and generates a downloadable domain map image or Excel file.

## Robots.txt

The robots.txt file at the root of a domain (for example `cnn.com/robots.txt`) lists directories the site owner does not want search engines to index. Directories listed under "Disallow" can be navigated directly in a browser to find non-indexed content. CNN's robots.txt listed /cnnbeta, /development, and /partners as disallowed directories.

Search for robots.txt files via Google or Bing with a query such as `site:cnn.com robots ext:txt`. Historical robots.txt changes are available via the Wayback Machine at `web.archive.org/web/*/cnn.com/robots.txt`.

## Search Engine Marketing and Backlinks

SEM services provide traffic, ranking, keyword, and referral data:

- Similar Web (similarweb.com): Traffic volume, geographic breakdown, traffic sources, top keywords, competitor domains, and social traffic. Some data is estimated rather than measured directly.
- Spyfu (spyfu.com): Site rankings, competitors, keywords, Google ad data, and backlinks. It replaced Alexa and Moon Search after those services were shut down. An alternative is Majestic (majestic.com).
- Shared Count (sharedcount.com): Returns Facebook likes, shares, comments, Twitter tweets, and Pinterest pins for a domain.
- Reddit domains: All Reddit posts linking to a target domain are listed at `reddit.com/domain/[domain]`, including discussion threads and usernames.
- Small SEO Tools Backlink Checker (smallseotools.com/backlink-checker): Lists domains linking to the target.
- Host.io (host.io): Additional backlinks at `host.io/backlinks/[domain]`, redirect sources at `host.io/redirects/[domain]`, and a full domain summary at `host.io/[domain]`. Domains forwarding to the target may have historical registration data worth examining.
- Small SEO Tools Plagiarism Checker (smallseotools.com/plagiarism-checker): Finds other sites with identical text, useful for verifying whether threatening content is original or copied (for example, song lyrics). An alternative is Copy Scape (copyscape.com).
- Octopus (octopus.do): Visual diagram of site pages and structure.
- XML Sitemaps (xml-sitemaps.com): Crawls a domain and produces an XML file of all public page URLs. Useful for importing into reporting systems and discovering previously unknown pages.

## Threat Data

Four services monitor for malicious content associated with domains. For OSINT use the focus is on the data they expose rather than their security function.

VirusTotal (virustotal.com) is described as the most useful of the four for OSINT. The "Details" tab shows DNS records, Whois, site category, and the SSL certificate Subject Alternative Names section, which reveals additional domains and subdomains on the same certificate. When searching cnn.com, the certificate Subject Alternative Names included cnn.io, revealing an associated domain to investigate. The "Relations" tab lists subdomains such as customad.cnn.com, go.cnn.com, and store.cnn.com. The "Files" section shows files hosted on the domain that have been analyzed, and files on other sites that reference the domain (including malicious files that impersonate the target, such as a virus disguised as a digital copy of a book). The "Community" tab contains analyst comments that sometimes include owner details or phishing campaign information. The chapter warns that files found here should only be opened in a virtual machine without network access.

Threat Intelligence Platform (threatintelligenceplatform.com): The "Connected Domains" section shows external domains linked from the target's page, which may reveal additional sites owned by the suspect. The "Potentially dangerous content" and "Malware detection" sections provide a historical view of malicious hosting, including phishing pages that have since been removed.

Threat Crowd (ci-www.threatcrowd.org): Shows server IPs, primary domains, and historically associated domains in a visual format.

Censys (censys.io): Receives SSL certificate data in real time at the moment of issuance, so it does not need to rely on internet scans for Subject Alternative Names. The "Details" view includes full HTTP and HTTPS page source code, which can be copied, saved with an .html extension, and opened in a browser to preserve the page if the live site disappears. The Certificates search at `censys.io/certificates?q=[domain]` reveals historical SSL hosting providers by year (for example Sectigo in 2020, Comodo via Namecheap in 2018, GoDaddy in 2016 for inteltechniques.com). Searching a specific certificate hash may reveal other domains secured by the same certificate, as it did for the hash 7583b0cb25632de96575dd0f00ff99fed81b9069 which connected computercrimeinfo.com, inteltechniques.com, and privacy-training.com.

## Cloudflare Investigation

Cloudflare hides the real web host and owner details. Three approaches help work around this:

1. Historical Whois records (Whoxy, Whoisology) may show the original host before Cloudflare was applied.
2. Censys SSL certificate history reveals hosting providers by year.
3. Analytics IDs and other third-party tracking identifiers may persist across domains even when registration is masked, connecting Cloudflare-protected domains to identifiable accounts.

## Advanced DNS and DMARC Records

Domains App DNS records (dmns.app) exposes DMARC records that sometimes contain an email address not visible in any other query. The URL format is `dmns.app/domains/michaelbazzell.com/dns-records`. An example for michaelbazzell.com showed entries indicating that all email is handled through Proton Mail (`v=spf1 include:_spf.protonmail.ch`) and a personal email address in the DMARC `rua=mailto:` field. The chapter notes that this approach revealed a personal email address during an active investigation while writing.

## WordPress Sites

Sites running WordPress can be scanned for version, hosting provider, plugins, themes, login usernames, and linked sites using sitecheck.sucuri.net or hackertarget.com/wordpress-security-scan.

## Domain Reputation

Three services check a domain for spam or malicious activity: spam.org, mywot.com, and Drace Eye (dracoeye.com). Drace Eye performs a passive security audit covering spam reports, malware flags, blacklists, and server details. Query via `dracoeye.com/search/[domain]`.

## Data Breaches

- Dehashed (dehashed.com): Searches breach data for email addresses matching the domain. Requires a free account. Query: `dehashed.com/search?query="inteltechniques.com"`.
- IntelX (intelx.io): Returns Pastebin and similar files mentioning the domain. Partial results are free, full results require a trial. Query: `intelx.io/?s=inteltechniques.com`.
- Leakpeek (leakpeek.com): Requires a free account. No direct URL query is available.

## Shortened URLs

Shortened URLs contain metadata accessible without special tools by appending a suffix:

- Bitly: Append "+" (e.g., `bitly.com/29A4U1U+`) to see click count. A free account reveals referring sites and country-level location data.
- Tiny.cc: Append "~" (e.g., `tiny.cc/v973ez~`) to see total clicks, unique visits, operating systems, browsers, and country data. Some domains are blocklisted.
- Google: Announced shutdown of its shortener service in August 2025.
- Naturl Link (naturl.link): Simple shortener requiring no account.
- CheckShortURL (checkshorturl.com): A catch-all service for cases where the specific shortener is unknown.

UNFURL (dfir.blog/unfurl/) accepts any URL and expands the structured data embedded within it. It works on Twitter post links, Instagram photo URLs, shortened URLs, and Torrent magnet links. For Torrent links, typical output includes web seed, tracker address, source, file details, and associated domains.

Each field accepts a domain name and a "Submit All" button opens results across multiple browser tabs simultaneously. The final section of the tool handles shortened URL metadata lookups.
