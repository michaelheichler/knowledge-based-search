## Overview

This chapter covers techniques for finding, analyzing, and extracting intelligence from online images. The main areas are: searching images across platforms, reverse image searching, extracting Exif metadata, detecting image manipulation, and using specialized tools for faces, vehicles, and AI-generated content.

## Standard Image Search

Rather than searching individual photo-sharing sites (Flickr, Tumblr, etc.) one by one, the preferred approach is to start with Google Images (images.google.com). Google's index already covers the major photo-sharing services, so a single query there will surface results from hundreds of sites at once. Filters for date, size, color, and type (photograph vs. line drawing) are available but should be used sparingly, since broader queries return more data. Bing Images (bing.com/images) covers similar ground and occasionally returns valuable images that Google misses. All standard search operators from web search apply equally to Google Images and Bing Images queries.

For platform-specific image searches, direct URL patterns exist. A Twitter/X image search for a keyword looks like `https://x.com/search?q=osint&f=media`. Facebook photo search follows the form `https://www.facebook.com/search/photos/?q=osint`. Tumblr photo search uses `https://www.tumblr.com/search/osint`.

## Reverse Image Search

A reverse image search submits an image (by URL or upload) to a search engine, which then finds identical or similar images across the web. Uses include identifying all sites where a target used the same profile photo, locating alias accounts that use a real photo, finding other people who appear in the same image, and tracking the original location of a shared photo.

An important workflow note: you must have the direct URL of the image file itself, not just the URL of the page that contains it. In Firefox, right-click and choose "view image." In Chrome, choose "open image in new tab." In Edge, choose "properties" to read the image URL.

### Google Lens

Google's reverse image search is now called Google Lens. After pasting a URL, the default display is "Visual matches," which are similar but not identical images. Clicking "Find image source" produces a new tab with closer matches. Adding contextual text (such as a target's name or employer) to that search improves accuracy. A URL can be submitted directly:

```
https://lens.google.com/uploadbyurl?url=<image_url>
```

The older Google reverse search endpoint also still functions:

```
https://www.google.com/searchbyimage?image_url=<image_url>&client=app
```

Within Google Lens, you can crop the image to focus on a specific person or object and re-run the search, which often surfaces results that a full-image search missed.

### Bing Visual Search

Bing's "Visual Search" launched in 2014. It generally returns fewer results than Google but on occasion finds matches that Google does not. The direct URL form is:

```
https://www.bing.com/images/search?view=detailv2&iss=sbi&q=imgurl:<image_url>
```

### TinEye

TinEye (tineye.com) focuses on exact duplicate images. Its result set is typically smaller than Google's, but it can find copies the others miss. Direct URL submission:

```
http://www.tineye.com/search/?url=<image_url>
```

### Yandex Images

Yandex (yandex.ru/images) is described as the strongest performer for reverse image search overall. Since around 2020 it has frequently returned accurate results that Google, Bing, and TinEye all miss. It is especially valuable when an image is cropped to isolate a target. Direct URL form:

```
https://yandex.com/images/search?rpt=imageview&url=<image_url>
```

### Baidu Images

Baidu (image.baidu.com) offers reverse image search through a Chinese-language interface only. In practice it fails more than it works and has been removed from the author's custom search tools, though it is included for completeness. Direct URL form:

```
https://graph.baidu.com/upload?image=<url-encoded_image_url>
```

### Cropped Reverse Image Searching

Beginning around 2018, Google and Bing began returning fewer results. Cropping an image to show only the subject of interest and resubmitting, especially to Yandex, can dramatically increase results. In a demonstrated case, a full-image Yandex search returned no useful results, but a cropped version immediately identified numerous additional images of the target. Google and Bing did not improve with the same crop.

### FaceCheck

FaceCheck (facecheck.id), which appeared in 2022, uses AI to compare a face against a database of billions of previously shared online photos. Unlike pixel-matching services, it identifies the same person across different settings, dates, and clothing. The service can be invoked by URL without uploading:

```
https://facecheck.id/#url=<image_url>
```

FaceCheck automatically crops to the face and runs the analysis. Uploading images is discouraged since doing so may add them to the service's database.

### CarNet

CarNet (carnet.ai), also from 2022, uses machine learning to identify the year, make, and model of a vehicle from an uploaded image or URL. It accepts blurry images (such as those from doorbell or dash cameras) and has proven accurate on obscure vehicles.

### Reddit Repost Sleuth

Reddit Repost Sleuth (repostsleuth.com) is a reverse image engine that searches only Reddit. It was built to detect reposts but is useful for finding every appearance of a target image on that platform. Direct URL form:

```
https://www.repostsleuth.com/search?url=<image_url>
```

### Root About and Wolfram Image Identification

Root About (rootabout.com) queries only the Internet Archive and Open Library. It does not accept direct URL submission. Wolfram Image Identification (imageidentify.com) identifies the content of an image (make and model of a vehicle, text translation, etc.) rather than finding duplicates.

### Pictriev

Pictriev (pictriev.com) analyzes a photo that includes a human face and attempts to locate additional images of the same person. Results are strongest for public figures with a large internet presence, but it works on lesser-known subjects as well. It also predicts the sex and approximate age of the person in the photo.

### Legal Caution

Submitting contraband images to reverse image services, even for investigative purposes, is illegal. Submitting child pornography to Google constitutes distribution. Classified materials carry similar restrictions. The guidance is to never upload such images from a local drive.

## Photo-Sharing Sites: Flickr

Flickr (flickr.com), now owned by SmugMug, holds a large archive of photos going back more than a decade, much of it not well indexed by general search engines. Searches can be made by topic, location, username, real name, or keyword. User profile data may include camera information and interests. Comments and location data attached to individual photos add further intelligence value.

Flickr Map (flickr.com/map) attempts to place photos on a map using Exif GPS data or user-provided tags. It is most useful when researching a specific past event or physical location.

The Flickr API allows queries not available through the standard interface. Three specific uses:

1. Look up a Flickr account by email address: `https://api.flickr.com/services/rest/?method=flickr.people.findByEmail&api_key=<key>&find_email=<email>`
2. Look up a user number by username: `https://api.flickr.com/services/rest/?method=flickr.people.findByUsername&api_key=<key>&username=<username>`
3. Retrieve full profile details by user number: `https://api.flickr.com/services/rest/?method=flickr.people.getInfo&api_key=<key>&user_id=<user_id>`

A free API key can be obtained at `https://www.flickr.com/services/api/`. The chapter provides a test key (27c196593dad58382fc4912b00cf1194) that may or may not still be active.

## Exif Metadata

Every digital photograph contains embedded metadata called Exif data. This data layer, not visible when viewing the image normally, can include:

- Capture date and time
- GPS coordinates (latitude and longitude)
- Compass heading
- Device make and model
- Lens type, focal range, aperture, shutter speed, and flash settings
- Author name and copyright details
- Original filename
- A thumbnail of the original image

Not all images retain Exif data. Facebook removes it before storing photos. Flickr does not. Images that have been compressed or resized often lose it. Images taken directly from a camera card will always have it. The largest available version of an image is most likely to still carry the data.

Exifinfo (exifinfo.org) is recommended for online Exif analysis. It accepts both URLs and uploads, processes the file, then immediately deletes uploads and retains result data for only three days. It maps GPS coordinates to OpenStreetMap. Its backend uses the open-source ExifTool (exiftool.org), which can also be run locally for sensitive files. A caveat: Exif data can be deliberately altered, so it should not be treated as conclusive without corroboration.

### Cropped Images and Embedded Thumbnails

Digital cameras store a small thumbnail of each photo within the Exif data. When a user crops an image, some software (such as Photoshop or Microsoft Photo Editor) overwrites this thumbnail to match the crop. Other tools and many online cropping services do not. The result is that the original uncropped view survives inside the Exif data of the cropped file. This technique has been used in law enforcement to identify individuals who cropped themselves out of images.

### Stolencamerafinder

Stolencamerafinder (stolencamerafinder.com) uses the camera serial number extracted from Exif data to search its database for other photos taken with the same device. A serial number can also be entered manually. This can link multiple photos to the same camera even when other identifying information is absent.

## Barcode Reading

Online Barcode Reader (online-barcode-reader.inliteresearch.com) can decode 1D, PDF417, Postal, DataMatrix, QR, and ID barcodes from image files up to 12 MB. This is useful when a photo contains a barcode (a boarding pass, a product, a printed QR code) that may carry text data not visible on the face of the document. Scanning unknown barcodes with a mobile device is discouraged due to malicious link risk. Additional alternatives include Online Barcode (onlinebarcodereader.com), Zxing (zxing.org), Cognex (manateeworks.com/free-barcode-scanner), and Online Decoder (online-barcode-reader.com).

## Image Manipulation Detection

### Foto Forensics

Foto Forensics (fotoforensics.com) accepts a URL or file upload and displays a darkened duplicate of the image below the normal view. Highlighted areas indicate possible manipulation. Images uploaded to this service become part of its collection and receive a public URL, which is a risk for sensitive files.

### Forensically

Forensically (29a.ch/photo-forensics) is an all-in-one image forensics tool that runs entirely in the browser. Images are not uploaded to any server. Its tools include:

- **Magnifier**: enlarges pixels and increases contrast to reveal hidden details.
- **Clone Detector**: finds copied and pasted regions within the image, which indicate manipulation. Parameters include Minimal Similarity, Minimal Detail, Minimal Cluster Size, Block Size, and Maximal Image Size.
- **Error Level Analysis (ELA)**: compares the image to a recompressed version. Manipulated regions often show up as brighter or darker than surrounding areas of similar content. Parameters include JPEG Quality, Error Scale, Magnifier Enhancement, and Opacity.
- **Noise Analysis**: isolates image noise to detect airbrushing, deformations, warping, and perspective-corrected cloning. Works best on high-quality images.
- **Level Sweep**: sweeps through the histogram to reveal discontinuities.
- **Luminance Gradient**: maps brightness changes along x and y axes to find anomalies in lighting or edge sharpness.
- **PCA (Principal Component Analysis)**: reframes image data to make certain manipulations more visible.
- **MetaData**: displays Exif data including GPS location.
- **Thumbnail Analysis**: reveals any hidden preview image stored inside the file.

### Aperisolve

Aperisolve (aperisolve.com) replicates several of the above methods and adds steganography detection, looking for hidden data embedded within the image file. Recommended for cases where file modification or hidden content is suspected.

## Image Enlarging and Upscaling

When an image is too blurry to read (such as a license plate), two tools are available. IMG Enlarger (imglarger.com) requires a free account and simply doubles image dimensions. IMG Upscaler (imgupscaler.com) requires no account and uses algorithmic enhancement to improve detail rather than just scale. In a documented case, it clarified two previously unreadable digits on a license plate, enabling a full vehicle registration lookup. Manipulating images may be inappropriate when they are evidence, so this step requires judgment.

## Location Detection from Image Content

GeoSpy (geospy.ai) analyzes image content itself, with no reliance on metadata, to estimate where a photo was taken. In a demonstration, it correctly identified a specific stone bridge at the Watchung Reservation in Millburn, New Jersey from a photo posted on Twitter.

## Detecting AI-Generated Images

Reverse image searches and metadata or ELA analysis are the first steps when a questionable image appears. In addition, Sightengine (sightengine.com) and Is It AI (isitai.com/ai-image-detector/) have performed well in testing. Both require a free account.

## Manual Visual Analysis

Beyond automated tools, closely inspecting images for context clues is a distinct investigation step. Selfies and social media photos frequently show home interiors, workplaces, vehicles, and neighborhoods. In a described child exploitation case, photos the suspect posted to social media disclosed the presence, make, and model of computers that were later seized. The photos also allowed investigators to brief tactical teams on counter-surveillance measures before serving a search warrant.
