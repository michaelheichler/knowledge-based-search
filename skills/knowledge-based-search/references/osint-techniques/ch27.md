## Overview

This chapter covers methods for investigating Instagram accounts, extracting media and metadata, documenting followers and interactions, and extending searches to related platforms including Threads. Instagram (owned by Meta, with over one billion active monthly users) works alongside Facebook and Twitter for photo and video distribution. Most techniques in the chapter require being logged into an Instagram account, ideally a burner account created for investigative purposes.

## Account and Keyword Search

Instagram's internal search is weak: it surfaces only a few user accounts and recommended terms, and searching hashtags returns only tagged posts rather than all posts containing a term. The preferred approach is to use Google with site-scoped queries.

Key query patterns:

- `site:instagram.com "OSINT"` finds posts mentioning a term in titles or comments.
- `site:instagram.com darren hak5` locates a profile by combining a first name with an associated name or brand when the last name alone fails (example: target @hak5darren).
- `site:instagram.com "hak5darren"` returns all pages and posts that contain the username text, including posts by associates.
- `site:instagram.com "@hak5darren"` narrows results to posts where others are actively mentioning the target.

These queries can be repeated on Bing and Yandex for broader coverage. Google-indexed posts can include specific keyword content (for example, `site:instagram.com "hak5darren" "pager"`) that Instagram's own search would not surface.

## Retrieving High-Resolution Images

Instagram displays compressed 150x150 pixel profile images and low-resolution post thumbnails, and blocks right-click access to images. To get the original high-resolution file, use the browser's developer tools (F12 or right-click and Inspect), go to the Network tab, reload the page, and filter by image type. The file list loads in the order images appear on the page, so the profile photo is near the top. Selecting the file shows a preview in Chrome's "Preview" tab or Firefox's "Response" tab, from which the image can be right-clicked and saved or opened in a new tab for download or reverse image search. In Firefox, if the image is not interactive, the "Headers" tab provides a direct URL to copy.

Third-party services that automate this process include instadownloader.co, igram.io, igdownloader.com, and toolzu.com/downloader/instagram/photo/.

## Extracting Metadata

**User ID.** Right-click the profile page and view page source, then search for `"profile_id"`. The number immediately following is the permanent user ID. Unlike usernames, user IDs cannot be changed. Example: @hak5darren has user ID 340416780.

If a target changes their username, the user ID can be used to recover the new username via the Instagram API. This requires first spoofing the user-agent to an Android/Instagram profile using the Firefox extension User-Agent Switcher and Manager, then visiting:

    https://i.instagram.com/api/v1/users/340416780/info/

The JSON response includes the current username, full name, privacy status, media count, follower and following counts, external URL, and a direct link to the profile image.

**Exact timestamps.** Instagram shows relative post times (e.g., "67 weeks ago") but not the time of day. To get the exact timestamp, open the post in the browser, open developer tools, go to the Network tab, reload the page, and search for the term `"taken"`. The number following it is a Unix timestamp. Converting it at epochconverter.com gives the precise date and time in GMT. Example: the value 1627648763 converts to Friday, July 30, 2021 at 12:39:23 GMT.

For comment timestamps, the same developer tools Inspector tab can be searched for the text of a specific comment. The result will include a date and time. Example: the comment "now I gotta go buy some beer" was found to have been posted November 24, 2018, at 14:27:02 GMT.

These details (user ID and exact timestamp) are presented as critical for legal investigations and distinguish thorough investigators.

## Hashtags

Hashtags can be browsed directly at `https://www.instagram.com/explore/tags/osint/`. The chapter advises against relying on hashtag searches because many users post relevant content without the hash sign, causing investigators to miss posts. Google keyword searches are preferred.

## Followers and Following

Viewing follower and following lists requires a logged-in account. The technique to document them fully:

1. Navigate to the target's Followers or Following list.
2. Scroll to load all accounts (Instagram limits display to around 1,000).
3. Press Ctrl+A (Windows/Linux) or Command+A (Mac) to select all content.
4. Right-click and choose "Copy selected links" (Firefox with recommended add-ons).
5. Paste into a spreadsheet (Excel or LibreOffice Calc).

Instagram also provides a URL-based API query for the first 50 following accounts using the target's user ID, but this is described as messy and partial. The manual method is preferred.

Within the Following window, there is also a hashtag tab showing hashtags associated with the target, which provides cultural intelligence and additional search keywords. Searching known aliases within the Following window may reveal alternate accounts, since people often follow their own alternate accounts.

## Likes and Comments

Clicking the like count on any post (not the heart icon itself, which would like the post from your account) opens a window listing every account that liked it. Scrolling loads all accounts. The same Ctrl+A then Ctrl+C method copies the list for pasting into a spreadsheet. Comments can be copied the same way.

## Complete Post Analysis Workflow

For a high-priority target, the recommended documentation steps are:

1. Use developer tools to inspect and save any media from the post.
2. Scroll through and expand all comments.
3. Open the likes window, scroll to load all, select all, copy, and paste into a spreadsheet tab named after the post ID.
4. Repeat for other posts of interest.
5. From the target profile, open Followers and repeat the select-copy-paste process into a "Followers" tab.
6. Repeat for Following.
7. Scroll through all posts on the profile, select all, copy selected links, and paste into a "Posts" tab.

The result is a multi-tab spreadsheet covering a specific post's interactions, all followers, all following, and all post URLs.

## Video Capture (Channels and Reels)

Instagram's IGTV channel feature has been largely replaced by Reels, but channels can still be accessed at `https://www.instagram.com/username/channel/`. To save a video:

1. Open the video page, launch browser developer tools (F12 or Inspect).
2. Go to the Network tab and play (or replay) the video.
3. Type "mp4" in the search field below the Network tab.
4. Sort resulting files by size and select the largest.
5. Copy the URL from the Headers tab.
6. Paste it into a new browser tab, delete the trailing byte-range segment (e.g., `&bytestart=4635232&byteend=4933185`), and press Enter.
7. Right-click the video and save it.

This manual method is recommended over browser extensions for legal defensibility: when testifying in criminal trials, being able to explain exactly how evidence was captured from the source is more credible than relying on tools that do not disclose their methods.

## Tagged Users

Posts in which the target is tagged can be viewed at `https://www.instagram.com/username/tagged/`.

## Instagram Stories

Stories are photos or videos up to 15 seconds long that disappear 24 hours after posting and appear at the top of the app feed. They require a logged-in account to view on Instagram. Third-party tools for viewing and downloading Stories:

- **InstaFollowers** (instafollowers.co/download-instagram-stories): the most useful option, also displays Stories Highlights of previously expired content.
- **StoriesDown** (storiesdown.com): similar functionality, useful as a backup.
- **Snapinsta** (snapinsta.app): supports images, videos, Reels, IGTV, and Stories without requiring developer tools knowledge, but shares target identity with a third party.

## Third-Party Profile Tools

- **Dumpor** (dumpor.com): allows browsing posts without logging in, useful when covert account use is prohibited by an organization. Supports username and tag searches and allows direct URL queries (`https://dumpor.com/v/username` or `https://dumpor.com/t/tag`).
- **Toolzu** (toolzu.com): uses the Instagram API to analyze a public profile and generate statistics not directly available from Instagram. Example for @ambermac: 2,000+ uploads, 35,600 followers, 1.29 posts per week, most likely to post Tuesday or Wednesday, common tags and caption terms, and interest category breakdowns. Supports direct URL input at `https://toolzu.com/profile-analyzer/instagram/?username=@username`.

**Suspension warning.** Third-party tools that require Instagram login can trigger account suspension. Always use a junk account, and expect to log back in and complete a Captcha to restore access.

## Twitter Cross-Reference

Many Instagram users share their posts to Twitter. Searching Twitter for references to an Instagram user can reveal their Twitter account and reactions from Twitter users. Query format:

    site:x.com "hak5darren" "instagram.com/p"

This finds tweets mentioning the target that also contain Instagram post links.

## Threads

Meta launched Threads (threads.net) in 2023 as a microblogging competitor to Twitter. Threads is an extension of Instagram, not a separate platform: it uses Instagram credentials, shares the same account ID, and every Threads user also has an Instagram account, though not every Instagram user has activated a Threads account.

To check whether an Instagram target has a Threads account:

    https://www.threads.net/@username

Threads search can be accessed without logging in (though results are limited) at `https://www.threads.net/search` or via direct query:

    https://www.threads.net/search?q=osint

Site-scoped Google searches also work:

    site:threads.net/@ "accountname"
    site:threads.net/ "keyword"

A target may have changed their Threads bio or profile photo independently of their Instagram, creating additional data points. Follower lists may overlap but can include unique accounts. Because many Threads users signed up through the Instagram integration but are not actively posting, the Instagram account is generally the richer intelligence source.

The Threads mobile app does not currently support contact exploitation (a technique where a clean device with only the target in its contacts prompts social apps to find "friends," revealing accounts belonging to the target). Threads is also in an early phase of federating with the Mastodon/fediverse ecosystem, though full cross-platform compatibility is uncertain.
