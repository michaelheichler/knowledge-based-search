## What an API is and why it matters for OSINT

An API (application programming interface) lets you query a company's data directly, without navigating a website. You formulate a URL or terminal command, supply an API key (a credential issued to your account), and receive raw data, usually in JSON format. Every service in this chapter requires such a key. The chapter's goal is to walk through each service manually first, then explain how a single custom shell script (api.sh) can absorb all keys and present a menu-driven interface, so the investigator never has to retype credentials.

## People Data Labs

**URL:** peopledatalabs.com

People Data Labs offers 1,000 free enrichment queries against large aggregated datasets. A free trial account, created under "Get API Key," produces a unique key visible in the dashboard. The API does not provide a web search form. Queries are constructed as URLs and can be entered in a browser or a script. The author recommends providing an email address associated with a personal domain when registering, to appear legitimate.

The base endpoint is:

```
https://api.peopledatalabs.com/v5/person/enrich?pretty=true&api_key=<KEY>&<PARAM>=<VALUE>
```

Supported input parameters include:

- `email` (example: `email=sean@peopledatalabs.com`)
- `phone` (example: `phone=+12225551212`)
- `profile` with a full social-network URL for X (Twitter), Facebook, or LinkedIn

A query by email for `sean@peopledatalabs.com` returned full name, birth year, LinkedIn URL, Facebook URL, X URL, work email, mobile phone, additional email addresses, and university. A query by phone number for a law enforcement contact returned name, gender, LinkedIn, Facebook, personal email, job title, industry, employer, home street address, postal code, geolocation, secondary employer, and school. A query against `facebook.com/zuck` returned Mark Zuckerberg's full name, birth year, LinkedIn, Facebook URL, mobile phone, and Harvard email address. The service also retrieved three successive locations associated with the author's own X profile going back to 2009, which no comparable free service could replicate.

The chapter notes the service may move to a paid model, as similar aggregators (Full Contact, Pipl) have done.

## Telephone (Caller ID) Lookups

### Twilio

**URL:** twilio.com

Twilio's Lookup API is the author's primary daily telephone number query tool. The advantage over the web portal is avoiding repeated logins and 2FA prompts. After creating a trial account, the home page shows an Account SID and Auth Token. The query command is:

```
curl -X GET 'https://lookups.twilio.com/v1/PhoneNumbers/+12025551212?Type=caller-name&Type=carrier' \
-u <ACCOUNT_SID>:<AUTH_TOKEN> | python3 -mjson.tool
```

The command uses `curl` to send a GET request, passes the Account SID and Auth Token with `-u`, and pipes output through `python3 -mjson.tool` for readable formatting. A query against a Google Voice number returned "MICHAEL BAZZELL" as caller name, carrier name "Google (Grand Central) - Level3," line type "voip," and country code "US."

### Telnyx

**URL:** refer.telnyx.com/refer/zrfmo (referral link providing a $10 trial credit)

Telnyx is the author's second-ranked telephone lookup service. New accounts face scrutiny and may be asked to describe intended usage. Once established, a trial balance can last several years with light usage. Queries require a terminal command rather than a plain URL:

```
curl -X GET \
--header "Content-Type: application/json" \
--header "Accept: application/json" \
--header "Authorization: Bearer <API_KEY>" \
"https://api.telnyx.com/v2/number_lookup/+12025551212?type=carrier&type=caller-name"
```

A Telnyx query of the same Google Voice number returned caller name "Michael Bazzell," carrier "Level 3/1," line type "fixed line," city "BELLEVILLE," state "Illinois," and porting data including LRN and OCN codes.

### CID Name

**URL:** cidname.com

CID Name offers roughly 100 free successful searches via a trial account requiring an email address and phone number (temporary addresses and Google Voice work). The API key is delivered by email and also visible in the portal. Queries use a browser URL:

```
https://dip.cidname.com/<TARGET_NUMBER>/<API_KEY>&output=raw&reply=none
```

The author recommends this service only as a fallback if Twilio and Telnyx are unavailable, or to cross-verify results. Empty (no-result) queries do not consume credits.

### Caller ID summary

Before these services existed, this type of data required a subpoena. The chapter gives an example where a caller ID result of "Jennifer S" matched how a subject labeled her portion of a shared family phone bill. Across all services, full names are commonly returned for cellular numbers. The chapter recommends using all available services together to gauge confidence in results, noting that even small deposits (a few dollars) can provide more queries than most investigations require.

### RapidAPI telephone options

**URL:** rapidapi.com

For investigators who cannot obtain Twilio or Telnyx accounts, RapidAPI hosts multiple caller ID APIs under a single free "Basic" account (no payment information required at signup). The investigator subscribes to individual API products via their pages and uses one shared `X-RapidAPI-Key`. Recommended subscriptions:

- `reverse-phone-api` (Trestle Solutions)
- `smart-cnam-api` (Trestle Solutions)
- `eyecon` (DataCrawler)
- `phone-number-caller-id-lookup` (DataCrawler)
- `viewcaller` (DataCrawler)
- `truecaller4` (DataCrawler)

Free tiers range from 3 to 100 lookups per month depending on the service. Each query follows the same curl pattern: `curl --request GET --url '<endpoint>' --header 'X-RapidAPI-Host: <host>' --header 'X-RapidAPI-Key: XXX' | python3 -mjson.tool`. A query of the author's Google Voice number through the Trestle reverse-phone-api returned full name "Michael John Bazzell," gender, carrier name, current and historical addresses, and state. The chapter notes the api.sh script supports these services and can be updated via:

```bash
cd ~/Documents/scripts
curl -O https://uvm:317@inteltechniques.com/osintvm/api.sh
chmod +x api.sh
```

When a listed service goes offline, the chapter advises searching RapidAPI for a replacement using queries such as "OSINT," "Caller ID," "Telephone," or "Email," then switching the playground language dropdown to Shell/cURL to copy the ready-made command.

## Breach Directory

**URL:** breachdirectory.org, accessed through the RapidAPI endpoint at `breachdirectory.p.rapidapi.com`

This service queries known data breach collections by email address, username, password, password hash (SHA1 or MD5), or domain. A free API key is obtained from the RapidAPI listing at `rapidapi.com/rohan-patra/api/breachdirectory`. All queries use `wget` with GET headers for `X-RapidAPI-Key` and `X-RapidAPI-Host`.

Query types and their endpoints:

- Email: `?func=auto&term=<email>`
- Username: `?func=auto&term=<username>`
- Password: `?func=password&term=<password>` (returns count of matching accounts)
- Domain: `?func=domain&term=<domain>` (was not functional at time of writing, expected to return)
- Hash: `?func=dehash&term=<hash>` (returns plaintext password if known)

A sample email result showed the target had accounts at Ledger.com, MyHeritage.com, Paxful.com, MyFitnessPal.com, Dropbox.com, Myspace.com, and appeared in the "Collection 1" breach. Passwords were partially masked (e.g., `pala*****`) but full SHA1 hashes were included. The chapter explains a practical follow-on step: copy the SHA1 hash into the VM's local hash-cracking tool to recover the complete password, then submit that password to the password-count endpoint to learn how many other accounts share the same compromised credential. The `sources` field in results shows which breach datasets contain the target's account.

## Historical WHOIS Lookups

### WhoisXMLAPI

**URL:** whois.whoisxmlapi.com

A free account provides 500 credits for historical domain registration queries. The API key is found under "My Products" in the account portal (format example: `at_0vPfsSUdf1ZpiCxc5`). Queries can be run as a curl command piped through `python3 -mjson.tool` or pasted directly into a browser:

```
https://whois-history.whoisxmlapi.com/api/v1?apiKey=at_0vPfsSUdf1ZpiCxc5&domainName=inteltechniques.com&mode=purchase
```

The service retrieved a 2013 registration record for inteltechniques.com from before the author had enabled whois masking. That record included the registrant's name, street address, city, state, postal code, email, and telephone. The author notes the historical API is the only feature of WhoisXMLAPI worth using beyond what free web-based whois tools already provide.

### Whoxy

**URL:** whoxy.com

Whoxy offers a free demo at `whoxy.com/whois-history/demo.php` but rate-limits suspected abuse. API access costs $2.00 for 400 queries. The URL pattern is:

```
https://api.whoxy.com/?key=XXXX&history=inteltechniques.com | python3 -mjson.tool
```

Results are structurally similar to WhoisXMLAPI, returning registrant contact fields including full name, mailing address, city, state, zip code, country, email, and phone number.

## The API Script (api.sh)

The chapter closes by describing a consolidated shell script that wraps all of the above services. The script is part of the OSINT VM setup from the preceding chapter and should already be present at `~/Documents/scripts/api.sh`. It is launched from the Activities menu or Dock as "API Tool."

The script uses `zenity` to present GUI dialog boxes that prompt the investigator for a target value (email address, phone number, social profile URL, etc.), then runs the appropriate `curl` or `wget` command with the stored API key, saves results to a text file in `~/Documents/API/`, and opens that folder automatically.

To use it, the investigator must open api.sh in a text editor and replace every placeholder "XXX" (API key) and "YYY" (account identifier, used for Twilio's Account SID) with real credentials from each service. Once populated, the script handles all formatting and file management. The structure for People Data Labs entries looks like:

```bash
$opt1 )
data=$(zenity --entry --title "PDL Email" --text "Email Address")
mkdir ~/Documents/API/
cd ~/Documents/API/
curl 'https://api.peopledatalabs.com/v5/person/enrich?pretty=true&api_key=XXXX&email='$data'' > $data-PDL.txt
open ~/Documents/API/
exit;;
```

The chapter closes by noting that the API ecosystem is large and constantly changing. When a listed service disappears, investigators should search RapidAPI for replacements and adapt the shell command format accordingly.
