## Overview

This chapter explains how to investigate virtual currency addresses using publicly available tools and APIs. Bitcoin is the primary focus, though several services also cover Ethereum, Ripple, Litecoin, Dogecoin, and others. The chapter treats a Bitcoin address as an identifier analogous to an email address: it carries a full public transaction history but is rarely linked to a real name.

## Core Lookup Services

**Blockchain (blockchain.info)** is the starting point for any Bitcoin address. It returns the number of transactions, total Bitcoin received, final balance, and a complete incoming and outgoing transaction history. The demo address 12t9YDPgwueZ9NyMgw519p7AA8isjr6SMw received 19.69355613 BTC, worth $1,333,710 USD at time of writing, and was used to collect ransomware payments.

**Bitcoin Who's Who (bitcoinwhoswho.com)** adds context: it flags known ransomware or scam associations, links to news coverage mentioning the address, and shows transaction IP addresses (which are typically behind VPNs). The recommended workflow is to use Blockchain for raw transaction detail and Bitcoin Who's Who for reputational context.

**BlockChair (blockchair.com)** works similarly to Blockchain but covers a broader set of currencies: Bitcoin, Ethereum, Ripple, Bitcoin Cash, Litecoin, Bitcoin SV, Dash, Dogecoin, and Groestlcoin. Each currency has a direct URL pattern, such as `https://blockchair.com/bitcoin/address/xxx`, making it suitable for automated queries.

**Chain Abuse (chainabuse.com)** reports whether others have flagged an address for malicious activity. The example address `1KUKcwCv64cXQZa4csaA1cF3PPTio6Yt2t` has entries logged on September 21, 2019, linking it to sextortion and ransomware emails sent from `peter6389dd@excite.co.uk` and `addntfogjnfi@activeware.com`.

**CloverPool (cloverpool.com)**, formerly BTC.com, provides summaries and full transaction lists for BTC, ETH, BCH, LTC, and ETC addresses via `https://explorer.cloverpool.com/btc/address/xxx`.

**Wallet Explorer (walletexplorer.com)** moves beyond individual addresses to virtual wallets. A single person often controls many addresses grouped in one wallet. Querying one address may reveal a wallet ID (for example, `00037fd441`), which then exposes all other addresses in that wallet and their transaction histories. This step is described as vital for tracking all activity tied to a suspect.

**Breadcrumbs (breadcrumbs.app)** is aimed specifically at investigations rather than general consumers. A free account provides twenty searches per month and accepts masked email addresses such as SimpleLogin for registration. It generates a customizable transaction graph suitable for case reports and offers an address monitoring feature that tracks activity over time and exports results as a CSV file.

**Scam Search (scamsearch.io)** searches virtual currency addresses alongside email addresses, usernames, and phone numbers. Querying `1FVuyuSN41aa3JN9sn8qkuD2PmaMEMHHnc` returns associated email addresses, IP addresses, and locations tied to an extortion suspect.

## Currency Units

Bitcoin amounts returned by APIs are expressed in Satoshi. One Satoshi equals 0.00000001 BTC, meaning one Bitcoin contains 100 million Satoshis. The **Bitbo calculator** at `https://tools.bitbo.io/satoshi-usd/` converts between Satoshi, BTC, and USD.

## API Reference

The following API endpoints are used to build a custom search tool. Each `xxx` placeholder is replaced with the target address or value.

| Purpose | URL |
|---|---|
| Validate address (returns Unix timestamp of first appearance, or error) | `https://blockexplorer.com/api/addr/xxx` |
| Current 24-hour BTC price | `https://blockchain.info/q/24hrprice` |
| Total received by address (in Satoshi) | `https://blockchain.info/q/getreceivedbyaddress/xxx` |
| Total sent by address (in Satoshi) | `https://blockchain.info/q/getsentbyaddress/xxx` |
| Current balance (in Satoshi) | `https://blockchain.info/q/addressbalance/xxx` |
| Convert BTC amount to USD | `https://api.coinconvert.net/convert/btc/usd?amount=xxx` |
| Convert USD amount to BTC | `https://blockchain.info/tobtc?currency=USD&value=xxx` |
| Address summary (received, sent, balance, tx count, first/last tx) | `https://chain.api.btc.com/v3/address/xxx` |
| Date address first seen (Unix time) | `https://blockchain.info/q/addressfirstseen/xxx` |

## Sample Investigation Walkthrough

The chapter works through address `1EzwoHtiXB4iFwedPr49iywjZn2nnekhoj`, used in an extortion email.

- Validation: valid format.
- 1 BTC price at time of example: $19,978.23.
- Satoshi received: 716,409,285,544 (approx. $136,925,336.62 USD).
- Satoshi sent: 716,371,585,974 (approx. $136,914,950.52 USD).
- Satoshi balance: 37,699,570 (approx. $7,205.23 USD).
- Total transactions: 3,534.
- Address first seen: Unix timestamp 1331482301, converting to March 11, 2012, 10:11:41 UTC.
- Chain Abuse: one malicious activity report, yielding a new email address for further research.
- Bitcoin Who's Who: links to Reddit threads mentioning the address.
- Wallet Explorer: wallet ID `00037fd441` with multiple additional Bitcoin addresses in the suspect's wallet.

The recommended next step after this summary is to feed each newly discovered address back through the same process and cross-reference any email addresses found using the email search tool.
