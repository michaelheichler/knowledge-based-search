## Overview

This chapter covers the installation and configuration of virtual machine (VM) software on Windows host computers. The two applications discussed are VirtualBox (free, open-source, from virtualbox.org) and VMWare Workstation Pro (free for personal use). The chapter walks through creating a Windows 11 VM inside each, then addresses USB connectivity, VM preservation (exports, clones, snapshots), disk shrinking, and common errors.

## VirtualBox Installation

VirtualBox is the primary recommendation. Two files are required: the main installer and the Extension Pack, both available from virtualbox.org/wiki/Downloads. During installation, the "VirtualBox Python Support" option under "Custom Setup" should be disabled. After VirtualBox is installed, the Extension Pack is activated by double-clicking its file from within VirtualBox. The Extension Pack has its own license terms that personal and organizational users must verify before use.

The only hardware requirement is a processor that supports virtualization. Most mid-range or high-end computers made within the past ten years qualify, though some require enabling virtualization in BIOS. Netbooks and low-end machines typically fail. The author notes that Windows VMs running on top of Windows hosts produced more errors than any other combination tested, and recommends macOS or Linux hosts when possible.

## Creating a Windows 11 VM in VirtualBox

The setup uses a Windows 11 ISO downloaded from microsoft.com/software-download/windows11. Microsoft sometimes blocks VPN connections during the download. Public Wi-Fi is a fallback.

Key configuration choices inside VirtualBox:
- Memory: half of the host system's RAM.
- Processors: half of the available CPUs.
- Disk: up to 150 GB maximum size.
- "Skip Unattended Installation" must be selected.
- "Enable EFI" must be deselected.
- Bidirectional Shared Clipboard and Drag n' Drop should be enabled under the Advanced tab.
- The host's Downloads folder should be added as a shared folder with Auto-mount enabled.

Because Windows 11 checks hardware compatibility before installing, the setup requires registry edits to bypass those checks. After pressing Shift+F10 at the "Install Now" screen to open Command Prompt, the user opens Registry Editor, navigates to `Computer\HKEY_LOCAL_MACHINE\SYSTEM\Setup`, creates a key named `LabConfig`, and adds four DWORD (32-bit) values each set to `1`: `BypassSecureBootCheck`, `BypassTPMCheck`, `BypassCPUCheck`, and `BypassRAMCheck`.

During Windows setup, a Microsoft online account is avoided by choosing the "work or school" sign-in path, then selecting "Sign-in Options" and the "Domain" connection option. This allows a local username and password to be set without a Microsoft account.

After Windows installs, VirtualBox Guest Additions must be installed via the "Devices" menu ("Insert Guest Additions CD Image"). The additions enable proper display scaling, clipboard sharing, and folder access. After installation and reboot, the Guest Additions ISO should be removed from the VM's storage settings.

The resulting Windows 11 VM operates as a legal trial copy. Microsoft permits repeated reinstallation when the trial expires.

## VirtualBox USB Connection

USB device access requires a filter to be created in the VM's USB settings before the VM is started. Once the VM is running and a USB drive is connected to the host, the drive is made available inside the VM through the "Devices" menu. VirtualBox defaults to a USB 3.0 driver. Older drives that go unrecognized may need the setting changed to USB 2.0 (or vice versa) in the VM's USB settings tab.

## VirtualBox Exports

Exporting a VM creates a complete, portable snapshot of the environment. This matters for investigations that may reach court, where the exact operating environment used during examination must be reproducible.

Two methods exist:
1. Copy the entire VM folder from the file system (accessible by right-clicking the VM and selecting "Show in File Manager").
2. Export to a single appliance file via "File" > "Export Appliance". This is the author's preferred approach. The exported file can be imported into any instance of VirtualBox and is stored in the Documents folder by default.

The author's practice is to shut down and export the VM at the end of each investigation and add the exported file to digital evidence storage on an external drive.

## VirtualBox Clones

Cloning duplicates a VM into an independent copy with its own data folder. The recommended workflow is to maintain one clean "Original VM" that receives only weekly updates, then clone it for each new investigation. The clone is named for the case, worked in freely, and either exported for evidence or deleted when finished. The original remains untouched throughout.

Steps: right-click the VM, select "Clone", provide a name, click "Next", then "Finish".

## VirtualBox Snapshots

Snapshots freeze a VM's state so it can be restored later. To take one: shut down the VM, open the Snapshots menu from the three-lines icon, click "Take", and name the snapshot (for example, the current date). Restoring a snapshot wipes all activity since it was taken. Deleting a snapshot removes the ability to return to that state.

The author now uses snapshots rarely, preferring clones and exports. Snapshots are considered more prone to user error and generate more wasted disk space, especially if many are created within one VM.

## Shrinking VM Disk Size

VMs accumulate unreferenced space over time because deletions inside the VM do not automatically reclaim space in the host's virtual disk file. To compact a Windows VM in VirtualBox:

Inside the Windows VM:
1. Delete unneeded files and empty the trash.
2. Run "Drive Optimization" (search "Defrag") and optimize the C drive.
3. Open Command Prompt and run:
   - `curl https://download.sysinternals.com/files/SDelete.zip -o SDelete.zip`
   - `tar -xf SDelete.zip`
   - `sdelete64.exe c: -z` (accepts terms, fills free space with zeros)
4. Shut down the VM.

On the Windows host, open Command Prompt, navigate to the VM folder, add VirtualBox to the path with:

`PATH "C:\Program Files\Oracle\VirtualBox"`

Then run:

`VBoxManage modifymedium disk Windows11.vdi --compact`

This compacts the `.vdi` file. The author runs this procedure after every major VM update.

## VirtualBox Common Errors

**VT-x is Disabled.** The most common startup error. Virtualization is not enabled in the BIOS. To fix, enter BIOS immediately after power-on (typically Delete, F2, or F10). For Intel processors, find "Virtualization (VT-x)" under the Advanced tab and enable it. For AMD processors, navigate to MIT > Advanced Frequency Settings > Advanced Core Settings and set "SVM Mode" to Enable.

**VT-x is not available.** Usually seen on Windows 10. Open Control Panel > Programs and Features > "Turn Windows features on or off" and uncheck all Hyper-V features, then reboot. If Hyper-V is already disabled, enable it first, reboot, then disable it and reboot again. Hyper-V competes with VirtualBox for exclusive processor virtualization access. If problems persist, consult the VirtualBox manual troubleshooting section.

**Auto-resize Guest Display greyed out.** Run the following commands in the Linux VM's terminal to repair guest display drivers:

```
sudo apt update
sudo apt install -y build-essential dkms gcc make perl
sudo rcvboxadd setup && reboot
```

## VMWare Workstation Pro

VMWare Workstation Pro is offered as a secondary option, free for personal use and requiring a commercial license for organizations. It can be downloaded without creating an account via techspot.com/downloads/189-vmware-workstation-for-windows.html. Users with the deprecated VMWare Workstation Player should first check whether it prompts an upgrade. If not, they should uninstall it before installing Workstation Pro. The "Join the VMWare Customer Experience" option should be disabled during installation.

Creating a Windows 11 VM in VMWare Workstation Pro is simpler than in VirtualBox. The process uses the "Typical" configuration, sets an encryption password (which substitutes for the registry bypass needed in VirtualBox), allocates half the system RAM and half the CPUs, and sets a 64 GB drive stored as a single file. VMWare handles Windows 11 compatibility checks without manual registry edits.

After Windows installs, VMWare Tools must be installed from the VM menu. This enables display scaling and integration features. The "Customize Hardware" button within the new VM wizard is where memory and CPU settings are adjusted.

The notable limitation of VMWare Workstation Pro is that file sharing between host and VM is unreliable and often fails. The author recommends having both VirtualBox and VMWare installed and choosing between them per case.

VMWare-specific issues:
- An EFI warning may prevent boot on Windows-on-Windows setups. Click inside the VM immediately and press any key.
- To release a captured cursor, press Alt+Ctrl simultaneously.
- Windows VM on Windows host is described as "frustrating". Errors should be searched online.

## VPN Interaction

Using the Proton VPN application on the Windows host in "Kill Switch" mode blocks all internet access to VMs running under both VirtualBox and VMWare Workstation Pro. The workaround is to disable "Kill Switch" mode in the Proton VPN host application while a VM is in use.
