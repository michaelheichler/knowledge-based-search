This chapter (labeled Chapter 33 in the converted text) covers how to investigate IP addresses encountered during OSINT work, how to obtain a target's IP address through covert means, and the legal and operational cautions that apply to each technique.

## Background

An IP address is the numerical address that actually hosts internet content. Domain names forward to these addresses. A single IP address can host many domains (shared hosting), while a single domain maps to one IP. IP addresses arise in investigations through subpoenas to internet providers, domain research, or active elicitation of a target.

## ViewDNS Tools (viewdns.info)

ViewDNS offers six IP-focused utilities, each queryable via direct URL by substituting any IP address.

**Reverse IP** (`/reverseip`): Lists all domains hosted on an IP. A large number of unrelated domains indicates shared hosting. A small, tight cluster may suggest associated properties.

**IP Location** (`/iplocation`): Cross-references an IP with publicly available location data. Returns city, ZIP, region, country code, and country name. A search of 54.208.51.71 returned Ashburn, Virginia, US.

**Port Scan** (`/portscan`): Checks common open ports. Port 21 is FTP, 53 is DNS, 80 is HTTP, 443 is HTTPS. Open ports indicate running services.

**IP Whois** (`/whois`): Returns registration information about the IP block. A search of 54.208.51.71 returned Amazon as the registrant.

**IP Traceroute** (`/traceroute`): Shows the path from ViewDNS servers to the target IP, including intermediate IP addresses and millisecond hop times. Can reveal associated networks and routers.

**Reverse DNS** (`/reversedns`): Returns the host name associated with an IP.

URL format examples:
- `https://viewdns.info/reverseip/?host=70.39.110.82&t=1`
- `https://viewdns.info/iplocation/?ip=70.39.110.82`
- `https://viewdns.info/portscan/?host=70.39.110.82`
- `https://viewdns.info/whois/?domain=70.39.110.82`
- `https://viewdns.info/traceroute/?domain=70.39.110.82`
- `https://viewdns.info/reversedns/?ip=70.39.110.82`

## Bing IP Search

Bing supports the operator `ip:` before an IP address (e.g., `ip:54.208.51.71`) to list websites hosted on that server. This only works on Bing. It is most useful when a target self-hosts, because large shared hosts like GoDaddy will produce unrelated results. Direct URL: `https://www.bing.com/search?q=ip%3A54.208.51.71`

## IPLocation (iplocation.net)

Runs the same IP query against five distinct services simultaneously. Results include business name, general location, and ISP. GPS coordinates are available but typically resolve to the ISP's location, not the individual user. Results naming Starbucks, Barnes and Noble, or other public Wi-Fi providers indicate the target was on a public network at that IP. Results can also confirm VPN use. Direct URL: `https://www.iplocation.net/ip-lookup?query=70.39.110.83&submit=IP+Lookup`

## That's Them (thatsthem.com/reverse-ip-lookup)

Aggregates marketing data from multiple sources, which can include IP address records collected during online purchases or website registrations. A search may return a person's name, home address, company, email, and age range. Works best on static business IP addresses. Home IP addresses change frequently and produce fewer hits. Direct URL: `https://thatsthem.com/ip/70.39.110.82`

## I Know What You Download (iknowwhatyoudownload.com)

Monitors torrent activity and associates downloaded file names with IP addresses. Returns movie or file titles, download dates, and times. Clicking a title shows every IP address that downloaded the same file. Works best on static IPs. The chapter gives a real example of an employee downloading large amounts of pornography on an employer's network, detectable because no VPN was in use. Searching a known VPN address (e.g., Private Internet Access address 173.244.56.138) demonstrates the value of VPNs in masking torrent activity. Direct URL: `https://iknowwhatyoudownload.com/en/peer/?ip=70.39.110.82`

## Exonerator (metrics.torproject.org/exonerator.html)

Verifies whether an IP address was part of the Tor network on a given date. Requires the IP and a date. If no date is known, the current date can be used, since most IPs are consistently always or never a part of Tor. If no other tools return results for an IP, Tor usage may explain the absence of data.

## Wigle (wigle.net)

A crowd-sourced database of wireless access points. Users scan their surroundings, collect router details, and submit to the database. A free account is required for search features.

Data returned for each access point includes router name (SSID), MAC address, first and last seen dates, encryption type, channel, and GPS coordinates.

Investigative uses include browsing a map of a target address to see nearby access points and their SSIDs. A search by SSID string can find routers named after a target or their username. Many users name their wireless router after their online screen name. A search for a username on Wigle may yield the router's MAC address, encryption type, and GPS coordinates. Those coordinates fed into Google Maps can identify a home address with satellite and street view. The chapter notes that the author searched for "Bazzell" as an SSID and found seven access points probably belonging to relatives.

Search URL examples:
- `https://wigle.net/search?ssid=bazzell`
- `https://wigle.net/search#fullSearch?postalCode=62002`

## Shodan (shodan.io)

A search engine that indexes device banners (metadata returned by servers, routers, cameras, and other network-connected hardware) rather than web pages. Common discoverable device types include servers, routers, storage devices, surveillance cameras, webcams, and VOIP systems. A free account is required for full search capability.

Search filters:
- `City:"San Diego"` (city name)
- `Country:US` (two-letter code)
- `Geo:50.23,20.06` (latitude and longitude)
- `Os:Linux` (operating system)
- `Net:18.7.7.0/24` (IP range)
- Keyword such as `Webcam` or `Netcam`

Filters can be combined. GPS-based search is more precise than city-based search because city names repeat across states. A search of `geo:39.55,-111.45 netcam` in Mount Pleasant, Utah returned a single Netcam device on ISP Central Utah Telephone at IP 63.78.117.229.

Connecting to a device that does not prompt for credentials may not be illegal, but connecting by entering credentials (even defaults like admin/admin) may constitute computer intrusion under local law.

**Shodan Beta** (`beta.shodan.io`): Full details for a specified IP in three URL forms.
- `https://beta.shodan.io/host/147.135.65.22` (standard view)
- `https://beta.shodan.io/host/147.135.65.22/raw` (text-only, useful for reports)
- `https://beta.shodan.io/host/147.135.65.22/history` (timestamped scan history in format `2020-04-26T07:49:17`)

**Shodan Maps** (`maps.shodan.io`): Geographic search interface. Premium service.

**Shodan Images** (`images.shodan.io`): Displays webcam captures from open devices. Premium service.

## Zoom Eye (zoomeye.hk)

A Shodan competitor with independent scanning data and often unique results. Direct URL: `https://www.zoomeye.hk/searchResult?q=70.39.110.82`

## Threat Crowd (ci-www.threatcrowd.org)

Associates IP addresses with malware and cyber threats. A result displays malware type, associated domain names, discovery dates, and researcher comments. Useful when investigating suspicious IPs. Direct URL: `https://www.ci-www.threatcrowd.org/ip.php?ip=70.39.110.82`

## Censys (censys.io)

A research-focused search engine that runs daily internet-wide scans and maintains a database of host and website configurations. An example search of 173.189.238.211 identified a Schneider Electric BMX P34 2020 device on a Windstream connection near Kansas City, Kansas. Direct URL: `https://censys.io/ipv4/70.39.110.82`

## IPv6 Addresses

IPv6 addresses (e.g., 2001:0db8:85a3:0000:0000:8a2e:0370:7334) are becoming more common as IPv4 space is exhausted. Many standard tools are adapting. Format conversion between full and compressed forms is available at `https://iplocation.io/ipv6-expand/`. The two recommended IPv6 lookup tools are:
- `https://search.dnslytics.com/ip/2001:db8::8a2e:370:7334`
- `https://myip.ms/view/comp_ip6/176883/2001:db8:85a3::8a2e:370:7334`

## Email Header Analysis

Web-based email services (Gmail, Yahoo) do not embed the sender's IP address in headers. Business users sending via desktop clients like Outlook may expose an IP. Two tools for automated header analysis:

**IP2Location** (`ip2location.com/free/email-tracer`): Paste the full header into the provided text box. Returns sender IP, location, ISP, an interactive map of the originating location, and links to further IP research.

**MX Toolbox** (`mxtoolbox.com/EmailHeaders.aspx`): Alternative header parser with similar output.

## Obtaining a Target's IP Address

The following techniques actively elicit a target's IP rather than passively looking up a known one. All require inducing the target to click a link or open a file. VPN and Tor use by the target will produce inaccurate location results.

**IP Logger** (`iplogger.org`): Generate a URL that redirects to any destination (e.g., cnn.com). Use the "URL and Image Shortener" option. When the target clicks the link, their IP address, operating system, and browser details are logged with a timestamp. The generated link can be shortened with Bitly to appear less suspicious. Example link: `http://www.iplogger.org/3ySz.jpg`. The chapter describes using this to identify a suspected criminal on a web forum: a bait link led to the subject's IP address in Newark, New Jersey. Limitation: Gmail blocks domains associated with IP Logger, and tech-savvy targets may recognize the service.

**Canary Tokens** (`canarytokens.org`): Creates tracking payloads including PDF and DOCX files. When the file is opened, it reports the opener's IP and location. More user-friendly than IP Logger. The chapter describes maintaining trap documents at `https://inteltechniques.com/canary/canary.pdf` and `https://inteltechniques.com/canary/canary.docx` to detect people searching for the author's home address. One recent opener was identified as living in Matawan, New Jersey, using MCI as an ISP, and had downloaded an Xbox 360 game via torrent. The service is noted as becoming less useful over time.

**LinkBait** (`github.com/AmIJesse/LinkBait`): A self-hosted PHP tracker that avoids all public-service detection and blocking. Copy the PHP file into a web-accessible directory on an Apache server (shared hosting works). Rename it (e.g., `index.php`). When a target visits the URL, a text file is generated containing the IP address and extensive fingerprint data: browser and OS, screen resolution and width, GPU, microphone detection, number and names of installed fonts, network MTU (MTU not 1500 indicates probable VPN use), active logins (e.g., Google services), Discord running status, and system timezone versus VPN server timezone. The chapter shows a sample capture that revealed the visitor was on a Mac using Firefox, connected to Private Internet Access VPN from a west coast server, with system time set to Mountain timezone, and logged into a Google product.

A test page at `https://inteltechniques.com/logger/` displays what would be collected from any visitor's browser without storing the data. Any website can in principle replicate these tactics.

## IntelTechniques IP Addresses Tool

An automation page at `https://inteltechniques.com/tools/IP.html` consolidates the common IP searches. Entering an IP and clicking "Populate All" inserts the address into all search forms. A single button opens multiple browser tabs for parallel querying. The online version is updated regularly.
